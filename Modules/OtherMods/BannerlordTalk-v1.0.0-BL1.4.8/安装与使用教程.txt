BannerlordTalk v1.0 安装与使用教程

一、先选对正式包

只能按游戏版本二选一，两个包不能混装，也不能同时启用：

1. BannerlordTalk-v1.0.0-BL1.4.8.zip
   - 只用于 Bannerlord 1.4.8。
   - 需要 MCM 5.12.2。
   - 可选兼容 Living Commanders 1.6.5。

2. BannerlordTalk-v1.0.0-BL1.3.15.zip
   - 只用于精确版本 Bannerlord 1.3.15.110062，不是所有 1.3.x 的通用包。
   - 需要 MCM 5.11.3。
   - 可选兼容 Living Commanders 1.6.4；这个版本没有 1.6.5 才提供的战后档案来源。

两个包的 DLL 和 SubModule.xml 不同。不要改名混用，不要把 1.4.8 的 MCM 或 Living Commanders DLL 复制到 1.3.15 环境。

二、安装模组

1. 退出游戏和启动器。
2. 如果以前装过 BannerlordTalk，先把旧的 Modules\BannerlordTalk 整个文件夹移到游戏目录外备份，不要把新旧文件混在同一目录。
3. 解压与你游戏版本完全对应的 ZIP。
4. 把压缩包中的 BannerlordTalk 文件夹复制到：
   Mount & Blade II Bannerlord\Modules\BannerlordTalk
5. 检查不要出现双层目录。正确路径应能直接看到：
   Modules\BannerlordTalk\SubModule.xml
6. 确认对应版本的 MCM 已安装并启用。在启动器中勾选 BannerlordTalk，让 Native、SandBoxCore、Sandbox、StoryMode 和 MCM 排在它前面；如果安装了对应版本的 Living Commanders，也让它排在 BannerlordTalk 前面。
7. 启动游戏并进入战役。第一次使用先打开 MCM 完成主模型配置。

三、配置主聊天模型

在 MCM 的“骑砍闲聊 | BannerlordTalk”中填写：

- API 地址：OpenAI-compatible 的 /chat/completions 地址。公网地址必须使用 HTTPS；本机回环服务可以使用 HTTP。
- API 密钥：由你自己的服务商提供。
- 模型名称：填写该服务商实际支持的模型 ID。
- 温度、最大输出 Token、超时：不确定时先保留默认值。

API 密钥会明文保存在本机 MCM 配置中，请自行保护。正式包不会附带、导入、覆盖或清空你的 MCM、API、提示词、Fish TTS 配置，也不会修改存档以外的其他模组设置。

四、导入通用提示词

1. 在游戏外打开“通用主聊天提示词.txt”。
2. 全选并复制正文。
3. 游戏中按管理面板快捷键，默认 Ctrl+J。
4. 打开“提示词”，选择“主聊天总体提示词”。
5. 点击“粘贴纯文本”，检查预览后确认导入并保存。

这是通用预设，不包含任何指定角色设定。角色的性格、目标和说话方式应在“人格卡”页面单独维护。程序仍会在玩家提示词之外强制加入单一发言人、实时事实、长度和输出协议等安全规则。

五、导入常识库

正式包附有三份可选的多行常识库：

- 卡拉迪亚
- 战锤旧世界
- 权游世界

一个战役只有一份公共常识库。通常只选择与当前战役世界对应的一份，三选一，不要把三个世界直接混合。

导入步骤：

1. 如果战役已有常识，先在“资料库 → 公共常识”点击“复制当前整库”，粘贴到游戏外文件备份。
2. 用支持 UTF-8 的记事本、Word 或其他文本编辑器打开所选常识库 TXT。
3. 必须在游戏外编辑。确认无误后全选整份文件并复制，不能只复制一小段预览。
4. 游戏中按 Ctrl+J，进入“资料库 → 公共常识”。
5. 点击“读取整库剪贴板”，核对识别条数、物理行数、五段式规则头数量和错误。
6. 确认后执行整体替换。它是原子替换，不是追加；解析失败或取消不会改动旧库。
7. 返回游戏后正常保存一次战役存档。

每个物理行是一条常识规则，格式为：

[关键词|权重|Any/All|可提取|后续可匹配]正文

如果预览只识别到 1 条，或提示一个物理行出现多个五段式规则头，说明复制时换行损坏。取消导入，回到原 TXT 重新复制。发现 U+FFFD（Unicode 替换字符）时也不要覆盖旧库。

六、可选 Fish TTS

1. 在 MCM 的“语音/Fish TTS”中开启语音播报。
2. 填写 Fish Audio API 地址、自己的 API 密钥和合成模型。
3. 为角色音色槽选择存档中的角色稳定 ID，并填写该声音的 reference_id。显示名只帮助识别，不参与匹配。
4. 正文、动作、可见心声可以分别决定是否播报；后台私密思绪永远不会播报。

Fish TTS 默认关闭。正式包不会自带或覆盖 API 密钥、reference_id、音色槽和其他本机配置。

七、常用操作与排错

- 默认 Ctrl+J：打开闲聊资料管理。
- 默认 Ctrl+H：隐藏或显示闲聊窗口，不会关闭后台自动生成、记忆或 TTS。
- 进入城镇、城堡或村庄菜单时，窗口默认完整隐藏以免挡住原生菜单；期间仍可按 Ctrl+H 临时显示。
- 模型一直不说话：先检查 MCM 是否启用、API 地址/密钥/模型是否正确、当前是否处于战斗或其他安全阻断场景，并等待失败退避结束。
- 常识没有命中：确认导入的是完整整库、已保存战役，并检查 MCM 中“启用常识检索”和匹配来源。
- TTS 没声音但文字正常：检查 Fish 开关、角色稳定 ID、reference_id、密钥和网络；TTS 失败不会阻止文字聊天。

八、升级与卸载提醒

升级前备份存档、旧模块目录、提示词和当前常识库。新版本安装时使用完整文件夹替换，不要把不同版本 DLL 混合。卸载前也建议先备份存档；模组离线构建通过不等于你的整套模组环境已经实机兼容，首次安装后应先用备用存档测试。
