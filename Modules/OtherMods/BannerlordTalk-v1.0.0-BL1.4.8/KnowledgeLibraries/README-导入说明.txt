BannerlordTalk v1.0.0 常识库导入说明

本目录的三份 TXT 都是完整的多行常识库，不是会自动加载的 MOD 文件。
当前战役只有一份公共常识库；通常从三份中选择与当前世界对应的一份整体导入，不要在不理解冲突的情况下把三个世界混在一起。

导入步骤：
1. 先在游戏的公共常识页点击“复制当前整库”，把旧库粘贴到外部文件备份。
2. 用 UTF-8 记事本、Word 或其他文本编辑器打开所选 TXT。
3. 复制文件内全部正文，不要只复制文件名或预览窗口的一小段。
4. 游戏中按管理快捷键（默认 Ctrl+J），进入“资料库 → 公共常识”。
5. 点击“读取整库剪贴板”，核对预览统计，再确认整体替换。这是原子替换，不是追加。
6. 返回游戏后正常保存一次战役存档；否则本次导入只存在于当前运行内存。

正确统计：
- 卡拉迪亚完整常识库：336 条 / 336 个物理行 / 336 个规则头
- 战锤旧世界完整常识库：280 条 / 280 个物理行 / 280 个规则头
- 权游（维斯特洛与厄索斯）完整常识库：382 条 / 382 个物理行 / 382 个规则头（由原始下载版 1:1 转换，未合并玩家修改）

如果预览只显示 1 条，或提示同一物理行有多个五段式规则头，说明换行已经损坏；取消导入，回到原 TXT 重新复制。发现 U+FFFD（Unicode 替换字符）时也必须取消，不要覆盖原库。

常识库只提供世界背景；实时存档中的地点、人物关系、势力归属、存亡和当前事件永远优先。模组不会根据原版、RoT 或其他世界自动选库。三份文件均应在游戏外编辑，再整体粘贴替换。
