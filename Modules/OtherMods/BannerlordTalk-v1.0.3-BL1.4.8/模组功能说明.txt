BannerlordTalk v1.0 功能说明

BannerlordTalk 是《骑马与砍杀2：霸主》的独立大地图人物闲聊模组。它让玩家和当前主队的英雄同伴按照存档中的真实处境、各自人格、记忆和相关世界常识自动交谈。核心功能不依赖 AnimusForge；Living Commanders 只作为可选的已验证战后事实来源。

主要功能

1. 自动闲聊
   - 系统按合格角色数量自动选择独白、两人对话或多人对话。
   - 每次请求只让当前一名角色发言，避免模型替其他人代写。
   - 玩家默认也可由 AI 代为发言，可在 MCM 关闭。
   - 发言只用于展示和记忆，不会真的执行交易、任务、命令、关系或存档操作。

2. 自然而非固定三段式的演出
   - 正文是主体。
   - 动作和可见心声都是可选内容，模型可以完全省略。
   - 最近公开历史只注入正文，不把上一轮动作和心声当作固定格式范例。
   - 窗口用不同颜色区分内容，不显示“动作”“心声”字段标签。

3. 人格卡
   - 玩家和主队英雄同伴各有独立人格卡。
   - 可手工编辑，也可让主聊天模型生成一份草稿。
   - 智能生成只产生人格、说话风格、长期目标、价值和禁忌；必须由玩家采用并保存，不会自动覆盖。

4. 个人记忆与私密思绪
   - 公开台词和已验证事件可形成分层个人记忆。
   - 私密思绪按每名角色累计有效发言数异步生成，默认不是每句话都生成。
   - 私密思绪只进入本人记忆，不在聊天窗显示，也不进入 TTS。
   - 可见心声属于主回复的偶尔演出，不等于私密思绪，也不会照搬整段思绪。

5. 公共常识库
   - 每个战役只保存一份公共多行常识库。
   - 使用“[关键词|权重|Any/All|可提取|后续可匹配]正文”的五段式规则。
   - 常识库只在游戏外编辑，游戏内读取整库剪贴板、完整预览并原子替换。
   - 正式包附卡拉迪亚、战锤旧世界和权游世界三份可选库，通常按当前世界三选一；不会自动加载或混合。
   - 当前地点、人物关系、势力归属、存亡和近期事件等实时存档事实始终高于常识正文。

6. 可编辑提示词
   - 管理面板可分别管理主聊天、独立思绪和记忆总结提示词。
   - 支持直接粘贴纯文本，也支持完整预设 JSON。
   - 玩家提示词不能覆盖程序强制加入的单一发言人、实时事实、字符限制和 JSON 输出协议。
   - 管理面板可查看最后一次实际发送给模型的 system 与 user 内容，便于核对。

7. 可选 Fish Audio TTS
   - 正文、动作、可见心声可分别开启或关闭播报。
   - 最多提供十个角色音色槽，按存档中的角色稳定 ID 精确匹配。
   - 语音异步排队；失败不会影响文字聊天、记忆或下一轮调度。

8. 场景与存档安全边界
   - 战斗、遭遇、任务场景和战后稳定期会阻止或取消生成。
   - 请求期间进入战斗、切换聚落或切换战役时，迟到结果不会写入。
   - 进入、离开或切换聚落会结束旧的自动会话，避免进城后继续讨论上一段赶路处境。
   - 同一条近期公开台词不会同时作为当前话题、普通记忆和公开历史重复三次注入。

9. 自适应闲聊窗口
   - 窗口支持左上角或右上角、缩放、收起/展开和快捷键完整显隐。
   - 尺寸与边距会随分辨率和 UI 缩放调整。
   - 进入聚落菜单默认整窗隐藏，不占用鼠标；透明度只改变外观，不提供鼠标穿透。

网络与隐私

- 主聊天、独立思绪、记忆总结和 Fish TTS 只在对应功能启用并配置后请求玩家指定的服务。
- 公网接口只允许 HTTPS；本机回环服务可用 HTTP；拒绝 URL 中的凭据、查询参数、片段和重定向。
- API 密钥明文保存在本机 MCM JSON，请自行保护；不会进入战役存档、常识库、提示词导出或正式发布包。
- 可选诊断 Probe 默认只记录元数据。只有玩家在 Probe 中明确开启正文审计时，才会记录提示词、模型原始返回和最终文本。

版本边界

- BL1.4.8 正式包只对应 Bannerlord 1.4.8、MCM 5.12.2，可选 Living Commanders 1.6.5。
- BL1.3.15 正式包只对应精确版本 1.3.15.110062、MCM 5.11.3，可选 Living Commanders 1.6.4。
- 两个包不能混装。1.3.15 包目前只有离线编译与合同验证，不等于已经完成 1.3.15 实机和长档测试。
