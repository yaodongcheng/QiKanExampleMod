# 骑砍2 画面与天气管线 —— 后处理、大气，以及和 RDR2 的差距

> 立档 2026-11-17。来源：当前 Steam 客户端（1.5.x）与 1.2.12 备份客户端的反编译、引擎自带 `postfx_graphs.xml`、`Native/Atmospheres/*.xml`、以及本机 `engine_config.txt` 实测。
> 用途：任何人问「为什么骑砍2 的雨雪/画面不如 RDR2」「能不能加丁达尔」「画质设置怎么调」时，先读这篇，不要重新猜。

## 一、结论（六条）

1. **引擎不缺后处理。** 丁达尔（sunshafts）、泛光、镜头光晕、横向拉丝、暗角、色差、胶片颗粒、景深、运动模糊、TSAO（屏幕空间环境光遮蔽）、SSR、次表面散射、曲面细分——全都有，各有一个**开关位**、一份**每场景可调的数值**、一套**运行时 API**。
2. **丁达尔是屏幕空间的近似，不是体积光。** 做法是「亮部提取 → 朝太阳屏幕位置径向模糊 → 模糊」，跑在 **0.25 分辨率**上。太阳不在画面里就没有光柱；做不出穿过树叶、窗棂的真实光锥。
3. **战役天气只改两个数：雨密度、雪密度。** 曝光、泛光阈值、太阳光柱强度、雾密度/雾色、天空亮度、环境色——**全部只由太阳高度算出来**，跟下不下雨无关。所以原版「下雨」= 晴天滤镜上盖一层雨丝。
4. **引擎没有的东西：** 体积云、体积雾（参与介质）、实时全局光照、闪电/雷。这四条是天花板，绕不过去。
5. **想让雨天像雨天，只有一条路：** 自己按天气驱动 `Scene` 的这一套 setter，并做平滑过渡。不需要改引擎，不需要新资产。
6. **设置层面很容易自我削弱。** 本机原有配置是整套 Medium，且 SSR / 镜头光晕 / 暗角全关；低贴图配高锐化还会让画面发硬。键名与档位上限见 §四。

## 二、引擎里到底有什么（证据）

### 2.1 后期链 = 一张固定图

- 文件：`<游戏根>\Modules\Native\ModuleData\postfx_graphs.xml`（只有一个 `postfx_graph`，全部效果按开关位拼装）
- 关键节点：`external_screen_injection` → `halfres_combine` → `histogram`（自动曝光/眼睛适应）→ `dof_coc` / `motion_blur` → `sssss` → `bloom_*` → `sunshaft_blurhalf` → `sunshafts_rays` → `sunshafts_blurt` → `lens_flare_*` → `streak_*` → `tonemap` → 抗锯齿（FXAA / SMAA / 时间 SMAA / TAA）→ `sharpen`
- **丁达尔三个节点的分辨率是 `relative 0.25`**（宽高各四分之一），这是它看起来软的原因
- 另有 `thumbnail_postfx_graphs.xml`（缩略图用，与游戏内无关）

### 2.3 每个 atmosphere 预设能调什么

范本：`<游戏根>\Modules\Native\Atmospheres\scene_atmosphere.xml`（106 行，全字段可作模板）。分五段：

| 段 | 字段（节选） | 作用 |
|---|---|---|
| `<values>` | `cloud_amount`、`middle_gray`、`color_grade_name`、`time_of_day`、`skybox_background_texture_name`、`global_envmap_multiplier`、`season` | 云量、调色 LUT、天空贴图、环境贴图 |
| `<fog>` | `fog_density`、`fog_falloff`、`fog_color`、`fog_scatter`、`scatter_strength`、`mie_scatter_particle_size`、`skybox_distance`、`fog_start_distance`、`cloud_shadow_color` | 距离雾与散射 |
| `<cloud_shadow>` | `cloud_shadow_amount/contrast/begin_height/end_height/scale/speed` | **云影投到地面**（原版战役从不驱动） |
| `<sun>` | `sun_altitude`、`sun_angle`、`sun_intesity`、`sky_brightness`、`cloud_brightness`、`sun_size`、**`sunshafts_strength`**、`rayleigh_constant`、`sky_noise_amount` | 太阳与天空；光柱强度在这里 |
| `<postfx>` | `brightpass_threshold`、`min/max/target_exposure`、`bloom_strength`、`bloom_amount`、`grain_amount`、`lens_flare_*`（13 项）、`streak_*`（6 项）、`vignette_*`（3 项）、`aberration_*`（3 项）、`lens_distortion`、`burnout_threshold`、`contrast_enhancement` | 后期全套数值 |

调色 LUT 走 `color_grade_name`；原生可用的名字（扫 `Native/Atmospheres` + `Shokuho/Atmospheres` 得到）：
`filmic_color_grade` · `color_grade` · `color_grade_empire_soft/harsh` · `color_grade_aserai_soft` · `color_grade_battania_soft` · `4_calradian_autumn` · `cg_25c` · `cg_25c_5b` · `cg_50c_5b` · `cg_75c_5b` · `cg_blue_20/40` · `cg_sepia_20`

### 2.4 运行时 API（`TaleWorlds.Engine.Scene`）

**1.2.12 与 1.5.x 都有：**

- 光柱与曝光：`SetSunShaftStrength`、`SetSunshaftMode(bool)`、`SetMinExposure`、`SetMaxExposure`、`SetTargetExposure`、`SetMiddleGray`
- 泛光：`SetBloomAmount`、`SetBloomStrength`、`SetBrightpassThreshold`
- 镜头：`SetLensFlareAmount/Threshold/Strength/DirtWeight/DiffractionWeight/HaloWeight/HaloWidth/GhostWeight/GhostSamples/AberrationOffset/BlurSize/BlurSigma`、`SetAberrationOffset/Size/Smooth`、`SetLensDistortion`、`SetStreakAmount/Threshold/Strength/Stretch/Intensity/Tint`、`SetGrainAmount`、`SetVignetteInnerRadius/OuterRadius/Opacity`、`SetHexagonVignetteAlpha/Color`
- 大气：`SetFog(density, color, falloff)`、`SetFogAdvanced(offset, minFog, startDist)`、`SetFogAmbientColor`、`SetSunSize`、`SetSunDirection`、`SetLightDiffuseColor`、`SetSkyBrightness`、`SetSkyRotation`、`SetEnvironmentMultiplier`、`SetTemperature`、`SetHumidity`
- 雨雪与地面：`SetRainDensity`、`SetSnowDensity`、`SetWinterTimeFactor`、`SetDrynessFactor`、`SetForcedSnow`、`SetLandscapeRainMaskData(byte[])`、`SetUseAdvancedWaterRendering`
- 景深：`SetDofParams`、`SetDofFocus`、`SetDofMode`

**只在 1.5.x 验证到：** `SetMieScatterStrength`、`SetMieScatterFocus`、`SetGlobalWindStrengthVector`、`SetDynamicSnowTexture(Texture)`

> ⚠️ `SetSunshaftMode(bool)` 的两种模式分别是什么，**未验证**（只有签名，无文档、无调用方）。
> ⚠️ 个别 setter 是否被 `PostfxConfig` 位掩码门控（即玩家在选项里关掉该效果后设强度无效）**未验证**；保守做法是先读选项再决定要不要增强。

### 2.5 选项层（`NativeOptions`）

图形选项页在 `TaleWorlds.MountAndBlade.dll` 的 `GetPerformanceGraphicsOptions()` 里逐项列举，类型来自 `NativeOptions.NativeOptionsType`；每个下拉项的档数在 `TaleWorlds.Engine.NativeSelectionOptionData.GetOptionsLimit()` 里写死（见 §四表格上限列）。
读写走 `NativeOptions.GetConfig(type)` / `SetConfig(type, value)`，落盘文件 = §四 的 `engine_config.txt`。

## 三、战役天气到底改了什么（差距的根因）

数据结构 `AtmosphereInfo`（`TaleWorlds.Library.dll`）：

```
Seed, AtmosphereName, InterpolatedAtmosphereName
SunInfo{ Altitude, Angle, Color, Brightness, MaxBrightness, Size, RayStrength }
RainInfo{ Density }, SnowInfo{ Density }
AmbientInfo{ EnvironmentMultiplier, AmbientColor, MieScatterStrength, RayleighConstant }
SkyInfo{ Brightness }
FogInfo{ Density, Color, Falloff }
NauticalInfo{ WaveStrength, WindVector, … }
TimeInfo{ TimeOfDay, NightTimeFactor, DrynessFactor, WinterTimeFactor, Season }
AreaInfo{ Temperature, Humidity }
PostProInfo{ MinExposure, MaxExposure, BrightpassThreshold, MiddleGray }
```

`TaleWorlds.CampaignSystem.dll` → `MapWeatherModel.GetAtmosphereModel()` 的赋值事实：

| 字段 | 由什么算 | 雨/雪参与？ |
|---|---|---|
| `RainInfo.Density` / `SnowInfo.Density` | 天气事件 | ✅ 就是它本身 |
| `SunInfo.Brightness/Color/Size/RayStrength` | 太阳高度 `environmentMultiplier` | ❌ |
| `FogInfo.Density/Color` | `environmentMultiplier` + 高度 | ❌ |
| `SkyInfo.Brightness` | 时辰 + `environmentMultiplier` | ❌ |
| `PostProInfo.*` | `environmentMultiplier` 的线性插值 | ❌ |
| `AmbientInfo.*` | `environmentMultiplier` | ❌ |
| `TimeInfo.WinterTimeFactor/DrynessFactor` | 日历/天气地形效果 | 部分（干湿） |

两条实测公式（证明与雨无关）：

```csharp
// 太阳光柱强度：只吃太阳高度，值域 [0.01, 0.5]
GetSunRayStrength(env) = Clamp(Sin(Pow((env-0.001)/0.999, 0.4) * PI/2) - 0.15, 0.01, 0.5)

// 雾密度：只吃太阳高度与海拔，雨天不额外加雾
GetFogDensity(env, pos) = Min((0 + (昼夜系数0.4/0.5) * (1-env)) * (1 - Clamp((pos.z-30)/200, 0, 0.9)), 10)
```

天气对画面的**另一条**影响：`GetSelectedAtmosphereId()` 按季节/雨雪换一个预设名 ——

| 条件 | 选中预设 |
|---|---|
| 默认 | `semicloudy_field_battle` |
| 据点内 | `semicloudy_<culture>` |
| 下雨但没到暴雨 | `wet` → `semi_rainy` |
| 暴雨 | `dense_rainy` |
| 下雪 | `semi_snowy` / `dense_snowy` |

> ⚠️ 这些名字在 `Modules\*\Atmospheres\` 下**没找到同名 XML**（该目录只有编辑器/测试用的预设）。推测在资产包或场景数据里。**未验证**落地位置。

**结论：原版「天气」是一个粒子开关 + 一个干湿系数，不是一种画面状态。**

## 四、画质设置：键名、档位、上限

**文件**：`%USERPROFILE%\Documents\Mount and Blade II Bannerlord\Configs\engine_config.txt`
**特性**：纯文本 `key = value`；**所有客户端共用这一份**（1.2.12 备份客户端与 Steam 主目录读同一个文件）；游戏**退出时**回写，运行中改会被覆盖。
**它不是资产也不是存档**，改它不影响进度、物品、剧情。

| 键 | 含义 | 取值（0 起） | 影响面 |
|---|---|---|---|
| `texture_budget` | 纹理预算 | 0..3 低/中/高/很高 | 显存占用 |
| `texture_quality` | 贴图质量 | 0..2 低/中/高 | 贴图清晰度 |
| `texture_filtering` | 纹理过滤 | 0..5 双线性/三线性/各向异性 2·4·8·16X | 远处贴图 |
| `shader_quality` | 着色器质量 | 0..2 | 材质与光照着色；**改档会触发一次着色器编译** |
| `particle_quality` | 粒子质量 | 0..2 | **雨雪粒子数量上限** |
| `particle_detail` | 粒子细节 | 0..2 | **雨雪近景细节** |
| `terrain_quality` | 地形质量 | 0..2 | 地面细节 |
| `decal_quality` | 贴花质量 | 0..4 | 地面痕迹/血迹 |
| `foliage_quality` | 植被质量 | 0..4 | 草树密度 |
| `environment_detail` | 场景细节 | 0..4 | 环境物件 |
| `character_detail` | 角色细节 | 0..4 | 人群 LOD |
| `water_quality` | 水面质量 | 0..2 | 水 |
| `shadowmap_resolution` | 阴影分辨率 | 0..3 低/中/高/很高 | 阴影锐度 |
| `shadowmap_type` | 阴影类型 | 0..2 无/仅静态/静态+动态 | — |
| `shadowmap_filtering` | 阴影过滤 | 0..1 无/PCF | — |
| `occlusion_technique` | 环境光遮蔽 | 0..1 无/TSAO | 接触阴影 |
| `lighting_quality` | 光照质量 | 0..2 | 光照精度 |
| `animation_sampling_quality` | 动画采样 | 0..1 低/高 | 动作顺滑度 |
| `number_of_ragdolls` | 布娃娃 | 0..5 = 0/1/3/5/10/无限 | 纯观感 |
| `antialiasing_technique` | 抗锯齿 | 0..5 无/FXAA/SMAA/SMAA×2/时间 SMAA/时间 SMAA×2 | 锯齿 |
| `postfx_ssr` | 屏幕空间反射 | 0/1 | 水面与湿表面反射 |
| `postfx_sunshafts` | 太阳光柱（丁达尔） | 0/1 | **画面空气感主力** |
| `postfx_bloom` | 泛光 | 0/1 | 高光溢出 |
| `postfx_dof` | 景深 | 0/1 | 电影感 |
| `postfx_sssss` | 次表面散射 | 0/1 | 皮肤/布料透光 |
| `postfx_lens_flares` | 镜头光晕 | 0/1 | 电影感 |
| `postfx_vignette` | 暗角 | 0/1 | 电影感 |
| `postfx_chromatic_aberration` | 色差 | 0/1 | 观感因人而异 |
| `postfx_streaks` | 横向拉丝 | 0/1 | 观感因人而异 |
| `postfx_motion_blur` | 运动模糊 | 0/1 | 有人会晕 |
| `postfx_grain` | 胶片颗粒 | 0/1 | — |
| `postfx_hexagon_vignette` | 六边形暗角 | 0/1 | 风格化 |
| `tesselation` | 曲面细分 | 0/1 | 很贵 |
| `enable_dynamic_resolution_scale` | 动态分辨率 | 0/1 | **开 = 画面忽清忽糊** |
| `resolution_scale` | 分辨率缩放 | 百分比 | **低于 100 = 整体降采样变糊** |
| `sharpen_amount` | 锐化 | 0..100 | 过高会在低贴图上产生硬边/闪烁 |
| `enable_flora_sway` | 植被摆动 | 0/1 | 风感 |

**排查顺序（"画面为什么糊/平/难看"）**：

1. `resolution_scale` 是不是 100、`enable_dynamic_resolution_scale` 是不是 0 —— 这两条是第一嫌疑；
2. `texture_quality` / `shader_quality` 是不是低档；
3. 想要的效果（`postfx_*`）是不是被关掉了 —— 尤其是 `postfx_sunshafts`、`postfx_bloom`、`postfx_ssr`；
4. `sharpen_amount` 是否过高在补偿低贴图（低贴图 + 高锐化 = 更"游戏感"）；
5. 最后才怀疑资产本身。

**本机基线（2026-11-17 调过一轮，RTX 4060 Ti / 1920×1080）**：除刻意保留关闭的（色差、拉丝、运动模糊、六边形暗角、曲面细分）与刻意不拉满的（植被/场景细节 High、阴影分辨率 High）外，其余拉到高档；`resolution_scale=100`、动态分辨率关、`sharpen_amount=25`。
⚠️ **这是快照，会随玩家改设置变化 —— 不要当作永久事实引用，现读文件。**

## 五、要补"RDR2 感"，按性价比排序

| 优先级 | 做什么 | 代价 | 说明 |
|---|---|---|---|
| 1 | 设置拉齐（§四） | 零 | 先排除自我削弱 |
| 2 | **天气驱动后处理**：晴/雨/暴雨/雪/黄昏各一组 exposure·fog·sunshaft·bloom·skybrightness·色温，切换时插值 | 纯代码 | 用 §2.4 的 setter；这是唯一能补原版缺陷的一步 |
| 3 | 新建 atmosphere 预设 + 手工调色 LUT | 数据 + 资产导入 | 走 ModKit，LUT 是新资产 |
| 4 | 闪电 + 延迟雷声 | 代码 + 音效 | **原版粒子库里一条 lightning 都没有** |
| 5 | 雨滴打盔甲/地面涟漪/积水 | 贴花 + 粒子 | 有现成贴花管线；`SetLandscapeRainMaskData` 可做"哪片地是湿的" |
| ❌ | 体积云 / 体积雾 / 实时 GI | — | 引擎没有，只能拿粒子贴片骗，收益不确定 |

**关于"别人的视频画面更好看"**：主流是 ReShade 预设（游戏是 DX11，通用）叠加 AO/锐化/调色/伪光柱/景深；再叠加 4K 采集、高画质档、黄昏低太阳角、以及视频压缩抹掉锯齿。**视频是精挑的时刻，不是"雨天战场"**。

## 六、待确认（别当成结论用）

1. `SetSunshaftMode(bool)` 的两种模式语义。
2. 战役 atmosphere 预设（`semi_rainy` 等）的实际落地位置。
3. `postfx_*` 各 setter 是否受 `PostfxConfig` 位掩码门控。
4. SSR 在非水面材质上的实际可见度。
5. 1.5.x 的 `SetDynamicSnowTexture` / `SetMieScatterStrength` 是否值得用（1.2.12 没有）。

## 七、项目内现状

- 我们已经有的天气入口：`custom.story_probe environment status|time|weather|snowcover|set|reset`（实现在 `ExampleModVS\ExampleMod\ExampleMod\CampaignMode\Tools\EnvironmentCommands.cs`，落地在 `Core\SceneEnvironment.cs`）。
- 它**只改四样**：雨密度、雪密度、时辰、积雪度；`Scene` 的后处理/雾/光柱一个都没接。
- 时辰改写依赖 1.2.12 的 `MBMapScene.SetFrameForAtmosphere`，**1.3+ 会被 `SceneEnvironmentTimeError` 拒绝**（见 `Core\VersionCompat.cs`）；而 §2.4 的 `Scene.SetXxx` 是跨版本稳定的，可作为 1.3+ 的替代通道。
