# 内容包最小字段交集（七类对象，织丰/原版对照判定）

> **用途**：内容包（Taikou/三国/…）数据上桌前的"字段完整性"对照表+判定法。写数据前查本档，一次看全、不挤牙膏。
> **来源**：2026-09-08 排雷复盘（用户裁定），判定方法 = `Scripts/check_taikou_field_coverage.py`（七类自动 diff）+ 人工甄别（误报/特例/可选三分类）。
> **配套**：`Scripts/check_taikou_xml_references.py`（自引用闭合，跑完 coverage 必跑）· `Scripts/prune_taikou_items.py`（引擎自给白名单：物品 51 + roster 5）

## 方法论（判定三类）

| 类别 | 定义 | 处置 |
|---|---|---|
| **必补** | 官方/织丰 cell 主属性 + 引擎真实消费 | 补（值 = 自有资源或官方样板值） |
| **误报** | 子元素/其它对象类属性被全局正则扫入（Item 的 Weapon 组件属性、Clan 的 policy 子节等） | 不补（cell 原文自带） |
| **特例** | 本世界形态无对应（流寇文化字段/佣兵布尔/家谱配偶/村庄专属） | 不补（世界扩展时再按文补）；判据写进注释 |

| 类 | 官方∩织丰 | 我们做法 | 补了什么 | 备注 |

## 用法（新内容包接入流程）

1. `python Scripts/check_taikou_field_coverage.py` → 看七类缺口
2. 缺口 → 按上表三分类（必补/误报/特例）处理；**特例必须写注释注明判据**
3. 补完 → `python Scripts/check_taikou_xml_references.py`（0 悬空 = 自引用闭合达标）
4. 每类 cell 的字段引用 → 全部指向自有资源（铁则：内容包纯数据、引用必须在自我体系内——详见 wheels.d/campaign-mode.md §1）
