# 原版地牢与劫狱机制分析

> 适用版本：v1.4.8（开发机实测）/ v1.3.15（一致）/ v1.2.12（早期简化版，见 §8）
> 反编译对象：`bin/Win64_Shipping_Client/TaleWorlds.CampaignSystem.dll`、`Modules/SandBox/bin/Win64_Shipping_Client/SandBox.dll`、场景文件 `Modules/SandBox/SceneObj/empire_dungeon_a/scene.xscene` 等
> 调研日期：2026-08-14。本 mod 接入点：随从坐牢/赎回（`CompanionDetentionBehavior`）、玩家扣押（`PlayerDetentionBehavior`）。

## 0. TL;DR

- **原版地牢实体 = 定居点的 `Party.PrisonRoster`**（+ 城堡的 `GarrisonParty.PrisonRoster`）。"被投进 {SETTLEMENT} 的地牢"（原版 quest 日志原话）在数据上就是"hero 进入该定居点 PrisonRoster + `ChangeState(Prisoner)`"。
- **地牢场景是文化共享的独立场景**（如帝国 `empire_dungeon_a`），玩家进地牢时，roster 里每个被俘英雄**强制刷在 `sp_prisoner` tag 的牢房点上**（`forceSpawnOnSpecialTargetTag=true`），固定站位播犯人姿势动画。
- **劫狱（Prison Break）是原版完整玩法**：付钱（赎金估值 + 1000 底价）→ 潜行两阶段 mission → 三种结局。只对**非己方阵营**定居点开放；同阵营地牢不能劫狱。
- **被俘英雄会随时间自动被赎回**（`RansomOfferCampaignBehavior`：AI 对 AI 每天 10% 概率 barter；涉玩家每天 20% 概率地图通知报价）——这是友方/中立抓人的原版兜底路径。
- **版本兼容**：1.2.12 有完整菜单/结局流程但 mission 是早期简化版（无两阶段潜行、无增援）；1.3.15+ 是成熟版（与 1.4.8 一致）。

## 1. 地牢实体模型

### 1.1 数据层：PrisonRoster 即地牢

| 对象 | 含义 |
|------|------|
| `settlement.Party.PrisonRoster` | **定居点地牢 roster**——原版所有地牢功能（劫狱选人、越狱、和平释放、地牢菜单）都读它 |
| `(Fief).Town.GarrisonParty.PrisonRoster` | 城堡/城镇卫戍部队自己关的俘虏（劫狱选人时合并列出） |
| `hero.PartyBelongedToAsPrisoner` | 英雄当前被谁关押（= settlement.Party 表示在地牢里） |

原版语义佐证（反编译）：
- 越狱选人 `CanPlayerStartPrisonBreak` → `Settlement.CurrentSettlement.Party.PrisonRoster.ToFlattenedRoster()`
- `SettlementHelper.GetAllHeroesOfSettlement(settlement, includePrisoners)` 把 PrisonRoster 里的 Hero 算作"settlement 的（俘虏）英雄"
- 和平条约 `ReleasePrisonersInternal` 遍历各定居点 PrisonRoster 释放英雄
- 原版 quest 日志文案：`"{TARGET_HERO.LINK} has been taken prisoner and thrown into the dungeons of {SETTLEMENT}."`（`capturer.IsSettlement` 分支）

### 1.2 英雄进地牢的状态变化（TakePrisonerAction.Apply）

`TakePrisonerAction.ApplyInternal(capturerParty, hero)`（本 mod 转押用的就是它）：

```csharp
// 从原队伍 member roster 移除
prisonerCharacter.PartyBelongedTo.MemberRoster.RemoveTroop(...);
prisonerCharacter.CaptivityStartTime = CampaignTime.Now;
prisonerCharacter.ChangeState(Hero.CharacterStates.Prisoner);
capturerParty.AddPrisoner(prisonerCharacter.CharacterObject, 1);  // → PrisonRoster
```

## 2. 俘虏进地牢的路径（原版全景）

| 路径 | 机制 | 说明 |
|------|------|------|
| 定居点当局逮捕 | `TakePrisonerAction.Apply(settlement.Party, hero)` | **本 mod 随从转押用的路径** |
| 守军/民兵打赢战斗 | `PartyBase.RosterToReceiveLootPrisoners` | garrison/militia 的战利品俘虏**直接进 `HomeSettlement.Party.PrisonRoster`** |
| AI 部队带俘虏进堡垒 | `SellPrisonersAction.ApplyForSelectedPrisoners(party.Party, settlement.Party, roster)` | `PartySellPrisonerCampaignBehavior.OnSettlementEntered`：非玩家部队进入非敌对堡垒时，敌国俘虏自动"卖"进地牢（玩家俘虏除外） |
| 玩家手动捐赠 | 部队屏幕 Donate prisoners → `EnterSettlementAction.ApplyForPrisoner` | 玩家自己部队带的俘虏**不会**自动进地牢，要手动捐/卖 |
| 任务交付 | `TransferPrisonerAction.Apply(..., settlement.Party)` | 如抓回逃犯 |
| 叛乱/守城战 | 叛乱代码把半数 garrison 投入地牢等 | 边缘场景 |
| 劫狱失败 | `TakePrisonerAction.Apply(currentSettlement.Party, Hero.MainHero)` | 玩家自己被关进同一座地牢 |

**玩家自己部队的俘虏不会自动进地牢**——只有"定居点当局/守军"抓到的人才会在地牢 roster 里。

## 3. 地牢场景与刷点 tag 体系

### 3.1 场景文件

- 地牢是**文化共享的独立场景**，不在城镇场景内：`Modules/SandBox/SceneObj/{culture}_dungeon_{a,b,stealth}/scene.xscene`
- 定位：`location_complex_templates.xml` 里 `Location id="prison" scene_name="empire_dungeon_a"`（按文化选择；`GetSceneName(wallLevel)` 取等级场景名）
- 场景带 level 标记：实体 `<levels><level name="civilian"/><level name="prison_break"/></levels>`——普通拜访用 civilian，劫狱用 prison_break
- 城镇场景（如 `empire_town_b/scene.xscene`）里只有通往地牢的通道实体（`_barrier_passage_prison`），地牢本体在独立场景

### 3.2 tag 清单（empire_dungeon_a 实测）

| tag | 数量 | 用途 |
|-----|------|------|
| `sp_prisoner` | 4 | **犯人刷点（牢房）**：普通进地牢时 PrisonRoster 英雄强制刷这里 |
| `sp_guard` | 5 | 地牢守卫刷点 |
| `npc_common` / `npc_wait` / `alternative` | — | 闲人/待机点 |
| `spawnpoint_cleaner` | 2 | 清理点 |
| `sp_prison_break` / `sp_prison_break_prisoner` | prefab 实体 | 劫狱 mission 玩家出生点 / 被劫者刷点 |
| `prison_break_reinforcement_point` | — | 阶段二守卫增援刷点（1.3.15+） |
| `stealth_agent` / `dynamic_patrol_area_tag` | 10 / 20 | 劫狱潜行守卫及巡逻区（`{culture}_dungeon_stealth` 变体） |
| `area_marker_1/2/3` | — | 监狱房间额外站桩守卫（`SettlementGuardCampaignBehavior` 按可用点刷） |

配套姿势 prefab：`sp_dungeon_prisoneer_idle_exhausted / sitting / leaning_wall / cleaning_floor`（注意官方拼写就是 "prisoneer"）、牢门 `empire_dungeon_cell_door_a_closed`。

### 3.3 犯人怎么刷进地牢场景（普通拜访）

`HeroAgentSpawnCampaignBehavior.CreateLocationCharacterForHero`（CampaignSystem）`HeroLocationDetail.Prisoner` 分支：

```csharp
text = "sp_prisoner";
forceSpawnOnSpecialTargetTag = true;   // 强制刷在该 tag
fixedLocation = true;                   // 固定站位
actionSetCode = GenerateActionSetNameWithSuffix(..., "_villager");
...AddFixedCharacterBehaviors
```

位置判定：`GetLocationForHero` → `hero.IsPrisoner && GetPrisonerHeroes().Contains(...)` → `HeroLocationDetail.Prisoner` + location `"prison"`。

**结论：玩家进地牢场景时，roster 里每个被俘英雄都刷在某个 `sp_prisoner` 牢房点上蹲着——是真实可见的，不是只有菜单文字。**

## 4. 地牢菜单链与进入权限

菜单链：`town` → `town_keep` → "Enter the dungeon"（`town_keep_dungeon` / `castle_dungeon`）→ `OpenMissionWithSettingPreviousLocation("center", "prison")` 打开地牢场景。

进入权限 `CanMainHeroEnterDungeon` → `CanMainHeroEnterKeepInternal`：

| 关系 | 权限 |
|------|------|
| 自家领地（OwnerClan == 玩家家族） | FullAccess |
| 同阵营 | FullAccess |
| 中立 | 家族等级 ≥3 → FullAccess；有犯罪值 / 等级 <3 → LimitedAccess（贿赂）；可乔装 |
| 敌对 | LimitedAccess（仅乔装） |
| 兜底否决 | LimitedAccess（贿赂/乔装）且 lordshall + prison 两个 location 都空 → **NoAccess** |

**重要推论**：地牢里关着人（location 非空）时，玩家保留进入渠道（贿赂/乔装）。这保证了"随从被关 → 玩家有办法进地牢看到人"。

## 5. 劫狱全流程（1.3.15+ / 1.4.8）

### 5.1 入口与前置

- 菜单：`town_keep_dungeon` / `castle_dungeon` / 敌占主楼 → "Stage a prison break"
- `DefaultPrisonBreakModel.CanPlayerStagePrisonBreak`：
  ```csharp
  result = settlement.MapFaction != Clan.PlayerClan.MapFaction
      && !DiplomacyHelper.IsSameFactionAndNotEliminated(...)
      && (garrison.PrisonRoster.TotalHeroes > 0 || settlement.Party.PrisonRoster.TotalHeroes > 0);
  ```
  → **同阵营地牢不能劫狱；敌方/中立可以**（前提：玩家能进地牢菜单）。玩家受伤时禁用。
- 7 天冷却（`prison_break_cool_down`），按定居点记。

### 5.2 选人付费

- 选人：`settlement.Party.PrisonRoster + GarrisonParty.PrisonRoster` 全部英雄列进 `ShowMultiSelectionInquiry`（敌对势力英雄标红不可选）
- 费用 `GetPrisonBreakStartCost`：`⌈(赎金估值/2000 × 治安 × 40 − 狡诈×10)/100⌉×100 + 1000`，钱不够不能选
- 确认菜单 `start_prison_break` → 扣钱 → 加 7 天 CD → 进 mission

### 5.3 潜行阶段（阶段一）

- 场景：`GetSceneName(wallLevel)` 的 dungeon 场景，sceneLevel = "prison_break"；玩家刷 `sp_prison_break` 点
- `LocationCharactersAreReadyToSpawn` 清空地牢角色，重建：1 名被劫者（`sp_prison_break_prisoner` 点，蹲姿、无武器、无队伍、Defensiveness=2）+ 8 名潜行守卫（`stealth_agent` tag、走 `dynamic_patrol_area_tag` 巡逻区）
- 守卫 = 敌国文化基础兵种树 2~3 级近战兵 + 强制换 `battania_mace_1_t2` 锤
- 提示"找到并和被劫者说话，别惊动守卫"；`StealthFailCounterMissionLogic` 15 秒败北倒计时
- 阶段一杀掉的守卫被记录

### 5.4 逃亡阶段（阶段二）

- 与被劫者交互 → "Let's get out of here!" → 被劫者加入玩家队（`FollowAgentBehavior` 跟随）、装备最便宜民用单手剑（带其家族纹章）
- 全体守卫警觉醒悟（AlarmFactor 2 + SetAlarmState）；地牢门禁解锁（`UpdateDoorPermission`）
- **阶段一杀掉的守卫从 `prison_break_reinforcement_point` 复活增援**
- 战斗期间不能主动离开（`OnEndMissionRequest`：canLeave 仅当玩家不活跃）

### 5.5 三种结局（OnEndMission 按存活切换）

| 结局 | 菜单 | 结算 |
|------|------|------|
| 成功（玩家+被劫者都活着出场景） | `settlement_prison_break_success` | 离城 → 大地图对话 → `EndCaptivityAction.ApplyByEscape` 释放 + 好感 +15（`GetRelationRewardOnPrisonBreak`）+ 狡诈技能经验；被劫者是同伴可选 "You could join me" 直接回队伍（`AddHeroToPartyAction`） |
| 玩家被打昏 | `settlement_prison_break_fail_player_unconscious` | 玩家自己被 `TakePrisonerAction` 关进同一座地牢 |
| 被劫者被打昏/死 | `settlement_prison_break_fail_prisoner_unconscious` | 丢下他逃掉（重伤死亡另有日志） |

## 6. 释放路径总览（被俘英雄怎么出来）

| 路径 | 机制 | 适用场景 |
|------|------|---------|
| **自动赎金** | `RansomOfferCampaignBehavior`：AI 对 AI 每天 10% 概率 barter（`ExecuteAiBarter` + `SetPrisonerFreeBarterable`）；涉玩家每天 20%（拒绝后 12%）地图通知 + 决策面板 | **所有阵营都适用——友方/中立抓人时玩家的原版兜底**；captor clan = `settlement.OwnerClan` |
| 和平条约 | `ReleasePrisonersInternal` 遍历各定居点 PrisonRoster 释放 | 停战时 |
| 劫狱成功 | `EndCaptivityAction.ApplyByEscape` | 敌方/中立地牢 |
| 越狱 | 地牢英雄随时间自行逃跑（原版 captivity 逻辑） | 概率性 |
| 玩家赎出（本 mod） | `CompanionDetentionBehavior` 赎回菜单 → `PrisonRoster.RemoveTroop` | 自己随从被关时主动救回 |

## 7. 本 mod 接入点

1. **转押**：`AttackTriggerMissionLogic.TransferArrestedCompanions` → `TakePrisonerAction.Apply(settlement.Party, hero)` + `CompanionDetentionBehavior.RegisterDetained(hero, settlement, eventId)`（MissionEnd 时执行，幂等，防双押）
2. **赎回**（2026-08-14 改造成二级菜单）：
   - 一级：village/town/castle 菜单注入「赎回随从」（`lwn_companion_ransom`）→ 切到二级菜单 `lwn_ransom_menu`
   - 二级：列出该定居点全部可赎回随从（`GetRansomableEntriesIn`，每人一选项，姓名 + `CrimePenaltyCalculator.ComputeCost(evt, Restitution)` 定价，付不起灰掉）；扣钱走 `AgentControlHelper.TransferGold`（铁律 4）；`PrisonRoster.RemoveTroop` 释放（hero 自动回原队伍）；事件 Resolved
3. **清理**：`OnHourlyTick` 验证 `hero.PartyBelongedToAsPrisoner == settlement.Party`，失效条目（原版释放/越狱/死亡）自动移除——**原版机制放走的随从，mod 状态自动跟随，不会残留幽灵条目**

## 9. 与本 mod 玩法相关的设计要点

- 随从被友方势力抓（同阵营地牢）：原版不能劫狱（`CanPlayerStagePrisonBreak=false`），玩家靠 **mod 赎回菜单**（village/town/castle 直达）+ 原版自动赎金（每日 20% 报价概率）双通道
- 随从被中立势力抓：玩家可进地牢（贿赂/等级≥3 全通）看到人，也可劫狱（`CanPlayerStagePrisonBreak` 只排除同阵营）
- 随从被敌对势力抓：玩家只能乔装进地牢或等自动赎金；劫狱菜单在 town_keep_dungeon 可见
- 地牢场景里随从可见（`sp_prisoner` 牢房点）——未来可实现"进地牢场景当面释放/对话"或"劫狱救随从"（`EndCaptivityAction.ApplyByEscape` 后 `OnHourlyTick` 自动清理条目，无需额外同步）
