# 骑砍2 网格贴图动画 —— 引擎能力与实现

> **一句话**：骑砍的**网格**要"贴图动起来"，材质层有**两条路** ——
> **翻页**（`use_animated_texture_coords`）与**漂移**（`use_texture_sweep`）。
> 两者**抢同一个 Vector Argument 1**，**二选一**，不能同时用。
>
> 全部结论来自 **ModKit 自带的 shader 源码**（`<游戏根>\Shaders\Sources\`，844 个文件），
> 不是猜的。所有引用都标了文件名与行号，可逐条复核。

---

## 一、选型表（先看这个）

| | **翻页**（flipbook） | **漂移**（sweep） |
|---|---|---|
| 材质 flag | `use_animated_texture_coords` | `use_texture_sweep` |
| 代码 | `pbr_standart_vertex_functions.rsh:38` | 同文件 `:91` |
| 本质 | **缩放 + 偏移** UV：整个网格缩到一格，再跳到当前帧那一格 | **平移** UV：`tex_coord.xy -= 速度 × 时间 × 1.64` |
| 贴图要求 | **图集**（N×M 栅格，每格一态） | **必须可平铺**（接缝看不出来） |
| 网格 UV | 保持 [0,1] ✓（shader 自己缩格） | 保持 [0,1] ✓ |
| 观感 | 形状**硬切**（无过渡）；4 帧会"一顿一顿" | **连续流动**，无接缝无硬切 ✓ |
| 🔴 关键差别 | **烘在贴图里的空间遮罩不会动**（因为它只缩放+偏移） | 🔴 **遮罩会跟着一起漂走**（因为是平移） |

**怎么选**：
- 要**流动感**（火焰沿刃口流、云在涌）→ **漂移**，且贴图必须可平铺
- 要**形状变化**（一朵云换另一朵）、或**贴图里有不能动的东西**（圆形遮罩、内热外冷的渐变）→ **翻页**
- 🔴 **"圆形遮罩 + 会动" 只能走翻页**：漂移会把遮罩漂出画面（2026-09-22 飞行法阵实测踩出来的）

## 二、源码原文（两条路的实现）

### 2.1 翻页 —— `Sources/pbr_standart_vertex_functions.rsh:38-56`

```hlsl
if(bool(USE_ANIMATED_TEXTURE_COORDS))
{
    uint  num_frames_x    = (uint)g_mesh_vector_argument.x;   // 图集**列数**
    uint  num_frames_y    = (uint)g_mesh_vector_argument.y;   // 图集**行数**
    float animation_speed = g_mesh_vector_argument.z;         // **帧/秒**
    uint  num_frames      = (uint)g_mesh_vector_argument.w;   // **总帧数**

    // 按世界位置错相 —— 多个实例不会同步闪（引擎自带的好处）
    int phase_difference = (int)((g_world._m03 + g_world._m13 + g_world._m23) * 2.4);

    uint cur_frame   = (uint)(g_time_var * animation_speed + phase_difference) % num_frames;
    uint cur_frame_x = cur_frame % num_frames_x;
    uint cur_frame_y = cur_frame / num_frames_x;

    tex_coord.x *= 1.0f / (float)num_frames_x;                // ← 缩到一格
    tex_coord.y *= 1.0f / (float)num_frames_y;
    tex_coord.x += ((float)cur_frame_x / (float)num_frames_x); // ← 再挪到那一格
    tex_coord.y += ((float)cur_frame_y / (float)num_frames_y);
}
```

**读出来的三件事**：
1. 帧序是**先横后纵**（`x = 序号 % 列数`，`y = 序号 / 列数`）→ 2×2 的播放顺序是 左上→右上→左下→右下
2. 是**缩放+偏移**，不是平移 ⇒ 每一格的内容被完整铺到**整个网格**上 ⇒ **画在格中央的圆形遮罩 = 铺在网格中央**，切换帧时**不动** ✓
3. `animation_speed` 单位是**帧/秒**：4 帧、速度 2 ⇒ 2 秒一轮

### 2.2 漂移 —— `Sources/pbr_standart_vertex_functions.rsh:91-93`

```hlsl
#if USE_TEXTURE_SWEEP && (!defined(SHADOWMAP_PASS) || ALPHA_TEST)
    output.tex_coord.xy -= g_mesh_vector_argument.xy * g_time_var * 1.64f;
#endif
```

**读出来的三件事**：
1. `Vector1.xy` = **u / v 两个方向的漂移速度**（每秒位移 × 1.64）
2. 是**平移** ⇒ 贴图里任何"位置性"的内容（遮罩、渐变、图集分区）**都会跟着漂** ✗
3. UV 会跑到 [0,1] 之外 ⇒ **贴图必须可平铺**（wrap），否则漂到边界会硬切一条

### 2.3 🔴 自发光**复用同一个 vec4** —— `Sources/standart.rsh:1237+`

`apply_self_illumination` 在**非 craft / 非 dual-skin** 分支（普通材质走这支）读的是**同一个** `g_mesh_vector_argument`：

```hlsl
randomness_value  = g_mesh_vector_argument.x;   // 顶点着色器那边 .x 是「图集列数」
flicker_frequency = g_mesh_vector_argument.y;   // .y 是「图集行数」
flicker_power     = g_mesh_vector_argument.z;   // .z 是「播放速度」
base_illumination = g_mesh_vector_argument.w;   // .w 是「总帧数」

float illum_amount = base_illumination * illum_mask;
if (flicker_power > 0) {
    tc_eff = texcoord.x + world_normal.y + world_normal.z*6.1 + (world_pos.x + world_pos.y)*2.8;
    // 🔴 是**乘法**，不是加法 —— 不闪就得让 flicker_power ≤ 0，而它正是「播放速度」
    illum_amount *= abs(sin(tc_eff * randomness + g_time_var * 4.8 * flicker_frequency) * 0.6 * flicker_power);
}
final_color.rgb += illumination_color.rgb * illum_amount * illumination_color_factor;
```

> ⚠️ `craft / dual-skin` 材质走的是 `g_mesh_vector_argument_2`（Vector Argument 2），普通材质走 Vector Argument 1。

### 2.4 Vector Argument 冲突总表（**最重要的一张**）

同一个 **Vector Argument 1**，三个效果三种读法：

| Vector1 | 翻页读成 | 漂移读成 | 自发光读成 |
|---|---|---|---|
| **x** | 图集列数 | u 漂移速度 | randomness_value |
| **y** | 图集行数 | v 漂移速度 | flicker_frequency（时间频率 = `4.8×y` Hz） |
| **z** | 播放速度（帧/秒） | 未用 | flicker_power（闪烁强度） |
| **w** | 总帧数 | 未用 | base_illumination（亮度） |

**结论：三个里只能开一个。** 两个都开的后果举例（4 帧圆云图集 `(2,2,2,4)`）：
- 翻页 ✓ 正常播；自发光把 `.y=2` 当频率 ⇒ **9.6 Hz 硬闪**，亮度 = `.w` = 4
- 而且频率**锁死改不了**（`.y` 必须 = 2 才切得对格）

## 三、flag 归属（别再拼错）

| flag | 只在哪些 shader 里 |
|---|---|
| `USE_ANIMATED_TEXTURE_COORDS` | `pbr_standart`（网格）· `light_emitter_sprite`（火把闪烁）· `show_texture` · `show_texture_with_smooth_transition` · `ui_shaders` |
| `USE_TEXTURE_SWEEP` | `pbr_standart_vertex_functions` · `deferred_blood_terrain` · `pointlight_shadow` |
| `SELF_ILLUMINATION` | pbr 家族（实现在 `pbr_shading_functions.rsh` → `standart.rsh` 的 `apply_self_illumination`） |
| `USE_SUNLIGHT` | 🔴 **只有粒子**（`particle_shading.rsh` / `gpu_particle_shading.rs`）—— **网格拿不到** |

**`pbr_metallic` 三个都能拿到**（include 链实测）：
```
pbr_metallic.rs
 ├─ standart.rsh                       ← apply_self_illumination
 ├─ pbr_shading_functions.rsh          ← #if SELF_ILLUMINATION 调用点
 └─ pbr_standart_functions.rsh
     └─ pbr_standart_vertex_functions.rsh  ← 翻页 / 漂移两段实现
```

**参数从哪来（C#）**：`TaleWorlds.Engine.Mesh` 上
```csharp
mesh.SetVectorArgument (float v0, float v1, float v2, float v3);   // → Vector Argument 1
mesh.SetVectorArgument2(float v0, float v1, float v2, float v3);   // → Vector Argument 2
```
（引擎侧变量名 `g_mesh_vector_argument` / `_2`；官方文档说"两个 Vector Argument，共 8 个实数"—— 对得上。）

## 四、怎么生成贴图

### 4.1 共用前提（两条路都要）

| 项 | 要求 | 为什么 |
|---|---|---|
| 格式 | **8bit RGB、无附加块** | 编辑器只吃这个；用 `tools/face-pipeline/scripts/png_for_editor.py` 过一遍（Blender 直出的 RGBA 会被编辑器连源图带产物一起删） |
| 底色 | **纯黑** | 配 `Add Alpha` / `Add Modulate Combined` 加法混合时，**黑 = 不发光 = 隐形**；铺满颜色会被当 albedo 受光 ⇒ 渲染成"木地板"（实拍过） |
| Mips | **保留** | 平面网格远看要靠 mip 防闪烁；`Do Not Generate Mips` 别勾 |
| 压缩 | 建议勾 **`Do Not Compress`** | DXT1 是 4×4 块压缩，**平滑渐变会出块状色阶**（云/火焰最明显）；1024² 从 ~0.5MB 涨到 4MB 显存 |

### 4.2 翻页贴图 = 图集

- **栅格**：N 列 × M 行，**每格一态**，格内内容会被完整铺满整个网格
- **网格 UV 保持 [0,1]**（shader 自己缩格）—— 不用改网格
- 🔴 **空间遮罩（如"圆形内聚外散"）烘在每一格里**：因为只缩放+偏移，遮罩会**稳稳停在网格正中央**
- 参数：`Vector1 = (N, M, 帧/秒, N×M)`
- 速度经验：**4 帧硬切**时，慢（1~2）看着像 glitch、快（8~12）糊成沸腾；**用形状相近的柔和内容当各帧**能把"切"的感觉压到最低

### 4.3 漂移贴图 = 可平铺

- **必须无缝平铺**，否则漂到边界会周期性地"硬跳一条"
- **怎么验证无缝**（判据）：`|左列−右列| 的均值 < 内部相邻列差异均值 × 1.6`（上下同理）；把图拼成 **2×2 目视**一眼就能看出接缝 —— **名字带 `_Tile` 不等于无缝**（实测 `T_Inky_Smoke_Tile` 接缝 2.2 / 内部基准 0.8 = 有明显缝）
- **亮度重映射**：UE 的噪声图暗部常不是 0（如 34）⇒ 加法下整片泛灰。要 `(亮度 − LO)/(HI − LO)` 拉满到 [0,255]
- 参数：`Vector1 = (u速度, v速度, 0, 0)`；UV 位移 = `参数 × 时间 × 1.64` ⇒ `0.03` ≈ 20 秒滚过一整张
- ⚠️ **wrap 模式不在贴图设置里** —— `Sources/definitions_samplers.rsh` 只写 `SamplerState linear_sampler : register(s_linear)`，address mode 由引擎注册 sampler 时定，**编辑器面板里没有这个字段**（2026-09-22 查证）。`USE_TEXTURE_SWEEP` 这个功能存在本身暗示是 wrap；不对的话症状是"周期性硬跳"

## 五、在 Material Editor 里怎么设（字段对照）

界面名 ↔ 引擎字段（dump 出来的名字）↔ 面板：

| 引擎字段 | 界面名 | 面板 |
|---|---|---|
| `shader` | Shader | 顶部 |
| `blend` | **Alpha Blend Mode** | **Transparency** |
| `alphaTest` | Alpha Test | Transparency |
| `shaderFlags` | **Material Shader Flags**（勾选列表） | 同名面板 |
| `flags` | Needs Forward Rendering / Don't Modify Depth Buffer / Don't Draw To Gbuffer / Don't Cast Shadow / Two Sided … | **Others** |
| `g_mesh_vector_argument` / `_2` | **Vector Argument 1 / 2** | **Vector Arguments** |
| `tex[0..N]` | Diffuse 1 / Diffuse 2 / … | **Textures** |

**一份能用的最小配方**（半透明发光网格，以飞行法阵为例）：

```
Shader              pbr_metallic
Textures            Diffuse 1 = 本贴图（自发光时发光图放 Diffuse 2）
Material Shader Flags
    ☑ use_animated_texture_coords（翻页）  或  ☑ use_texture_sweep（漂移）—— 二选一
    ☑ use_specular                        （官方：这条恒开）
    ☐ self_illumination                   （会抢 Vector1，与上两者同时开 = 硬闪）
Vector Arguments
    Vector1 = (2, 2, 2, 4)                （翻页）/ (0.03, 0.015, 0, 0)（漂移）
    Vector2 = 全 0
Transparency        Alpha Blend Mode = Add（黑底发光贴图**就选 `Add`**）
                    ⚠️ **别选 `AddAlpha`** —— 名字像"加法"，实际是 `背景 + 贴图×alpha`，
                       而 RGB 贴图（编辑器只吃 8bit RGB）**alpha 是 0** ⇒ 加了个 0 = 完全看不见
                       （实机实拍过：Opaque 看得见实体、AddAlpha 近乎全透明）。
                       完整档位表见下面「六、坑」第 9 条。
                    Alpha Test = 0
                    Ignore Alpha（在**贴图**资产的 Texture Flags 里）☑ 双保险：让 shader 把 alpha 当 1.0
Others              ☑ Two Sided（单面片必勾，否则背面看不见）
                    ☑ Needs Forward Rendering
                    ☑ Don't Modify Depth Buffer
                    ☑ Don't Draw To Gbuffer
                    ☑ Don't Cast Shadow
Factor Colors       保持纯白
最后点             Compile Shader → Save
```

> 🔴 **`self_illumination` 的正确用法**（官方文档原文）："Illumination texture should be specified in **Diffuse 2**. Brightness parameters can be adjusted in **Vector Arguments** panel." —— 即发光图放 **Diffuse 2**、亮度走 Vector1.w。**只在不开翻页/漂移时才用它**（三者共用 Vector1）。

## 六、坑与硬限制

| # | 坑 | 症状 | 正解 |
|---|---|---|---|
| 1 | 🔴 **漂移会把贴图里的空间遮罩漂走** | 云飘出圆心、方形网格的四角露出方边 | 有遮罩就只能用**翻页**（缩放+偏移，遮罩不动）；或把遮罩改烘进**几何**（顶点色/圆盘网格） |
| 2 | **三个效果抢 Vector Argument 1** | 开了自发光后云在以 9.6Hz 硬闪 | 三者只开一个 |
| 3 | **`USE_SUNLIGHT` 是粒子 shader 的** | 网格材质里勾不到/勾了没用 | 别给网格用；那是 `particle_shading.rsh` 的东西 |
| 4 | **平铺名的图不一定无缝** | 漂移时周期性硬跳一条 | 跑接缝判据 + 2×2 目视 |
| 5 | **`Assets\<类>\<名>\*_tex.tpac` 没有像素** | 想从编辑器工程里"捞回"原图 —— 只有导入设置 | 原图的第二份在**已发布的 `AssetPackages\*.tpac`** 里：`tpaccli dump --packdir <模块>\AssetPackages --filter <名> --format png` |
| 6 | **备份脚本不幂等就自己冲自己** | 第 2 次运行时把"上次生成的产物"当成了"原图"备份 | 备份**只在备份不存在时做一次** |
| 7 | 贴图改完编辑器不拉 | 缩略图还是旧的 | 判据看 `Assets\...\<名>_tex.tpac` 的 **mtime**（不是镜像的）；不行就删掉该资产重新 Import FBX |
| 8 | 新 shader 组合要现编 | Publish 卡很久 | 官方：新增的「shader + flag 组合」要勾 `Compile Shaders`（30~60 分钟；单条组合通常很快） |
| 9 | 🔴🔴 **`AddAlpha` 不是纯加法** —— 黑底发光贴图选它 = 完全看不见 | Opaque 下看得见实体，`AddAlpha` 下近乎全透明；实机"能看到在流动、但看不到血红" | 🔴 **选 `Add`**（纯 `背景 + 贴图`，不看 alpha）。原因是编辑器贴图只吃 **8bit RGB**（没有 alpha 通道）⇒ `贴图×alpha` = `×0`。`Alpha Blend Mode` 完整档位（2026-09-22 实拍菜单）：`None` / `Modulate` / `AddAlpha` / `Multiply` / **`Add`** / `Max` / `Factor` / `Add Modulate Combined`。**只改 blend 不该动 Others**（见第 10 条） |
| 10 | 🔴 **别把粒子材质的 `Others` 选项套到网格上** | 网格预览/材质预览里几乎不可见 | 我照着 `prt_shd_smoke_1`（**粒子**材质）的 dump 给网格勾了 `Needs Forward Rendering` / `Don't Modify Depth Buffer` / `Don't Draw To Gbuffer` / `Don't Cast Shadow` —— 那些是粒子要的。**网格材质：Others 全保持默认**，只留 `Two Sided`（单面片必勾）。（`Two Sided` 是几何选项，安全） |
| 11 | 🔴 **加法材质的编辑器预览不可信** | 预览里暗得看不出颜色，容易误判"材质坏了" | 预览按**受光渲染**显示，不模拟"往背景加光" ⇒ 黑底贴图在预览里当然接近全黑。**判据只能是实机**（今天为此在编辑器里白绕了好几轮） |
| 12 | **贴图做太白，加法叠上去是"白雾"不是"火光"** | 实机：能看到形状在流动，但看不出血红色（被亮背景一衬更糊） | 原版最热的色实测是**鲑红** `(246,150,135)` / p95 `(255,194,185)`，**不是白** —— 贴图底色的饱和度要**比目标更红**（游戏里的 bloom 会自然把它洗白）。做法：把"白热"从纯白改成**白热偏橙**（如 `(255,170,132)`）且只混 40%，再把蓝通道压到 ~0.7 |
