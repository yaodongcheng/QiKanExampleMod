# 原版场景跟随系统分析 —「队伍成员进场景后跟着我」

> 反编译对象：Latest（v1.4.x）SandBox.dll / TaleWorlds.CampaignSystem.dll。行号为反编译输出行号，跨版本仅供参考。
> 分析日期：2026-08-03。**结论先行**：原版常驻跟随是 **Campaign 层名单 + Mission 层 FollowAgentBehavior** 两段式，触发点是「进定居点」而非「进酒馆」，默认只跟随一个符合条件的 hero。

## 二、触发时机表（ClanMemberRolesCampaignBehavior）

| # | 时机 | 回调 | 动作 |
|---|------|------|------|
| 1 | **主队进定居点场景**（大地图→Town/Castle/Village） | `OnSettlementEntered`（要求 GameMode==战役、LocationComplex.Current!=null） | `UpdateAccompanyingCharacters()` 全量重建 |
| 2 | **对话「跟着我」**（定居点 center/village_center 内，对任意在队 Hero，且其 `AgentNavigator.GetActiveBehavior()` 不是 FollowAgentBehavior） | `clan_member_follow_me_on_condition` → 选项 → `_isFollowingPlayer.Add(hero)` + 立即注册 | 手动加人；「别跟着我」→ 移除 |
| 3 | **对话「召集所有同伴」** | `clan_member_gather_on_condition` → `_isFollowingPlayer.Add` + 注册（GatherAll 语义） | 手动加人 |
| 4 | **队员入队时**（入队瞬间正好在定居点 && 名单空） | `OnHeroJoinedParty` | `UpdateAccompanyingCharacters()` 补位 |
| 5 | **开任务场景前** | `BeforeMissionOpened`（名单里的人在 CharactersAccompanyingPlayer 中缺失时） | 补注册——任务场景跟随者也照常跟着 |
| 6 | **开局默认** | 初始化 | 自动选第一个成年未伤非囚犯的在队 hero 入名单（`!flag`） |

**清理**：
- `OnSettlementLeft`（主队离开定居点）→ `RemoveAllAccompanyingCharacters()` + `_isFollowingPlayer.Clear()`
- `RemoveAccompanyingHero` / `OnHeroGetsBusy`（hero 忙了，如被谈话/关押）→ 移出名单 + 卸载

## 三、跟随者资格条件（易踩坑）

`UpdateAccompanyingCharacters` 遍历 **`MainParty.MemberRoster.GetTroopRoster()`**（主队名册，不限同族）：

| 条件 | 说明 |
|------|------|
| `IsHero` | 名册中的英雄 |
| `!= Hero.MainHero` | 玩家自己不算 |
| `!IsPrisoner` | 非囚犯 |
| **`!IsWounded`** | 🔴 **未受伤**——刚打完仗带伤的 hero 不跟随（最大变数） |
| `Age >= HeroComesOfAge` | 成年 |
| `!flag` | 🔴 **默认只跟第一个**（名单每次进定居点重建为 1 人；多人跟随仅在单次停留内靠对话维持） |

## 四、FollowAgentBehavior（SandBox.Missions.AgentBehaviors）源码要点

- 状态机：`Idle / OnMove / Fight`。**Fight**：5m 内有敌人 → 停下警戒（WatchState），敌人消失恢复跟随。
- 移动触发：与目标距离 > `4m + idleDistance` → OnMove；到达 → `DisableScriptedMovement()` + `SetMaximumSpeedLimit(-1f)` 释放。
- 目标点计算（MoveToFollowingAgent）：
  1. 目标位置 - 朝向×纵向偏移（徒步 0.6m / 骑乘 1.25m）- 侧向×横向偏移（左右按所处侧 1m / 1.5m）
  2. **多跟随者排队**：遍历 Mission.Agents 找同目标的其他 FollowAgentBehavior（按 DailyBehaviorGroup 归属），左右各按人数向外推（徒步 +0.6m 纵 / +1m 横，骑乘 1.25/1.5）——多人不重叠
  3. **邻近避让**：`AgentProximityMap` 查槽位 0.5m 内有他人 → 退回直接跟目标点
  4. **navmesh + 视线校验**：`GetNavMesh() != 0` && `IsLineToPointClear(身体胶囊半径)`，不通试偏移 1.5m，再不通直接跟
- 移动指令：`SetMovePos` → `Navigator.SetTargetFrame(pos, 旋转, rangeThreshold, AIScriptedFrameFlags)`；Stealth 模式（Mission.Mode==4）目标蹲下 → flags |= 0x200 同步蹲走。
- `SetTargetAgent(null)` 解除跟随；`SetTargetAgent` 时会处理 `navigation_mesh_deactivator` 场景标签的面排除（允许跟随者走禁行面）。
- 运行时挂卸接口：`CampaignMissionComponent : ICampaignMission` 的 `CheckIfAgentCanFollow / AddAgentFollowing / RemoveAgentFollowing`（SandBox.dll:12027）。业务方随时挂/卸（范本：PrisonBreakMissionController 犯人跟随、CombatMissionWithDialogueController 对话后跟随）。

## 五、与本 mod 的关系与复用建议

**🔴 冲突点**：原版跟随挂在 `DailyBehaviorGroup`（AgentBehavior 体系），本 mod `AgentBrain` 接管时走 `SuspendVanillaAI`——两者打架。接管前先 `SetTargetAgent(null)`（或移除 FollowAgentBehavior），释放后再恢复。

**复用**：要做「队友在场景里一直跟着我」，**不要自研寻路**：
1. Campaign 层：`PlayerEncounter.LocationEncounter.AddAccompanyingCharacter(locationCharacter, true)`
2. Mission 层：原版 `MissionAgentHandler.SpawnCharactersAccompanyingPlayer` 自动出生在玩家身边 + 挂 FollowAgentBehavior
3. 需要自定义跟随目标时：`AgentNavigator.GetBehaviorGroup<DailyBehaviorGroup>()` → `SetScriptedBehavior<FollowAgentBehavior>()` → `SetTargetAgent(target)`

**对照本 mod `FollowAgentAction`（AI/Actions/AtomicAction.cs）**：一次性演出跟随（占 Brain 队列）用自研版；常驻跟随（陪逛/遇敌停手/多人排队）用原版 FollowAgentBehavior。
