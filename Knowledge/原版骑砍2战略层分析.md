## 一、王国层（Kingdom Level）

原版骑砍2有一套**完整的 AI 外交决策系统**，全部在 `TaleWorlds.CampaignSystem.dll` 中实现。

### 1.1 战争/和平评分引擎：`DefaultDiplomacyModel`

核心方法是 `GetScoreOfWarInternal(IFaction, IFaction, IFaction, bool, out TextObject)`（约 470 行），用一个**巨型加权公式**计算 faction A 对 faction B 的战争/和平倾向。

#### 公式包含的因素

| 因素 | 变量来源 | 计算方式 | 含义 |
|------|---------|---------|------|
| **国力对比** | `CalculateBenefitScore(f1Stats, f2Stats)` | fief 总价值 × 力量比率的 1.1 次幂函数 | 战争获益预期 |
| **地理距离** | `GetDistance(f1, f2)` | 两方最近 3 个定居点的加权平均距离 | 太远 → -30万~-40万分惩罚 |
| **性格-Valor（勇猛）** | `hero.GetTraitLevel(DefaultTraits.Valor)` | Valor > 0 → 敌方强时战争倾向 +；Valor < 0 → 和平倾向 + | 越勇越想打 |
| **性格-Mercy（仁慈）** | `hero.GetTraitLevel(DefaultTraits.Mercy)` | Mercy > 0 → 我方强时战争倾向 -；Mercy < 0 → 不受影响 | 越仁慈越不想欺负人 |
| **性格-Honor（荣誉）** | `hero.GetTraitLevel(DefaultTraits.Honor)` | 撕毁近期和约惩罚加重（+25% / -25%） | 越荣誉越守信 |
| **战争疲劳** | `stanceWith.WarStartDate.ElapsedDaysUntilNow` | 60 天拐点，之后每天 -400 | 打越久越想停 |
| **近期和约** | `stanceWith.PeaceDeclarationDate.ElapsedDaysUntilNow` | 不满 60 天撕毁 → 高额惩罚 | 刚签就撕 = 背信 |
| **俘虏** | 遍历 faction 所有 Hero | 本方贵族被俘 → 求和倾向 +3000×/人（自己家族的 ×3） | 救人压力 |
| **纳贡** | `stanceWith.TotalTributePaid` | 纳贡太高 → 宣战倾向 +（每 1000 贡金 = +70000 倾向） | 不甘纳贡 |
| **文化** | 敌方定居点 Culture 匹配 | 有同文化敌方定居点 → 宣战倾向 +30000 × count^0.7 | 文化统一诉求 |
| **政治停滞** | `Kingdom.PoliticalStagnation` | 每点 ×1000 进入宣战评分 | 和平太久 = 想打仗 |
| **侵略性** | `faction.Aggressiveness` | 对方侵略性高 → 宣战倾向 ×(1+0.002×Agg) | 对侵略者更强硬 |
| **关系** | 两方统治家族间 relation | 关系越差 → 战争倾向越高 | 个人恩怨影响国策 |
| **顶狗压制** | 其他王国对战争双方的力量对比 | 防止一家独大——强者会被其他王国联合压制 | 平衡机制 |
| **多线作战** | `faction.TotalStrengthOfEnemies` | 已多线作战 → 新增战争收益打折 | 避免多线崩溃 |
| **玩家因素** | `faction.Leader == Hero.MainHero` | 对方是玩家 → 停战倾向 +10000；宣战距离惩罚从 -40万 降到 -30万 | 对玩家稍宽松 |

#### 最终公式结构

```csharp
float score = (
    cultureBenefit                      // 文化统一收益
    + clanPersonalityBonus * num18      // 家族性格随机偏移（±20000）
    + distanceDecay * num18             // 地理距离衰减
    + (benefit - risk)                  // 收益 - 风险（核心）
    + warDurationEffect                 // 战争持续时间影响（正=想打，负=想停）
    + peaceTreatyCoolDownEffect         // 近期和约冷却
    + politicalStagnation * num18       // 政治停滞加成
    - clanRiskScore * num18             // 家族风险扣减
    + relationBonus                     // 关系修正
    - captivePenalty                    // 俘虏惩罚
    + traitBonus * num18                // 性格修正
) * distanceMultiplier;                 // 最终距离缩放（0.1~1.0）

// 再加上顶狗压制和战争疲劳：
score += topDogScore - multiWarPenalty - warFatigueScore;
```

### 1.2 政治停滞系统：`PoliticalStagnationAndBorderIncidentCampaignBehavior`

**文件位置**：`TaleWorlds.CampaignSystem.dll` → `PoliticalStagnationAndBorderIncidentCampaignBehavior`

```csharp
// DailyTick() 每王国每日：
int stagnationChange;
if (有敌国 fief 数 >= 本国的 2+0.6×fiefCount)
    stagnationChange = -2;  // 快速降低停滞（敌人够强）
else if (有敌国 fief 数 >= 本国的 1+0.2×fiefCount)
    stagnationChange = -1;  // 降低停滞（有像样的敌人）
else
    stagnationChange = +1;  // 停滞积累（没有值得打的敌人）

kingdom.PoliticalStagnation += stagnationChange;
Clamp(0, 300);

// 宣战时额外削减：
kingdom.PoliticalStagnation = (int)(stagnation * 0.85 - 3);
Clamp(0, ...);
```

**机制**：`PoliticalStagnation` 是王国层面的"久不作战厌烦度"。长期不打仗就涨，一宣战就砍。停滞值直接进入战争评分公式（每点 ×1000 分）。

**`HourlyTickSettlement`**：每小时扫描定居点周围 10 单位半径内所有 party：
- 敌方 party → `NumberOfEnemiesSpottedAround += f(party 兵力, aggressiveness)`
- 友方 party → `NumberOfAlliesSpottedAround += f(party 兵力, aggressiveness)`
- 每小时后衰减（敌人 ×0.95，友方 ×0.8）

### 1.3 叛乱系统：`RebellionsCampaignBehavior`

**文件位置**：`TaleWorlds.CampaignSystem.dll` → `RebellionsCampaignBehavior`

```
条件检查（每日每城镇）：
  ① loyalty <= RebelliousStateStartLoyaltyThreshold
  ② Random < 0.25（每日 25% 概率抽检）
  ③ loyalty <= RebellionStartLoyaltyThreshold
  ④ militia >= garrison × 1.4  ← 民兵力量远超守军

触发叛乱：
  1. 创建 4 个叛军 Hero（Leader + Governor + 2 Supporters）
     - 年龄 25~40
     - 随机生成外观
  2. 创建新 Clan（RebelClan, 初始名望 200~300）
  3. 守军 50% → 俘虏，民兵 60% → 新守军
  4. loyalty 重置 100
  5. 30 天后叛军 Clan 转正（不再是 RebelClan）
  6. 90 天内叛军无地 → 全部处决
```

#### 选举系统：`KingdomElection`

```csharp

new KingdomElection(decision).StartElectionWithoutPlayer();  // AI 自动投票
new KingdomElection(decision).GetLikelihoodForOutcome(0);    // 查询通过概率

```

#### 决策生命周期

```
DailyTickClan → 家族掷骰决定是否提议
  → new KingdomDecision(clan, target)
  → kingdom.AddDecision(decision)
  → new KingdomElection(decision)  // 开始投票

投票通过：
  → DeclareWarAction.ApplyByKingdomDecision(f1, f2)
  → MakePeaceAction.ApplyByKingdomDecision(f1, f2, tribute)
  → 广播事件触发 HandleDiplomaticChangeBetweenFactions

投票不通过：
  → 决策过期（15 天）
  → ShouldBeCancelled（条件变化）
  → kingdom.RemoveDecision(decision)
```

## 二、家族层（Clan Level）

### 2.1 决策提议引擎：`KingdomDecisionProposalBehavior`

**这是整个王国 AI 决策的"发动机"**。每个家族每天独立掷骰：

```csharp
DailyTickClan(clan):
  // 前置条件
  if (游戏天数 < 5 || clan 灭亡 || 玩家家族 || 无兵力 || 无王国 || influence < 100)
      return;

  float probabilityPerClan = Min(0.33, 1 / (有影响力的家族数 + 2));

  // 玩家王国调整：
  if (clan.Kingdom == 玩家王国)
      probabilityPerClan *= 玩家是国王 ? 0.5 : 0.75;

  float r = Random;

  if (r < prob && influence > 停战费用)
      → 提议停战（随机选一个交战国，排除已有人提议的）

  else if (r < prob*2 && influence > 宣战费用)
      → 提议宣战（随机选一个非交战国，需 ConsiderWar 通过）

  else if (r < prob*2.5 && influence > 政策费用 × 4)
      → 提议政策（随机选一个政策，废除已有或新增未有的）

  else if (r < prob*3 && influence > 700)
      → 提议吞并（随机选一个关系 < -25 且有封地的家族）
```

#### 宣战/停战附加检

```csharp
// ConsiderWar: 支持率 > 50% 后，额外概率检：
Random < 1.4 × 支持率 - 0.55  → 才实际提议

// ConsiderPeace: 计算纳贡金额，支持率 > 5% 后：
Random < 2.0 × (支持率 - 0.5)  → 才实际提议
// 对方是玩家 → tribute += 15000（偏向玩家）

// 防重复逻辑：
// 同一对方不能同时有宣战和停战两个待决议案
```

### 4.3 `GetBehaviors()` — 核心决策流

每 0.25 游戏小时（约游戏中 6 分钟）运行一次：

```
TickInternal():
  1. 如果在 MapEvent（战斗中）→ 跳过
  2. 如果是主玩家 party 追击不可见目标 → 停止
  3. AI 被禁用且冷却到期 → 重新启用
  4. 如果是 Army 附属 → 跳过（由 Army 控制）

  GetBestInitiativeBehavior():
    扫描周围 9 单位半径内所有 party：
      ├── 过滤：自己/不活跃/非敌对/应忽略/正在当前定居点驻防/非领导 party
      ├── 计算双方力量比
      ├── 检查附近友军
      ├── 考虑 party 攻击性（Aggressiveness）
      └── 输出最佳主动行为 + 分数

  如果 initiative score > 1.0:
    → 覆盖 DefaultBehavior

  按 DefaultBehavior 做路径规划：
    EngageParty      → 直接追击目标
    PatrolAroundPoint → GetPatrolBehavior（随机偏移方向 + 距离，防抖）
    FleeTo*          → GetFleeBehavior（远离威胁方向 + 找友军/城门）
    EscortParty      → GetFollowBehavior（跟着目标到定居点）
    BesiegeSettlement → GetBesiegeBehavior（行军到城门 → 开始围城 → 准备突击）
    GoAroundParty    → 计算绕行路径（旋转 CCW 找可达面）
    DefendSettlement → 找攻击者 → GoAroundParty 绕过去拦截
```

**巡逻行为（`GetPatrolBehavior`）的具体逻辑**：
- 当前目标太远（> patrolRadius × 3.2）→ 先走向定居点
- 到达巡逻半径内 → 随机方向偏移（朝向中心 + 随机角度，比例随距离变化）
- 12.5% 概率重新选方向，其余时间保持

**逃跑行为（`GetFleeBehavior`）的具体逻辑**：
- 优先：附近有我方定居点 → FleeToSettlement / FleeToGate
- 其次：附近有我方大部队 → FleeToParty
- 否则：反方向 + 随机偏移 → FleeToPoint（距离 = 威胁比 × 3 + fleeingCount × 2）

## 五、完整决策流（王国 → 部队）

```
第 0 层：时间推进
  CampaignEvents.DailyTick / HourlyTick → 事件广播

第 1 层：政治停滞
  PoliticalStagnationAndBorderIncidentCampaignBehavior.DailyTick()
    → 每个王国按敌人体量调整 PoliticalStagnation [0, 300]
    → HourlyTickSettlement 追踪定居点周围敌友 party 频率

第 2 层：家族提议决策
  KingdomDecisionProposalBehavior.DailyTickClan(clan)
    → 每个有影响力的家族独立掷骰
    → 提议概率 = Min(0.33, 1/(活跃家族数+2)) × 玩家修正
    → 防重复：同目标不能同时有宣战+停战提案
    → 过期清理：15 天未解决 → 移除

第 3 层：决策投票通过
  KingdomElection.StartElectionWithoutPlayer()
    → 计算所有家族投票权重
    → 支持率 > 50% → 通过
    → DeclareWarAction.ApplyByKingdomDecision()
      → FactionManager.DeclareWar(f1, f2)
        → StanceLink.StanceType = AtWar
        → PoliticalStagnation 削减
        → 敌方定居点/party 视觉刷新（变红）
      → CampaignEventDispatcher.OnWarDeclared

第 4 层：军团响应
  某方领袖（Hero）发起 Army 集结：
    → AIBehavior = PreGathering → Gathering
    → 成员 party 从王国各地向集结点移动
    → 总力量 ≥ 0.7 × 目标 → WaitingForArmyMembers
    → TravellingToAssignment（向敌方定居点行军）
    → Besieging / Raiding / Defending
    → 目标完成或 Cohesion 耗尽 → Disband

第 5 层：部队执行
  MobilePartyAi.Tick() 每 0.25 小时：
    → GetBestInitiativeBehavior() 扫描周围
    → 按 DefaultBehavior 导航
    → 发现敌人 → 主动出击/逃跑（EngageParty / FleeTo*）
    → DoNotMakeNewDecisions = true → 完全锁定（本 mod 接管用）
```

## 七、LivingWorldNpcs 与原版战略层的关系

### 7.1 本 mod 没有动什么

- ❌ 没有替换或 Hook `DefaultDiplomacyModel`
- ❌ 没有替换或 Hook `KingdomDecisionProposalBehavior`
- ❌ 没有替换或 Hook `PoliticalStagnationAndBorderIncidentCampaignBehavior`
- ❌ 没有替换或 Hook `RebellionsCampaignBehavior`
- ❌ 没有替换或 Hook `Army` 类的任何逻辑
- ❌ 没有替换或 Hook `MobilePartyAi.GetBehaviors()`
- ❌ 没有调用过 `DeclareWarAction` / `MakePeaceAction` / `GatherArmyAction` / `DisbandArmyAction`

**原版的王国 → 家族 → 军团 → 部队四层决策链完整保留，原样运行。**

### 7.2 本 mod 做了什么

| 层 | 本 mod 的操作 | 影响 |
|----|-------------|------|
| **王国层** | 被动读取 `FactionManager.IsAtWarAgainstFaction` 检查战争状态 | 战争期间世界事件概率 ×1.5 |
| **部队层** | 对特定 party 调 `SetPartyAiAction` + `SetDoNotMakeNewDecisions(true)` | 接管世界事件生成的 party 的行为 |
| **新增世界事件层** | `WorldEventSimulator` 每天运行，生成 Hero 驱动的局部冲突 | 14 种事件类型，动机扫描 + 随机回落 |
| **Mission 层** | `SuspendVanillaAI` / `ResumeVanillaAI` 接管 Agent 行为 | 城镇内 NPC 的 AI 控制权切换 |

### 7.3 关键理解：`SuspendVanillaAI` / `ResumeVanillaAI` 的作用域

这两个 API 操作的是 **Mission 层的 Agent AI**（城镇/战斗场景内的个体 NPC 行为），不是 Campaign 层的 `MobilePartyAi`。

```csharp
// SuspendVanillaAI：禁用 DailyBehaviorGroup → Agent 不再每 15 秒随机闲逛
dailyGroup.IsActive = false;       // 停掉行为选举
nav.SetTarget(null);               // 清空 AgentNavigator 目标

// ResumeVanillaAI：恢复原版 AI
agent.DisableScriptedMovement();   // 清除本 mod 的脚本化移动
dailyGroup.IsActive = true;        // 重新激活行为选举
dailyGroup.ForceThink(0f);         // 立即闲逛，不等 15 秒
```

跟大地图上的王国宣战、军团集结、party 行军决策**没有关系**。
