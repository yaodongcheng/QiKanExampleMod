## 二、地形层在文件里的样子

`scene.xscene` 末尾：

```xml
<terrain enabled="true" node_dimension_x="3" node_dimension_y="3" node_size="200.000" ...>
  <layers version="1">
    <layer name="grass_yellow">
      <summer is_enabled="true" name="grass_yellow" physics_material="grass" scale="7.000, 7.000" ...>
        <textures>
          <texture type="diffusemap"     name="ground2"/>
          <texture type="areamap"        name="ground_area_map_a"/>
          <texture type="normalmap"      name="ground2_bump"/>
          <texture type="specularmap"    name="none"/>
          <texture type="splattingmap"   name="none"/>
          <texture type="displacementmap" name="none"/>
        </textures>
        <layer_flags>...</layer_flags>
        <meshes/>
      </summer>
      <fall   is_enabled="true" name="grass_yellow" .../>
      <winter is_enabled="true" name="grass_yellow" .../>
      <spring is_enabled="true" name="grass_yellow" .../>
    </layer>
    ...
  </layers>
</terrain>
```

- **每一层 = 一个 `<layer>`**，里面固定四个季节子节点（summer / fall / winter / spring）。
- **季节是整套替换，不是叠加**：例如 `benchmark_battle_11` 的 `grass_a` 层，夏季贴 `ground_pebbles_a_d`、冬季换成 `snow_b_d`。
- 缺少贴图的季节节点 = 该季节不覆盖（沿用基础定义）。
- `is_flora_layer="true"` 的层是**程序化植被层**，不铺地面贴图；它的 `diffusemap` 多半是编辑器占位图 `editor_grid_8`（启用夏季的 226 个 `editor_grid_8` 层里，206 个是 flora 层）。
- `Modules/Native/ModuleData/terrain_materials.xml` 只有 **10 条编辑器预设**（`default` / `rock_cliff` / `desert_a` / `desert_b` / `desert_cliff` / `soil_b` / `flora_habitat_a` / `mud_cliff` 等），原版场景的层名绝大多数不在其中 —— 它只是编辑器调色板，不是运行期材质清单。

## 六、层名怎么读

- **无语义默认名**：`default`、`default_1..N`、`new_layer`、`first_material`、`flow`、`base`、`base_rock`、`detail_*` —— 编辑器批量加的，必须看贴图才知道是什么。
- **语义名（多为土耳其语，TaleWorlds 是土耳其工作室）**：`yol`=路、`kum`=沙、`tarla`=耕地、`toprak`=土、`tas`=石、`camur`=泥、`kar`=雪、`agac`=树、`cim`=草、`kaya`=岩石、`orman`=森林、`saman`=秸秆、`patika`=小径、`golge`=阴影。
- **按用途分三类**：地面（土/草/石/沙/雪/路/泥）、耕地（`plowed_field_a_d`）、植被层（`is_flora_layer="true"`，视觉由 flora 系统决定）。

## 七、口径与坑

1. **层名不是材质 ID**。同名 `default` / `grass` / `rock` 在不同场景对应不同贴图；复制场景时抄贴图 + `physics_material` + `scale`，不要只抄名字。
2. **只统计夏季会漏**。雪/干草/落叶是季节覆盖（4137 层里 1522 层至少有一个非夏季季节带自己的贴图）；全季节启用材质共涉及 121 张贴图。
3. **flora 层不是地面**。`is_flora_layer="true"` 的层用 `editor_grid_8` 占位图；把它当"地面材质"统计会虚高（启用夏季的 226 层里，206 层是 flora 层）。
4. **`terrain_materials.xml` 不是运行期清单**。它只有 10 条编辑器预设；原版场景真正用的是 `scene.xscene` 内联定义。
5. **大地图 `dirt` 的 physics 是 `burning_jar_small`**（原版数据，疑似笔误），照抄时改 `soil`。
6. **室内场景通常没有地形层**（35 个室内场景 0 层）；地牢大多也没有。
7. 场景层名大小写不统一（`Sand` / `sand` / `MUD_Snow`），按名字做批量处理时要用不区分大小写。
