# 骑砍2 音效系统 — 引擎能力与实现

> **本文写给"要给 mod 加声音"的人。** 全部结论均有出处：反编译（会标 DLL 与类型）、官方 XML 注释、或**本项目实机实测**（2026-10-10，钩索绳声 + 飞行风噪落地时验证）。
> 速查版在 [plans/rules/wheels.d/audio.md](../plans/rules/wheels.d/audio.md)（五步链路表）；本文是完整版：能力边界、API 全貌、实测坑。

---

## 一、结论先行（八条）

1. **引擎直接吃 WAV**（`.ogg` 也吃）——**不需要转格式**。已证可用的规格：16bit / 24bit · 44.1k / 48k · 立体声。
   证据：Taikou 火器 32 个 wav = 48k/24bit 实机验证；Shokuho 抽样 250 个里 240 个 = 44.1k/16bit 且正式发布中；我们自己的 7 个（16bit 立体声 44.1/48k）实机出声。
2. **🔴 没有音量 API**。`TaleWorlds.Engine.SoundEvent` 全成员里没有 `SetVolume`（反编译实证）。
   强度只能靠：**密度**（间隔）/ **分层**（同时叠几条）/ **素材响度** / **分类** / **距离**（3D 衰减）。
   ⇒ **"声音太小"的两条正解**（都能不重编译地改）：
   · ① **素材响度烘进 WAV**：`Scripts/gen_lwn_module_sounds.py`（压缩 → 缩放到目标短时 RMS → 前视限幅；
     幂等：从源目录重读重算，改目标值重跑）。实测有效：4 条本该"几乎听不见"的风声被拉起 12~14 dB、
     6 条风的响度差从 18.6 dB 收到 1.6 dB（2026-10-10）。
   · ② **换分类**：`mission_foley` 是**背景动效层**（护甲摩擦那类，混音上刻意压低）；
     `mission_combat` / `mission_siege_loud` / `mission_material_impact` 是前景层（火器枪声在 combat 档、实机够响）。
     改 `<module_sound sound_category="…">` 一行即可。
3. **🔴 2D 播放实测不出声**（本项目 2026-10-10 实机）：`is_2d="true"` + `CreateEvent(scene)` + 无位置 `Play()` = 全程静音，而**同分类（`mission_foley`）的 3D 事件同一条代码路径正常出声**。原因在 native、C# 层查不到。
   ⇒ **一律走 3D**；"自己身上的声音"= **3D + 每帧把位置跟到锚点**（锚点 = 玩家 `Agent.Main.Position`，玩家不在时兜底相机 `Mission.GetCameraFrame().origin`）。范本 `ExampleModVS/.../Flight/FlightWindFx.cs`。
4. **长音必须每帧跟锚点**：世界锚定的一次性声音，玩家一移动它就被甩在后面。实测口径：1.8 秒的阵风在冲刺 26 m/s 下会漂到 **45 米外**，尾巴被距离衰减吃掉。
5. **一次性声音只有两条播法**（都验证过）：`SoundEvent.CreateEvent(id, scene)` + `Play()`（本项目现行）；或 `Mission.MakeSound(...)`（native 注释推荐的一次性用法，本项目未改用它）。
6. **注册是三件套，缺一不响**：音频文件在 `ModuleSounds/` + 事件声明在 `ModuleData/module_sounds.xml` + **`ModuleData/project.mbproj` 里挂 `soln_module_sound` 行**。第三条最容易漏 —— 文件在、行没挂 = **一个都不注册**（Taikou 火器 2026-09-16 踩过：症状是"开火只剩引擎默认弩声"）。
7. **分类（`sound_category`）不合法 = 不播**（官方注释原话 "Sounds that dont have valid categories wont be played!"）。合法分类表见 §三。
8. **发布链还有第四处**：`package_mod.py` 的 `ITEMS` 必须含 `"ModuleSounds"`，否则**发布包丢音效文件**（本机测试看不出来，玩家装了没声）。

## 二、三条并行管线（别搞混）

| 管线 | 声明文件 | 加载方式 | 本项目现状 |
|---|---|---|---|
| **音效**（短音效，本文主角） | `ModuleData/module_sounds.xml` | **soln 体系**（走 `project.mbproj`，见 §五） | ✅ 在用（钩索绳声 / 飞行风噪 / Taikou 火器 / 剧情 BGM） |
| **音乐**（Psai 主题音乐） | `Music/soundtrack.xml`（`PsaiProject → Theme → Group → Segment → AudioData`） | soln 体系（`soln_soundtrack`） | ✅ 在用（Taikou 主菜单音乐；`PsaiCore.Instance` 播放，见 `Taikou/ModuleData/project.mbproj` 第 1 行） |
| **语音**（NPC 战斗喊话等） | `ModuleData/voice_definitions.xml` + `skins.xml` 的 `voice_types` | soln / XmlNode 体系 | ❌ **从未用过**（要做 NPC 语音才需要，见 §七） |

⚠️ **剧情 BGM 走的是"音效"管线不是 Psai**：Taikou 的 40 首 BGM（`01_DAIMYOU` … `40JINGLE`）全部声明在 `module_sounds.xml` 里（`campaign_bed` 分类），由 `Story/SystemCommands.cs` 的「ＢＧＭ變更」指令用 `SoundEvent` 播 —— 因为要的是"放一首、能停"的精确控制，Psai 那套是主题音乐引擎。两者可并存（互不干扰）。

## 三、`module_sounds.xml` 全字段（扫全部已装模块统计）

```xml
<!-- 可直接抄的现行写法（LWN 风噪）：3D + 前景分类 + 多变体 -->
<module_sound name="lwn_flight_wind"        <!-- 事件名：全局唯一，起名带前缀（lwn_ / tk_ / sho_…）防撞原版 -->
  sound_category="mission_combat"           <!-- 必填且必须合法，否则不播；foley = 背景层（刻意压低）别用 -->
  min_pitch_multiplier="0.9" max_pitch_multiplier="1.1">  <!-- 随机音高（Native/Artems 用过，我们未用） -->
  <variation path="lwn_flight_wind_1.wav" weight="1" />   <!-- 多变体：引擎按 weight 随机挑一条 -->
  <variation path="lwn_flight_wind_2.wav" weight="1" />
</module_sound>

<!-- ⚠️ 两条别踩：is_2d="true"（2D 实测不出声，见 §一.3，省略即 3D）· sound_category 乱填（不播） -->
```

**已见属性全集**（`name` / `path` / `is_2d` / `sound_category` / `min_pitch_multiplier` / `max_pitch_multiplier` + `<variation path weight>`）。
⚠️ **没有 `volume` 属性**；`min_distance` / `max_distance` 只有 CSDN 教程提过，**全部已装模块零使用**，未验证（运行期有 `SoundEvent.SetEventMinMaxDistance(Vec3)` 可改）。

**合法分类表**（抄自 `Native/ModuleData/module_sounds.xml` 的官方注释）：

| 分类 | 时长上限 | 用途 |
|---|---|---|
| `mission_ambient_bed` / `_3d_big` / `_3d_medium` / `_3d_small` | persistent | 场景环境音（火堆/火把/船吱呀） |
| `mission_material_impact` | ≤4s | 兵器交击类 |
| `mission_combat_trivial` | ≤2s | 护甲层等小点缀 |
| `mission_combat` | ≤8s | 受伤 / 弓弦 |
| `mission_foley` | ≤4s | 一般动效（⚠️ **背景层、混音刻意压低** —— 2026-10-10 实测"太小"，换 combat 后解决） |
| `mission_voice_shout` / `mission_voice` / `mission_voice_trivial` | ≤8s / ≤4s / ≤4s | 喊话 / 用力声 / 小用力 |
| `mission_siege_loud` | ≤8s | 爆炸 / 大动静（Taikou 火器 far 档用它） |
| `mission_footstep` / `_run` / `mission_horse_gallop` / `_walk` | ≤1~2s | 脚步 / 马蹄 |
| `ui` | ≤4s | 所有 UI 音 |
| `alert` | ≤10s | 警报钟等 |
| `campaign_node` / `campaign_bed` | persistent | 大地图据点音 / 大地图环境床 |
| `music` | persistent | 音乐流 |

## 四、播放 API 全貌（反编译 `TaleWorlds.Engine.SoundEvent` / `SoundManager` / `Mission`）

### `SoundEvent`（实例；本项目用 `CreateEvent` 这条路）

| 成员 | 说明 | 我们验过？ |
|---|---|---|
| `static int GetEventIdFromString(string)` | 名字 → id。**查不到 = -1**。应该缓存（官方注释明说避免运行期字符串操作） | ✅ |
| `static SoundEvent CreateEvent(int id, Scene scene)` | 建实例。⚠️ **`scene` 不能为 null**（这一版裸解引用 `scene.Pointer`）；想不定位用 `CreateEventFromString`（它有 null 守卫）或 2D 静态 API | ✅ |
| `static SoundEvent CreateEventFromString(string name, Scene)` | 按名字直接建（内部查 + 建，null 守卫） | ❌ |
| `Play()` / `PlayInPosition(Vec3)` | 播 / 在位置播 | ✅ `Play` |
| `SetPosition(Vec3)` | **每帧跟锚点就靠它**（§一.4） | ✅ |
| `SetVelocity(Vec3)` | 多普勒用（我们把速度喂进去能出多普勒，未试） | ❌ |
| `Pause()` / `Resume()` / `Stop()` / `Release()` | 停控。`Stop()` 会把 `_soundId` 置 -1 | 部分 |
| `IsPlaying()` / `IsPaused()` / `IsStopped()` / `IsValid` | 状态查询（**跟锚点的句柄靠 `IsPlaying()` 判生死**） | ✅ `IsPlaying` |
| `SetParameter(string, float)` / `SetParameter(int, float)` | FMOD 具名参数 —— **引擎级音量控制的唯一候选入口，未验证**（programmer sound 有没有可写参数不知道） | ❌ |
| `SetEventMinMaxDistance(Vec3)` | **设**这个实例的衰减距离（未用；Vec3 三分量谁管什么没写明） | ❌ |
| `GetEventMinMaxDistance()` | **读**衰减距离 —— 本项目用它做"听不见是不是被距离吃了"的诊断（§六.2），**Vec3 三分量语义仍未确定**（日志原样打三个数） | ✅ |
| `SetSwitch(group, state)` / `TriggerCue()` / `PlayExtraEvent(name)` | FMOD 高级功能 | ❌ |
| `static bool PlaySound2D(int/string)` | **专门的 2D 直播 API**（本项目没试过；考虑到 `is_2d` 实测不出声，要用先做 5 分钟实验） | ❌ |
| `static CreateEventFromExternalFile(programmerEventName, 文件路径, scene, is3d, isBlocking)` | 直接播一个外部文件（不经 module_sounds 声明）。CSDN 教程用它播旁白 | ❌ |
| `static CreateEventFromSoundBuffer(...)` | 从内存字节播（联机语音那条线在用） | ❌ |

### `Mission.MakeSound`（native 注释推荐的一次性用法）

```csharp
MakeSound(int soundIndex, Vec3 position, bool soundCanBePredicted, bool isReliable,
          int relatedAgent1, int relatedAgent2);                       // 官方 module_sounds.xml 注释里的范例
MakeSound(..., ref SoundEventParameter parameter);                     // 带 1 个具名参数
```
`SoundEventParameter`（`TaleWorlds.Engine`，struct）= **`string ParamName`（上限 32 字符）+ `float Value`** —— 一个具名浮点参数。
⇒ **如果哪天需要"音量/强度"旋钮，这里的 `ParamName` + `SoundEvent.SetParameter(name, v)` 是仅有的两个候选**（能不能用取决于 programmer sound 认不认这个名字，未验证；5 分钟实验可判定）。

### `SoundManager`（静态全局）

`SetListenerFrame(MatrixFrame[, attenuationPos])` / `GetListenerFrame()` / `GetAttenuationPosition()` · `SetGlobalParameter(name, v)` / `SetState(group, state)` · `PauseBus(busName)` / `UnpauseBus` · `CreateEvent(name, scene)` · `StartOneShotEvent(name, pos[, paramName, paramValue])` / `StartOneShotEventWithIndex` · 语音通话一族（`CreateVoiceEvent` / `StartVoiceRecording` / `UpdateVoiceToPlay`…，联机语音用）。

## 五、注册链路（为什么"文件在却没声"）

```
ModuleSounds/
    lwn_flight_wind_1.wav …             ← ① 音频文件（引擎标准目录；XML 的 path 只写文件名）
ModuleData/
    module_sounds.xml                   ← ② 事件声明（见 §三）
    project.mbproj                      ← ③ 🔴 <file id="soln_module_sound" name="ModuleData/module_sounds.xml" type="module_sound"/>
package_mod.py  ITEMS += "ModuleSounds" ← ④ 发布包白名单
```

- **为什么走 mbproj 不走 SubModule.xml**：`module_sounds` 属 **soln 体系**（与 `action_sets` / `skins` / `item_holsters` / `particle_systems` 同类）。引擎把**所有模块**注册到同一 soln id 下的文件**合并**后交给 native（`MBObjectManager.GetMergedXmlForNative("soln_module_sound")`）⇒ 多个模块（Native / Taikou / LWN）各写各的**新事件名是安全的纯追加**；**同名重复定义没试过**（同体系的 `action_sets` 有过"逐字拷贝 Native → KeyNotFoundException"的实机崩溃先例）⇒ **起名一律带前缀防撞**。
- **离线把守**：`Scripts/check_module_registration.py` 会报「soln 体系文件未挂 project.mbproj」（本项目已进体检）。
- **诊断金句**：静音时的第一件事是确认**事件名能不能解析** —— 本项目 `Combat/SoundFx.cs` 在第一次查不到时打一行
  `[SoundFx] 音效 'x' 查不到 —— 静音。检查 ModuleData/module_sounds.xml 是否声明、以及 project.mbproj 是否挂了 soln_module_sound 行`。

## 六、写法与模式（本项目现行，可直接抄）

**唯一入口 = `ExampleModVS/.../Combat/SoundFx.cs`**（`internal static class SoundFx`）：

| 方法 | 用途 |
|---|---|
| `Play3D(name, pos)` → 返回 `SoundEvent`（查不到/播不出 = null） | 世界里的定位音（抛出的绳）。**要"跟着走"的调用方留句柄** |
| `ListenerPosition()` | 相机位置（兜底锚点） |
| `TryResolve(name)` / `Describe(name)` | id 缓存解析 / 控制台回执（纯英文） |

**四个已验证的模式**：
1. **一次性定位音**（钩索绳声）：`SoundFx.Play3D("lwn_grapple_rope", launchFrom)`，忽略返回值。范本 `Combat/GrappleLogic.cs`（`ThrowInternal` 里 `_hook.Launch` 成功之后一行）。
2. **"自己身上的声音"**（飞行风噪）：3D + **每帧跟锚点**（见 §一.3/§一.4）。范本 `Flight/FlightWindFx.cs` —— 保存句柄列表 + `IsPlaying()` 判生死 + **场景守卫**（换场景只丢句柄**绝不碰已销毁的句柄**，同 `GrappleCommands` 体检板的口径）。句柄列表要有上限（范本 `MaxLive = 8`）。
   🔴 **多路调用者共用同一个调度器时**：速度低于门槛的那次调用**只解除"待发"标记、不推进计时器**（不要写"每帧把计时器封顶"）—— 否则两路各调一次会把节奏压成固定值。现行两路 = `PlayerFlightBehavior`（飞行模式，每帧喂，非飞行喂 0）+ `GrapplePull`（被钩索拽着飞，喂玩家位移速度）。
   🔴 **短事件必须给"强制起一阵"的口子**（`FlightWindFx.Kick()`）：只按速度密度播，遇上**又短又要速度达标**的动作（拉拽全场 ~1 秒、速度曲线中后段掉到门槛以下）会**一阵都凑不出来** —— 计时器只在"速度达标"的帧里走，累计时长不够。事件型触发（"起拽那一刻"）直接 Kick，不受门槛管。
   🔴 **3D 音效听不见时先量距离**：听者 = 相机，本项目机位常常在身后几米（拉拽机位臂长 **8 米**）⇒ 声源锚在玩家身上时，**相机↔声源距离**就是实际衰减距离。诊断 = `SoundEvent.GetEventMinMaxDistance()`（`SoundFx` 首次播放时打一行 `[SoundFx] '<名>' 衰减距离 vec=(…)`），拿它跟相机距离对比即可判定"是不是被衰减吃掉了"。
3. **强度无音量可调 ⇒ 用密度**：范本 `FlightWindFx` 的速度 → 间隔映射（悬停无声 / 3 m/s ≈ 1.6s 一阵 / ≥22 m/s ≈ 0.45s 一阵 / 每阵 ±30% 抖动防节拍感）。素材是"带衰减包络的阵风"（不是无缝循环）时，**重复单次比硬做循环自然**。
4. **素材响度规整**（"太小"的第一正解）：`Scripts/gen_lwn_module_sounds.py` = 生成器（源目录 → `ModuleSounds/`），
   链路 = **压缩（压峰均比）→ 缩放到目标短时 RMS → 前视限幅**（封顶 −1 dBFS）。
   🔴 **两个必踩的坑**（都在里面注释了）：① 压缩器阈值**以下**必须原样（写成 `thr + over/ratio` 会把安静段顶到阈值电平）；
   ② 包络检波**追不上单样本尖峰** ⇒ 必须**前视限幅**（`maximum_filter1d` 开 3 ms 窗），否则一放大就顶破封顶、响度提不上去。
   指标口径 = **50 ms 短时 RMS 的滑动最大值**（≈听感响度）；目标参考：一般音效 −12~−18、前景重音 −8~−10 dBFS。

**验收命令**（每加一个音效就该配一条）：`custom.grapple sound` / `custom.flight sound` —— 试听 + 打印状态（事件名 / 开关 / **能不能查到**），静音故障一眼定位。

## 七、没挖的（后来人接手清单）

| 项 | 入口 | 备注 |
|---|---|---|
| **音量控制** | `SoundEvent.SetParameter(name, v)` / `Mission.MakeSound(..., ref SoundEventParameter)` | 唯一两个候选；programmer sound 认不认参数名未知，**5 分钟实验可判定** |
| 2D 的正确姿势 | `SoundEvent.PlaySound2D(id)` / `CreateEventFromString(name, null)` | `is_2d` 那条路已实测死；这两个 API 没试过 |
| 循环音 | persistent 分类 + **无缝循环素材** | 我们没做过；素材必须真无缝（阵风类别硬做） |
| 外部文件直播 | `CreateEventFromExternalFile` | CSDN 教程用它播旁白；路径解析基址未验证 |

| 多普勒 | `SoundEvent.SetVelocity` | 快速移动的声源（飞行的风如果做成循环音）可试 |
