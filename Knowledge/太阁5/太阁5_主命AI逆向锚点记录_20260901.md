# 太阁5 主命/AI 逆向锚点记录（exe 盲探 2026-09-01）

> 目标：主命系统 / 战略AI / 互动玩法的**代码入口锚点**。方法：SJIS 中文词在 `Taikou5.exe`（3.47MB, x86, 2004）中的命中 = 菜单/UI 数据段；从字符串锚点展开反汇编。

## 已定位锚点（TAIKOU5WIN exe）

### 🌟 核心发现：exe 0x33F8E0-0x341000 = 主命/战略/商人 UI 机制文案段（内容实证）

**格式串**：`%s(%s)` ×8 + `%3d > %3d` + u32 数值序列（90/21/25/19/…/5000/3000/2000/8000/748/9396）——面板显示与数值校准表（0x33FD38 前后）。

## 新进展（2026-09-01 晚）：壳识别 / 码表 / 动态条件

- **Taikou5.exe 壳**：无已知壳签名（UPX/ASPack/PECompact 均无），但 EP=0x1000 处 `E9 7B C7 17 00` 大跳 → **自解压壳**。静态 xref 均不可用（VA/文件偏移双向搜引用 0 命中）→ **战略 AI 函数必须动态入手**（运行时内存、修改器/DLL 注入）。
- **高亚男 GameShare.dll** = Delphi 外挂（49KB，Borland RTL 签名）——**它内部就是"人物/城/忍者/水岩 结构图"**；本机静态扫描未提取到偏移常量（无运行时上下文），需动态反编译或运行挂载。
- **战机入口已备**：上述文件读「人物/城」时用它的内存地址偏移；下一步 = 针对「主命任务下发」时在修改器上观察内存变化。

## 环境结论（诚实边界）
- 静态逆向对 Taikou5.exe = **触顶**（壳 + 自解压）
- 动态路径 = 跑游戏+挂修改器/断点——**需要一台能跑 Taikou5 的 Windows 环境**（你本地有,我没法操作游戏进程;-）但可借助你手上「内存修改器」直接看结构。

## 已知结构（可信）
- **exe 内嵌 SJIS 中文文本**（繁体版）：菜单/面板文案可见（面版式数据 `%s(%s)` + 数值 u32 序列）
- 位于 RVA 0x33Fxxx 段（文件尾段）——**此为「游戏 UI/数据串表」区域**

## 下一步展开（下轮继续）
1. 0x33Fxxx 段整体 dump → 菜单命令列表（「外交」「行商」「茶会」…一一列出）→ **主命/大项菜单总表**
2. 用 `0x88 0x13` 等 u32 数值做**交叉引用**：「00 88 13 00」在代码段的 `cmp reg, imm` / `jcc` 中找 → 数值被引用处 = 判定逻辑入口
3. 单挑/合战/茶会等**玩法入口**：搜「演武」/「茶盃」等 SJIS 词（下轮扩词表）
4. 工具：本机尚无 Ghidra 安装（需要 JDK）；先用 objdump/字符串法做锚点图，按需再上 Ghidra
