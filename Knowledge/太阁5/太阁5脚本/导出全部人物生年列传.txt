// ===================================================================
// 用途：全量导出太阁5所有角色的 出生年 + 列传（生卒年文本 + 列传正文）
// 原理（语法全部取自官方剧本 / 官方测试用例，非猜测）：
//   容器設定:(人物,無效,無效)                 = 全量人物容器（同 导出全部角色ID.txt，已跑通）
//   容器選擇:(人物Ａ,先頭) + 容器清理:(消去,1)  = 逐个取人物对象
//   代入ａ:(人物Ａ.人物番號)                   = 人物番号（database.xml 人物屬性 id=0）
//   代入ｙ:(人物Ａ.生年)                       = 出生年（数值；0 = 该人物无生年数据）
//       官方先例：劇本/獨立劇本/靈魂穿越.txt「代入ｙ:(人物Ｂ.壽命)+(人物Ｂ.生年)」
//   文字列設定:(文字列Ａ)(人物Ａ.列傳生卒年)    = 生卒年文本（如 1538～1570；空 = 无）
//   文字列設定:(文字列Ｂ)(人物Ａ.列傳)          = 列传正文（空 = 无；汎用NPC/无卡角色多无列传）
//       官方先例：腳本/測試用例/測試人物列傳.txt（读的就是这两个属性）
//   [[<人物Ａ>]]                              = 人物对象插值 = 人物名字
//   日誌:[[...]]                              = 输出到 E:\TKHACK\log\ 日志
//       文字列变量可插值，先例：劇本/測試事件/撲克遊戲測試.txt「日誌:[[玩家牌：<文字列Ａ>]]」
// 用法：tkhack 事件管理 → 添加事件 → 加载本文件 → 大地图上移动一格即触发 →
//   去 E:\TKHACK\log\ 抓日志行（DX 版文件名 tkhack-dx-dll-<日期>.log，有效行形如 "Log: BIO|..."）。
// 输出格式：BIO|序号|人物番号|名字|生年|生卒年|列传正文
//   🔴 列传正文含换行时（原文里的 \n）会跨多行——解析规则：
//      凡以 "BIO|" 开头的行 = 一条新记录；紧随其后不带 "BIO|" 的行 = 上一条列传的续行，拼接即可。
//      列传正文 = 第 6 个 "|" 之后的全部内容（正文里若出现 | 不影响解析）。
//   判定空值：生年=0 且生卒年/列传皆空 = 该人物确实没有列传数据（汎用NPC/无卡角色），不是导出失败。
// 可选：想连带导出元服年，在 代入ｙ 那行下面加
//   代入ｇ:(人物Ａ.元服年)
//   并把 日誌 那行改成 [[BIO|<ｋ>|<ａ>|<人物Ａ>|<ｙ>|<ｇ>|<文字列Ａ>|<文字列Ｂ>]]
//   （此时列传正文 = 第 7 个 "|" 之后的全部内容）
// ===================================================================
