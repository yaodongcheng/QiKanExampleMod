// ===================================================================
// 用途：全量导出太阁5所有据点的大地图坐标（tkhack 运行时导出）
// 原理：
//   容器設定:(據點,無效,無效)         = 全量据点（不按类型、不按番号过滤）
//   容器選擇:(據點Ａ,先頭)+容器清理   = 逐个取据点对象
//   據點Ａ.橫座標 / 據點Ａ.縱座標      = 据点大地图坐标（tkhack v2.4.20.39+ 属性）
//   據點Ａ.據點類型                   = 据点类型（原版据点容器按此属性筛选，见官方事件）
//   日誌:[[...]]                      = 输出到 tkhack 日誌（一行一条，变量可插值）
// 用法：tkhack 事件管理 → 添加事件 → 加载本文件 → 大地图上移动一格即触发 → 去
//   E:\TKHACK\log\ 抓日志行（日誌指令写在哪就抓哪个文件，跑一次即知）。
// 输出格式：序号|据点名称|据点类型|横座標|纵座標（一行一个据点）
// 参考范本：地圖事件測試.txt（据点容器全量枚举 + 坐标读取 + 日誌）
// ===================================================================

事件:導出全部據點座標{
    屬性:一次
    發生契機:移動畫面表示後(無效)
    發生條件:{
    }
    執行:{
        容器設定:(據點,無效,無效)
        代入ｎ:(容器記錄數)
        代入ｋ:(0)
        條件循環:(容器記錄數)!=(0){
            代入據點Ａ:(無效)
            容器選擇:(據點Ａ,先頭)
            容器清理:(消去,1)
            代入ｘ:(據點Ａ.橫座標)
            代入ｙ:(據點Ａ.縱座標)
            代入ｔ:(據點Ａ.據點類型)
            代入ｋ:(ｋ)+(1)
            日誌:[[<ｋ>|<據點Ａ>|<ｔ>|<ｘ>|<ｙ>]]
        }
        自語:[[全部據點座標已寫入日誌，共<ｎ>個。]]
    }
}
}//腳本
