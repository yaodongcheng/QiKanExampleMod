// ===================================================================
// 用途：全量导出太阁5所有角色的人物番号（ID）+ 名字（tkhack 运行时导出）
// 原理：
//   容器設定:(人物,無效,無效)      = 全量人物容器（官方事件用 5 处，含死亡/事件人物/町人）
//   容器選擇:(人物Ａ,先頭)+容器清理 = 逐个取人物对象
//   代入ａ:(人物Ａ.人物番號)        = 人物番号（官方属性：武田劇情促成/上杉劇情促成/靈魂穿越/基礎宏 等 50+ 先例；
//                                    测试表明人物番号与人物对象同值可比（場合分歧:(人物::武田信玄) 直接吃番号），
//                                    但卡系统存在对象值≠卡番號（偏移370）的坑，故统一取属性不走对象值）
//   [[<人物Ａ>]]                   = 人物对象插值 = 人物名字
//   日誌:[[...]]                   = 输出到 tkhack 日誌（一行一条，变量可插值）
// 用法：事件管理 → 添加事件 → 加载本文件 → 大地图上移动一格即触发 → 去
//   E:\TKHACK\log\ 抓日志行。
// 输出格式：人物番号|人物名字（一行一个角色）
// 如需只导出存活人物：在 容器設定 之后加两行
//   容器篩選:(人物,死亡標誌,0)
//   容器篩選:(人物,出現標誌,1)
// ===================================================================

事件:導出全部角色ID{
    屬性:一次
    發生契機:移動畫面表示後(無效)
    發生條件:{
    }
    執行:{
        容器設定:(人物,無效,無效)
        代入ｎ:(容器記錄數)
        代入ｋ:(0)
        條件循環:(容器記錄數)!=(0){
            代入人物Ａ:(無效)
            容器選擇:(人物Ａ,先頭)
            容器清理:(消去,1)
            代入ａ:(人物Ａ.人物番號)
            日誌:[[<ａ>|<人物Ａ>]]
            代入ｋ:(ｋ)+(1)
        }
        自語:[[全部角色ID已寫入日誌，共<ｎ>個。]]
    }
}
}//腳本
