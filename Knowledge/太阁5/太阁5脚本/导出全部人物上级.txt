// 用途：全量导出太阁5「每个人的直接上级」——此行回答三件事：
//   ① 此人是直属还是陪臣（看 立場 一栏：當主 / 直臣 / 陪臣 / 寄騎 / 其他 / 無效）
//   ② 他的直接上级是谁（看 上司 一栏）
//   ③ 再往上是谁（看 當主 一栏 = 顶头大名）→ 三段链条：自己 → 上司 → 當主
//
// 属性出处（全部查 E:\TKHACK\database\database_dx.xml 的「人物屬性」表，非猜测）：
//   立場         id=12  valueType=立場┇列舉  （當主0 / 直臣1 / 陪臣2 / 寄騎3 / 其他4 / 無效5）
//   所屬上司     id=18  valueType=人物   ← 直接上级（本脚本的主角）
//   所屬當主     id=1   valueType=人物   ← 顶头当主
//   所屬勢力類型 id=13  列舉（大名家0 / 商家1 / 忍者眾2 / 海賊眾3 / 浪人4）
//   所屬大名家14 / 所屬商家15 / 所屬忍者眾16 / 所屬海賊眾17 / 所屬據點11 / 人物番號0
//
// 🔴 坑（2026-09-11 实测）：**空字段会打出「槽位默认值」，不是空**
//   所屬上司 / 所屬當主 为空时，引擎返回「无效对象」，直接插值会打出固定垃圾值：
//     · 人物槽  → 「门卫」（实测 当主 69 行 + 其他 686 行 全部如此，零例外）
//     · 大名家槽 → 「一宫家」（实测 1304 行中 1003 行如此）
//   故本脚本**不裸插值**：先用 立場 / 所屬勢力類型 分流，只在真有值时才取对象，否则写「无」。
//   判据（实测零例外）：立場 = 直臣/陪臣/寄騎 → 上司与當主必有值；立場 = 當主/其他/無效 → 必为空。
//
// 语法出处（逐条都有先例，非猜测）：
//   容器存取:(保存) / 容器存取:(恢復) = 借用「全量人物容器」去反查某人手下时，先存外层进度、用完还回来
//       先例：劇本\青藤語\花之御所\DX\花之御所-优昙花开之时.txt:139 存 → 嵌套建容器 → :293 恢復

//       先例：同文件多处「容器篩選:(人物,所屬上司,明智光秀)」「容器篩選:(人物,所屬上司,織田信勝)」
//   容器篩選:(人物,立場,2) = 在上面基础上再筛出陪臣（2 = 陪臣；数字写法先例「容器排除:(人物,立場,2)」）
//   ⚠️ 先 容器設定:(人物,無效,無效) 再 容器篩選 —— 两步都逐字有先例，不写「容器設定:(人物,所屬上司,X)」（无先例）
//   代入ｙ:(狀況::年) / 代入ｚ:(狀況::劇本) = 当前年 / 当前剧本号
//       官方先例：劇本\水落清秋\三好劇情重構.txt「代入ａ:(狀況::劇本)」「調查:(狀況::年)>=(1553)」
//                 劇本\測試事件\編譯測試\代入.txt「代入ｂ:(狀況::月)」「代入ｃ:(狀況::日)」
//       🔴 剧本号对照（实证，非猜测）：原版 0~5 = 六章；DX 追加 6/7/8。

//           + 劇本\測試事件\插件測試\青藤语…上泉信綱.txt「調查:(狀況::劇本)!=(7)//不是夢幻之章」）。
//          其余号未逐一实证 → 本脚本只打号不打章节名，靠 年 读；跑一次各剧本即可补齐对照。
//   容器設定:(人物,無效,無效) + 容器選擇/容器清理 = 全量人物容器（同 导出全部角色ID.txt，已跑通）
//   代入人物Ｂ:(人物Ａ.所屬上司) / 代入人物Ｃ:(人物Ａ.所屬當主) / 代入大名家Ａ:(人物Ａ.所屬大名家)
//       官方先例：資源\官方事件源文件解密\EFF0C300.evm.decompiled.txt「調查:(人物::林秀貞.所屬上司)==(人物::織田信勝)」
//   場合別:(人物Ａ.立場){ 場合分歧:(N){ ... } } = 把枚举打成文字

// 输出格式（| 分隔）：**每条人物行前缀带年份**，循环前另打一条头行标明剧本号

//
// 部下 / 陪臣 两栏怎么算的：
//   · 部下 = 「所屬上司 == 此人」的人数（直接部下总数，不分立场）
//        对当主 = 他的直臣数；对城主/国主 = 挂在他名下的陪臣数
//   · 陪臣 = 上述部下里、立場为陪臣的人数
//   ⚠️ 性能：这两栏要给每个人反查一遍全量人物容器（1300 人 × 2 次全量筛选）。
//      嫌慢就把那 6 行（容器存取…代入ｅ）删掉，并把 日誌 里的 |部下:<ｆ>|陪臣:<ｅ> 去掉。
//
// 怎么读这张表：
//   · 立場=直臣  → 直属大名。实测上司 = 當主 本人
//   · 立場=陪臣  → 陪臣。上司 = 他直接侍奉的那位（城主 / 国主），當主 = 再往上的大名
//                  → 完整上级链 = 上司 → 當主（实测 10 行全部「上司 ≠ 當主」）
//   · 立場=寄騎  → 主君仍是當主，但日常听「寄到的城主」指挥 → 读法同陪臣，看 上司 栏
//   · 立場=當主  → 本人就是一家之主，没有上级（上司 栏 = 无）
//   · 立場=其他  → 无主（浪人 / 汎用NPC / 已死亡槽位），上司 栏 = 无
//   · 立場=無效  → 空槽位，同上
//   · 找「谁手下有一帮陪臣」→ 直接按 陪臣 栏降序排；找「谁在中间层带人」→ 陪臣>0 且 立場=直臣 的多半是城主/国主
//   ⚠️ 欄位显示 "?" = 该枚举值落在预期之外（立場 不在 0~5 / 勢力類型 不在 0~4），属数据异常信号。
//
