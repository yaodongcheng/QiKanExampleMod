# 太阁5 势力编号体系 与 ForceTaikou 校验经验（2026-09-01）

> 会话产物固化：`Knowledge/太阁5/骑砍2织丰角色ID对应/csv/ForceTaikou.csv` 的构建规则与本轮发现的编号方法论。
> 结论优先；细节证据见各节。**下个会话重构/扩展该表前先读本文。**

## 一、编号体系（三层四套，搞不清必错）

| 编号 | 公式/范围 | 性质 | 用途 |
|---|---|---|---|
| ①专属番号 | 当主人物番号 + 70（织田家 265） | `xxＡ.xx番號` 属性字段值 | 游戏内属性读取 |
| ②統一勢力番号 | 当主人物番号 + 120（织田家 315）：大名段 120-919 / 商家 920-944 / 忍者 950-961 / 海贼 965-978 | **database.xml 全库唯一**；专属番号在商家/忍者段会撞号（56=小西屋/52=风魔众），**必须用统一号做身份** | ForceTaikou.TK5_ID 值域 |
| ③快照 force_id | 0-99 每时代重排 | **漂移**（织田家 1554→19、1598→10；德川 25→40），只能调试 | ⛔ 禁止当身份 |
| ④织丰 Kingdom ID | `oda`/`tokugawa`/`honjo` 小写罗马 | 织丰 mod 王国键 | ForceTaikou.ID 值域 |

### 关键规则（均已按用户拍板落实）
- **官方大名家实体 = 当主人**，无"家"独立编号：`統一號 = 当主人物号 + 120`（验证锚点：信长 315=120+195、家康 626=120+506、信玄 569=120+449）
- **TK5_ID 按「当主本姓」归属**：编号随人走——真田昌幸(479)只能归真田家，武田家只有 信玄/胜赖等（567-573）；一行 = 该家历代当主实体全集，多值 `|` 连接，**不可按"快照当主名"塞入别家**
- **改名族并归**：羽柴家→丰臣家（637|638 共享，别名补）、长尾家→上杉家（Kongdom uesugi 唯一化）；改名前名进别名列，不建独立行
- **官方字形变体黑白桥**：畠山↔田山（官方中文写作田山）、阪田↔坂田（935）、畠山/双形；人名 FirstName 缺时用名前缀兜底（小野寺/姊小路/津轻）
- **多值纪律**：`|` 连接（编号|编号 与 Owner 换主一一对应）；铁律 24 半角竖线

## 二、三层存在链：问"有没有"必须指明层

| 层 | 载体 | 例 |
|---|---|---|
| 词表层 | keywords.xml（全域词库） | 浴池屋/风吕屋 **有**（町设施 token） |
| 数据库层 | database.xml（类型/枚举/实体定义） | 商家 25、忍者 12、海贼 14、砦 208+（柏崎砦=260） |
| 快照层 | era_v2/{1554-1598}/forces|cities|persons.csv | 势力按年代增减，商号 13→24 家轮换 |

- **"词表有" ≠ "势力有"**：浴池屋/石头屋等 18 家 = 町设施类型（无势力实体）；官方全库 0 命中
- **"官方有" ≠ "剧本用"**：末吉屋(938)/柏崎砦(260) = 官方定义在、六代剧本从未登场（Owner 全 `-`）
- **"织丰有" ≠ "官方有"**：本庄家（织丰原生 Kingdom honjo，官方无当主实体）；真田/二阶堂/三木/少贰/一宫 = Kingdom.csv 补造 IsShokuho=0（剧本层虚拟王国声明，**不要在织丰引擎注册新王国**——据点增删研究已证引擎注册器 NRE 不可行）

## 三、校验法（复用于任何 TK5 表）
1. **OpenCC 双端 t2s**：s2t 单向变体化会假漏（栗→慄、淀→澱、托↔託），两侧都转简体再比 → 零误报（hero 5→2、item 20→19 的教训）
2. **双向校验**：行内编号序列 ↔ Owner/当主序列 互推；模板行（模板NPC=1/pronoun）**剔除**映射（茶屋店主=模板"忍者"撞名之坑）
3. **先读磁盘再下结论**：IDE 缓存/旧快照曾致两轮误报空值；`git status`+重新读取为准
4. pykakasi 读音 slug 陷阱：简体汉字读不准（伊贺众→`i`），须用**官方繁体名**做源，退化名（钵屋/户隐/羽黑/透波）手工校正（hachiya/togakushi/haguro/suppa）
