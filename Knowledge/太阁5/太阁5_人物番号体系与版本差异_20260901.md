4. **🔴 AppearID（外观ID）≠ 人物番号——另一把钥匙**（2026-09-01 重申）：

| | 人物番号 | 外观ID（AppearID） |
|---|---|---|
| 什么是它 | 游戏内人物数据表编号（武将/町人/泛用……） | 外观/立绘资源槽编号（BUSTUP 目录「编号_姓名」0-1291，共 1292 槽） |
| 出处 | `database.xml`/`database_dx.xml` 人物段；运行时 `人物Ａ.人物番號` 属性 | `E:\taikou5\TaikouImage\BUSTUP` 目录、`character_1292_名单.csv`、编辑器显示列表 |
| TaikouHero 列 | —（无） | ✅ 「外观ID」列（**原列名「TK5编号」已于 2026-09-01 改名**） |
| 史实段 | 信长 195／家康 506 | 信长 195／家康 506（**顺排巧合一致**） |
| 追加段 | 阿市 1019（原版）／1181（DX） | 阿市 1049（=人物番号+30 的槽偏移实证） |
| 含模板 | 无 | 1000+ 大量「无卡海贼」等模板占位（1292 槽=编辑器全套外观，非真人物） |

   **判别法（不会搞错）**：立绘目录/编辑器列表里看到的编号 = 外观ID；游戏内人物对象/剧本城表城主字段/快照槽 = 人物番号。两套**禁止互当**。

## 四、执行纪律（三条，防串号）

1. **写编号一律写名字**——tkhack 事件/脚本里引用人物（`代入人物Ａ:(阿史)`、`場合分歧:(人物::武田信玄)`）走名字，**编译器按运行版本自动解析**，两版都对。**禁止手写数字番号硬怼**。
2. **运行时取数 = 容器 + `人物Ａ.人物番號` 属性**——游戏是什么版本，就返回什么版本的真实番号，零配置适配（本会话两版导出脚本均按此设计）。
3. **数字番号只作为「已标注版本的对照表」锚**——任何列数字番号的 CSV/表，表头必须写清是原版还是 DX。
