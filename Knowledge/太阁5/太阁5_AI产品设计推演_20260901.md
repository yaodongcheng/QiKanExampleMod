## 0. 太阁5 的 AI 是什么（一句话）

**太阁5 的 AI = 一个「状态会跑、城市属于人、人物会做事」的世界模拟器。** 玩家是某个人物，其余所有人/势力/城市由 AI 驱动。设计上分 4 层：

| 层 | 职责 | AI 决策内容 | 证据 |
|---|---|---|---|
| 世界层 | 时代状态（6 年代快照） | 谁活着、谁在哪、城归谁 | 【实锤】Snr 全量表（person/force/city） |
| 势力层 | 大名/首领/城主战略 | 方针 → 目标 → 距离判定 → 行动 | 【实锤】「方針ターゲットからの距離？」 |
| 人物层 | 家臣/商人/忍者/海贼 | 主命（被分配/主动）、行商、门弟 | 【实锤】主命面板全案 |
| 玩法层 | 合战/单挑/忍海行动 | 军令指令（秘技选择） | 【实锤】秘技攻击谱系 |

## 1. 主命系统设计（【实锤】exe 0x33FE44-0x33FEC8）

### 1.1 概念
主命 = **统治者给部下的「月度任务」**。玩家（大众部）或 AI 大名给家臣下发。游戏的主命面板露出三种类型+一个状态判定：

```
主命 [+ 主命同行者]         ← 主命面板：下发 = 指定主命 + 选同行者
依頼主命                    ← 普通任务（内政/军事/外交…）
友好依頼主命                ← 友好型请求（对方倾向答应）
指名主命                    ← 指名给特定人物
主命発生可能                ← 面板按钮/条件提示：哪些主命当前可发生
```

### 1.2 设计推断（【推断】，用户可游戏内核对）
- **主命三要素**：类型（内政/军备/外交/茶会/…）、执行人（家臣）、目标（城/人物/物品）
- 「主命発生可能」= 发生条件门控：目标城市存在、目标人物在场、势力势力关系程度满足 → 才列为主命选项
- 「友好依頼」= 低压力请求（亲密度/友好度门槛）；「指名」= 直接点名（家老/重臣）

## 2. 战略 AI 设计（【实锤·锚点】「方針ターゲットからの距離？」 0x33FF30）

### 2.1 决策链（从锚点文本推出）
忍者势力的战略逻辑（同构推及大名/海贼）：

```
[方针] 选择 → 决定「方針」（目标类型：攻略/袭扰/暗杀/谍报…）
   ↓
[目标] ターゲット 选择 → 每个备选目标（城市 / 人物）
   ↓
[判定] からの距離？→ 距离判定（近=先动）—— 战术优先级核心规则！
   ↓
[执行] 派兵/刺客/谍报…
```

【推断】`距離` 判定 = 战略 AI 的默认优先级权值：**目标越近越优先**（成本低、补给近）。这是太阁5「近畿大名互相打得凶/偏远势力龟缩」现象的设计根因。

### 2.2 大名战争逻辑（【推断】+ 世界表为输入）
- 人口/兵力/粮食 = 城表字段（我们已解出每个城当年的兵力/粮/金）→ 战略计算输入
- 大名家每月按「金钱-兵力-土地」三轴决定征伐/内政/外交（证据：势力功绩表字段同构——见 §3）

## 3. 商人玩法/AI 设计（【实锤】0x33F8E0-0x33F924）

### 3.1 商人面板 = 业绩对比表
```
商人司 ユーザー功績     ← 玩家业绩
     他勢力 功績       ← AI 商人势力业绩（玩家最比对象！）
```
商家 = **与 AI 商家比拼功绩**（买低卖高 → 业绩），「他勢力功績」= AI 对手动态数字——**商人玩法的对手 = AI 商家的逐月业绩序列**。

### 3.2 商机判定（行商チェック / 宿屋チェック）
- 行商チェック：此城行商（买卖货物）成功率判定
- 宿屋チェック：宿屋事件/情报判定（睡一觉触发事件，绑定城与人物）
【推断】两者 = 城数据（买卖价、町规模）+ 人物（宿屋老板）双表联动的「机会生成器」：每个城每天判定一次，命中 → 生成行动选项。

## 4. 合战军令 / 秘技系统 AI（【实锤】0x329E08-0x329EED 全谱系）

### 4.1 战斗指令空间（武将可执行的「军令=秘技」）
```
主命(战斗) 人争：
  秘技 単体攻撃：→ 单体目标（一刀/一品）
  秘技 毒単体攻撃   ← 上毒
  秘技 麻痺単体攻撃 ← 麻痹
  秘技 直線貫通攻撃 ← 直线穿透（一列）
  秘技 三方複数攻撃 ← 3 方（扇形）
  秘技 四方複数攻撃 ← 4 方（四面）
  秘技 円軌道複数攻撃 ← 环形
  秘技 ランダム複数攻撃 ← 随机多个
  秘技 全範囲複数攻撃 ← 全屏
  秘技 忍犬複数攻撃 ← 忍犬（独特单位攻击）
  …返し技攻撃（反击技）
```
【实锤】11 种攻击模式 = 战斗单位的「行为型」——**AI 武将的战斗决策 = 从这 11 种中选择何时放哪种**（与武器/技能卡绑定）。

### 4.2 战斗 AI 设计推断（【推断】）
- AI 判定输入：目标数量、距离、自身武力/技能、士气（战场集气→放秘技）
- 优先序：能贯通/全体时先清小兵→单体点杀大将
- 玩家版 = 同表同列（平权设计：AI 与玩家同一套军令菜单）

## 5. 门派/道场 AI（【实锤】「門弟が人増えた！」0x33FB98）
- 弟子增加事件 = 门派势力增长的 UI 反馈；门派 AI = 每月弟子成长判定（入门概率/徒弟数）
【推断】概率权重 = 主角名气（武力/剑术卡）、所在町繁荣度。

## 6. AI 的世界状态输入（【实锤】已全量破解）

| 输入 | 数据源 | 作用 |
|---|---|---|
| 人物归属/身份/上司/忠诚/野心/俸禄 | 六年代 persons.csv | 人物 AI 的主观能动性（野心高→谋反/自立） |
| 势力当主/成员/兵力 | forces.csv | 势力 AI 的行动预算 |
| 城：城主/兵力/粮食/金钱/训练/士气 | cities.csv | 城市 AI 的攻守势 |

**这条链的意义**：太阁5 的世界 = 数据实时驱动。任何「AI 决策」= 读以上字段 → 判距离/数值 → 执行。**我们已经把「世界输入层」100% 破解了**（6 年代全量），剩下的只在「决策代码层」里补权重。
