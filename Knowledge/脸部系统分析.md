# 骑砍2 脸部系统分析（含自定义换脸管线）

> **最终结论（2026-08-29）**：换脸目标经 26+ 版本实测判定为**贴图替换不可达**——
> 五官层级不在 diffuse（原生=FaceGen 合成层；织丰=独立子网格/材质 eye/mouth/brow）。
> 全部踩坑与"不再重走"清单见 **`Knowledge/换脸踩坑与结论-2026-08.md`**。本文事实部分仍有效。

> 状态：预研完成 + 管线工具链打通（2026-08-28/29，基于 v1.2.12 与 v1.5.2 双安装实测）。
> 工具实现见 `tools/face-pipeline/`（解包/打包/渲染/测量/拼脸全链路脚本）。
> 本文档沉淀"事实与结论"，实验过程不展开。

## 一、脸是怎么生成的（为什么丑）

1. **角色只存一串 FaceKey 数字**：`<BodyProperties key="...">` 含 320 个变形权重 + 年龄/体脂。
   JSON 里 `GetParamsFromKey` → `FaceGenerationParams`（KeyWeights[320]，最多 320），见 CSDN #16。
2. **运行时 FaceGen 生成头网格 + 合成脸贴图**：托管壳 `TaleWorlds.MountAndBlade.FaceGen : IFaceGen`
   （`TaleWorlds.Core.FaceGen` 静态门面 + `IFaceGen`），核心生成在 native 引擎（TaleWorlds.FaceGenImpl?）。
   `GetBodyPropertiesWithAge`（年龄变化）、`FaceGen.GetBaseMonsterFromRace`（怪物模板）等 API 见
   `TaleWorlds.MountAndBlade.dll` `FaceGen` 类。
3. **皮肤（skin）矩阵**：`Modules/Native/ModuleData/skins.xml` 按 race × gender × age 选 skin 节点，
   skin 节点指定 `face_meta_mesh`（头网格）、`body_meta_mesh`（身体）等 + 全部 deform_keys（320 权重的范围定义）。
4. **丑的根源**：① 大头网格全游戏就一个（男 `head_male_a` / 女 `head_female_a`），五官靠 320 个
   "顶点挤捏"往**统计平均骨架上套**；② 脸部贴图由 FaceGen 从样本脸库**混合合成**（`face_cache` 缓存），
   混合结果永远"平均脸"；③ 低模 + 护甲头盔/血污/变老共用同一管线，不为"好看"优化。
5. 对照实验：织丰（Shokuho）把男性 skin 换成 `sho_head_male_japanese`（自建网格+4096 贴图，
   `ModuleData/skins.xml` 覆盖），**证明 skin 矩阵可以被 mod 覆盖**（这正是"换头"mod 的机制）。

## 二、五官怎么会动（换脸不破坏动画的关键）

- **面部动画 = 顶点动画（morph）**，不是骨骼、不是贴图切换：
  `Modules/Native/AssetPackages/morph_anims.tpac` 含 `face_01~12`、`face_smile1`、`face_smiling_hard`、`face_cutscene` 等 clip。
- 播放入口：`Agent.SetAgentFacialAnimation(FacialAnimChannel.High/Low, "face_03", loop)` →
  native `IMBAgent.SetAgentFacialAnimation`；骨架级：`Skeleton.SetFacialAnimation(channel, name, playSound, loop)`
  （`TaleWorlds.MountAndBlade.dll` `Skeleton` 扩展，`AGENT` 也支持 `FacialAnimChannel`）。双通道（眉眼/嘴可分列）。
- **推论：换脸贴图不改动画**——morph 动的是网格顶点，贴图只是被拉着走的"皮"。
  新贴图只要与引擎 UV 布局对齐，动画照常；代价 = 表情时贴图 2D 形变（观感等价于女头美化类 mod 的效果）。

## 三、头部资源布局（换脸的直接目标）

| 资源（男/女一致） | 类型 | 说明 |
|---|---|---|
| `head_male_a`（metamesh） | 网格 | 头网格；男=全游戏公用 |
| `head_male_a_d/_n/_s` | 贴图 | diffuse/normal/specular；原版像素在 **私有的 `Bannerlord.gts`**（Graphine 图集，103MB，TpacTool 解不出）→ 换脸贴图必须**全新建** |
| `eye_a_d` | 贴图 | 眼球独立小贴图（左小岛）；眼睛/睫毛/嘴为 head 网格的子 mesh（`head_male_a.0/1/2/3`，CSDN #16） |
| `male_eyebrow_1..10` | 贴图/网格 | 选装眉毛（独立网格+纹理） |

**男头 UV 布局（head_male_a，v1.2.12 实测）**：
- 整脸挤在贴图**左下角 u 0.01–0.20、v 0.02–0.36** 的窄区：眼带 u[0.06,0.20] v~0.29（**左右镜像共用一小岛**），
  鼻尖 (0.012,0.235)，嘴 (0.020,0.184)，下巴 (0.047,0.114)；
  **眉毛在贴图中部 (0.50,0.17) 独立岛**（与其余五官不同层！）；耳朵岛 (0.114,0.208) 与嘴/眼带相邻。
- 女头布局完全不同（脸区居中）→ **锚点必须从"想换的那个头的网格"重新测量**（几何/渲染双轨校准，见工具）。

## 四、覆盖机制（换脸落地方式）

1. **引擎无"覆盖清单"**：同名资源后加载者覆盖先加载者。mod 的 `AssetPackages/*.tpac` 里放同 ID 资源
   （如 `head_male_a_d`），排 Native 之后即可。**SubModule.xml 只是注册 mod 名字/依赖，无覆盖规则**。
2. 范本：GT_Face（换女头，无任何 XML 覆盖）、WomeninCalradia（女性换头，自建 `head_malfoy_a_*`资源）。
3. **给特定角色换脸** = 拆 skin/race（`skins.xml` 加节点 + 角色 `face_meta_mesh` 引用），织丰自己的
   `sho_head_male_japanese` 就是完整先例。牵涉 `face_mesh_cache`（见下）。

## 五、脸缓存（NPC 为什么不刷新的机制）

- `face_mesh_cache="true"`（NPCCharacter 属性，织丰领主们都有）→ **该 NPC 的脸生成结果缓存**；
  `AgentBuildData.UseFaceCache/FaceCacheId`（`TaleWorlds.MountAndBlade.dll`，`AgentBuildData`
  `UseFaceCache`/`FaceCacheId`）+ `FlushFaceCache`（`FaceGen.FlushFaceCache`）。
- 实测：**旧存档里的 NPC 不受新贴图影响**（脸已固化）；主角（无此属性）实时生成。
- 处理：新档全生效；旧档需清缓存字段（存档手术，待实现）；或让 NPC 的 `face_mesh_cache=false`。

## 六、已验证的管线与探针法（2026-08-29 实机）

| 包 | 对方 | 结论 |
|---|---|---|
| A 包（孤儿资源 `test_face_d`，不覆盖任何东西） | mod 框架 | 引擎认，进游戏 → **tpac 段格式 OK** |
| B 包（覆盖 `head_male_a_d`） | 主角 | 主角脸生效（**红/黑/绿底色探针全部呈现**）→ **机制全通** |
| 红/黑/绿+蓝块探针 | 主角 | 底色通道 100% 生效；**五官区仍显原版** → **暂结论：脸部有独立"合成五官层"在基础贴图之上（FaceGen 合成层）**，仅纯色能透出；**待精确探针定案** |
| 标尺网格探针（0.1 网格+五官紫点） | 主角 | 校正 U V 坐标之（**测试中**） |
| v1-v17 拼脸包 | 主角 | 从"黑脸"→"五官对位"演进；用户端仅"下巴黑纹可见"→ 与合成层/UV 差都有关系（探针后定） |

- **视图分叉坑（重要）**：Bash（沙箱）产出的文件与宿主（IDE/游戏）不同视图 → **最终交付（dist/装游戏）必须走 PowerShell 或 Write/Read 工具**。
- **怪包大小正常**：tpac 段有压缩（均匀贴图 147KB 是压缩后，不是数据缺失；roundtrip 字节级一致已证）。

## 七、工具链（`tools/face-pipeline/`）

```
tpactool/            # TpacTool fork + TpacToolCLI（list/dump/roundtrip/makeface/one）
scripts/             # warp_face(拼脸) render_head(软渲染预览) render_uvview(UV色图)
                     # geo_anchor_v2/v3/v4(几何锚点) uv_pick(数值桥) uv_pick_sho(自适应)
                     # find_eyes(原版贴图抓瞳) make_anchor_map 等
data/                # meshes/*.obj(解包导出)  + 关键对照图 + 输入/输出
dist/FaceCustomLWN   # 覆盖用 mod（SubModule.xml + AssetPackages/face_lwn.tpac）
```

CLI 关键命令（`tools/face-pipeline/README.md` 有完整用法）：
`tpaccli list/dump(<packdir>)`、`roundtrip`（Save 写端验证）、`makeface`（PNG/DDS → 纹理对象 → tpac）。
