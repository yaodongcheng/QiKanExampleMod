# How to report a crash

<!-- 源: https://docs.bannerlordmodding.lt/guides/how_to_report_a_crash/ | 抓取日期: 2026-09-09 -->

Crash report without a crash log is (useless) not very helpful. To get a crash log follow these steps:

1. Install [ButterLib](https://www.nexusmods.com/mountandblade2bannerlord/mods/2018) mod
2. Make sure it's active

   ![](https://docs.bannerlordmodding.lt/pics/2411111949.png)
3. `Disable when Debugger is Attached` option (with new ButterLib versions crash will not be generated when this option is ON)

   Show where

   ![](https://docs.bannerlordmodding.lt/pics/2411111853.png)
4. Play the game, wait for the crash (exception)
5. Do as said in the image:

   ![](https://docs.bannerlordmodding.lt/pics/2411111946.png)
6. Also add a description what you were doing when the crash happened.

Send ONLY the link.   
  
Do NOT send HTML file, do NOT send screenshots, do NOT send archives, etc.  
  
 SEND ONLY THE LINK!!!
