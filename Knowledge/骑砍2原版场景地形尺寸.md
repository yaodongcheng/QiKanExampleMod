## 二、计算口径

`scene.xscene` 中的地形节点：

| 属性 | 含义 | 关系 |
|---|---|---|
| `node_dimension_x` / `node_dimension_y` | X / Y 方向的节点数 | — |
| `node_size` | 单个节点的边长（米） | — |
| **世界尺寸** | 地形网格的实际跨度 | `node_dimension_x × node_size` × `node_dimension_y × node_size` |
| **高度图分辨率** | 导入编辑器时的 PNG 像素 | 节点数 × **每节点分辨率**（编辑器里的 Single Node Dimensions），不是世界尺寸推出来的 |

改世界尺寸只动节点数或节点边长；高度图放多大只影响网格精细度，不改变世界大小。

## 三、大地图（Calradia）

| 项 | 原版实测值 |
|---|---|
| 节点 | 16 × 16 |
| 单节点边长 | 53 米 |
| **世界尺寸** | **848 × 848 米** |
| 高度图 / 顶点网格 | **4096 × 4096**（每节点 256 段，约 0.207 米/顶点） |
| 高度范围（Scale） | 0 ～ 25 米 |
| 材质层 | 8 层（default / flora_forest / rock / grass / dirt / dirt2 / forest2 / river） |
| 备注 | 原版 `water_exists=false`，视觉上的海是材质层；背景山/图标散布到网格外约 ±430 米，**那 1821×1785 米不是地形尺寸** |

官方 wiki 写每节点 256×256 顶点；项目实测是 **256 段 = 257 个顶点**（每个节点多一条边界），所以引擎内部顶点网格是 4097² 的同构结构。编辑器导入原版那张 4097 高度图成功过。

对照：织丰 Main_map = 16×16 @132 米 = **2112 × 2112 米**，257 顶点/节点，高度图 4096²，Scale 20.968（min -8）。

## 八、口径与坑

- **不要把地形网格当城区面积**：3000×3000 的城镇场景里有大量城外地形，实际逛街/战斗区域只是其中一块。
- **世界尺寸与高度图分辨率解耦**：改 PNG 像素不会改世界大小；要改世界大小只能改节点数或 `node_size`。
- **每节点分辨率不在场景 XML 里**：`scene.xscene` 只记录节点数与边长，每节点顶点数由编辑器里的 Single Node Dimensions 决定，不能从世界尺寸反推。
- **未使用场景**：`khuzait_town_c`（3000×3000）无聚落引用；引用前先确认它是否真的会被加载。
- **攻城场景不一定是独立场景**：例如阿弥塔堤斯的中心场景就叫 `empire_town_j_siege`，不是"另一个攻城副本"；部分聚落的攻城另有 `*_siege_001` 场景（如 `empire_siege_001`）。
- **大地图旧稿的 1821×1785 米是错的**：那是背景山/图标的装饰环跨度，地形网格本身是 848×848 米。

## 九、复现方法

数据全部来自场景文件，不需要进游戏：

```
cd "H:\SteamLibrary\steamapps\common\Mount & Blade II Bannerlord\Modules"
rg -o --no-heading --with-filename 'node_dimension_x="[0-9]+" node_dimension_y="[0-9]+" node_size="[0-9.]+"' SandBoxCore/SceneObj SandBox/SceneObj Native/SceneObj
```

聚落与场景的绑定关系读 `H:\SteamLibrary\steamapps\common\Mount & Blade II Bannerlord\Modules\SandBox\ModuleData\settlements.xml` 里各 `<Location>` 的 `scene_name*` 属性；中文名读 `Native\ModuleData\Languages\CNs\std_common_strings_xml-zho-CN.xml`。

生成脚本（一次性）：`H:\SteamLibrary\steamapps\common\Mount & Blade II Bannerlord\Modules\LivingWorldNpcs\Debug\offline\_gen_scene_size_tables.py`（按目录归口，`_` 前缀临时物，不进 git）。
