> 日期: 2026-06-28

## 一、动画系统三层架构

```
action_types.xml    → 定义 action type ID（如 act_death_fall_front, type="actt_fall"）
action_sets.xml     → 定义 action_set → animation clip 映射（如 as_human_warrior: act_death_fall_front → death_fall_front）
TPAC 资源文件        → 实际骨骼动画数据（animation_clip = death_fall_front）
```

**C# 调用链**：
```csharp
ActionIndexCache.Create("act_death_fall_front")  // ① 查 action_types.xml → 得 action index
agent.SetActionChannel(0, actionCache, ...)       // ② 查 agent 的 action_set → 得 animation clip → 播放
```

## 二、Action Set 继承链：XML 有，运行时没有

XML 声明了完整继承链：
```
as_human_villager → as_human_hideout_bandit → as_human_warrior (ROOT)
```

但 **`SetActionChannel` 在运行时不会穿透 `base_set` 查动画**。村民的 `as_human_villager` 只直接定义了走/站/转，战斗动作虽然 `as_human_warrior` 里有，但运行时查不到 → 静默失败。

**解决方案**：`ForcePlayAction` 临时切换 action set
```csharp
// 1. 获取根 action_set
MBActionSet warriorSet = MBActionSet.GetActionSet("as_human_warrior");

// 2. 构造 AnimationSystemData（包含骨骼索引等完整数据）
AnimationSystemData warriorData = agent.Monster.FillAnimationSystemData(
    warriorSet, agent.Character.GetStepSize(), hasClippingPlane: false);

// 3. 切换
agent.SetActionSet(ref warriorData);

// 4. 播放
agent.SetActionChannel(0, actionCache, ignorePriority: true, blendInPeriod: 0.15f);
```

**注意**：`AnimationSystemData` 由 `Monster.FillAnimationSystemData()` 填充，包含了骨骼索引（PelvisBoneIndex、NeckRootBoneIndex 等）和物理参数。`MBActionSet.GetName()` 可以获取 action set 名称用于调试。

## 三、human vs human_child：同骨架，不同 Monster

`monsters.xml` 中两个独立 Monster：
```xml
<monster id="human" action_set="as_human_warrior" arm_length="0.9" standing_eye_height="1.70" ... />
<monster id="human_child" base_monster="human" action_set="as_human_child" arm_length="0.6" standing_eye_height="1.20" ... />
```

- 骨架都是 `human_skeleton`，但 `human_child` 的骨骼索引和体型参数不同
- `as_human_child` 只定义了 walk/idle/talk 动画，**没有任何 death/fall/stun 动画**
- Even with `ForcePlayAction` switching to `as_human_warrior`, adult death animations don't play on child skeletons — 骨骼比例差异导致动画 clip 不兼容
- 验证方法：`agent.Monster.StringId == "human_child"` 判断 Monster 类型

**判断儿童的正确方式**：用 `agent.Monster.StringId` 而非 `agent.BodyPropertiesValue.Age`。age < 18 的青少年可能仍使用 `human` monster，对应关系不严格。

## 四、Brain 自动 Resume 竞争问题

**现象**：手动 `SuspendVanillaAI(target)` → 3ms 后被 `ResumeVanillaAI` 恢复。

**根因**：AgentBrain 的 idle 循环：
```csharp
// AgentBrain.Tick()
if (_currentAction == null && _actionQueue.Count == 0)
{
    DecideDefaultBehavior();  // → ResumeVanillaAI(Owner)
}
```

手动 Suspend 没有通知 Brain，Brain 队列为空，下一帧 Tick 自动 Resume。

**正确做法**：走事件系统投递，让 Brain 自己管理
```csharp
// Brain.ReceiveEvent
else if (aiEvent.EventType == "event_agent_knocked_out")
{
    ClearAllActions();
    EnqueueAction(new StayAction(null, false));
    // EnqueueAction 自动调 SuspendVanillaAI（队列空→非空转换时）
    // StayAction 永不结束 → Brain 永远不触发 DecideDefaultBehavior
}
```

调用方：
```csharp
AgentAIController.Instance?.SendEventToAgent(target, "event_agent_knocked_out");
```

## 五、`IsUsingGameObject` 与对话中的 NPC

**`IsUsingGameObject`** = `CurrentlyUsedGameObject != null`——Agent 正在"使用"场景物体（椅子、墙壁、桌子等 `UsableMachine`）。

**两个 NPC 面对面聊天时**：
- 不一定 `IsUsingGameObject = true`
- 更可能是 `AIScriptedFrameFlags.InConversation` (0x100) + conversation 动画循环
- 动画由 `DailyBehaviorGroup` 中的社交行为每帧重设

**打断方式**：
```csharp
// 无论哪种情况，先暴力打断
if (agent.IsUsingGameObject)
    agent.StopUsingGameObject(true, Agent.StopUsingGameObjectFlags.None);
// SuspendVanillaAI（通过 EnqueueAction 自动调用）停止 DailyBehaviorGroup
// SetScriptedFlags(DoNotRun | NoAttack) 锁引擎层
```

调试日志打印 `IsUsingGameObject` + `GetScriptedFlags()` 确认实际状态。

## 六、ForcePlayAction 完整调用链

```csharp
public static void ForcePlayAction(Agent agent, string actionId, bool restoreAfter = false)
{
    // 0. 打断当前交互
    if (agent.IsUsingGameObject)
        agent.StopUsingGameObject(true, Agent.StopUsingGameObjectFlags.None);

    // 1. 验证 action 存在
    ActionIndexCache actionCache = ActionIndexCache.Create(actionId);
    if (actionCache == ActionIndexCache.act_none) return;

    // 2. 切换到 as_human_warrior
    MBActionSet warriorSet = MBActionSet.GetActionSet("as_human_warrior");
    AnimationSystemData warriorData = agent.Monster.FillAnimationSystemData(
        warriorSet, agent.Character.GetStepSize(), hasClippingPlane: false);
    agent.SetActionSet(ref warriorData);

    // 3. 播放
    agent.SetActionChannel(0, actionCache, ignorePriority: true, blendInPeriod: 0.15f);
}
```

## 七、击晕完整流程（TryKnockoutAgent）

```
TryKnockoutAgent(target)
  ├── 0. 前置检查
  │     ├── target.IsActive()?
  │     └── agent.Monster.StringId == "human_child"? → 跳过（骨骼不兼容）
  ├── 1. ForcePlayAction("act_death_fall_front")  ← 切 action set + 播倒地动画
  │     └── 内部 StopUsingGameObject + SetActionSet + SetActionChannel
  ├── 2. SendEventToAgent("event_agent_knocked_out")  ← 事件投递
  │     └── Brain: ClearAllActions + EnqueueAction(StayAction) → Suspend + 永久占位
  └── 3. SetScriptedFlags(DoNotRun | NoAttack)  ← 引擎层锁死
```

|-----------|------|----------------|------|------|
| `act_death_fall_front` | `actt_fall` | `death_fall_front` | monster_usage_fall direction="back" death_type="knock_back" | 背后击晕倒地（面朝下） |
