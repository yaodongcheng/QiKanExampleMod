## 二、下一步：**给混天绫做布料模拟**（待办）

### 2.1 已确认的事实（**别重查，都是实测**）

**① 引擎布料是原生能力**，原版 231 处在用。控制参数 = 顶点色 `COLOR_0` 的 **alpha**；
手感参数在 `cloth_materials.xml`，碰撞胶囊在 `cloth_bodies.xml`。

**② 原版凡带布料的披风/围巾，全是「映射模式」**（渲染件 + 一个低模替身）—— 一件直接模拟的都没有：

```
battania_scarf_a    -> clo_battania_scarf_a      映射
aserai_shoulder_a   -> clo_aserai_shoulder_a     映射
battania_cloak_furr -> clo_battania_cloak_furr   映射
```

**③ 原版围脖 `battania_scarf_a` 的完整配方**（照它做）：

| 项 | 值 |
|---|---|
| 渲染件 LOD0 的 alpha | **开关式**：2319 个顶点里只有 **184 个 = 1.0**（就是那条垂尾），围脖全 0 |
| 替身 | **60 顶点**、单 LOD、单子网格，只盖住垂尾 |
| 替身 alpha | **活动半径** 0 → **0.18 m**，8 档各 6 点 |
| 替身材质 | bend 0.5 · shear 0.5 · stretch 0.5 · anchor 1 · **damp 0.35** · **grav 3** · inertia 0.5 · **wind 0.2** · airdrag 0.4 |
| 渲染件那几个参数 | damp 0.95 / grav 1 / wind 1 / airdrag 0.5 —— **不起作用**（用了替身就以替身为准） |
| 碰撞体 | `cape_body` |
| LOD1~5 | alpha 全 1.0 但**无布料标记** ⇒ 远处刚性 |

## 四、附：为什么走披风槽（当初核实过的事实，仍然有效）

1. **槽位现成** —— `EquipmentIndex.Cape = 9`。原版有 **91 件**披风类物品
   （`SandBoxCore/ModuleData/items/shoulder_armors.xml`）。
2. **原版披风自带布料模拟**（实测 `battania_cloak_furr`：有低模替身 + 碰撞体 + `uses_cloth_simulation`）
   ⇒ 不用自己写物理、不用绑骨。
3. **不改骨架** —— 骑砍骨架全游戏共用一份（`human_skeleton`，31 根身体骨）。想给丝带加自己的骨链
   = 给这个角色换骨架 = 每人一套，成本高一个数量级（战无2 总纲 §4.18.7 已论证并否决）。
   **布料的"钉死区"本身就是绑定**：顶点色 alpha = 0 的顶点被钉在骨骼上，alpha > 0 的才被模拟。

**坐标口径（世界坐标 == 游戏坐标）**：`+z 上 · +x 右 · 正面 = +y · 背面 = -y`。
判据 = 基准甲（`taikou_nobunaga_do_a`，已实机验证）的脚：踝往 +y 伸 0.118 m、往 -y 伸 0.050 m
⇒ 脚尖在 +y。
🔴 **`tpaccli dump` 的 OBJ 导入 Blender 时必须显式给 `forward_axis='Y', up_axis='Z'`**
（默认是 `-Z/Y`，会把 Z-up 的 dump 转一道 —— 围巾"飘到身前 1.4 m"的假象就是这么来的）。
