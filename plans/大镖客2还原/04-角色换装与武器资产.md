## 一、目标（一句话）

把 RDR2 的 **① 角色头部 ② 上身/下身服装 ③ 帽子 ④ 武器** 整理成骑砍2 可导入的资产，统一落到
`Modules\RDR2\AssetSources\ImortReady\rdr2_char\`，并按「材质先行 → 网格导入 → 装备接线」的顺序接进游戏。

**不做**：动物、载具、坐骑、过场专用服装（后续另立）。

## 三、关键裁定（先定这五条，不然批量返工）

| # | 裁定 | 凭什么 / 代价 |
|---|---|---|
| **1** | **服装必须蒙皮到骑砍2 人形骨架**，不能当静态件 | RDR2 交付的是静态网格；不蒙皮就不跟动作。做法沿用战无2 甲那套「**权重从源件取**」（`tools/armor-pipeline` 的 `--weights-from`），代价 = 穿插风险高，需逐件目视 |
| **2** | **骑砍2 只有 4 个身体槽**（Head / Cape / Body / Gloves / Legs），RDR2 有 10+ 层 ⇒ **必须定「多层合成一件 Body」的组合规则** | 上衣+背心+外套+衬衫+领巾+腰带 在骑砍2 只能算一件 Body 网格。**规则待拍板**（见 §七） |
| **3** | **头部走自建头件管线**（`tools/face-pipeline`，101 条通道），不做 28 骨重定向 | 与蒂法/萨菲罗斯/战无2 同一条管线；RDR2 头是整头+脸贴图，要先拆眼/牙/发并清洗 |
| **4** | **帽子 = 静态件，以头骨挂点为原点导出** | 骑砍2 的帽子就是 Head 槽的静态网格，跟头骨走；原点错 = 浮空（原文档的老坑） |
| **5** | **武器 = 静态 TRF + ItemObject**，与 Taikou 长枪同路 | 已有成熟链路（`tpaccli meshmake` / TRF 导入 + `items.xml`） |

**命名纪律（铁律 27 / 32，硬性）**

- 头：脸壳 = 裸名（`head_xxx_a`），配件加后缀 `_eye` / `_mouth` / `_lash` / `_neck`；
- 服装 / 帽子 / 武器：`<槽位>_<原模型名>`（例 `body_uppr_001`、`hat_gambler01`、`wpn_springfield`);
- **材质名必须与贴图名对应，且必须共用已有材质 datablock**，否则编辑器里是白板。

## 四、落点与规格

```
Modules\RDR2\AssetSources\ImortReady\rdr2_char\
├─ head\      头部件（<头名>.fbx + <头名>_eye/_mouth/_lash/_neck）
├─ body\      上下身合成件（含腿/靴；以**脚底中心**为原点）
├─ hat\       帽子（以**头骨挂点**为原点）
└─ weapon\    武器（以**握把**为原点）
```

- 贴图三件套 `_d / _n / _s` 与网格同目录；**先建材质、再导网格**（编辑器按材质名绑定，事后不回填）。
- 轴：Z-up、`axis_forward='Y', axis_up='Z'`（骑砍2 约定）。
- 批量目录名与 `batches.csv` 同风格，每批 ≤ 560 件。

## 五、分阶段（阶段 0 不过，不进批量）

| 阶段 | 做什么 | 判据 |
|---|---|---|
| **0. 样张** | 各挑 1 件：1 个头、1 套上下身、1 顶帽子、1 把武器 → 导出 → ModKit 导入 → 实机穿 | 穿上不穿模、动作跟随、帽子不浮空、武器握点对 |
| **1. 清单** | 出「RDR2 slot → 骑砍2 装备槽」映射表 + 每件的面数/贴图/是否可组合 | 映射表覆盖全部 6,106 件（含"不做"的明确标注） |
| **2. 转换** | GLB → FBX：原点归位、材质名规范化、蒙皮权重迁移、多层合成 | 抽样 20 件，包围盒/面数与源一致 |
| **3. 导入** | ModKit 批量导入（用户操作，每批 ≤560，导完重启） | 资产数 = 清单数、无白板 |
| **4. 接线** | `ModuleData\items\*.xml` 建装备定义（Body/Head/Weapon 槽） | 游戏里能穿、能打 |

## 六、验收判据

1. **编辑器**：导入资产数对得上清单；材质名全部有定义（无白板）；
2. **实机**：穿上后①动作跟随②不穿模③帽子不浮空④武器握点正确；
3. **性能**：单套（头+身+帽+武器）不超过约定面数上限（待定，参考战无2 的 8k 面/套）。

## 八、参考（战无2 那套里直接能抄的）

- 权重迁移：`tools/armor-pipeline`（`--weights-from` 用源件权重）；
- 头件 101 通道 + 材质名判角色：`tools/face-pipeline` + `install_pack.py --fullmat`；
- 坑：多用户材质要 `copy()` 再改名（否则只剩最后一个名字）、导出前跑预览会污染材质名；
- 装机后处理：`--clear-flags` 是整包清，别顺手用完不补。
