# 音效：钩索绳声 + 飞行风噪（已实施 · 实机跑通）

> 状态：**已实施 + 实机跑通**（2026-10-10）。当天经三轮修正：
> ① 风声 2D 实机静音 → 改 **3D + 每帧跟锚点**；② 用户反馈"都太小" → **素材响度规整 + 分类换前景层**；
> ③ "被拉起来没听到风"（速度太慢凑不出阵风）→ **起拽瞬间 Kick 强制起一阵**。
> 一句话：`D:\BrainMaker\骑砍2动画重定向\UEAnims` 的 7 个 WAV 变成游戏内音效 —— 绳声接钩索**抛出瞬间**，风声接**飞行与被拽两路**（速度越快越密）。

## 一、最终形态

| 事件名 | 什么时候响 | 素材 |
|---|---|---|
| `lwn_grapple_rope` | 抛出钩索的那一下（钉住 / 拉拽不另配音），3D 定位于抛出手 | `RopeGrapple.WAV` |
| `lwn_flight_wind` | **三条触发**：① 飞行模式（起飞/空中/坠落）② 被钩索拽着飞（`GrapplePull.FeedWind` 喂位移速度）③ **起拽瞬间强制一阵**（`Kick()`）。悬停/慢速（<3 m/s）无声 → 巡航约 1.6 秒一阵 → 冲刺约 0.45 秒一阵 | `clothwind1-6.WAV`（6 变体引擎随机挑） |

**三条硬结论（踩出来的，别再犯）**：

1. 🔴 **2D 不用**（`is_2d="true"` 实测全程静音，事件 id 解析正常、分类合法，原因在 native）；"自己身上的声音" = **3D + 每帧把位置跟到锚点**（锚点 = `Agent.Main.Position`，玩家不在兜底相机）。**必须每帧跟** —— 1.8 秒的阵风在 26 m/s 下会漂到 45 米外、尾巴被距离吃掉。
2. 🔴 **引擎没有音量 API** ⇒ 调响度只有两条路：**素材响度**（生成器脚本）与**分类**（§四）。
3. 🔴 **短动作要 Kick**：只按"速度密度"播，遇上又短又要速度达标的动作（拉拽全场 ~1 秒、速度曲线中后段掉到门槛以下）会**一阵都凑不出来**（计时器只在达标帧里走）⇒ 事件型触发直接 `FlightWindFx.Kick()`，不受门槛管。

**不需要转格式**：引擎直接吃 WAV（Taikou 48k/24bit 实机 + Shokuho 抽样 240/250 是 44.1k/16bit 且正式发布中）。

## 三、验收

| 命令 | 干什么 |
|---|---|
| `custom.grapple sound` | 试听绳声 + 状态（事件名 / 开关 / **名字能不能查到**）——静音故障第一诊断入口 |
| `custom.grapple sound on\|off` | 绳声开关（默认开） |
| `custom.flight sound` | 试听一阵风 + 状态（大地图敲会明确报 not in a mission） |
| `custom.flight sound on\|off` | 风声开关（默认开） |
| `custom.flight tune windgapmin 0.3` | 调风密度（同理 `windgapmax` / `windmin` / `windmax`） |

**实机动作**：拿钩索 → 抛（听绳声）→ 被拽走（**起拽那一下必有"呼"声**）；`custom.flight start` 起飞 → 加速听变密 → 落地听停。

**日志三行**（排查"太小/听不见"就看它们）：
`[Grapple] 拉拽起风（Kick…）` · `[Grapple] 拉拽中 … 速度=x.x m/s（风噪门槛 3）` · `[SoundFx] '<名>' 衰减距离 vec=(…)`（听者 = 相机；拉拽机位臂长 **8 米**，拿它对比即可判断有没有被距离吃掉）。

**已过**：XML parse ✓ · `check_module_registration.py` soln 段「全部已挂 ✓」· 隔离目录编译 0 错 · **实机出声**（用户实测）。

## 四、响度（第二轮修正："都太小"）

**引擎没有音量 API** ⇒ 两条杠杆都用了（**都不用重编译**）：

| 杠杆 | 做了什么 | 怎么再调 |
|---|---|---|
| **① 素材响度规整** | `Scripts\gen_lwn_module_sounds.py`：**6 条风的响度差从 18.6 dB 收到 1.6 dB**（4 条"几乎听不见"的被拉起 12~14 dB） | 改脚本 `FILES` 的目标值 → 重跑（**不用编译**，重启游戏即可） |
| **② 分类换前景层** | 两个事件 `mission_foley`（背景动效层，混音刻意压低）→ **`mission_combat`**（火器枪声同档） | 改 `module_sounds.xml` 一行（**不用编译**） |

实测（短时 RMS）：绳 −10.4 → **−8.9** dB（该素材不"压扁"的上限）；六条风 −24.7~−6.1 → **−10.0~−11.6** dB。
