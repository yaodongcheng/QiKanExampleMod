## 分步实施

### Step 1 — 事件解析器（parse_tk5_events.py）
- 解析 `TK5AllEvents.txt` JSON → 中间表示（trigger/条件树/命令序列/文本）
- 按章节提取：桶狭间/本能寺相关事件子集（id 列表 + 关键词过滤）
- 验收：事件子集导出（trigger 类型分布、条件树、命令序列 dump）

### Step 2 — 触发/条件/命令三映射（映射表 = 蓝图 §六 三表）
- **触发时机映射**：太阁5 trigger → 剧本触发时机（據點畫面表示後→玩家进聚落求值；野戰結束時→OnPlayerBattleEndEvent；評定開始時→评议会；軍團移動結束時→ArrivalScan；每月/每日→DailyTick；遊戲開始時→OnNewGameCreated）
- **条件变量域映射**：狀況::年/月→DateAfter/DateBefore；人物::X.事件参加可能→HeroAlive+位置归属；人物::主人公→PlayerIs；據點::X→SettlementOwner/PlayerNear；人物::X.所屬據點→HeroLocation（01 新增原语）；旗標類→FlagSet
- **命令映射**：ＢＧＭ變更→StoryEngine BGM；分歧→SCN_CHOICE_BRANCH；代入人物→ActorResolver；對話→对话通道；登場/退場→StageDirector；能力值/物品→Scenario effects（经 AgentControlHelper，铁律 4）
- 验收：事件子集按三映射转出 ScenarioJson 草案

### Step 3 — 角色归一（gen_actors.py）
- 消费 `taikou_final_v9_inference.xlsx`：Final_ID/Final_Faction/Final_Culture → actors_jp.json 初稿（heroIds 两轮列表 = [Final_ID, 预设别名]）
- 无匹配（594）→ `spawnIfMissing:true` + 名字/阵营/装备来自太阁5 数据
- 时代表：Hero.csv 九时期列 → 每个剧本的 `eraAge/eraAlive`（按剧本年份取列）
- 人工校对：匹配报告_带候选项.txt 为底稿
- 验收：actors_jp.json（信長/光秀/义元等关键角色 + 时代表）校验

### Step 4 — 城池归一（gen_cities.py）
- `Taikou5City.xlsx` + `太阁5全城池.txt` → 织丰聚落映射表（Settlement_Data_Output.xlsx 织丰侧）
- 无法映射 → `nearestFallback:true`（就近聚落）
- 验收：京都/清洲/骏府/浜松等关键城池映射正确（对照 07 的 town_KIN5 等）

### Step 5 — DSL 翻译器（translate_dsl.py）🔴 关键新层
- 太阁5 DSL（TaikouContent StoryJson 169 个：`{cmd:"ＢＧＭ變更"/"對話"/"主人公別"/"主人公分歧", params, text}`）→ **StoryEngine 指令格式**（翻译而非直读）
- 文本变量展开（{二人稱}/{前田利家.名前} 等 → 本地化占位符）
- 验收：本能寺相关 DSL 事件翻译为指令流

### Step 6 — StoryCompiler 接入（05 的编译器消费本管线产物）
- DSL 翻译产物 → StoryCompiler → **编译产物**（分幕/站位/镜头/进出场）+ `_director_notes.json` 导演标注
- **intensity 自动分配**：按事件类型 → L1-L7（通知类→L1、对话类→L4/L5、移动类→L3、战斗类→L6）→ 人工抽查校对
- 验收：桶狭间事件链编译产物 + intensity 分配 dump

### Step 7 — 本地化（gen_loc.py）
- 全部文本走 `{=LWN_SCN_*}` key（铁律 13）；输出 `std_scn.xml`
- 汉化包 Shokuho_CNs 词汇参考（称谓/官职/地名）
- 验收：文本 XML 加载 + 游戏内显示中文

## 出口验证（Phase 2/3）

1. 桶狭间/本能寺事件子集 → ScenarioJson + 编译产物 + actors_jp.json + 城池映射 + 本地化 全链路产出
2. 产物 JSON Schema 校验通过（01 的 Schema）
3. 产出物在织丰战役中走通（Phase 2/3 验收）

## 风险

- 2594 事件量大——按章节子集提取（先桶狭间/本能寺，不全量转）
- 太阁5 DSL 语义与骑砍2 差异（如"據點畫面表示後"的触发点映射需人工核对）
- GBK 编码（character_names_table.csv 中文列）读时转换
- 匹配率 56.8% → 无匹配 594 人补造量大（首版只补剧本关键角色，非全员）
- intensity 自动分配需人工校对（抽查）
