## 这一步做什么（一句话）

开局**先选时代，再选角色**（2026-08-24 用户裁定，对齐 04 多角色 / 官方 1.5.1 两层扩展点）：①**选时代**（worldscenarios——如"桶狭间之战"1560 / "本能寺之变"1582）→ 世界拨到那个年代：该活着的活着（信长 26 岁、今川义元 41 岁正当年），不该活的还没出生或已死；②**选角色**（scenarios 开局身份——该时代内**存活**的历史人物（🔴 2026-08-25 裁定：人人可扮演，不限于剧本个人线；信长/义元/元康/织田家臣……））→ 玩家变成所选人物本人——名字、阵营、位置、部队、装备全套注入；织丰里缺的角色按剧本表补造；玩家扮演的角色死了，换继承者继续。

## 玩家视角

- 新游戏 → 高级开局选项多一个"时代"选择（官方 worldscenarios，零 UI 代码）→ 选"桶狭间时代" → 世界拨到 1560 → **再选角色**（"扮演谁"列表：信长/义元/元康/织田家臣——角色池 = 该时代存活的（2026-08-25 修正：人人可扮演；playerRoles 仅推荐置顶），官方 scenarios 开局身份）→ 开局你就是所选人物：顶着 TA 的名字、阵营、站在 TA 的位置
- 世界是 1560 年的：义元活着、光秀还年轻、该在的城都在
- 你扮演的人战死（比如信长本能寺没打过去）→ 不直接结束：换扮演继承者继续，剧情进 IF 线（假想剧情线，与史实分叉的另一条路）


## 怎么实现（四个部件）

1. **开局选择器（🔴 两层）**——官方"高级开局选项"扩展点（worldscenarios 机制 = 1.5.1+ 引擎实证；🔴 版本环境按 mod 逐一裁定，README 裁定 25：织丰 = 1.2.12，开局选择器按其自身版本支持选用——支持 1.2.12 就直接用，不支持才降级设置菜单）：
   - 第一层 **时代（worldscenarios）**：世界剧本下拉（桶狭间 1560 / 本能寺 1582）
   - 第二层 **角色（scenarios 开局身份）**：该时代内**存活**的人物列表——🔴 **2026-08-25 用户裁定：人人可扮演**（角色池 = 时代存活，不限于剧本个人线）；09/10 剧本表的 `playerRoles` = **有个人线的推荐清单**（选择器置顶推荐，非可扮演限制）；**时代先定，角色池随时代过滤**（1582 时代不列义元；下拉过滤 + validator 双层校验防选到已死/未出生）
   - 选中值随存档保存
2. **时代重置**（开档后执行一次，官方 API 已验证可行）——🔴 **以"全时间轴人物池"为输入**（表驱动选择性激活，2026-08-24 用户裁定）：
   - 🔴 **决定：人物池 = 1560-1582+ 全时间轴人物全集，含已死/未出生人物**——含当前时代已死的（道三/雪斋/信秀）、未出生的（秀赖等）、存活核心人物
   - 理由：死人与没出生的人不是垃圾数据——死亡记录 / 关系网节点（信长是道三女婿）/ 开场叙事参考都要用
   - 数据源：`Knowledge/骑砍2织丰角色ID对应/骑砍2太阁Mod表_v1.xlsm.xlsx` TaikouHero 表——骑砍2太阁Mod表 1960 人 × 125 列（骑砍ID / 生年 / 登场 / 终年 / 死因 / 家系 / 六维·技能·卡 / 9 剧本章节 = 阵营演变现成数据；07 织丰 XML + 08 转化管线合并产出）
   - 每项 = StringId / 姓名 / 出生年 / 死亡年（剧本设定）/ 阵营演变（章节状态；9 章节 ↔ 本时间轴映射表）/ 关键事件标记 / 🔴 个人线标记（09/10 剧本表 playerRoles——选择器推荐用；可扮演 = 时代存活人人可，2026-08-25）
   - 按池逐项核对激活三态：**活着 / 未出生**（生日设未来，防成年事件拉活）/ **已死**（官方击杀流程）
   - 改年龄（把生日设到对应年份）
   - 重算技能/等级（官方初始化流程，顺序有讲究：先改年龄再算技能）
   - 阵营归属（谁该在哪个势力——按池的阵营演变段）
   - ⚠️ 只在新档做，存档里重算会掉级
   - 🔴 **角色池（选择器第二层）= 人物池中该时代还活着的人（2026-08-25 修正：人人可扮演，见前）**；`playerRoles`（09/10 剧本表）只影响"个人线推荐 + 专属演出 involved"，**不影响可否扮演**；扮演非个人线角色 = 无专属剧情线，但三通道保证可见（在场看现场演出/缺席收渠道/世界变化地图可见——04 三通道纪律）；已死/未出生人物不是垃圾数据——多时代剧本（如未来规划更早的 1547 时代）可扮演彼时已死的人物（太阁5 五剧本同款）；回忆/关系网/开场叙事照常引用亡者
3. **玩家身份注入（🔴 按所选角色，非固定信长）**——改名（剧本表里所选人物的名字）→ 换阵营（该人物所属势力）→ 传送到剧本起点 → 配部队（兵种按剧本表，找不到就遍历兜底）→ 装备 → 执行剧本的"开局世界格局"（势力关系/战争状态重排）
4. **补造缺失角色 + 玩家死亡处理**——织丰缺的角色（剧本表标了"缺失则补造"的）用官方造人流程补（名字/阵营/装备来自太阁5 数据）；玩家角色死亡 → 死亡过场 + 换扮演继承者（**不替换引擎的主玩家对象**——全局引用，替换有风险，用"新造一个角色注入身份"的方案）

## 要注意的坑

- 改年龄/生死/技能的坑（官方文档实证过的四个）：改年龄不联动技能（要重算）；未出生必须同时把生日设未来；改状态有副作用（其他系统会响应）；重复击杀已死角色会断言崩溃
- 玩家对象不替换（全局引用风险）——继承者方案
- 角色 ID 找不到（其他 mod 可能屏蔽）→ 先查预设列表再遍历兜底，都找不到按剧本要求处理（禁用剧本或补造）
- 🔴 **时代 × 角色相容性**：角色池 = 时代存活（🔴 2026-08-25 裁定：人人可扮演，见前）；防选到"该时代已死/未出生"角色——下拉过滤 + validator 双层校验；`playerRoles` 个人线清单只做选择器推荐与专属演出 involved，不是可扮演限制
