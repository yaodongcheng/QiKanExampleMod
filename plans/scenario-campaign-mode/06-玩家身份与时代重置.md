# 06 — 玩家身份与时代重置（PlayerInjection & Era Reset）

> **Phase 1 | 依赖：01, 07（角色映射）| 出口：ASO 剧本下拉 + 时代重置链（年龄/生死/技能）+ spawnIfMissing**
> 对应蓝图：§3.6。代码位置：`Scenario/ScenarioPlayerInjection.cs`。

## 目标

玩家扮演历史角色本人（ASO/StartAsAnyone）：开局选剧本 → OnNewGameCreated 后按剧本 `eraYear` 重置世界（角色年龄/生死/技能/归属 + 玩家身份注入）+ 织丰缺角色补造（spawnIfMissing）。

## 分步实施

### Step 1 — ASO 开局选择器（`#if MB2_GE_150`）
- `[StartOptionsProvider]` 静态方法（仿 SandBoxStartOptionsProvider）：`options.Add(new ListAdvancedStartOption("Scenario", "worldscenarios", items, cond, "none"))`
- items = `ScenarioStore.GetAvailableScenarios()`（剧本名 → 本地化 key，铁律 13）
- 读取：`Campaign.Current.AdvancedStartData.GetOption("Scenario")`
- `#else`（≤1.4.x）：MCM 下拉 + `custom.scenario_start <id>` 兜底（见 11）
- 验收：开局面板出现剧本下拉；选中值随存档持久化

### Step 2 — 时代重置链（OnNewGameCreated 后，官方 API 已实证——ASO 文档 §四·六/四·七）
- 遍历 `Hero.All` 按剧本 `eraYear` 生死年龄表：
  ① 年龄：`hero.SetBirthDay(CampaignTime.YearsFromNow(-age))`
  ② 生死：`ChangeState(Active/NotSpawned)`（🔴 设未出生必须把生日设未来，防 OnHeroComesOfAge 拉活）/ `KillCharacterAction.Apply`（死）
  ③ 技能/等级重算：先 `SetBirthDay` 再 `GetDefaultSkillsForHero` → `SetSkillValue` → `HeroDeveloper.InitializeHeroDeveloper`（🔴 顺序依赖；UnspentAttributePoints 可能变负，重算前确认；只开档做）
  ④ 阵营归属：`ChangeKingdomAction.ApplyByJoinToKingdom` / clan 迁移
- 数据源：剧本 actors 表 `eraAge/eraAlive`（内容包从 Hero.csv 九时期列生成，见 08）
- 验收：1560 剧本 → 信长 26 岁 Active、义元 41 岁 Active；1582 剧本 → 义元已死

### Step 3 — 玩家身份注入
- 改名 `hero.SetName(new TextObject(name), ...)`（名字来自剧本 actors 表）
- 换阵营 `ChangeKingdomAction.ApplyByJoinToKingdom(Clan.PlayerClan, kingdom)` + `V.JoinKingdom`
- 传送 `TeleportHeroAction` / `V.SetPos` + 部队填充（兵种经 ActorResolver 两轮解析）→ 装备
- 执行 `initialWorldState`（01 Step 6：势力格局/战争状态重排）
- 验收：玩家开档即信长（名字/阵营/位置/部队）

### Step 4 — spawnIfMissing 补造
- ActorResolver 解析失败 + `spawnIfMissing:true` → `HeroCreator.CreateSpecialHero` 补造（名字/阵营/装备数据化）+ 时代重置同管线
- 无匹配角色清单来自 08 角色归一（匹配率 56.8%，594 人需补造）
- 验收：缺失角色补造成功（名字/阵营正确）

### Step 5 — 玩家死亡处理（HandlePlayerDeath）
- HeroKilledEvent 监听 MainHero → 死亡结局过场（默认）或 **换扮演继承者**（`HeroCreator.CreateSpecialHero` 新 Hero + 注入身份；🔴 **不替换 MainHero 对象**——引擎全局引用迁移风险）
- `ReleaseAll()`（02 纠正器释放）+ 分支继续（IF 判定）
- 验收：玩家扮演信长战死 → 死亡过场 → 换扮演秀吉/光秀

## 出口验证（Phase 1）

1. ASO 开局面板剧本下拉；选桶狭间 → 时代重置（信长 26/义元 41 活）→ 玩家身份注入（名字/阵营/位置/部队）
2. 缺失角色 spawnIfMissing 补造
3. 玩家死亡 → 继承者方案
4. `#else` 路径 MCM 下拉 + 控制台兜底

## 风险

- ASO 文档 §四·六四个坑：①改年龄不联动技能 ②OnHeroComesOfAge 自动激活 ③ChangeState 副作用（OnHeroActivated 其他系统响应）④KillCharacterAction 断言（已死重复击杀 FailedAssert；有 quest 的 notable 禁杀）
- 技能重算 UnspentAttributePoints 变负 → 重算前确认/重置
- 只开档做（存档中重算会掉级）
- 织丰角色 StringId 解析失败（铁律 5 两轮策略 + 剧本禁用兜底）
