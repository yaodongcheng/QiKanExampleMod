## 这一步做什么（一句话）

开局**先选时代，再选角色**（2026-08-24 用户裁定，对齐 04 多角色 / 官方 1.5.1 两层扩展点）：①**选时代**（worldscenarios——如"桶狭间之战"1560 / "本能寺之变"1582）→ 世界拨到那个年代：该活着的活着（信长 26 岁、今川义元 41 岁正当年），不该活的还没出生或已死；②**选角色**（scenarios 开局身份——该时代内**活着且有戏份**的历史人物：信长/义元/元康/织田家臣……）→ 玩家变成所选人物本人——名字、阵营、位置、部队、装备全套注入；织丰里缺的角色按剧本表补造；玩家扮演的角色死了，换继承者继续。

## 玩家视角

- 新游戏 → 高级开局选项多一个"时代"选择（官方 worldscenarios，零 UI 代码）→ 选"桶狭间时代" → 世界拨到 1560 → **再选角色**（"扮演谁"列表：信长/义元/元康/织田家臣——角色池 = 该时代活着且有戏份的，官方 scenarios 开局身份）→ 开局你就是所选人物：顶着 TA 的名字、阵营、站在 TA 的位置
- 世界是 1560 年的：义元活着、光秀还年轻、该在的城都在
- 你扮演的人战死（比如信长本能寺没打过去）→ 不直接结束：换扮演继承者继续，剧情进 IF 线

## 怎么实现（四个部件）

1. **开局选择器（🔴 两层）**——官方"高级开局选项"扩展点（1.5.1 专属，老版本用游戏内设置菜单兜底）：
   - 第一层 **时代（worldscenarios）**：世界剧本下拉（桶狭间 1560 / 本能寺 1582）
   - 第二层 **角色（scenarios 开局身份）**：该时代内**活着且有戏份**的人物列表（09/10 剧本表的"可扮演者"清单）——🔴 **时代先定，角色池随时代过滤**（1582 时代不列义元；角色池 = 时代内 alive + 剧本表"可扮演"标记）
   - 选中值随存档保存
2. **时代重置**（开档后执行一次，官方 API 已验证可行）——🔴 **以"全时间轴人物池"为输入**（表驱动选择性激活，2026-08-24 用户裁定）：
   - 🔴 **人物池 = 整个时间轴（1560-1582+）可能出现的人物全集**（内容包数据，🔴 **现成数据源 = `Knowledge/骑砍2织丰角色ID对应/骑砍2太阁Mod表_v1.xlsm.xlsx` TaikouHero 表**：1960 全人物 × 125 列——骑砍ID（lord_1_xxx StringId，1047 已有、其余 Sheet1"需新建"清单）/ 生年 / 登场 / 终年 / 死因 / 家系（父亲·祖父·亲族）/ 六维+技能+卡 / 🔴 **9 剧本章节 × 每章（未登场·姓名·身份·立场·所属势力·所属据点·所属流派）= 阵营演变现成数据**；07 织丰 XML + 08 转化管线合并产出）：**含当前时代已死的**（道三/雪斋/信秀——存在意义 = 死亡记录 / 关系网节点（信长是道三女婿）/ 开场叙事参考）、**未出生的**（秀赖等）、存活核心人物；每项 = StringId / 姓名 / 出生年 / 死亡年（剧本设定）/ 阵营演变（🔴 章节状态，9 章节 ↔ 本时间轴的映射表）/ 关键事件标记 / 🔴 可扮演标记（09/10 清单）
   - 按池逐项核对激活三态：**活着 / 未出生**（生日设未来，防成年事件拉活）/ **已死**（官方击杀流程）
   - 改年龄（把生日设到对应年份）
   - 重算技能/等级（官方初始化流程，顺序有讲究：先改年龄再算技能）
   - 阵营归属（谁该在哪个势力——按池的阵营演变段）
   - ⚠️ 只在新档做，存档里重算会掉级
   - 🔴 **角色池（选择器第二层）= 人物池 ∩ 可扮演标记 ∩ 时代存活**；已死/未出生人物不是垃圾数据——多时代剧本（如未来 1547 时代）可扮演"更早时代已死"的人物（太阁5 五剧本同款）；回忆/关系网/开场叙事照常引用亡者
3. **玩家身份注入（🔴 按所选角色，非固定信长）**——改名（剧本表里所选人物的名字）→ 换阵营（该人物所属势力）→ 传送到剧本起点 → 配部队（兵种按剧本表，找不到就遍历兜底）→ 装备 → 执行剧本的"开局世界格局"（势力关系/战争状态重排）
4. **补造缺失角色 + 玩家死亡处理**——织丰缺的角色（剧本表标了"缺失则补造"的）用官方造人流程补（名字/阵营/装备来自太阁5 数据）；玩家角色死亡 → 死亡过场 + 换扮演继承者（**不替换引擎的主玩家对象**——全局引用，替换有风险，用"新造一个角色注入身份"的方案）

## 做完怎么验收

> 🔴 分拆验证（12 总纲 A7）：`custom.identity_inject <剧本>`（开局注入）→ `custom.identity_spawn <heroId>`（补造角色）→ `custom.identity_die`（死亡继承/换扮演）；拼装验收 = 12 Phase 1。分拆全绿前不拼装。

1. 开局面板时代下拉 → 选桶狭间时代 → 世界拨到 1560（信长 26/义元 41）→ 角色列表出现该时代可扮演者（义元可选、1582 时代不列义元）→ 选角色 → 玩家成为所选人物（信长/义元/元康/家臣各验一次）
2. 缺失角色自动补造
3. 玩家死亡 → 继承者方案走通
4. 老版本（≤1.4.x）路径：设置菜单下拉 + 控制台兜底

## 要注意的坑

- 改年龄/生死/技能的坑（官方文档实证过的四个）：改年龄不联动技能（要重算）；未出生必须同时把生日设未来；改状态有副作用（其他系统会响应）；重复击杀已死角色会断言崩溃
- 玩家对象不替换（全局引用风险）——继承者方案
- 角色 ID 找不到（其他 mod 可能屏蔽）→ 先查预设列表再遍历兜底，都找不到按剧本要求处理（禁用剧本或补造）
- 🔴 **时代 × 角色相容性**：角色池 = 时代内 alive + 剧本表"可扮演"标记（09/10 清单）；防选到"该时代已死/未出生"角色——下拉过滤 + validator 双层校验
