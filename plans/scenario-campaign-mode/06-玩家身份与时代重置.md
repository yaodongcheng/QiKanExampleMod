# 06 — 玩家身份与时代重置

> 阶段：Phase 1 ｜ 依赖：01、07（角色映射） ｜ 完成后：开局选剧本 → 世界拨到那个年代 → 玩家成为历史人物本人

## 这一步做什么（一句话）

开局选剧本（比如"桶狭间之战"）之后，把整个世界**拨到 1560 年**：该活着的活着（信长 26 岁、今川义元 41 岁正当年），不该活的还没出生或已死；然后**玩家变成织田信长本人**——名字、阵营、位置、部队、装备全套注入；织丰里缺的角色按剧本表补造；玩家扮演的角色死了，换继承者继续。

## 玩家视角

- 新游戏 → 高级开局选项里多一个"剧本"下拉（官方 1.5.1 机制，零 UI 代码）→ 选"桶狭间" → 开局你就是信长：顶着信长的名字、织田家的大名、站在尾张
- 世界是 1560 年的：义元活着、光秀还年轻、该在的城都在
- 信长战死（比如本能寺没打过去）→ 不直接结束：换扮演秀吉或光秀继续，剧情进 IF 线

## 怎么实现（四个部件）

1. **开局选择器**——官方"高级开局选项"扩展点：注册一个"剧本"下拉（1.5.1 专属，老版本用游戏内设置菜单兜底）；选中值随存档保存
2. **时代重置**（开档后执行一次，官方 API 已验证可行）——遍历游戏里全部角色，按剧本的"生死年龄表"：
   - 改年龄（把生日设到对应年份）
   - 改生死（没出生的设为未出生——注意要把生日设到未来，否则成年事件会把他拉活；该死的用官方击杀流程）
   - 重算技能/等级（官方初始化流程，顺序有讲究：先改年龄再算技能）
   - 阵营归属（谁该在哪个势力）
   - ⚠️ 只在新档做，存档里重算会掉级
3. **玩家身份注入**——改名（剧本表里信长的名字）→ 换阵营（织田家）→ 传送到剧本起点 → 配部队（兵种按剧本表，找不到就遍历兜底）→ 装备 → 执行剧本的"开局世界格局"（势力关系/战争状态重排）
4. **补造缺失角色 + 玩家死亡处理**——织丰缺的角色（剧本表标了"缺失则补造"的）用官方造人流程补（名字/阵营/装备来自太阁5 数据）；玩家角色死亡 → 死亡过场 + 换扮演继承者（**不替换引擎的主玩家对象**——全局引用，替换有风险，用"新造一个角色注入身份"的方案）

## 分步骤清单

| 步骤 | 做什么 | 完成标志 |
|---|---|---|
| 1 | 开局选择器（剧本下拉 + 老版本兜底） | 开局面板有剧本下拉；选中值随存档 |
| 2 | 时代重置（年龄/生死/技能/归属） | 1560 剧本：信长 26 岁活、义元 41 岁活；1582：义元已死 |
| 3 | 玩家身份注入（名字/阵营/位置/部队/装备 + 开局世界格局） | 开局即信长（名字/阵营/位置/部队正确） |
| 4 | 补造缺失角色 | 缺失角色补造成功（名字/阵营正确） |
| 5 | 玩家死亡处理（死亡过场 + 换继承者） | 信长战死 → 过场 → 换扮演秀吉/光秀 |

## 做完怎么验收

1. 开局面板剧本下拉；选桶狭间 → 世界拨到 1560（信长 26/义元 41）→ 玩家是信长
2. 缺失角色自动补造
3. 玩家死亡 → 继承者方案走通
4. 老版本（≤1.4.x）路径：设置菜单下拉 + 控制台兜底

## 要注意的坑

- 改年龄/生死/技能的坑（官方文档实证过的四个）：改年龄不联动技能（要重算）；未出生必须同时把生日设未来；改状态有副作用（其他系统会响应）；重复击杀已死角色会断言崩溃
- 玩家对象不替换（全局引用风险）——继承者方案
- 角色 ID 找不到（其他 mod 可能屏蔽）→ 先查预设列表再遍历兜底，都找不到按剧本要求处理（禁用剧本或补造）
