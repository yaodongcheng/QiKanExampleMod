## 这一步做什么（一句话）

织丰 mod 提供了日本战国的一切素材（地图、40 个势力、848 座城、全套日式兵种装备、上百个日式场景）——但**它的程序（DLL）在 1.5.1 用不了**（已反编译实测：引用了 1.5.1 已删除的程序集 + 一批接口签名变了，加载即崩）。**好在它的世界是 100% 用数据文件搭的**（程序里没有任何生成逻辑）。所以：我们自己写一个几十行的"壳"，注册"战国战役"入口，织丰的数据文件照常加载——地图、人物、兵种、场景全用它的，程序用我们的。

## 玩家视角

- 主菜单多一个"历史剧本战役"入口（替代织丰原来的入口）
- 选剧本进世界：40 个日本势力、848 座城、日式兵种装备、日式场景全在
- 年代不锁死 1568（织丰原版锁死在 1568 年开局）——由你选的剧本决定（桶狭间 1560 / 本能寺 1582）

## 怎么实现（四个部件）

1. **数据核对清单**——把织丰 1.2.12 客户端的资源盘点清楚（这是只读检查）：场景清单（哪些能用于程序化战斗）、装饰部件清单、角色/城池 ID 表（织田信长=lord_1_oda、京都=town_KIN5 这种）、汉化包结构。产出素材表供 03 用
2. **克隆注册层**（内容包的小 DLL）——注册"历史剧本战役"入口 → 启动战役 → 加载织丰的数据文件（势力/人物/城/兵种/装备全自动，数据文件本身带了"只在战国战役加载"的开关，我们的战役名跟它兼容就零改动）→ 注册战斗相关的基础规则（织丰 60 个规则里只挑与战斗/剧本相关的，其余跳过）→ 加载战场选择表（哪个地形用哪个场景）
   - 明确放弃：织丰的抽卡/海战/港口/寺庙/决斗玩法、它内嵌的外交 mod（启动弹窗警告逻辑必须绕开）——这些与历史剧本无关，首版不做
3. **素材表落地**——把盘点结果写成数据文件（场景候选、装饰部件、火粒子、氛围），供 03 程序化编排器读取
4. **接线验证**——本 mod 引擎在织丰战役里跑通：世界观自动生成正常（数据型 mod 天然适配）、剧本条件能命中织丰对象（"尾张城归织田家"能查出来）

- 织丰的数据文件与 1.5.1 的兼容性**必须实测**（预计可用——数据格式跨版本稳定，但没验证过就不算数）
- 我们的战役名怎么起（跟织丰兼容 = 数据文件零改动）
