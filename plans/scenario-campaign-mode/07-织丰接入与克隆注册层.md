# 07 — 织丰接入与克隆注册层（Shokuho Integration & GameType Clone）

> **Phase 2 | 依赖：01-06 机制层完成 | 出口：织丰战役可启动（数据全用织丰，不用 Shokuho.dll）+ 素材表**
> 对应蓝图：§二 / §4.2 / §八。数据源：`MB2_1.2.12\Mount & Blade II Bannerlord\Modules\Shokuho\`（完整解压版）+ `Shokuho_CNs`。

## 背景（反编译实锤，2026-08-24）

Shokuho.dll 是 1.2.12 专属产物，**在 1.5.1 硬失败**：
- ❌ 引用 `TaleWorlds.MountAndBlade.CustomBattle.dll`（1.5.1 不存在，加载即崩）
- ❌ `SetPartyAiAction.GetActionFor*(2参)` 约 20 处（1.5.1 已改 4~5 参）
- ✅ 世界生成 **100% 靠 XML**；场景/prefab/粒子/汉化全部版本无关 → **克隆注册层 = 唯一主方案**

## 分步实施

### Step 1 — 织丰数据核对清单（只读盘点，1.2.12 客户端）
- 场景：`SceneObj/` ~120 个（31 野战 + 11 城堡 + 村庄/藏身处/比武场），确认 `sho_battle_*`/`sho_castle_map_*` 场景文件格式与 1.5.1 兼容（xscene 格式版本）
- Prefabs：`Prefabs/` 19 个 XML（sho_* 系）+ Native 76 个（营地/篝火/帐篷/拒马/火把全系列）——素材表
- ModuleData：spkingdoms（40+）/ spclans（8 文件）/ heroes（1387）/ lords（~1381）/ settlements（848）——StringId 清单（已有 `Knowledge/骑砍2织丰角色ID对应/` 资产库可复用）
- 汉化：Shokuho_CNs 13 个 XML（`{=key}` 键值）
- 输出：`素材表.md`（场景池/prefab 清单/粒子/氛围）+ 关键 StringId 表（信長=lord_1_oda、光秀=lord_1_akechi、京都=town_KIN5 等）

### Step 2 — 克隆注册层（内容包 DLL，TaikouContent 扩展）
```
ScenarioCampaignGameManager 体系（替代 ShokuhoCampaign）：
  ├─ 注册 GameType 入口（主菜单"历史剧本战役"选项——替代 Shokuho 的 CustomSandBoxNewGame）
  │    🔴 同时解决年代问题：不锁 1568（织丰 CampaignStartTime=1568-04-05 是反射写入的静态字段），
  │        由剧本选择（06 ASO/主菜单）决定初始世界状态（1560/1582）
  ├─ CampaignGameStarter.AddModel：织丰 60 个 GameModel 中【与剧本/战斗相关】选择性复刻或跳过
  │    （首版最小集：战斗奖励/晋升等；抽卡/海战/港口/寺庙/决斗模型跳过）
  ├─ AddBehaviors：同理选择性（原创 Issue Quest/抽卡/海战跳过）
  ├─ 加载织丰 XML：SubModule.xml Xmls 列表（IncludedGameTypes=ShokuhoCampaign 门控自动加载
  │    ——我们的 GameType 若命名为 ShokuhoCampaign 或兼容值则织丰 XML 零改动）
  └─ LoadSPBattleScenes(sho_sp_battle_scenes.xml)（地形索引→场景映射 31 条目，程序化选场数据模型）
  放弃（数据替代不了或与剧本无关）：内嵌 Diplomacy（启动弹窗 AbortGame 逻辑必须绕开）、
  抽卡 Gacha/海战/港口/寺庙/决斗模型、UIExtenderEx 自定义 ViewModel（首版跳过）
```
- 验收：织丰战役主菜单入口 → 新档启动 → 40 王国/848 聚落/兵种装备正常 → 1568 或剧本指定年代开局

### Step 3 — 素材表落地（程序化编排器的输入）
- 场景池：sceneIds 候选清单（两轮策略首轮 = 织丰场景，兜底 = 原版）
- 装饰 prefab 表（铁律 5：预设 ID 列表 + 场景实体 grep 兜底）：营帐/篝火/火把/拒马/和风装饰（篝火灯笼/天守/町屋）
- 粒子表：fire 系 44 个 + 烟系
- 氛围表：`sho_conv_*_noon/night/sunset`（30+）+ 原版雨夜预设
- 输出：`ModuleData/ScenarioJson/assets_jp.json`（内容包数据）
- 验收：03 编排器读取素材表 → 程序化营寨用织丰装饰/和风元素

### Step 4 — 与 LWN 核心的接线验证
- LWN 在织丰战役（克隆 GameType）内运行正常（世界观指纹机制天然适配——数据型 mod；WorldBackgroundBehavior 生成战国世界观文本）
- 剧本引擎条件原语对织丰对象（Kingdom.oda/Settlement town_CHUB11 等）解析正常
- 验收：织丰战役新档 → `custom.scenario_start` 可用 → 条件原语命中织丰对象

## 风险（最高风险项）

- 织丰 XML 与 1.5.1 的兼容性（xscene 场景格式/XML schema——预计可用，但必须实测）
- GameType 命名策略（ShokuhoCampaign 兼容值 → 织丰 XML 零改动；或需批量改 IncludedGameTypes）
- 织丰 XML 引用的 native 对象（equipment_sets/cultures 引用）在 1.5.1 是否完整
- 内嵌 Diplomacy 的 AbortGame 逻辑必须绕开（织丰 DLL 不加载则天然绕开——克隆注册层无此问题）
- 回退路线：1.2.12 客户端（MB2_V1212，ASO 不可用退 MCM）
