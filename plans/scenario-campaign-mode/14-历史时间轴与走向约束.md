## 这一步做什么（一句话）

回答"这些历史事件（1562 清洲同盟、1567 岐阜、1568 上洛、1575 长篠…1582 本能寺）如何触发、历史走向如何被约束"：**一个剧本 = 一条历史时间轴**（里程碑事件清单）+ **一套走向约束**（世界按历史轨迹演化，但玩家干预就让路、脱轨就进 IF 模式）。

## 玩家视角

- 桶狭间打赢后，时间自然流：1562 年清洲同盟的演出来了、1567 年稻叶山城换了旗、1568 年你上洛了……**世界在按历史走，但每一步你都参与或能干预**
- 你干预了（提前灭了今川 / 扶植今川 / 自己打乱了格局）→ 时间轴**让路**：该来的历史事件要么变体、要么不来了，剧本进入"你塑造的历史"——后续事件按条件生成，不再照史实排
- 你不会觉得"历史是剧本写的"（没有强制的命运感）——修正器是**导向性**的（织田的 AI 更进取、今川更保守），不是瞬间改状态

### 2. 触发机制（年份 + 世界状态双条件）

- **里程碑事件 = 01 的 ScenarioEvent，条件里加"绝对年份"原语**：`DateAfterYear(1562)` = 游戏内年 ≥ 开局基准年 + 2（骑砍2 日历从开档算年，无历史纪年——年份 = `eraYear + 流逝年数`）
- 触发 = 年份到了 **且** 世界状态满足（信长活着/光秀在明智家…）——年份是主触发，状态是前提
- 触发时走 01 事件链（演出 → 效果 → flag）——09/10 的桶狭间/本能寺就是时间轴上的两个里程碑
- 玩家可能改变前提（提前灭了今川 → 桶狭间条件不满足）→ 时间轴对该事件**让路**（见 3）
- 🔴 **玩家在场性（3D 多视角，04 三通道）**：事件触发不依赖玩家在场——玩家不在场时**结算照常执行（世界事实唯一）**、演出跳过、信息走渠道（IM 延迟失真 / PartyHUD 动向 / 世界状态变化）；🔴 **NPC 当事人从不演出**（NPC 侧 = 世界模拟结算，与太阁5 一致——事件只服务玩家视角）；**禁止"玩家不在场事件就不发生"**（历史不能等玩家——出戏）

### 3. 历史走向约束（drift 施加 + 偏离检测 + 历史脱轨）

- **drift 施加（导向性修正，非瞬间改状态）**：背景剧本（02 的纠正器）按年份逐步施加"历史轨迹"——
  - 势力趋势（织田 expanding / 今川 declining）：影响 AI 倾向（织田更积极宣战/集结，今川更保守）——**改 AI 倾向不是改状态**，世界看起来是"自然"走向历史
  - 关键节点（稻叶山城 1567 归织田）：年份窗内由织田 AI 进攻触发（02 的 lock_party 辅助织田打稻叶山城），不是凭空换旗
  - 角色状态（元康 1562 独立+结盟）：条件事件（年份+状态）触发演出 + 效果
- **偏离检测（每季评估）**：世界与历史轴的偏离度 = 关键城归属 / 势力存亡 / 关键人生死 的差集
- **历史脱轨判定**：偏离超阈值（如织田灭亡/今川存活且强盛/信长早死）→ 剧本进入 **"玩家塑造的历史"模式**：
  - 时间轴剩余里程碑**不再照史实排**，改为**条件性/IF 生成**（后续事件按世界状态推导：织田亡了 → 本州争霸线；今川强了 → 今川上洛线）
  - 修正器对已脱轨项**永久让路**（记录在案）
- 🔴 **保险丝不是牢笼**（设计哲学）：修正器只维持"未被玩家干预"的走向；玩家每一次关键干预都记录（flag），驱动 IF 分支

## 做完怎么验收

> 🔴 分拆验证（12 总纲 A9）：`custom.timeline_advance <days>`（年份条件/里程碑触发）→ `custom.timeline_dump`（drift 修正/脱轨判定）；拼装验收 = 12 Phase 3。分拆全绿前不拼装。

1. **历史自然走**：新档玩家基本不干预 → 时间自然流，里程碑按年份逐一生发（1560 桶狭间 → 1562 同盟 → 1567 岐阜 → 1568 上洛 → 1575 长篠 → 1582 本能寺），每步有演出/效果/世界变化
2. **导向性修正**：织田扩张/今川衰落是"AI 倾向 + 关键节点进攻"驱动的，没有凭空改状态（玩家视角世界像自然的）
3. **干预让路**：玩家提前灭今川 → 桶狭间不再触发 → 修正器让路 → 后续走 IF/条件生成
4. **历史脱轨**：织田灭亡 → 剧本进"玩家塑造的历史"模式（时间轴改条件生成），不硬掰回史实
5. 绝对年份计算正确（eraYear + 流逝年）；存读档时间轴状态保持

## 要注意的坑

- **导向性 ≠ 瞬间改**：drift 只改 AI 倾向和辅助关键节点，禁止"到年份直接换旗/改关系"——出戏
- 绝对年份的锚点：开档基准年（eraYear）+ 游戏流逝年（骑砍2 日历从开档算）——1582 开局时年份基准不同，原语要按剧本 eraYear 算
- 偏离检测别太敏感：玩家一次小干预不该触发脱轨——阈值只盯"结构性偏离"（势力存亡/关键城/关键人）
- 修正器让路后要**记录在案**（flag），否则下次 Tick 又拉回来
- 脱轨后的条件生成别失控：定义"IF 分支模板"（织田亡→争霸线；今川强→上洛线），不是完全自由生成
