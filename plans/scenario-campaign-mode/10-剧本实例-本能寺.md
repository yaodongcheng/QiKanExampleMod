## 这个故事是什么

1582 年，织田信长（玩家）已是天下霸主，正住在京都本能寺，身边只有少数随从。家臣明智光秀突然谋叛，率军包围本能寺放火——信长葬身火海，日本历史就此转向。**玩家可以还原历史（信长死），也可以改写历史（突围成功）**。

**玩家 = 织田信长**（48 岁）。关键人物：明智光秀（54 岁，叛将/IF 线核心人物）、羽柴秀吉（46 岁，西国征讨中，闻变返京讨伐光秀——史实线接任者）、森兰丸（信长近侍）。

## 玩家体验流程（六步，全程序化）

1. **前奏（私信铺垫）**：光秀的苦闷私信一条条来（几天的铺垫），织田家内政按背景剧本调防
2. **大军进京**：光秀的部队锁定向京都移动——你扮演信长在京都看着他的部队越来越近
3. **本能寺之夜**（分阶段巷战，程序化）：城堡场景，光秀军**一波波进攻——大门→回廊→大殿→本堂**，你率少数卫队且战且退；中途有选择（死守/突围/召集家臣）
4. **大火氛围**：火光粒子 + 橙红氛围 + 火势随时间越来越旺（引擎没有真实的火焰蔓延机制，这是氛围级的——诚实边界）
5. **战果分流**：信长败/亡（史实）→ 死亡过场 → **换扮演**秀吉或光秀继续；信长突围成功（IF）→ 全局 IF 线
6. **战后**（史实）：光秀败/降 → 秀吉继任 → 结局过场；或 IF 结局

## 剧本数据要点（内容包数据，转化管线 08 产出）

**衔接（时间连续流，太阁5 模式）**：同一时间轴——1560 桶狭间后时间自然流逝，事件按「年份 + 世界状态」双条件触发（清洲同盟 1562、岐阜 1567、上洛 1568、长篠 1575…）；1582 年到来时本能寺条件自然成立。世界格局由背景剧本（02）长时段维持。也可直接以 1582 为开局年代（06 时代重置：信长 48、光秀 54、义元已死）。

**触发条件**：`and( (Time::year) >= 1582, (Hero::lord_1_oda.alive) == true, (Hero::lord_1_mitsuhide.clan) == (Clan::<明智家 Clan ID，待 07 核实>), <玩家在京都附近 50f（游戏内距离单位，数值待实测核对）——写法待核> )`——🔴 **此处为简写示意，正式 DSL 表达式见 09**（风格统一为 09b condition 的 `and(...)` 文本表达式；字段名照 16 注册表：`Time::year` / `Hero::…alive`（与 09b 一致）/ `Hero::…clan`；相对开局 22 年后的 1582 或直接以 1582 开局；明智家 Clan ID 与京都附近判定两项待 07 素材表核实后补全）

**事件链**（6 个事件）：
1. `trigger`：光秀私信铺垫（3-4 条）+ 内政状态纠正
2. `night`：延迟数日 → "本能寺之夜"演出（火光氛围）→ 战术选择（死守/突围/召集家臣 → 记旗标）
3. `attack`：光秀军锁定进京 → 分阶段巷战战役 → 战果分流：败/亡 → 信长死 + 死亡过场 + 换扮演；胜 → 信长存活 IF
4. `aftermath`（史实）：光秀败/降 → 秀吉继任 → 结局过场
5. `if`（IF：信长存活）：关系纠正 + 专属事件线 + 结局
6. `mitsuhide_success`（IF：玩家扮演光秀且成功）：光秀天下线（后续剧本展开点）

**IF 分支点**：①夜战选择（死守/突围/召集家臣）②战果（信长存/亡）③玩家扮演的角色（信长/光秀——06 的身份选择）

**战役编排参数**（供 03）：场景 = 织丰城堡（没有用原版兜底）；夜氛围；布局 = 哨站链/分阶段（大门→回廊→大殿→本堂，光秀是最后的大将）；兵力 = 信长卫队（少数）vs 光秀军（逐波）；**大火** = 火光粒子 + 橙红氛围 + 火势递增。

## 验收（Phase 3）

1. 时间自然流到 1582（或 1582 开局）→ 本能寺触发条件成立 → 光秀私信铺垫 → 本能寺之夜演出（火光氛围）
2. 1582 直开局档：开局即条件成立 → 前奏（光秀私信铺垫）→ 夜战（本能寺之夜演出）
3. 分阶段巷战（四阶段 + 光秀压轴）→ 大火氛围可见
4. 史实线：信长亡 → 死亡过场 → 换扮演秀吉 → 秀吉继任结局；IF 线：突围成功 → 信长存活专属事件线
5. 玩家扮演光秀的变体（光秀天下线）
6. 存读档全程保持；没配 AI 全流程可玩

## 要注意的坑

- **大火是氛围级**（粒子 + 光色 + 火势递增），不是真实的火焰蔓延——引擎没有这个机制，别在这上面期待 KCD2 效果
- 换扮演不替换引擎主玩家对象（全局引用风险），用"新角色注入身份"
- 分阶段巷战用程序化波次实现（不依赖场景编辑器摆的出生点）
