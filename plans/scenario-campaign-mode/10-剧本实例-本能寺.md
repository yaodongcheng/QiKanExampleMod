## 三、事件链（honnoji.json events）

### evt_honnoji_trigger
- effects：
  1. `im_message`（光秀苦闷私聊线 3-4 条：IM 铺垫——每日一条，塑造动机）
  2. 织田家内政状态纠正（背景剧本调防）
- goto：evt_honnoji_night

### evt_honnoji_night（delayDays 链式延迟）
- effects：
  1. 演出："本能寺之夜"（sho_castle_map_a + 火光氛围 + StoryEngine 编译产物：信长与兰丸/家臣对话，intensity L5）
  2. `SCN_CHOICE_BRANCH`（死守/突围/召集家臣 → flag: honnoji_tactic）
- goto：evt_honnoji_attack

### evt_honnoji_attack
- effects：
  1. `lock_party(akechi_mitsuhide, town_KIN5, engage)`（光秀军锁定进京）
  2. `battle_mission`（分阶段巷战，编排参数见下）
- 战果分流（03 战果 flag）：
  - 败/亡 → `kill_hero(oda_nobunaga)` 结算 + 死亡过场 + `HandlePlayerDeath`（06：换扮演秀吉或光秀，IF 展开）→ goto evt_honnoji_if
  - 胜（信长突围）→ goto evt_honnoji_aftermath

### evt_honnoji_aftermath（史实线）
- effects：光秀败/降（`change_hero_clan(akechi_mitsuhide, ...)` 纠偏 + `release_party` 全部）→ 秀吉继任（`change_clan_leader` + 结局过场）→ 结局 end_honnoji_history

### evt_honnoji_if（IF 线：信长存活）
- effects：朝廷/大名关系纠正 + 专属事件线 + 结局 end_honnoji_nobunaga_alive

### evt_honnoji_mitsuhide_success（IF：玩家扮演光秀且成功）
- 光秀天下线（后续剧本展开点）→ 结局 end_honnoji_mitsuhide_success

**IF 分支点**：①夜战选择（死守/突围/召集家臣）②战果（信长存/亡）③玩家扮演角色（信长/光秀——06 玩家身份选择）

## 五、演绎链（六步，全程序化——蓝图 §4.6）

1. 前奏（IM 光秀铺垫 + 内政纠正）
2. 大军进京（lock_party 锁定京都；玩家扮演信长在京都能看到光秀军接近）
3. 本能寺之夜 mission（PhaseWaveLogic 分阶段逐波：大门→回廊→大殿→本堂；信长率少数卫队且战且退；SCN_CHOICE_BRANCH 战术）
4. 大火氛围（fire 粒子 + 橙红氛围 + FireSpreadLogic 递增——氛围级大火，引擎无真实燃烧，诚实边界）
5. 战果分流（信长败/亡→史实+死亡过场+换扮演；突围成功→IF）
6. 战后纠正（光秀败/降 + 秀吉继任 或 IF 结局）

## 六、验收（Phase 3）

1. 09 史实线完成（okehazama_history_done）→ 剧本推进到本能寺章节（"数年后"叙事）
2. 玩家在京都 → 触发 → IM 光秀铺垫线 → 本能寺之夜演出（火光氛围）
3. 分阶段巷战（四阶段逐波 + 光秀 boss）→ 大火氛围可见（粒子 + 橙红）
4. 史实线：信长亡 → 死亡过场 → 换扮演秀吉 → 秀吉继任结局；IF 线：突围成功 → 信长存活专属事件线
5. 玩家扮演光秀的剧本变体（光秀天下线）
6. 存读档全程保持；无 LLM 全流程可玩
