# 12 — 验证与发布（QA & Release）

> **全周期 | 依赖：各 Phase 出口 | 出口：端到端验证清单 + 铁律验收 + 发布流程**

## 一、端到端验证（按 Phase 顺序）

### Phase 0 验收（01 出口）
1. 新档 → `custom.scenario_start demo_border_war` → 控制台改条件（set flag/宣战）→ 事件触发 → effects 生效（宣战/停战/换主可观测）→ `[Scenario]` 日志齐全
2. 存读档 → ScenarioState 保持（事件指针/flag/已触发集合）
3. 坏 JSON / 缺失角色 / 演出中触发 → 不崩（铁律 1）

### Phase 1 验收（02-06 出口）
1. `custom.scenario_trigger` 带 lock_party → party 锁定（SetDoNotMakeNewDecisions 生效）→ 大军集结（GatherArmy 汇合）→ 到达（ArrivalScan）→ `ArmyAt` 命中 → 事件链推进 → ReleaseParty 解锁
2. 背景剧本：玩家不动 → 战争状态维持/角色调防；玩家主动改变 → 修正器让路（保险丝不是牢笼）
3. 主命：节拍派发 → 任务面板可见 → 接（推进）/拒（代价）双路径
4. 强度谱系 L1-L4 通道走通（L5 接 05 后）
5. **演示战斗**：原版场景程序化营寨（帐篷圈 + 篝火粒子 + 主将中央 + 卫队环形 + 沉睡初始态）→ 击杀主将 → 敌军 Panic 溃散 → 胜利 → flag 写入
6. StoryCompiler：太阁剧本样例 → 编译产物 dump；PlaybackEngine 播放无运行时扫描
7. StoryDialogVM 升级：多 agent 轮转 + 旁听者 + 镜头跟随说话人；旧链已断（无 OnDialogClosed 崩溃）；IM confirmFight 正常
8. ASO 开局面板剧本下拉 → 时代重置（信长 26/义元 41）→ 玩家身份注入；spawnIfMissing 补造；玩家死亡继承者
9. 无 LLM 全流程可玩（预写对话树 + 模板降级）

### Phase 2 验收（07/09 出口）
1. 织丰战役可启动（克隆注册层，不用 Shokuho.dll）；40 王国/848 聚落/兵种装备正常
2. 素材表落地（assets_jp.json）→ 03 编排器可用织丰素材（和风装饰/篝火灯笼）
3. 织丰战役新档 → ASO 选桶狭间 → 时代重置 → 玩家为信长
4. 45 天后触发链全走通：通知 → IM → 今川大军集结北上（地图可见）→ 玩家贴身不被攻击 → 雨夜前夜演出（御殿会议多 NPC）→ 战术选择 → 程序化营寨 mission（沉睡营地 + 雨夜）→ 击杀义元 → 敌军 Panic 溃散 → 战果过场 → 大地图溃逃 + 停战 + 元康转投（史实）或 IF 线
5. 存读档全程保持；两轮 StringId 兜底日志正常

### Phase 3 验收（08/10 出口）
1. 09 史实线完成 → 剧本推进到本能寺章节（"数年后"叙事）
2. 玩家在京都 → 触发 → IM 光秀铺垫 → 本能寺之夜演出（火光氛围）→ 分阶段巷战（四阶段 + 光秀 boss）→ 大火氛围（粒子 + 橙红）
3. 史实线：信长亡 → 死亡过场 → 换扮演秀吉 → 秀吉继任结局；IF 线：突围成功 → 信长存活事件线；玩家扮演光秀变体（光秀天下线）
4. 转化管线全量：TK5AllEvents 子集 → ScenarioJson + 编译产物 + actors_jp.json + 城池映射 + 本地化，产物 Schema 校验通过

## 三、LLM 降级矩阵（铁律 1）

| 功能 | 有 LLM | 无 LLM |
|---|---|---|
| 剧本主线对话 | 预写对话树 + LLM 润色 | 预写文本直出 |
| IM 私聊 | ImReplyService LLM 回复 | 模板降级 |
| 世界观段 | LLM 自动生成（WorldBackgroundBehavior） | 整段省略 |
| 演出（StoryEngine 编译产物）| 编译产物 + 可选 LLM 扩展 | 编译产物兜底文本 |
| 主命/Quest | 正常 | 正常 |

## 五、发布流程（项目惯例）

1. 机制层（Phase 0/1）在 LWN 主仓库开发（卡拉迪亚演示验证）→ 独立发布（普通玩家不受影响）
2. 数据包（Phase 2/3）TaikouContent 独立工程发布（依赖 LWN + 织丰）
3. 发布前：`dotnet build -c Release`（本机游戏版本自动检测）；最终测试用 VS2022 手动编译 DLL（项目约定 2026-08-19）
4. 织丰资源安装：用户解压 Shokuho.7z 或使用 1.2.12 客户端（发布说明写明）
