## 各阶段验收清单

### Phase 0 骨架（01）
1. 新档 → 控制台开始演示剧本 → 手动改条件（设旗标/宣战）→ 事件触发 → 效果生效（能观察到宣战/停战/换城）→ 日志齐全
2. 存档 → 读档 → 进度保持
3. 坏剧本文件 / 找不到角色 / 战斗中触发 → 都不崩

### Phase 1 机制（02-06）
1. 事件强制触发带"锁军" → 部队集结成军团、只朝目标移动 → 到达 → 下一事件条件命中 → 释放后 AI 恢复
2. 背景剧本：玩家不动 → 世界按表走；玩家干预 → 引擎让路
3. 主命：节拍派发 → 任务面板可见 → 接/拒双路径（详见 13 验收）
4. **演示战斗**（原版场景）：程序化营寨（帐篷圈 + 篝火 + 主将中央 + 沉睡）→ 击杀主将 → 敌军溃散 → 胜利 → 战果旗标
5. 演出：样例剧本编译产物 dump 完整 → 播放无现场计算；多人对话轮转 + 旁听者；旧崩溃链已断
6. 开局：🔴 时代下拉（worldscenarios）→ 世界拨到 1560 → 角色列表（scenarios，按时代过滤——1582 无义元）→ 选角色 → 玩家是所选人物（信长/义元/元康/家臣各验一次）；缺失角色补造；玩家死亡换继承者
7. 没配 AI 全流程可玩

### Phase 2 战国数据 + 桶狭间（07-09）
1. 织丰战役可启动（织丰 mod + 我们的剧本入口，🔴 必须 1.2.12）；40 势力/848 城/兵种装备正常
2. 素材表落地 → 程序化营寨用织丰素材
3. 织丰战役新档 → 选桶狭间 → 全链走通（见 09 验收）
4. 存读档全程保持；角色 ID 两轮查找日志正常

### Phase 3 本能寺 + 转化管线（08-10）
1. 时间自然流：1560 桶狭间 → 1562 清洲同盟 → 1567 岐阜 → 1568 上洛…→ 1582 本能寺章节自然到来（事件按年份+条件触发，无跳跃）
2. 分阶段巷战 + 大火氛围 + 史实/IF 双结局 + 换扮演
3. 转化管线：事件子集 → 剧本/人物表/城池映射/编译产物/翻译 全链路产物，格式校验通过

## 发布流程

1. **机制层**（Phase 0/1）在 LWN 主仓库开发（卡拉迪亚演示验证）→ 独立发布（普通玩家不受影响——剧本模式默认关）
2. **数据包**（Phase 2/3）ShokuhoTaikouExpansionPack 独立工程发布（依赖 LWN + 织丰；内容 = 剧本文件 + 补充 XML 数据包，LWN 只承担机制）
3. 🔴 **发布前跑 validator 自检查**（01「自检查脚本」：事件脚本全部内容有正确定义——语法/注册表/引用 ID/本地化/资源引用/事件间引用）+ **台本校验脚本**（05「台本校验」：语法/时序在场/能力层——说话人先入场、结尾无未完成等待、动作能力匹配等），错误 = 阻断发布
4. 发布前用 Release 编译（版本自动检测本机游戏版本）；最终测试用 VS2022 手动编译的 DLL（项目约定）
5. 织丰资源安装：发布说明写明（解压织丰包或使用 1.2.12 客户端）
