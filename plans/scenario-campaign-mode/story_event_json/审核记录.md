**设计要点**：
1. 占位符 key 用 `{PH_N}` 顺序号（TextObject 只收大写 ASCII——中文 key 不合法；注入表记录 类型+源，运行时按表注入）
2. 注入表 = 每事件报告输出（report_okehazama.txt「文本变量注入表」节）——agent 审核时对照 07 数据包逐条确认注入来源
3. 称呼规则（姓/名/名前）依赖 07 数据包字段（角色表需补 名/苗字 分列）——🔴 待 07 素材表产出后注入表才有最终值
4. `{未知NN}` 是唯一需要人工语义裁决的类别（~1,500 次全语料，桶狭间 4 处）——工具已输出清单
