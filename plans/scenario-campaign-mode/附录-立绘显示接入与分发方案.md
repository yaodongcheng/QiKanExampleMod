## 〇、叙事动机（沿用《角色头像生成》原文，2026-08-25 用户裁定）

🔴 **骑砍2 角色建模是短板**：模型丑陋、换皮即 NPC。参考仙剑四/侠客风云传的叙事法：
- **3D 角色只做基本站位动作**（舞台）；**人物认知与表情交给 2D 立绘**（面孔）——两通道分离：3D = 舞台，2D = 面孔
- 玩家对"这个人是谁、什么气质、什么表情"的认知来自**光荣风格立绘**（太阁5 认知惯性）
- 构成立绘系统的**必要性**：这是人物认知主通道（非可选），虽然载体是内容包工作

**推论**（对下文显示接入的意义）：谁在说话 → 谁的头像/立绘上屏（对话面板/IM/多 agent 演出面板）；情绪由立绘状态 + 文本表达。

- **Seedream 实测（仅历史）**：最小尺寸硬门槛 3,686,400 像素；参考图必须 base64（外网 URL 超时）；不支持透明背景（必须本地抠图）；`watermark:false` 必须带；seed 固定可复现；返回值 URL 只活 24 小时必须即刻落盘
- **实际执行链（以现实脚本为准）**：`gen_portrait.py`（b64/URL 双分支）→ `verify_pose.py` 双闸（脸≥0.025-0.030/肩≤-0.15，贴线带 need_eyes）→ `run_batch.py`/`rerun_remaining.py`（断点 build_log）→ `pick_gui.py` v3 按卡审批 → `collect_selected.py`（selected/ + mirror）→ `matte_rembg.py`（512×768 透明）→ `build_profileassets.py`（bustup/minihead/CSV）
- **成本实测**：全量 1292 卡 + 三轮重生成，单张 ¥0.4（1024×1536 medium）——旧文「1049 人/¥300-400/350-450MB/情绪图 ¥1150」为**旧模型时代的估算，已弃用**（实际约百张×0.4 ≈ ¥500 量级含全部批次）
