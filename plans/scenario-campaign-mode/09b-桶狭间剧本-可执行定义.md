## 一、剧本文件头 `scn_okehazama_1560.json`

> 🔴 **剧本结构 = 三层，自由度边界在层与层之间**（01 设计；本文件所有 JSON 都在这三层里）：
> - **剧本层**（本文件头）= 一个可选战役模式：世界状态 + 事件集 + 结局清单——玩家在剧本层**一直自由行动**（04 间隙期：主命/跑图/战斗/经营）
> - **事件层**（二~九节）= 剧情时刻：`when`（触发条件）+ `script`（步骤序列），几分钟演完——**触发瞬间打断自由行动 → 演完 → 继续自由**（01 每日调度，战斗中触发先挂起）
> - **演出层**（十节 StoryJson）= 事件内部的演绎：对白/choice/镜头——事件内**过场式全控**（观赏 + choice 节点发言，2026-08-25 裁定）
>
> **一句话**：事件之间玩家是自由的，事件内部玩家跟着剧本走。一个 22 年长档 = 大量自由时间 + 稀疏的事件时刻。
>
> 🔴 **script 执行语义（01 步骤表 2026-08-25 补）**：默认**同步顺序**——上一步完成才执行下一步（perform 演出演完 → 才轮到下一个 effect）；需并行的步骤显式标 `"async": true`（im 后台发送等）。本文件所有 script 均按此标注。
