# 历史战役剧本模式 — 总纲（先读这篇）

## 这是什么

一句话：**让玩家在骑砍2 里玩"历史剧本"**——像太阁立志传/三国志那样，选一个时代剧本（桶狭间之战、本能寺之变…），扮演历史人物（信长、光秀），历史事件会在合适的时机发生，玩家可以亲身参与、甚至改变历史走向。

**不自己画地图、不做兵种模型**——美术全部用"织丰"mod 的现成资源，我们只做"编排"。

## 玩家会体验到什么

平时世界是活的：主公会给你派任务（主命），各势力按历史背景互相攻伐，你自由发展。
事件来了有风声：先收到消息（私信/公告）→ 你亲自赶去现场 → 事件展开。
事件进行时可能是：多人对话大戏（御殿会议）、你亲手上阵的战役（桶狭间雨夜突袭今川本阵）、或历史时刻（本能寺大火）。
结局有分支：照着历史走，或者改变历史（救下今川/信长），进入 IF 线。

## 这个工程分两块

- **LivingWorldNpcs（本 mod）= 通用引擎**：造一套"历史剧本"机制——以后换权游/三国的皮，同一套引擎直接能用。代码里不允许出现任何日本战国字串。
- **TaikouContent（战国数据包）= 战国内容**：剧本、人物表、城池表、战役编排、翻译——内容从太阁立志传5 的剧本转化而来（有 2594 个现成事件）。

## 十二个分步 plan，每个一句话

| 编号 | 系统 | 一句话说明 |
|---|---|---|
| 01 | 剧本引擎骨架 | 造"事件表+条件+触发"的地基，用卡拉迪亚演示剧本验证管线 |
| 02 | 战略 AI 纠正器 | 让历史事件能指挥军队——今川大军该来围攻尾张时，引擎真把他拉过来 |
| 03 | 程序化战斗编排器 | 战役参数（谁在哪、营帐篝火摆哪、主将在哪）写成数据，引擎自动生成战场，不手工搭 |
| 04 | 体验设计 | 平时玩什么（主命）、事件怎么通知、演出分轻重（看字/亲自跑过去/亲自打） |
| 05 | 演出系统 | 太阁5 剧本翻译成骑砍2 演出；升级对话面板（接近原版样式，支持多人轮转说话） |
| 06 | 玩家身份与时代重置 | 开局选剧本后把世界拨到那个年代（信长 26 岁、义元还活着），玩家扮演历史人物 |
| 07 | 织丰接入 | 织丰的 DLL 在 1.5.1 用不了（已实测），我们自己写壳加载它的数据（地图/人物/兵种/场景照用） |

| 09 | 桶狭间剧本 | 完整剧本：今川大军压境→雨夜突袭→义元死→全军溃散→停战/洗牌 |
| 10 | 本能寺剧本 | 完整剧本：光秀苦闷→本能寺之夜→分阶段巷战→大火→信长生死两线 |
| 11 | 存档与配置 | 进度怎么存、玩家开关放哪、调试指令 |
| 12 | 验证与发布 | 每个阶段的验收清单和发布流程 |

## 关键设计决定（为什么这么做）

1. 事件要"条件+时间"触发，不是死时间线 → 玩家自由度高，世界像真的
2. 事件触发后 AI 要按历史行动 → 桶狭间要有"今川大军压境"的压迫感
3. 玩家扮演历史人物本人 → 代入感
4. 支持改变历史（IF 线）→ 重玩价值
5. 战役全部程序化生成 → 一个人开发，不可能为每个战役手工搭场景
6. 资源只组合不造 → 全部用织丰/原版现成的（已盘点清单在附录）
7. 内容来自太阁5 剧本转化 → 现成的 2594 个事件文本和人物数据
8. 织丰 DLL 用不了 → 用我们自己的壳加载它的数据（已反编译实锤）
9. 演出预编译 + 对话面板升级 → 解决旧 StoryEngine 演出死板、对话面板老旧的问题
10. 本 mod 永远是通用引擎 → 权游/三国以后能直接用

## 分几步做完

**Phase 0 骨架**（01）：地基跑通 → **Phase 1 机制**（02-06）：全部玩法机制就位 → **Phase 2 战国数据+桶狭间**（07-09）：第一个完整剧本 → **Phase 3 本能寺+转化管线**（08-10）：第二个剧本 + 批量转化工具。
每一步做完都有"可玩的验证点"（见 12）。

## 红线（每条都踩过坑）

1. 本 mod 代码里不允许出现"织丰/日本战国/太阁"字串——只准出现在数据包
2. 资源查找不能写死 ID（其他 mod 可能屏蔽导致查不到）→ 先查预设列表、查不到再遍历兜底
3. 玩家看到的文字必须走翻译表（引擎的本地化机制）
4. 没有配置 AI 也要能玩（自动降级成模板文本）
5. 新增存档字段必须同步加清理逻辑（不然换存档会串数据）
6. 旧对话系统升级时，必须切断一条会崩溃的旧回调链；游戏内确认弹窗不能走新面板的关闭接口
7. 每个新机制完成后自问："权游/三国剧本能用吗？"——不能就重新设计
