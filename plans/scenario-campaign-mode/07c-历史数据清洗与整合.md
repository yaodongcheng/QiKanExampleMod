## 〇、一句话

「把太阁5数据导入织丰」的三轮历史产物（旧匹配实验 / 753 生成物 / 废弃 StoryJson）清洗成**一套可运行的织丰数据底座**：人、家、城、中文名全部对齐织丰现有 StringId，只补织丰真没有的，产出全部进扩展包 `ModuleData/`。

**运行环境（已定性）**：织丰在 **1.2.12** 原生可运行（1.5.1 硬不兼容）——一切产出按 1.2.12 格式。

## 一、四原则（用户 2026-08-28 裁定，本 plan 的验收依据）

1. **沿用**：织丰 mod 已有的 hero/lord/clan/kingdom/culture/settlement StringId 一律沿用，零改动
2. **按需新增**：太阁5剧本点名、织丰没有的角色 → 新增（生成补充 XML）。🔴 **检查口径 = 并集**：`事件点名（522）∪ BaseInfo 人物全集（≈1049）`——因为 `csv/BaseInfo.csv` 里基本全是**太阁5 本身就有的人物**（1506 行 = 太阁5 人物底表，去重 1049），剧本数据包会拉到它的全部；只扫事件点名会漏掉「太阁5 有、事件近期没登场」的一大片（归一后并集 = **1127 人**：1049 + 事件独有 78）。口述核对：凡 BaseInfo 里的人名、事件点名的人名，都要有运行时 StringId 或明确的新增条目
3. **化名匹配**：同一人多名的（木下藤吉郎 = 丰臣秀吉 = 羽柴秀吉）必须先对名再谈新增
4. **最终物**：`ShokuhoTaikouExpansionPack/ModuleData/` 下的补充 XML 能跑事件，且**正确性经检查**
