`义元已死（桶狭间史实线完成 或 玩家亲手击杀）+ 元康活着 + 元康仍在今川家 + 年份 1562（时间窗 1560-1563）`

### 发生什么（玩家视角）
1. 通知/IM：今川家内部瓦解，元康派人秘密联络信长（三河独立意愿）
2. **演出（05，L5）**：清洲会面——元康来访，两人对谈（元康在太阁5 是"三河武士"人设：谦逊、重义），结盟仪式

4. 效果（可执行定义见上）：元康独立为德川家 + 与织田结盟 + 改名 + 关系大涨

### 行动后果（post）

### 验收

## 二、美浓攻略（1567，稻叶山城→岐阜）

### 史实
织田持续进攻美浓斋藤家，1567 年稻叶山城落城，信长移居并改名**岐阜**，立"天下布武"之旗——政权中心从尾张迁美浓，上洛的跳板。

### 前置条件
`清洲同盟完成 + 年份 1566-1568（时间窗）+ 稻叶山城仍在斋藤家 + 织田-斋藤交战（drift 维持战争）`

### 发生什么（玩家视角）
1. **drift 辅助**（02/14）：织田 AI 持续围攻稻叶山城（lock_party 辅助进攻），玩家可加入围城/亲自指挥
2. 攻城（骑砍2 围城战原版机制，drift 保证织田侧实力占优）
3. **落城**：稻叶山城归织田（`ChangeOwnerOfSettlementAction`）→ 演出：入城/改名**岐阜**（聚落改名）→ "天下布武"旗（通知/过场）
4. **选择**（IF 挂点）：善待斋藤家臣（招降，关系/人才）vs 清算（斋藤灭亡）

### 行动后果（post）
- 史实线：岐阜成为织田政权中心；织田名望大涨（上洛跳板就绪）
- **IF-拖延/失败**：若 1568 年仍拿不下（玩家不协助/斋藤有强援）→ 上洛事件延期（时间窗顺延）或变体（织田从尾张直接上洛，力量较弱）
- **IF-玩家速攻**：提前拿下 → 上洛提前

### 验收
drift 辅助进攻可见（织田 AI 真在围城）→ 玩家参与 → 落城 → 改名岐阜 + 天下布武演出

## 三、上洛（1568）

### 史实
流亡的足利义昭（足利幕府末代将军之弟）求助于信长，信长拥立其上洛，控制京都，义昭成为傀儡将军——信长自此挟将军以令天下。

### 前置条件
`岐阜完成 + 年份 1568-1570（时间窗）+ 足利义昭存在（织丰 ashikaga 势力）+ 京都归属（drift 辅助织田侧拿下京都/三好家退出近畿）`

### 发生什么（玩家视角）
1. **drift 辅助**：织田 AI 向京都进军（lock_party + 近畿攻略）
2. 通知/IM：义昭使者求援（演出：义昭拜见信长——落魄将军的屈辱与野心的对话）
3. **演出（L5）**：入京/上洛仪式（织丰城堡或京都市井场景 + 仪仗）
4. **选择**（IF 挂点）：拥立义昭（史实）/ 自立（不拥立，直接控制京都）/ 扶持他人
5. 效果：京都归织田侧；义昭成为将军（傀儡）；织田名望大涨

### 行动后果（post）
- 史实线：义昭=将军 → **与信长对立伏笔**（义昭暗中联络各势力反信长——关联 10 的"织田家内政混乱"背景）；信长获得大义名分（后续征伐有名义）
- **IF-自立**：无将军 → 各势力不认大义名分（后续事件变体：信长-朝廷/其他大名关系不同）
- **IF-义昭反叛**：义昭后来联合武田/浅井等组成"信长包围网"（若 drift 维持）→ 织田四面受敌（可设计为包围网事件，Phase 3 扩展）

### 验收
义昭拜见演出 → 入京 → 京都归织田 → 义昭将军位 → 后续对立伏笔生效（内政/包围网迹象）

## 四、长篠之战（1575）

### 史实
武田胜赖围攻长篠城（德川侧），织田-德川联军救援。信长以**铁炮三段击**（大量铁炮 + 防马栅）大破武田引以为傲的骑兵，武田名将尽丧——武田家由盛转衰。

### 前置条件
`上洛完成 + 年份 1574-1576（时间窗）+ 武田-织田/德川交战（drift 维持）+ 长篠城在德川侧被围（drift 辅助武田围城）`

### 发生什么（玩家视角）
1. 通知/IM：长篠告急——德川求援（联军集结）
2. **程序化战斗（03，L6）**：长篠救援战——织田-德川联军 vs 武田军：
   - 布局函数：`volley_line`（铁炮三段击阵型——防马栅 + 铁炮列，武田骑兵冲锋被层层射杀）——**03 布局库新增"三段击"布局**
   - 武田骑兵冲锋（数量/兵种数据化）+ 织田铁炮（织丰有 guns.xml 铁炮！）
3. **战果**：胜 → 武田重创（武田胜赖威望崩塌、名将战死——drift 武田 declining 生效）；败/玩家不参战 → 变体

### 行动后果（post）
- 史实线：武田势衰（后续武田家臣离心/武田胜赖失势）；织田东线安定 → 专心西进（石山本愿寺等）→ 直至 1582 本能寺
- **IF-武田胜**：武田不衰 → 织田东线吃紧 → 1582 年世界格局不同（本能寺条件仍成立但信长可能东线作战——触发条件里"玩家在京都"可能不满足，事件顺延/变体）
- **IF-玩家缺席**：AI 对决（坐镇）也能按 drift 走向（织田优势）结算

### 验收
三段击布局（铁炮 vs 骑兵）程序化战斗走通 → 战果 → 武田 declining 可见（drift 生效）

## 各事件与 14 drift 的关系

| 事件 | drift 辅助 | 玩家干预 → IF |
|---|---|---|
| 清洲同盟 | 元康独立状态事件（年份窗触发演出+效果） | 拒绝 → 无同盟，长篠变体 |
| 美浓攻略 | 织田 AI 围攻稻叶山城（lock_party 辅助） | 拖延/速攻 → 上洛时间窗顺延/提前 |
| 上洛 | 织田 AI 进京（lock_party 辅助） | 自立 → 无大义名分变体 |
| 长篠 | 武田 AI 围长篠 + 织田-德川联军集结 | 武田胜 → 武田不衰变体 |

**IF 变体原则**：玩家干预只改变"该事件及其后续"，不推翻整条时间轴（结构性脱轨才走 14 的"玩家塑造的历史"模式）。
