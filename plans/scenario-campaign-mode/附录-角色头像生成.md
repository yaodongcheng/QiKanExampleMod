# 附录 — 角色头像（AI 生成 + PNG 导入）

> **状态：⏳ 非前期必须**（Phase 2+ 数据包阶段）｜ 技术路径已验证：`plans/custom-png-import-guide.md`（2026-07-03 端到端验证，PNG 正常显示颜色正确）
> 🔴 **不阻塞 Phase 0/1**（引擎/机制）——引擎侧只留"头像引用位"（占位先行），头像生成是数据包内容工作。

## 设计动机（为什么是"立绘叙事"，2026-08-25 用户裁定）

🔴 **骑砍2 的角色建模是短板**：模型丑陋、不同的人没有区分度（换皮即 NPC）。参考古早 3D 游戏（**仙剑四 / 侠客风云传**）的叙事方法：

- **3D 角色只做基本的站位动作**（槽位/走位/actor_action——05 的舞台调度已覆盖，不求精细）
- **人物认知与表情控制交给"立绘 + 对话框"**：玩家对"这个人是谁、什么气质、什么表情"的认知来自 2D 立绘（**光荣风格 = 玩家对战国人物的既有认知**——太阁5 玩家看立绘认人），对话情绪由立绘表情状态 + 文本表达
- 即：**3D = 舞台（站位/走位/基本动作），2D = 面孔（认知/表情/情绪）**——两通道分离，互不越界：3D 不追求精细面捕（引擎做不到），2D 不承担走位（立绘不动）

**推论**：头像/立绘系统是**人物认知的主通道**（虽是 Phase 2+ 内容工作，但叙事上是必要件，不是可选项）。

## 目标

骑砍2 **没有原生头像**（对话面板/大地图 UI 无角色头像资源）。方案 = **数据包为每个角色 AI 生成"光荣风格"头像**（立绘风/半身像），通过已验证的 PNG 导入链路加载——**大地图 IM/对话可见"角色头像在说话"，多 agent 演出面板谁说话切谁的头像**。

## 使用场景

1. **大地图 IM 聊天**：消息行显示说话人头像（wheels.d/im.md 群聊 UI 扩展——头像位先留占位）
2. **05 多 agent 对话面板**：名字/头像/文字区——**谁说话切谁的名字头像**（05 面板升级第 3 部件，头像位先留占位）

**🔴 表情控制（立绘承担，古早 RPG 式）**：对话中角色情绪（怒/笑/惊/哀）→ 立绘/头像切换对应**情绪状态图**（数据包每角色多情绪图，仙剑四式立绘表情切换；首版可只做静态头像 + 文本情绪，情绪图按需批次生成）——3D 表情引擎做不到，表情全走 2D。

## 技术路径（custom-png-import-guide.md，已验证）

| 环节 | 方案 |
|---|---|
| 纹理加载 | 🔴 Harmony 补丁 `Patch_TextureLoadFallback`：`.tpac` 命中放行 → 未命中搜 `GUI/SpriteParts/{name}.png` → 加载 |
| 通道转换 | PNG（RGBA）→ `System.Drawing.Bitmap` → 另存 BMP（BGRA）→ 引擎加载——**直接加载 PNG 红蓝对调** |
| 注册 | `GUI/{前缀}SpriteData.xml`：**零注释 / 全子元素 / `<GenericSprite>` / `<SpriteSheetSize>` 必须填实际宽高**（坑全表见教程第七节） |
| 加载 | `AlwaysLoad="true"` 引擎自动加载；兜底手动 `cat.Load(ctx, depot)` |
| 引用 | `<Widget Sprite="taikou_avatar_xxx" />` |
| 补丁目标 | `LoadTexture` 是显式接口实现——必须 `TargetMethod()` + `GetInterfaceMap().TargetMethods`（教程坑 #9） |

## 头像数据（ShokuhoTaikouExpansionPack 数据包）

- **生成**：AI 生成"光荣风格"头像（立绘风/半身像），**随 ShokuhoTaikouExpansionPack 数据包加载**（不塞 LWN 核心——worldview 铁律：日战头像属数据包，模块职责划分裁定 2026-08-25）
- **覆盖范围**：首版 = 人物池 ∩（有戏份/可扮演）角色（09/10 剧本表 + 高频 IM 角色，几十~百级）；全量 1960 人按需批次生成（TaikouHero 表全量）
- **命名规范**：`taikou_avatar_{heroId}.png`（heroId = **骑砍 ID StringId**——头像与角色绑定用 StringId，铁律 20；不用显示名）
- **尺寸**：固定 256×256（SpriteSheetSize 必须准确，教程坑 #4）
- 每 SpriteCategory 一个角色头像（或批量合图——SpriteSheet 大小限制内可拼；首版一角色一图最稳）

## 集成要点

- **05 对话面板**：头像位先留占位（无头像显示角色首字/默认图标），AI 头像到位后填——05 面板升级步骤的"头像"不阻塞
- **IM 聊天**：消息行头像位占位先行（无头像不显示或显示首字）
- **降级**：无头像角色 → 占位正常显示不崩（与 LLM 降级同精神）

## 验收（Phase 2+）

1. 数据包安装后：大地图 IM 消息显示说话人头像；多 agent 面板说话人切换头像（谁说话切谁）
2. 无头像角色：占位正常（不崩、不空白报错）
3. 头像与 StringId 绑定正确（改名/多语言下头像不错位）
