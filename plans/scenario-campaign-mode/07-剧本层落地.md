## 现状（已完成，不再重复实施）

- **Taikou 内容包可跑**：多时代机制已实机验证通过（`TaikouCampaign1560` / `TaikouCampaign1582` 双时代，
  建世界 → 建号/选人 → 日本图 → 进城全通；见 [时代剧本切换-验证](../时代剧本切换-验证.md)）
- **LWN 通用战役层就位**：`LivingWorldCampaign` + `LivingWorldCampaignGameManager` + 选人/建号管线
- **1.2.12 为运行环境**（不变）；织丰相关的历史验证见附录（**禁止实施**）

## 这一步做什么（一句话）

**把剧本引擎挂到 Taikou 战役上**：玩家装 Taikou + LWN，主菜单「剧本」入口进战国世界跑剧本引擎（事件/时间轴/演出/主命）。
Taikou 的世界与数据保持原样，剧本引擎附加在其上。

> 🔴 **与原方案最大的不同：没有"共存"问题了。**
> 原方案要核对织丰的 **138 个 Harmony 补丁 + 19 个行为**与剧本引擎的冲突面；
> **Taikou 是纯数据包**（ModuleData XML + thin 战役类，**零补丁、零行为**），
> 行为全部由 LWN 提供——而 LWN 就是我们自己的代码。**冲突面从"跨 mod 共存"变成"我们自己的模块内协调"。**

## 玩家视角

- 玩家装两个 mod：**Taikou**（内容包：世界数据 + 日式资源）+ **LivingWorldNpcs**（引擎：剧本/演出/主命/IM）
- 主菜单「剧本」入口 → 选剧本 → 选人 → 进战国世界（**多时代已通**：1560 / 1582 各一套数据）
- 选剧本进世界：Taikou 的势力/据点/人物 + 日本图（`Main_map`）+ 日式兵种装备
- 年代由**所选时代**决定（不是运行时改时间——多时代 = 多套数据段，见 [时代剧本切换-验证](../时代剧本切换-验证.md)）

## 内容归属（2026-08-25 定，2026-09-11 改载体）

**实现载体：`Taikou` 内容包**（`Modules/Taikou`；数据 + 资源 + 剧本文件一体）。发布依赖 = **Taikou + LivingWorldNpcs**（原"织丰 + LWN + ASO + 补充包"作废）。

- 🔴 **内容归属**：**所有剧本文件（DSL 剧本/演绎剧本/编译产物/本地化）+ 补充 XML 数据包（人物/城池/势力等）全部在 Taikou 内开发产出**；LivingWorldNpcs 只承担功能机制（worldview 铁律：核心零日战字串）
- 🔴 **版本要求：必须 1.2.12**（Taikou 的目标机；1.5.x 的战役模式暂不接入）
- **明确不做**：不打包织丰任何资源（织丰已退役，其资源不进入本工程）

## 明确要做（四块）

### 1. 战役层对接（原"共存性验证"，性质已变）

**不再需要跨 mod 冲突核对**——改为**确认剧本引擎与 LWN 现有行为的协调面**：

- 剧本引擎（01-06）与 LWN 既有系统同场：`AgentBrain`（NPC 行为接管）/ `WorldEventStore`（犯罪事件）/
  IM 传讯 / 记忆系统 / 存档 —— 逐条核对**同一世界状态下两者会不会打架**（如：剧本让某领主移动 vs 行为层自主决策）
- 剧本的"战略纠正"（02）与 LWN 的自主演化：**纠正优先**（剧本是历史骨架，行为层填充血肉）
- 产出**协调清单**，有冲突的记入 02/14 的处理

### 2. 嵌入层（剧本层核心）

- **剧本入口**：复用**已有的「剧本」入口**（`EraCatalog.BuildEntryOption` + `ScenarioSelectScreen`，
  多时代验证时已实现）——剧本 = 该时代下的"剧本实例"（桶狭间 = 1560 时代的一个剧本），
  入口链已经在位：主菜单「剧本」→ 选剧本 → 选人 → 开局
- **战役启动**：`TaikouCampaign<年份>`（我们自己写的 thin 类，**无需反射覆盖别人的时间锁**）+ LWN 通用 GameManager
- **剧本注入**：`OnGameStart`/`OnCampaignStart` 阶段向 campaign 注入剧本行为（时间轴/事件调度/演出/主命）——
  **LWN 的 `LivingWorldCampaign` 就是注入点**（加 behavior 是我们自己的代码，零反射）
- **角色创建**：走已有的**选人流程**（`HeroSelectOverlay` + `StartingHero`，已实机通过），扮演历史人物

**设计依据（对照原方案的差异）**：

| 原方案（挂织丰） | 现方案（挂 Taikou） |
|---|---|
| 需反编译确认织丰的 AddBehaviors 无条件执行 | **不需要**——Taikou 无行为；LWN 的行为由我们自己注册 |
| 需反射覆盖织丰时间锁（`CampaignStartTime`） | **不需要**——时代由 `TaikouCampaign<年份>` 的 GameType 决定（多时代机制已解决） |
| 复用织丰 `ShokuhoCampaignGameManager` | 复用**我们自己的** `LivingWorldCampaignGameManager`（已是通用基座） |
| 共存：织丰 138 补丁 + 19 行为冲突面 | **不存在**（Taikou 零补丁零行为） |

### 3. 素材表落地

**盘点 Taikou 现有素材**（供 03 编排器用）：
- **已有**：日本图（`SceneObj/Main_map`，地形 + 地图实体）、据点内部场景（当前为 Native 占位）、
  立绘资产（2720 张，已迁入 Taikou `AssetPackages/`）
- **待补（T5）**：日式场景 / 日式兵种装备外观 / 火器粒子 / 氛围
- 产出素材表 + **关键 ID 确认**（剧本引用的对象：信长/京都等）

### 4. 接线验证

剧本条件能命中 Taikou 对象："尾张城归织田家"等条件查得出来；剧本事件在 Taikou 世界正常触发；演出/主命跑通。

## 要注意的坑

- **依赖 01-06 审核**：嵌入层需要剧本引擎在场，01-06 未通过前禁止实施
- **世界数据按时代分**（不再是"织丰 1568 快照"问题）：Taikou 每个时代一套数据段（`settlements_<年份>.xml` 等），
  剧本年代 = 所选时代；**剧本若要更细的时间点（如 1560 年内的事件），那是剧本层自己的时间轴（14），与数据加载无关**
- **剧本层的存档字段与 LWN 既有存档共存**：新增 `SaveableField`/`SyncData` 注意 ID 冲突
  （LWN 已有 `LivingWorldSaveableTypeDefiner`，新类型在它里面加号段）
- **选人流程已实机通过**：扮演历史人物走 `HeroSelectOverlay`（不再需要 ASO/StartAsAnyone 外部依赖）
- 🔴 **不要恢复"挂织丰"的任何做法**：织丰已退役为本工程的写法参考，不参与运行
