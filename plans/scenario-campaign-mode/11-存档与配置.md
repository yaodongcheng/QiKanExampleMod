## 这一步做什么（一句话）

三件杂事但都是红线：**进度存哪里**（剧本进行到哪一步、哪些旗标、哪些部队被锁定——存进存档，读档不丢）、**玩家开关放哪**（游戏内设置菜单 vs 配置文件，按项目规矩两边不交叉）、**调试指令**（控制台一键看状态/触发事件）。

## 玩家视角

- 游戏内"Mod 选项"里有一个总开关："剧本模式"（默认关——普通卡拉迪亚玩家完全不受影响）；老版本（无官方开局选择器）还有一个剧本下拉
- 开发者改配置文件可以调日志详细度、乱世事件频率
- 调试：控制台指令查看剧本状态/强制触发/设旗标

## 怎么实现（三个部件）

1. **存档**——剧本进度（当前剧本/事件指针/已触发集合/分支旗标/锁定部队登记/主命状态）序列化成一段文本存进存档；**新档必须清空**（这是防串档的红线，加一个字段就要加一行清理）；旧存档没有这段数据 → 安全跳过
2. **配置**——按项目"双配置"规矩，同一项只放一边：
   - 游戏内 Mod 选项（玩家看的）：剧本模式总开关、剧本下拉（老版本兜底）
   - 配置文件（开发者看的）：日志详细度、乱世事件频率、主命开关
3. **控制台指令**——剧本列表 / 开始剧本 / 中止 / 强制触发某事件 / 设旗标 / 看内部状态 / 看主命

## 分步骤清单

| 步骤 | 做什么 | 完成标志 |
|---|---|---|
| 1 | 存档（进度序列化 + 新档清理 + 旧档兼容） | 存读档进度保持；新档无残留；旧档不崩 |
| 2 | 配置（游戏内开关 + 配置文件，两边不交叉） | 开关生效；关掉后完全不影响普通玩家；配置文件热重载 |
| 3 | 控制台指令全集 | 全部指令可用、日志统一前缀 |

## 做完怎么验收

1. 存读档：事件指针/旗标/锁定部队/主命状态全保持；新档干净
2. 游戏内开关生效（关 = 普通玩家无感）；配置文件热重载
3. 控制台指令齐全（调试全靠它们）

## 要注意的坑

- 存档内容超长会被引擎裁剪 → 有自动防护 + 监控（剧本状态如果膨胀要拆分）
- **新档清理遗漏 = 串档**（实机踩过的坑）——任何新增的静态状态都要同步加清理
- 设置菜单的显示顺序有坑（倒序显示），照现有写法办
