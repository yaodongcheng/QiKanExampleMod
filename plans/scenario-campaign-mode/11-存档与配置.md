# 11 — 存档与配置（SaveState & Configuration）

> **各 Phase 同步 | 依赖：01（ScenarioStore）| 出口：lwn_scenario 存档 + MCM 开关 + 控制台指令齐全**
> 对应蓝图：§3.7。代码位置：`Scenario/ScenarioSaveState.cs` + `Core/MCMSettings.cs` + `Core/Settings.cs`。

## 目标

剧本模式的持久化与配置，全部走项目既有纪律（SyncData 范式 + 双配置体系 + 控制台指令）。

## 分步实施

### Step 1 — 存档（ScenarioSaveState.cs + MyBehavior 接线）
- `ScenarioStore.Serialize()` → JSON 字符串（ScenarioState：ActiveScenarioId/CurrentEventPointer/FiredEventIds/BranchFlags/LockedPartyRegistry/Orders 状态）
- `MyBehavior.SyncData` 新增 key：`string scnJson = SaveStringGuard.GuardJson("lwn_scenario", ScenarioStore.Serialize()); dataStore.SyncData("lwn_scenario", ref scnJson); if (dataStore.IsLoading) ScenarioStore.Deserialize(scnJson);`
- 🔴 `ResetAllCampaignState()`（MyBehavior.cs:98）补 `ScenarioStore.ResetAll()`（static + 只在 IsLoading 恢复 = 必须清，现有 18 组清单同步）
- 旧档无 key → Deserialize 空安全（不崩）
- 验收：存读档 ScenarioState 保持；新档清理正常（ResetAll 不残留）

### Step 2 — 配置（双配置体系纪律：同一项只能进一边）
- **MCMSettings（玩家可见）**：
  - `[SettingPropertyBool] EnableScenarioMode`（总开关，默认关——不影响普通卡拉迪亚玩家）
  - `[SettingPropertyDropdown] ScenarioOverride`（无 ASO 版本（≤1.4.x）的剧本选择兜底；1.5.1+ 走 ASO 面板）
- **Settings（config.json，开发者项）**：
  - `ScenarioLogLevel`（0/1/2：`[Scenario]` 日志详细度）
  - `ScenarioWorldEventFrequency`（乱世氛围降频系数，默认 0.5）
  - `ScenarioOrdersEnabled`（主命系统开关，默认 true）
- 🔴 LLM 三字段、PlotEnabled 等既有字段不碰；新字段 `[JsonIgnore]` 规则照办
- 验收：MCM 面板出现剧本开关；config.json 热重载（Settings.Reload）

### Step 3 — 控制台指令全集（ScenarioConsoleCommands.cs）
- `custom.scenario_list`（剧本/事件/状态/flag dump）
- `custom.scenario_start <id>` / `custom.scenario_abort`
- `custom.scenario_trigger <evtId>`（强制触发，调试）
- `custom.scenario_flag <name> <0|1>`
- `custom.scenario_state`（内部状态：事件指针/锁定 party/挂起队列）
- `custom.scenario_orders`（主命池/当前主命）
- 验收：全部指令可用 + 日志格式统一 `[Scenario]`

### Step 4 — 与既有系统并发策略（未决问题①落地）
- 剧本模式激活时（EnableScenarioMode + ActiveScenario 非空）：犯罪/委托/IM 系统保留但降频（WorldEventSimulator.SuppressAutoGeneration 已有总闸 + ScenarioWorldEventFrequency 系数）
- IM 系统保留（剧本 IM 铺垫依赖它）
- 验收：剧本模式下乱世事件降频但 IM 正常

## 出口验证

1. 存读档：事件指针/flag/锁定 party/主命状态全保持；新档 ResetAll 干净
2. MCM 开关生效（关 = 完全不影响普通玩家）；config.json 热重载
3. 控制台指令全集可用（调试全流程靠它们）
4. 双配置纪律：新项只进一边（grep 检查无交叉）

## 风险

- 存档超长防护（SaveStringGuard.GuardJson 30KB 裁剪）——ScenarioState 增长监控（锁定 party 登记表/已触发集合）
- ResetAll 遗漏 = 串档（static 残留）——新增任何 static 同步补（CLAUDE.md 存档纪律）
- MCM 显示倒序坑（Order 属性，L43 注释）
