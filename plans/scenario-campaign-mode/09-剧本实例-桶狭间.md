## 这个故事是什么

1560 年，今川义元（当时最强大的大名）率数万大军上洛，途经尾张。织田信长（玩家）以数百兵力奇袭今川本阵，义元战死，今川家崩溃——**日本史的转折点**。

🔴 **"数万大军"怎么呈现（骑砍2 百人战约束，三层方案）**：引擎一场战斗极限就是百人级，"数万"必须靠**呈现分层**，不是真实生成几百个角色单位（engine 术语 agent）：
- **大地图层（02）**：今川军团 = 6-10 支部队（每支 50-90 人）从骏府列队沿东海道推进，抵达后对尾张形成包围态势——地图上一大片部队旗帜，规模感来自部队群 + 包围姿态
- **战斗层·实际参战（03，百人级）**：玩家实际切入的义元本阵营地，可战兵力 ≈ 百人（卫队 + 足轻 + 骑马）——这就是骑砍2 的真实战斗规模，数据见 [09b 战斗预设](09b-桶狭间剧本-可执行定义.md)
- **战斗层·氛围外圈（03/05 以少代多）**：营地外圈"氛围环"——火把阵列、旗帜、帐篷排、远处人影 + 持续声景（营啸/战鼓），视觉上"营帐绵延数里"；**不生成可打的角色单位**（性能 + 意义双考量）；击杀义元后氛围环同步"炸营"：旗帜倒伏、火把四散、声浪外扩——"数万大军一夜崩溃"的体感来自氛围层，不是真的几百个逃兵

**玩家 = 织田信长**（26 岁，尾张之主）。关键人物：今川义元（41 岁，大敌/IF 线（假设线）核心人物——IF = 与史实不同的假设分支）、松平元康（18 岁，三河小领主——义元死后脱离今川独立，与织田**结清洲同盟（对等同盟）**，史实线）。

**多角色（06 开局选择器）**——三条裁定（2026-08-25）：

- **决定：人人可扮演**——时代内存活角色皆可（理由：自由感）。5 条个人线之外的角色无专属剧情，但三通道保证看得见（在场看现场演出 / 缺席收渠道 / 世界变化地图可见）
- **决定：个人线推荐五条**——信长（奇袭者主线）/ 义元（当事人，败亡 = 真实战败 → 06 死亡继承换今川氏真）/ 元康（今川先锋 + 独立者）/ 织田家臣（利家线：被处罚 → 随军 → 论功）/ 秀吉（婚约线）。**同一个桶狭间，立场不同玩法不同**（详见下方多视角三通道节）
- **决定：演出不走交互、全过场**——剧情演出 = 过场式全控，玩家纯观赏（05 前期 MVP，理由：纯观赏保沉浸）；**不做拔剑打断/掀桌/秩序维持者交互**；仅在剧情选项节点（如战术选择）玩家发言选路

### A. 信长线（主视角）——奇袭者

0. **开局叙事·我是信长**：醒来是信长（26 岁尾张之主）。进城，家臣禀报"今川义元集结数万大军，可能要上洛"；旁白宣告"东海第一武士今川义元，终于发兵上京"（159 情报宣告）。任务面板出第一条主命"整顿尾张防务"——第一分钟知道我是谁/大敌是谁/要干嘛
1. **间隙期**：主命 + 自由行动；地图上今川部队开始聚拢（压迫感渐强）
2. **今川压境**：鸣海陷落换旗（战报渠道）；你贴着今川大军走它不理你（AI 锁定，"没被发现"的模拟）
3. **出阵·敦盛之舞**（EFF0C300_159 T25-T43 第一人称）：城主间，信长独舞《敦盛》"人生五十年……"→"出兵！"→ 利家请罪获赦（带罪家臣归队；EPF29300_705 = 09c 利家线）；秀吉随军（🔴 2026-08-25：带罪仅利家）
4. **热田参拜**（162）：数骑疾驰参拜热田神宫，吉兆（马衔之音）"天运在我们这边！摘了义元的首级！"——天命感
5. **野战开场**（大地图立绘，2026-08-25 裁定）：两军相遇 → 义元止步休憩（EFF0C300_163 织田线机位／EFF06E00_163 今川线完整版；EPF29300_707 = 利家带罪线替换线，09c）→ 信长观察窄道"有胜算了！" → 战术选择（选项时发言，其余观赏）→ 密令 → 战役
6. **战役**：雨夜突袭沉睡营地（布阵侧指挥）→ 击杀义元 → 全营炸营（近处溃散 + 外圈氛围炸营）→ 自动判胜
7. **战后**：胜利过场 → 义元死亡结算 → 今川停战溃逃 → 鸣海换首级（使者来访，165）
8. **余波**：论功主持（709）→ 三河风声（渠道）→ 1562 清洲同盟（15 演出）→ 时间连续流继续

### B. 义元线——当事人（败亡 = 真实战败）

0. **开局·我是义元**：醒来是义元（41 岁今川之主，"东海第一武士"）。决意上洛，召集诸将（今川-北条-武田同盟在册）
1. **出阵**：骏府出征（**无敦盛之舞——那是信长的戏**）；大军沿东海道推进（地图上你的军团）
2. **鸣海捷报**：元康攻陷鸣海（161 报捷——庆功酒的由头）
3. **休憩**（163 第一人称）：庆功酒 →"全军止步！休息"→ 部将劝谏"毫无防备的场所！危险！"→ 不听 → 豪雨降下
4. **被袭**：奇袭混乱（第一人称：喊杀声四起，卫队护主）→ 真实战斗（营地防守侧）
5. **终局**：战败被杀 → 06 死亡继承换氏真（今川衰落线）；或信长线放走 → IF 存活线（今川继续强盛）

### C. 元康线——先锋与独立者

0. **开局·我是元康**：醒来是元康（18 岁三河小领主，今川先锋）
1. **攻略**：攻鸣海（161 **第一人称指挥小仗**）→ 陷落报捷
2. **归途**：战后随今川军行动（义元死后军团溃散背景下）
3. **独立**：大树寺打探（167 第一人称：今川代官弃城而逃）→ 接收空城冈崎 → 独立决断（史实线：等 15 清洲同盟；IF 线：义元活时独立 = 背叛，需由头）
4. **终局**：德川家成立 / 隐忍留今川（IF 分支）

### D. 利家线——带罪家臣（太阁5 主人公原型）

0. **开局·我是利家**：带罪之身（被逐/浪人），在自宅得知今川入侵（704 浪人视角）→ 赶回清洲
1. **请罪获赦**（705 **第一人称**）：闯城主间请罪——"处罚就此取消，发挥你的枪法本领吧！"→ 人物登用

4. **论功**（709 第一人称）：受赏——"利家，你回来了。"处罚解除 + 功勋 + 复归家臣

### E. 秀吉线——足轻与求婚者

0. **开局·我是秀吉**：木下藤吉郎（足轻/浪人出身），闻今川入侵

## 🔴 多视角三通道（2026-08-24 用户裁定）

**同一个桶狭间，你扮演谁就是谁的命**——不做太阁5 式"每视角一份完整演绎"（AVG 重放：3D 出戏 + 成本爆炸）。三通道：**结算唯一**（历史节点的世界效果全局只执行一次）、**真实玩法共享**（名场面 = 同一场可打的仗，玩家在哪侧哪侧有戏）、**缺席走渠道**（IM 传闻延迟失真、世界信号——情报必须来自渠道）。

**太阁5 源名场面清单**（每场谁在场看演出/谁参与玩法/谁收渠道的落点映射见 [09b 第十二节](09b-桶狭间剧本-可执行定义.md)）：敦盛之舞+出阵（EFF0C300_159 T25-T43）｜鸣海攻防（160/161）｜热田参拜（162）｜布阵 vs 休息（707/163 镜像——3D 里是同一场仗的机位差异）｜义元之死（708/164）｜凯旋+世界结算（166）｜鸣海换首级（165）｜大树寺独立（167）｜论功（709）｜秀吉·宁宁婚约（166 内嵌分支）。

**纪律**：结算（义元死/元康独立/清洲同盟）只在各自结算点执行一次；玩家不在场事件照常发生（14 在场性）；NPC 当事人从不演出（世界模拟结算）。

## 要注意的坑

- 今川大军的"数万军"（骑砍2 百人战约束）= **三层呈现**（见"这个故事是什么"节）：大地图 6-10 支部队列队推进/包围（02 军团）→ 实际切入的本阵 = 百人级真实战斗（03）→ 战斗外圈氛围环撑场面（05 以少代多，不生成可打 agent）；"一夜崩溃"的体感 = 近处真实溃散 + 外圈氛围炸营（旗帜倒/火把散/声浪外扩）
- "没被发现"靠 AI 锁定模拟，战役里靠"沉睡营地"（敌人 AI 冻结，你靠近才激活）
- 史实线 → 本能寺：**时间连续流（太阁5 模式，04 时间模型）**——不跳时间，事件按「年份 + 世界状态」双条件在时间轴上自然发生；22 游戏年（1560-1582）在骑砍2 是正常长档（一年 360 天（12 月 × 30 天），一档 1000+ 天常见）；**世界格局维持 = 背景剧本（02）的长时段职责**（织田稳步扩张、其他势力平衡），保证 1582 本能寺条件仍成立
