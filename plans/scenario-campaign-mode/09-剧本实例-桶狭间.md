## 二、事件链（okehazama.json events）

### evt_okehazama_trigger
- when：`And[ DateAfter(45), SettlementOwner(town_CHUB11, clan_oda_1), HeroAlive(imagawa_yoshimoto), HeroClan(imagawa_yoshimoto, clan_imagawa_1), AtWar(Kingdom.oda, Kingdom.imagawa, true), Not[FlagSet(okehazama_started)] ]`
- effects（按序）：
  1. `set_flag(okehazama_started)` 
  2. `scenario_notification`（出征过场——织丰 scn_cutscene_* 或自适配）
  3. `im_message`（信长 IM 铺垫：今川大军北上问计）
  4. `army_gather(imagawa_yoshimoto, town_CHUB11)` + `lock_party(imagawa_yoshimoto, town_CHUB11, besiege)`（今川全军锁围攻尾张）
  5. `lock_party(oda_nobunaga, town_CHUB11, defend)`（织田军锁防守）
- goto：evt_okehazama_battle

### evt_okehazama_battle
- when：`And[ ArmyAt(imagawa_yoshimoto, town_CHUB11, 3f), Not[FlagSet(okehazama_battle_started)] ]`
- effects：
  1. `set_flag(okehazama_battle_started)`
  2. 演出（StoryCompiler 编译产物）："桶狭间前夜"御殿会议（meeting_castle_sho_a）——信长 vs 家臣多 NPC 对话（intensity L5）
  3. `SCN_CHOICE_BRANCH`（奇袭/正面/夜袭 → flag: okehazama_tactic）
  4. 雨夜 Atmosphere（TOD_photo_02_30_rainy_night）
  5. `battle_mission`（编排参数见下）
- goto：evt_okehazama_resolution

### evt_okehazama_resolution
- when：`FlagSet(battle_won)` 或 `FlagSet(battle_lost)`（03 NarrativeBattleLogic 战果写）
- 分流：
  - battle_won → 胜利过场 + `kill_hero(imagawa_yoshimoto)`（玩家亲手击杀则自然结算）+ goto evt_okehazama_history / evt_okehazama_if_alive（分支：onPlayerChoice——玩家曾选"放走义元"→ IF 线）
  - battle_lost → 结局 end_okehazama_defeat（败北）

### evt_okehazama_history（史实线）
- effects：`release_party(imagawa_yoshimoto)` 全部解锁 → 尾张洗牌（松平元康转投织田：`change_hero_clan(matsudaira_motoyasu, clan_oda_1)`）→ `peace_correct(oda, imagawa)` → `set_flag(okehazama_history_done)`（衔接本能寺）→ 结局 end_okehazama_history

### evt_okehazama_if_alive（IF 线）
- effects：`peace_correct(oda, imagawa)` + `release_party` 全部 → 松平元康独立（`change_clan_leader`）→ 结局 end_imagawa_alive（今川存活，后续 IF 展开）

**IF 分支点**：①战术选择（奇袭/正面/夜袭）②战后杀/放义元

## 四、演绎链（七步，全程序化，无新美术——蓝图 §4.5）

1. 大军压境（army_gather + lock_party besiege）
2. "没发现织田军"（今川 army AI 锁定只向尾张移动，无视贴身织田 party——引擎无天气视野，AI 锁定模拟）
3. 雨夜氛围（Atmosphere 凌晨 2:30 大雨浓雾）
4. 突袭触发（玩家 Engage 今川本阵 party）
5. 雨夜突袭 mission（camp_raid 布局：营帐/篝火/火把粒子摆一圈、义元营中央 + 卫队环形、织田军雨夜侧翼出生；敌方沉睡）
6. 义元死→溃散（Team.GeneralAgent + Panic() + BattleEndLogic 判 EnemyRetreated）
7. 战后世界纠正（其余今川 party 溃逃回远江 VisitingSettlement + ReleaseParty + 停战/洗牌）

## 五、验收（Phase 2）

1. 织丰战役新档 → ASO 选桶狭间 → 时代重置（信长 26/义元 41）→ 玩家为信长
2. 45 天后（条件满足）→ 通知 + IM + 今川大军集结北上（地图可见）→ 玩家贴身不被攻击（隐蔽模拟）
3. 雨夜前夜演出（御殿会议多 NPC）→ 战术选择 → 程序化营寨 mission（沉睡营地 + 雨夜氛围）
4. 击杀义元（或卫队击杀）→ 敌军 Panic 溃散 → 胜利 → 战果过场
5. 大地图其余今川 party 溃逃 + 停战 + 元康转投（史实）或 IF 线（义元活）
6. 存读档全程保持；无 LLM 全流程可玩
