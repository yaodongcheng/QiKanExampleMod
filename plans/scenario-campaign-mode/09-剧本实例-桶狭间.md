## 这个故事是什么

1560 年，今川义元（当时最强大的大名）率数万大军上洛，途经尾张。织田信长（玩家）以数百兵力奇袭今川本阵，义元战死，今川家崩溃——**日本史的转折点**。

**玩家 = 织田信长**（26 岁，尾张之主）。关键人物：今川义元（41 岁，大敌/IF 核心）、松平元康（18 岁，三河小领主——义元死后脱离今川独立，与织田**结清洲同盟（对等同盟）**，史实线）。

## 玩家体验流程（七步，全程序化，无新美术）

1. **大军压境**：义元的大军（多支部队汇合成军团）真的向尾张推进，地图上看得见；引擎锁定它的行动（只往尾张走）
2. **"没被发现"**：你带着少量兵力贴着今川大军走，它不理你——它的 AI 被锁定只盯着尾张（这就是"雨夜没发现织田军"的模拟，引擎没有天气视野机制，靠 AI 锁定实现）
3. **雨夜氛围**：凌晨两点半、大雨、浓雾
4. **突袭**：你主动撞上今川本阵部队 → 进入战役
5. **战役**（程序化生成）：今川营地中央是义元（被卫队围着，周围帐篷篝火），正在沉睡；你从雨夜侧翼摸进来
6. **义元死 → 全营崩溃**（引擎原生机制）：击杀义元 → 敌方全军士气崩溃四散溃逃 → 自动判胜
7. **战后世界（时间连续流，太阁5 模式）**：其余今川部队溃逃回远江 → 今川家衰落 → 元康脱离今川独立（三河）→ 与织田**结清洲同盟（对等同盟）** → 织田攻略美浓（稻叶山城→岐阜）→ **时间自然流逝**，后续历史事件按年份条件陆续发生（1568 上洛、1575 长篠…直至 1582 本能寺）——**不跳跃时间**；或者你放走了义元，进 IF 线（今川继续强盛，后续走向由玩家塑造）

## 剧本数据要点（内容包数据，转化管线 08 产出）

**演员与时代表**（1560）：信长 26 岁活（玩家）、义元 41 岁活、元康 18 岁活；关键城：尾张=清洲 town_CHUB11（织田家）、今川本据=骏府 town_CHUB8、浜松 town_CHUB9。

**触发条件**（正式格式，01 DSL——文本表达式，英文 token + StringId 引用）：

```jsonc
"when": "and( (Time::year) >= 1560,                                  // 年份到了
              (Settlement::town_CHUB11.owner) == (Clan::clan_oda_1), // 清洲归织田家
              exists(Hero::lord_1_imagawa),                          // 今川义元存在
              (Hero::lord_1_imagawa.clan) == (Clan::clan_imagawa_1), // 义元在今川家
              atWar(Faction::Kingdom.oda, Faction::Kingdom.imagawa), // 织今交战
              not( (Flag::okehazama_started) == true ) )"            // 没触发过
```

**事件链**（5 个事件）：
1. `trigger`：出征过场 + 私信铺垫 + 今川大军集结锁定围攻尾张、织田军锁防守
2. `battle`：今川军到达尾张（"部队已就位"条件）→ 雨夜前夜御殿会议（多人演出：信长与家臣密谋）→ 战术选择（奇袭/正面/夜袭 → 记旗标）→ 进战役
3. `resolution`：战果判定——胜 → 胜利过场 + 义元死亡结算；**分支**：你曾放走义元 → IF 线；败 → 败北结局
4. `if_alive`（IF 线）：义元活着 → 停战 + 解除锁定 + 元康独立 → 结局"今川未倒"
5. `history`（史实线）：义元死 → 今川衰落 → 元康独立 + **清洲同盟** → 织田攻略美浓（稻叶山城→岐阜）→ **时间自然流继续**（1562 同盟、1567 岐阜、1568 上洛…均为时间轴上的后续事件，按年份条件触发）

**IF 分支点**：①战术选择 ②战后杀/放义元

**战役编排参数**（供 03）：场景 = 织丰平原战场（没有就用原版兜底）；雨夜；布局 = 环形营寨（义元营中央 + 卫队 + 帐篷篝火圈）；兵力 = 今川卫队+足轻 vs 织田骑马队+足轻（数量可调）；今川方沉睡；叙事钩子 = 主将死→全员溃逃、战果记旗标。

## 验收（Phase 2）

1. 织丰战役新档 → 选桶狭间 → 世界拨到 1560 → 玩家是信长
2. 45 天后触发：公告 + 私信 + 今川大军集结北上（地图可见）→ 你贴着它走不被攻击
3. 雨夜前夜演出（御殿会议多人）→ 战术选择 → 程序化营地战役（沉睡 + 雨夜）
4. 击杀义元 → 敌军溃散 → 胜利过场 → 大地图其余部队溃逃 + 停战 + 元康转投（史实）或 IF 线
5. 存读档全程保持；没配 AI 也能全流程玩

## 要注意的坑

- 今川大军的"数万军"在大地图上 = 多支部队汇成军团（引擎军团机制），不是字面 4 万人——规模感靠军团 + 战役里兵力数字表达
- "没被发现"靠 AI 锁定模拟，战役里靠"沉睡营地"（敌人 AI 冻结，你靠近才激活）
- 史实线 → 本能寺：**时间连续流（太阁5 模式，04 时间模型）**——不跳时间，事件按「年份 + 世界状态」双条件在时间轴上自然发生；22 游戏年（1560-1582）在骑砍2 是正常长档（一年约 84 天，一档 1000+ 天常见）；**世界格局维持 = 背景剧本（02）的长时段职责**（织田稳步扩张、其他势力平衡），保证 1582 本能寺条件仍成立
