## 这一步做什么（一句话）

以 3A 标准设计玩家体验：**新档第一分钟到第一个高潮，玩家每一步在做什么、看到什么、感受到什么**——不是机制清单，是体验叙事。机制实现细节指向各分步 plan（13 任务链 / 05 演出 / 03 战斗 / 02 AI）。

## 一、玩家旅程（分钟级体验叙事，以桶狭间剧本为例）

### 开场（第 0-15 分钟）——我是谁

- 新游戏 → 选剧本"桶狭间之战" → 开局：你醒来就是**织田信长**——尾张之主，26 岁
- 世界是 1560 年：信长的家臣在侧、今川义元在世、尾张城头旗帜是你的
- **第一个信号**：进城，家臣告诉你"今川义元集结了数万大军，可能要上洛"——世界的第一印象：**你是历史棋局里的一方，而且有大敌**
- 引导：任务面板出现第一条主命（"整顿尾张防务"），地图标出尾张边界——**玩家立刻知道我是谁、我在哪、我要干嘛**

### 间隙期（第 15 分钟 - 数小时）——我是大名的日常

- 主命节拍：主公（你自己就是大名——主命来源可以是朝廷/家老/联盟压力，或你的家臣提议）派任务：筹粮、练兵、外交
- 自由行动：修炼技能、走访家臣、贸易、清剿边界小股敌人（世界事件）
- **世界在动**：地图上今川的部队在集结、边境偶尔有摩擦、IM 里家臣议论时局——**你能感到战争在逼近，但还没来**
- 引导：任务面板"剧本主线"页签（当前阶段 + 历史脉络）；世界信号（边境消息、部队动向）

### 首次事件（条件满足触发）——战争来了

- **通知**："今川大军集结完毕，沿东海道北上！"——地图上今川军团真的开始移动（02 AI 纠正：军团朝尾张推进）
- **IM 铺垫**：家臣们私信纷至（"主公，今川来势汹汹！"），信长的性格在对话中确立
- **主命/任务**："率军迎击 / 固守尾张"——玩家选
- **世界信号**：今川军团贴着尾张边境推进，你带着少量部队靠近它——**它不理你**（被锁定只盯着尾张——这就是"雨夜没被发现"的伏笔）

### 首次高潮（桶狭间之战，约 30-60 分钟）——奇袭

- **前夜**（多人演出，05）：御殿会议——家臣团争论（迎击/固守/夜袭），镜头跟随说话人，你选战术（奇袭/正面/夜袭）
- **氛围**：暴雨、凌晨、浓雾（03 Atmosphere）
- **上战场**（03 程序化）：今川营地沉睡——帐篷圈、篝火、义元营中央被卫队围着；你从雨夜侧翼摸进去
- **爆发**：杀进营地，直取义元——击杀他的瞬间，**整个营地炸营**：敌军四面溃逃（引擎原生士气机制），战斗自动判胜
- **余波**：胜利过场 → 大地图上今川部队溃逃回远江 → 今川家衰落 → 松平元康脱离今川独立（三河）→ 与织田**结盟（清洲同盟——对等同盟，非臣属）** → 织田开始攻略美浓（稻叶山城→改岐阜）→ **时间自然流逝**，后续历史事件按年份陆续发生（1562 同盟、1567 岐阜、1568 上洛、1575 长篠…直至 1582 本能寺）

### 🔴 时间模型：连续时间流（太阁5 模式，2026-08-24 修正）

- **时间大部分时候不跳跃**：剧本不是"打完一章跳数年后"，而是**一个连续的世界**——事件按「年份 + 世界状态」双条件在时间轴上自然发生，玩家活在 1560-1582 的连续世界里（太阁5 正是如此：桶狭间打赢后游戏继续，玩家以信长身份一路经营，事件随年份到来）
- **桶狭间与本能寺 = 同一时间轴上的章节事件，不是两个独立剧本**：可选的开局年代（1560 开局 / 1582 开局）决定起点，历史事件（桶狭间→清洲同盟→美浓→上洛→长篠→本能寺）是时间轴上的里程碑
- 🔴 **历史事件的触发与走向约束机制 = 14-历史时间轴与走向约束.md**：里程碑 = 01 事件（年份+状态双条件触发）；走向约束 = drift 表导向性修正（AI 倾向+关键节点，非瞬间改状态）；玩家干预 → 让路 + IF/脱轨判定（"玩家塑造的历史"模式）
- **骑砍2 时间节奏可行性**：一年约 84 游戏天，22 游戏年 ≈ 1800+ 游戏天——骑砍2 玩家一档玩 1000+ 天很常见，**长档完全可行，无需快进**
- 🔴 **前提保障 = 背景剧本（02）**：22 年间世界格局必须维持接近历史（织田稳步扩张、其他势力相对平衡），保证 1582 年时本能寺条件仍成立——这是背景修正器的长时段职责；玩家干预历史前提 → 修正器让路 + IF 分支
- **角色年龄自然演化**：时代重置只做开局（1560 信长 26 岁），之后年龄自然增长（1582 年信长自然 48 岁）——不用每章重设

### 情绪曲线（这 30 分钟）

平静（会议争论）→ 紧张（暴雨中摸进营地）→ 爆发（突入本阵）→ 宣泄（义元死、全营溃散）→ 余韵（战后格局变化）——**这就是一次完整的"张弛"**。

## 二、核心循环（三层）

| 层次 | 周期 | 内容 | 反馈 |
|---|---|---|---|
| 分钟级 | 跑图/对话/战斗 | 完成任务链的当前阶段（前往→执行→提交） | 阶段推进、任务面板更新、世界变化 |
| 小时级 | 主命节拍 | 接主命→做→回报；自由行动（修炼/贸易/社交） | 报酬、关系、声望、剧本推进度 |
| 天级 | 剧本推进 | 背景剧本维持世界（战争/调防），事件条件随时间成熟 | 通知/世界信号/IM 铺垫，事件触发 |

**每一层都有反馈闭环**：做了什么 → 看得见的结果（面板/通知/世界状态/关系）——不允许"做了没反应"。

## 三、节奏设计（张弛有度）

剧本事件不密集轰炸，按"平静-升温-高潮-余波"编织：

| 阶段 | 内容 | 玩家体验 |
|---|---|---|
| 平静期 | 主命 + 自由行动 + 世界背景运转 | 自主感、生活感（世界在推进但你有空做自己的事） |
| 升温期 | 事件预警（通知/IM/部队动向） | 压迫感渐强（今川在集结）、选择感（备战/外交/主动出击） |
| 高潮期 | 战役/大事件（程序化战斗/演出） | 全力以赴的投入（奇袭/巷战） |
| 余波期 | 战后世界变化（停战/洗牌/新格局） | 成就感/好奇（我的选择改变了什么）、为下一章铺垫 |

🔴 **纪律**：同一时间最多一个"高潮"候选（事件触发条件互相抑制），防止玩家被事件淹没；平静期不得空虚（主命/自由行动保底）。

## 四、引导与目标（每时每刻知道干什么）

多通道引导，任一时刻玩家至少有一个明确指向：

| 通道 | 内容 | 频率 |
|---|---|---|
| 任务面板"剧本主线"页签 | 当前章节/阶段/下一步（"前往清洲见信长"） | 常驻 |
| 任务面板"主命"页签 | 主公/家老派的任务（目标/期限/报酬） | 节拍 |
| 地图标记 | 关键目标/大军位置/目标 NPC（TrackedObjects） | 常驻 |
| 通知/公告 | 大事发生（"今川大军集结北上！"） | 事件 |
| IM 私信 | 人物立场/情报/密谋（家臣议论、光秀苦闷线） | 事件+日常 |
| 世界信号 | 部队动向、边境摩擦、聚落状态 | 持续 |

**引导纪律**：新信息 ≥2 个通道触达（通知 + 任务面板，或 IM + 地图信号）；禁止"玩家不知道下一步干嘛"（信息不丢失：离开再回来有回顾入口）。

## 五、反馈与后果（世界对我的行为有反应）

| 行为 | 看得见的反馈 |
|---|---|
| 完成主命/任务 | 报酬 + 关系 + 任务面板 + 主公反应（IM/对话）；可能推进剧本 |
| 拒绝主命 | 关系代价 + 剧本推进变慢（但世界继续走，压力自然产生） |
| 改变历史前提（如提前灭今川） | 事件条件不再满足 → 剧本分支/IF 判定（02 修正器让路） |
| 战役胜利/失败 | 战果过场 + 世界格局变化（停战/洗牌/溃逃） |
| 角色死亡 | 死亡过场 + 换扮演继承者（06） |

**反馈纪律**：负面反馈不是"无事发生"——拒绝有代价、失败有后果、冷案有交代（设计哲学原则一）；**演出打断有反应**（设计哲学三 NPC 接得住）：玩家拔剑打断关键演出 → NPC 惊愕/中止/战斗分支（05 封控分级），禁止"玩家介入演出而演出无反应"。

## 六、成长与推进（世界与玩家一起变强）

**双成长线**（🔴 2026-08-24 用户裁定：仿太阁5 功勋升级，机制详见 17-功勋与晋升）：

- **功勋晋升线**（家臣/浪人身份，17）：为主公做事（主命/战斗/献金）→ 功勋累积 → **季度评定**（太阁5 式评定会演出，05）→ 官职晋升（足轻→组头→侍大将→…→家老，阶梯数据包定义）→ 俸禄/权限/称呼升级。**数值渐进，间隙期的主节奏**——"做主公的事，主公看得见"
- **剧本推进线**（所有身份）：事件驱动地位跃迁（家臣→家督→霸主，06/14）——质变线。**衔接**：功勋/官职可作剧本事件门控（功勋不够 → 主公不委以重任 → 历史事件推迟/换人，14 drift）
- **大名阶段**：无主公 → 无功勋线；成长 = 骑砍2 原版（声望/领地/部队）+ 剧本推进（大名支配力线后续 plan）
- **世界推进（时间连续流）**：时间自然流逝，事件按年份条件发生 → 角色年龄/势力格局自然演化（信长 26→48 岁）→ 历史事件（桶狭间→同盟→上洛→本能寺）沿时间轴逐一生发
- **关系网**：与关键历史人物的关系（IM 日常 + 事件中的选择）影响分支（光秀关系差 → 本能寺提前？）
- 🔴 成长必须是"看得见的"：面板显示**功勋/官职/俸禄** + 声望/关系/剧本进度；世界状态（城头旗帜/部队规模）随玩家成长变化

## 七、失败与挫折（失败也是体验）

- **主命超时/失败**：关系惩罚（贪污本金更重）、剧本推进变慢——但不挫败（还有别的路）
- **战役失败**：不是 Game Over——败北结局/退守/IF 展开（桶狭间败了 → 尾张失守的新局面）
- **角色死亡**：换扮演继承者（06），故事继续——"历史不因你死而停止"
- 🔴 纪律：失败必须**有后果、有出路、有叙事**（不能是"任务失败，什么都没发生"）

## 八、重玩性（为什么想再来一遍）

- **IF 线**：救今川/救信长/光秀天下线——每个剧本至少一条史实线 + 一条 IF 线
- **多角色 · 多视角演绎**（🔴 三通道模型，2026-08-24 用户裁定）：同一剧本可扮演不同人物（信长/元康/义元/家臣，06 开局选择）。**不做太阁5 式"每个视角一份完整演绎"**（AVG 重放范式——3D 里成本爆炸、玩家被切走看文字 = 出戏，铁律 6），改三通道：
  1. **世界结算唯一**：历史节点的事件效果（势力/角色/领地变更）全局只执行一次（01 纪律）；玩家不在场事件照常发生（14 在场性）
  2. **真实玩法共享**：名场面 = 真实可打的仗/可参与的现场（03 程序化）——**玩家阵营/站位天然就是视角**（织田侧看布阵、今川侧看休息、别处看传闻），同一场仗不用各写一份
  3. **事件只在玩家身上运行一次**（太阁5 同款互斥选路，2026-08-24 校准）：一份事件组按玩家身份选一条路径运行——玩家扮演谁，谁的视角戏才演出（05 参与门控）；🔴 **NPC 当事人从不演出**（NPC 侧 = 世界模拟结算，太阁5 同样如此）；玩家不在场/非当事人 → 信息走渠道（IM 私信延迟失真 / PartyHUD 部队动向 / 世界状态变化——情报必须来自渠道）
  - **当事人 = 玩法不是演出**：扮演义元被杀 = 真实战斗失败 → 06 死亡继承；扮演信长布阵 = 亲自下令——当事人亲历，不重放
- **事件随机性**：主命池/世界事件随机组合 → 每局间隙期不同
- **完成度**：剧本通关标记（史实/IF 各结局），解锁/记录在案

## 九、阶段化任务链（机制落地，与 13 呼应）

一个剧情节点/主命 = **多阶段任务链**（13 的 QuestDef stages）：每阶段明确"去哪/干什么/怎么表现"，完成一个解锁下一个（任务面板显示当前阶段）。

例："去偷 XX → 找谁提交" = ①接受委托（对话）→ ②前往目标地点（跑图）→ ③执行偷窃（操作/检定）→ ④返回提交（对话 + 报酬/情报）。

每阶段的表现方式（从轻到重）：公告文字 → 私信 → **亲自跑图**（默认）→ 面对面对话 + 说服检定 → 多人演出面板（可走动/拔剑/中断）→ 亲自战斗 → 操作型小节点。

🔴 **关键剧情默认阶段化**：禁止"一条表现方式走完一个节点"——玩家每一步都知道去哪、干什么。

## 十、大地图叙事载体（三国志式军团发言）

🔴 修正（2026-08-24）：军团就地发言**不走 IM 私信**（全屏覆盖 UI + LLM 聊天重心，不适合）。做法 = **campaign 层 PartyHUD（仿 AgentHUD）**：地图上关键 party/军团头上挂名牌（名字/兵力/状态）+ 说话冒泡（数据驱动短台词，可选 LLM 润色、无 LLM 直出）；距离分级（远处只显名牌）；靠近可互动对话。IM 私信保留给人物长对话/密谋铺垫（光秀苦闷线）。UI 纪律按 wheels.d/ui.md。

| 3 | 节奏控制（高潮候选互斥 + 平静期保底） | 事件不密集轰炸；平静期有主命/自由行动 |
| 4 | 反馈闭环（完成/拒绝/失败/改变历史 → 看得见的反馈） | 每行为有反馈（验收对照"反馈纪律"） |
| 5 | 成长与重玩（进度显示 + 关系网影响分支 + 多结局/多角色） | 剧本通关标记；IF 线可达 |

## 做完怎么验收

1. **玩家旅程走通**：新档 → 我是谁（开场）→ 间隙期（主命+自由）→ 首次事件（通知/IM/部队动向）→ 首次高潮（会议→奇袭→溃散→余波）——按旅程表逐段核对
2. **引导盲测**：任意时刻问"我现在该干嘛"——玩家答得出（面板/标记/信号任一通道）
3. **节奏**：事件不密集轰炸；平静期不空虚
4. **反馈**：对照"反馈纪律"逐条验证（拒绝有代价、失败有后果、改变历史有分支）
5. **失败路径**：主命超时/战役失败/角色死亡 → 有后果、有出路、有叙事
6. **重玩**：史实 + IF 线各通一遍；多角色可选

## 要注意的坑

- 体验设计 ≠ 功能清单：验收以"玩家旅程走通 + 引导盲测"为准，不是"功能全在"
- 节奏控制是软的：事件条件互相抑制 + 高潮候选互斥（01 调度器加抑制表）
- 反馈闭环最容易漏"负面反馈"（拒绝/失败/冷案）——对照设计哲学原则一逐条查
- 成长显示要量化（声望/关系/剧本进度面板），不然玩家感觉不到在变强
