## 〇、写作规格（达不到这几条就是不合格）

| 项 | 标准 | 反面（不要这样） |
|---|---|---|
| **每个节点台词** | **2~6 行**，含动作 / 神态 / 停顿 | 一句「新鲜。不买就让开。」 |
| **玩家选项** | **3~4 个完整口语句子**，带人格（软 / 硬 / 好奇 / 贪 / 玩笑） | 两个【打听】【求】标签 |
| **信息分层** | 寒暄 → 试探 → 交易 → 情绪，一层一层给 | 一次把底全交了 |
| **NPC 会反问** | 他也在观察你，会问回来 | 玩家问什么答什么 |
| **任务日志** | **200~300 字**，有人名、地点、缘由、风险、可选做法 | 「去教训 thug」 |
| **不做完美人设** | 每个人都有小算盘，帮忙也是为自己 | 热心肠工具人 |

**节点的固定骨架**（每个节点都要有）：
1. **场景/动作**（一行，写他在干什么）
2. **台词**（2~6 行，可以多段）
3. **玩家选项**（3~4 条，各带明确后果）

## 一、执行格式：用 DialogueInjector v2，不用太阁5 事件 JSON

**为什么不用太阁5 那套**：那套是**战役层事件引擎**（事件 JSON 只有条件 / 效果 / 分支 / `perform` 引用，长对话另进演绎剧本），而 `plans/scenario-campaign-mode/00-开工评审.md` 已写明：**数据加载器、DSL 求值器、StoryCompiler、播放器改造 4 件核心代码都还没写**——它现在只是一套文档，喂进去没人读。

**序章能跑的是 `DialogueInjector` 的 v2 JSON**（已实装），落点：

```
ModuleData/DesignData/Dialogues/story_probe_<npc>.json
```

可用 `custom.inject_dialogue story_probe_pawnbroker` 单独验证。

### 1.1 数据结构

```csharp
DialogueNode {
    string Id;                       // 节点 Id
    string NpcLine;                  // NPC 台词（可多行；多方对话用说话人前缀）
    Func<string> LazyNpcLine;        // 懒求值（按状态换台词）
    List<DialogueTransition> Transitions;   // [] = 关窗
}

DialogueTransition {
    string PlayerLine;               // 玩家选项（完整口语句子）
    TransitionCheckType CheckType;   // None / SkillCheck
    string Action;                   // "NONE" 或 "INTENT:xxx"
    string ActionParam;
    string NextNodeOnSuccess;        // "" = 关窗
    string NextNodeOnFail;           // 仅 SkillCheck
}
```

### 1.2 命名约定

| 项 | 约定 | 例 |
|---|---|---|
| 文件 | `story_probe_<npc>.json` | `story_probe_pawnbroker.json` |
| NPC 键 | `pawnbroker` / `widow` / `son` / `butcher` / `blocker` / `rival` / `outlaw` / `thug` / `debtor` | — |
| 节点 Id | `<npc>_<用途>` | `pawnbroker_ask_sister` |
| 事件节点 | `event_<n>_<用途>` | `event_1_join` |
| 台词键 | `LWN_story_<npc>_<节点>_<n>` | `LWN_story_pawnbroker_ask_sister_2` |
| 选项键 | `LWN_story_<npc>_opt_<名>` | `LWN_story_pawnbroker_opt_redeem` |

## 二、多方在场怎么谈（事件接入的核心）

骑砍2 原版对话流**一次只有一个对手方**。多人争吵靠三件事表达：

### 2.1 多行台词块（说话人前缀）

`NpcLine` 写成一整段带前缀的多行文本，引擎按段落显示，读起来就是"两个人当着你的面吵"：

```
thug：看什么看？没你的事。
老板：……客官，您别掺和，他喝了酒。
thug：（把柜上的秤推到地上）钱呢？
老板：（弯腰去捡）这月实在……
```

- 前缀用 `名字：`，不用引号嵌套；
- 每方**一轮最多两句**，超过就假；
- 动作写在同一行括注里，不单独占段。

### 2.2 选边之后，焦点收敛到一个人

玩家一旦表态（帮谁 / 问谁），后续节点**只跟一个人谈**，另一个人用**一行插话**留在场：

```
thug：你他妈算哪根葱？（手已经摸到腰后）
老板：（在你身后小声）别……别在这儿动手，他真敢捅人。
```

### 2.3 插话节点（第三人称打断）

在关键节点插一个"另一个人忍不住说话"的节点，玩家可以回应也可以不理。这是多方感最强的地方，**每个多人事件至少一个**。

## 三、入口：哪些节点会被注入

**入口只有一个**：`hero_main_options` 里的 `【说两句】`（Gateway 模式），点进去落到当前该 NPC 的第一个可用节点。

构建器按下面优先级挑入口（自上而下，第一条成立的胜）：

| 优先级 | 条件 | 入口 |
|---|---|---|
| 1 | 委托目标已完成，尚未交差 | `<npc>_turnin` |
| 2 | 已交差 | `<npc>_chat` |
| 3 | 已搭话 | `<npc>_hub` |
| 4 | 事件接入 | 事件节点路由过来 |
| 5 | 从未见过 | `<npc>_intro` |

**没话可说就不注入**（例如未搭话前的守门人只有 `blocker_open`）。

## 四、人物小传（写台词前先看这个）

> 没有小传的台词怎么写都是 AI 味——因为你不知道他怕什么、想要什么、哪句话会戳到他。

### 4.1 当铺老板 · 老周（`pawnbroker`）

**六十岁上下，驼背，左手缺半截小指。** 早年跑过南北货，赔光了本钱，在这城门口盘下这间当铺。他不算好人——放贷收利、压价收当——但他守着一条：从不逼死人。码头帮每月来收保护费，他给了三年，账本上记得清清楚楚，一笔不落。

- **他想要**：安稳做到死，别惹事。
- **他怕**：码头帮砸摊（他见过隔壁绸缎庄被砸成什么样）。
- **他在意**：账本。他记账比记人清楚。
- **口头习惯**：先说价，再说事；爱用「童叟无欺」这种生意人的套话，但底下是精明。
- **对玩家的态度**：一开始只当是又一个穷鬼；玩家帮他收账之后，他真会拿你当半个自己人——因为三年了没人替他出过头。

## 五、当铺老板的完整线（`pawnbroker`）——质量样板

> 节点 Id 是 JSON 里的，正文是给玩家看的中文原文。
> 每段台词都标了 `LWN_story_*` 键，写本地化时直接取。

### 5.1 事件 1：收保护费（多人）

> 这是玩家**第一次见到他**，也是 `pawnbroker_intro` 的实际发生地。

#### `event_1_join`（事件暂停，玩家走进 4 m）

```
（摊子前的秤摔在地上。老板半蹲着，一只手还扶在柜沿上。）
thug：看什么看？没你的事。
老板：（没抬头）客官，您别掺和……他喝了酒。
thug：（一脚踹翻木箱）钱呢？这月的。
老板：（慢慢站起来，从怀里摸钱袋）……这就给，这就给。
```

**玩家选项**

| 选项 | 后果 |
|---|---|
| 「他欠你多少？我替他出。」 | → `event_1_pay`（钱够）/ `event_1_poor`（钱不够） |
| 「钱的事等会儿。你先把手从他领子上拿开。」 | → **SkillCheck 武力**：成 `event_1_win`；败 `event_1_lose` |
| 「这跟我没关系。」 | → `event_1_walkaway` |
| （站着不动，看完整场） | → `event_1_watch` |

#### `event_1_pay`

```
thug：（转头看你，眼神在你身上量了一遍）你替他出？行啊。
老板：（急了）客官！您别——
thug：一共八十。拿来。
（老板在你背后轻轻拉了一下你的袖子。他不想让你出这个钱，但他也不敢拦。）
```

**选项**：【数出八十第纳尔递过去】→ `event_1_paid`｜【算了，钱我还留着】→ `event_1_walkaway`

#### `event_1_paid`

```
thug：（数完，塞进怀里）算你识相。
（他转身走了两步，又回头）
thug：下月照旧。你要是还想当好人，接着掏。
（老板一直没说话，直到那人的脚步声拐出巷子。）
老板：（长长吐了口气）……客官，你这是何苦。
```

→ 关系：码头帮 −，老板 +++；进入 `pawnbroker_intro_after`

#### `event_1_win`（武力检定成功）

```
（你上前半步，正好卡在他和摊子中间。）
thug：（愣了一下）哟，来劲了？
（你抓住他手腕往下一压——他吃痛，骂了一句，退了半步。）
thug：行，行……你等着。
（他走了。走的时候没敢回头。）
老板：（手还在抖，弯腰去捡秤）三年了。……三年了头一回有人拦他。
```

→ `pawnbroker_intro_after`

#### `event_1_lose`（武力检定失败）

```
（你一出手，他就笑了——他打架比你想象的多。）
thug：（一拳砸在你胸口，你退了三大步）
老板：（赶紧挡在你前面）别打了！别打了！钱我给，这就给！
（thug拿了钱，吐了口唾沫，走了。）
老板：（扶着摊子，半天没说话）……客官，你不该动手的。
```

→ 关系：码头帮 −，老板 +；回到 `pawnbroker_intro_after`（老板仍记你这人情，只是嘴上埋怨）

#### `event_1_walkaway` / `event_1_watch`

```
（你转身走了。身后的骂声和求饶声混在一起，很快就听不清了。）
```

→ 事件回循环（可再来一次，但老板态度会冷一档）

#### `pawnbroker_intro_after`（事件收尾 = 搭话）

```
老板：（把秤摆回柜上，拍了拍手上的灰）……客官，你方才那一下，我记着了。
老板：当东西？找门路？还是有事要问？
```

**选项**：
- 「先说说你自己吧。」→ `pawnbroker_ask_self`
- 「我在找人。」→ `pawnbroker_ask_sister`
- 「你这摊子，天天这样？」→ `pawnbroker_ask_gang`
- 「没事。路过。」→ 关窗（解锁 `pawnbroker_hub`）

### 5.2 打听线

#### `pawnbroker_ask_self`

```
老板：（笑了一下，笑纹堆在眼角）我？姓周，人家都叫老周。
老板：这铺子开了二十三年。前十年挣钱，后十三年给别人挣。
老板：你别看这摊子小——城里谁家嫁女、谁家办丧、谁欠了谁的债，都从这儿过一遍。
老板：我这个人啊，别的本事没有，就是嘴严、账清。
```

**选项**：【所以你也知道不少事？】→ `pawnbroker_hub`｜【那你为什么不走？】→ `pawnbroker_ask_stay`

#### `pawnbroker_ask_stay`

```
老板：（沉默了一会儿）走去哪。
老板：我这岁数，出了这城门，就是路边的死人。
（他把算盘珠子拨了一声，很轻）
老板：人啊，不是不想走，是走不动。
```

→ `pawnbroker_hub`

#### `pawnbroker_ask_sister`（妹妹线索 1）

```
老板：（停下手里的算盘，抬眼打量你）找人？男的还是女的。
（你说：女的，穿青布，三个月前进城。）
老板：（低头，从柜下抽出一本翻得起毛的账本，一页一页翻）
老板：三个月前……青布……（手指停住）有了。
老板：「银镯一只，押三十，赎期三日」。写的日子是四月初九。人没来赎。
老板：（合上账本，看着你）那镯子，我留到现在。
```

**选项**：
- 「她后来去哪了？」→ `pawnbroker_sister_where`
- 「镯子我赎。」→ `pawnbroker_sister_redeem`（钱够）/ `pawnbroker_sister_poor`（不够）
- 「你怎么记得这么清楚？」→ `pawnbroker_sister_why`

#### `pawnbroker_sister_where`

```
老板：（摇头）这我真不知道。
老板：那姑娘来的时候，后头跟着个人。穿水靠，站门外没进来。
老板：（压低声）码头帮的。他们那会儿还没开始收我的钱，但我认得那身衣裳。
老板：押完镯子，她是跟那人走的。走的时候还回头看了一眼——看什么呢，我也说不上来。
```

→ 关窗（记下线索 1：当票 + 水手 + 码头帮）

#### `pawnbroker_sister_redeem`

```
老板：（把镯子从柜下取出来，放在秤盘上）三十。
（是一只素银镯子，内侧刻了个「宁」字。）
老板：赎期过了，按规矩该加二成。……不过（他看你一眼），算了，就三十。
```

**选项**：【数三十第纳尔】→ `pawnbroker_sister_got`｜【先记着，我一定回来赎】→ `pawnbroker_sister_hold`

#### `pawnbroker_sister_got`

```
（老板把镯子推过来，手指在镯子边上停了一下。）
老板：客官，我说句多余的话。
老板：这城里丢过的人，比丢过的钱多。你要找，就往码头那边找。
老板：（顿了顿）别一个人去。
```

→ 关窗（得到镯子；关系 +）

#### `pawnbroker_sister_poor`

```
老板：（看你摸钱袋的样子，把镯子又收了回去）没有就算了。
老板：我不缺这三十。可规矩是规矩。
老板：（把镯子放回柜下，忽然说）你要是能替我办件事，这镯子就当我送你的。
```

→ `pawnbroker_deal`

#### `pawnbroker_sister_why`

```
老板：（指了指自己的脑袋）这行当，靠的就是记。
老板：谁什么时候押了什么，押了多久，赎没赎——记错一笔，我这摊子就完了。
老板：（笑）你妹妹那只镯子，是我这三个月里唯一一只没人来赎的。
```

→ `pawnbroker_hub`

#### `pawnbroker_ask_gang`（情报：守门人弱点）

```
老板：（把声音压低了些）门口那个？姓什么我不知道，都叫他铁头。
老板：贪。给钱就抬眼皮。
老板：（顿了顿）但他不怕狠的。你要是跟他来硬的——他真敢捅人，这我见过。
老板：你要想过那道门，别在他面前亮刀子。要么给钱，要么……
（他没说完，只是抬下巴朝城里努了努）
```

**选项**：
- 「要么怎么样？」→ `pawnbroker_ask_gang_2`
- 「钱要多少？」→ `pawnbroker_ask_gang_3`
- （记下）→ `pawnbroker_hub`

#### `pawnbroker_ask_gang_2`

```
老板：要么，别让他认出你。
老板：（打量你）你这张脸，城门上贴着呢。虽然画得不像。
老板：……我什么也没说啊。
```

→ `pawnbroker_hub`（提示遮面 / 乔装）

#### `pawnbroker_ask_gang_3`

```
老板：一百。这数我心里有。
老板：我这摊子一个月才挣多少，你算算。
（他把算盘珠子拨得噼啪响，像是在替你算，也像是在替他自己的肉疼。）
```

→ `pawnbroker_hub`（记下打点价格 100）

### 5.3 求与委托

#### `pawnbroker_deal`

```
老板：（收起账本，正了正神色）客官，我看你不是来当东西的。
老板：你缺钱，我缺人。
老板：码头帮有个收数的，叫 debtor。他欠我三笔账，拖了半年，利钱都不给了。
老板：（盯着你）我放贷这么多年，头一回让人欠到我头上。
老板：你要是能把钱给我收回来——不用动手，收回来就行——你要什么，我替你想办法。
```

**选项**：
- 「行。他在哪？」→ `pawnbroker_quest_accept`
- 「收账这事，你怎么不自己去？」→ `pawnbroker_deal_why`
- 「我只想打听人，不想惹码头帮。」→ `pawnbroker_deal_refuse`

#### `pawnbroker_deal_why`

```
老板：（笑得很短）我去？
老板：我这把骨头，去了就是躺在那儿回来。
老板：（指指柜上的秤）我这辈子只跟数字打交道。刀的事，我不懂。
老板：（往后靠了靠）你还年轻。你要是不愿意，我也不勉强。
```

**选项**：【我去。】→ `pawnbroker_quest_accept`｜【让我再想想。】→ `pawnbroker_hub`

#### `pawnbroker_deal_refuse`

```
老板：（点点头，不恼）也对。
老板：（把账本收进柜里）码头帮那伙人，进去一个躺一个。你惜命，是应该的。
老板：不过我这话撂在这儿——你要找的那个姑娘，最后也是被他们带走的。
（他不再看你，重新拨起了算盘。）
```

→ `pawnbroker_hub`

#### `pawnbroker_quest_accept`

```
老板：（从柜下摸出一张纸条，推给你）他叫 debtor。每天午后在城西巷口收数。
老板：你只要让他把欠我的三笔钱吐出来——一百二十第纳尔，一分不能少。
老板：（补了一句）别闹出人命。这城里死个人，麻烦比钱大。
（他想了想，又加一句）
老板：他身边常跟着两个人。你要是硬来……自己掂量。
```

→ 关窗（任务进 state）

### 5.4 交差

#### `pawnbroker_turnin`

```
老板：（看见你，先看你身后，再看你脸上）回来了。
老板：（放下手里的活）钱呢。
（你说：收回来了，一百二十。）
老板：（伸手，接钱的时候手停了一下）……真收回来了。
```

**选项**：【钱在这儿。】→ `pawnbroker_turnin_ok`｜【先说好，我惹了码头帮。】→ `pawnbroker_turnin_trouble`

#### `pawnbroker_turnin_trouble`

```
老板：（手停在半空）……你把人怎么了。
（你说了。）
老板：（沉默了很久，把算盘往边上推了推）
老板：我让你收账，没让你拆我的摊子。
```

## 六、任务日志（KCD 体，200~300 字）

> 玩家在任务栏里读到的东西。不是写给 NPC 的，是写给玩家自己的。

### 6.1 主日志：进城

**城门**

> 我妹妹三个月前进城做工，之后再没消息。我一路追到这座城下，钱在路上被偷光了，身上只剩她最后一封信。
>
> 城门口挂着我的通缉——码头帮栽的赃，我到现在都不知道那天到底发生了什么。守门的人不会听我解释。我试过硬闯，被人从门口拖走，扔进牢里关了三天。
>
> 牢里有个老囚给了我一身旧衣服和一块面罩。他说：想进城，先让人认不出你。
>
> 现在我又站在城门前。这一次，我不能再硬来了。

### 6.2 委托：收账

**老周的账**

> 当铺的老周让我替他去收一笔账。欠钱的是码头帮一个叫 debtor 的收数人，拖了老周三笔账，半年不还，连利钱都断了。
>
> 老周说得很清楚：一百二十第纳尔，一分不能少，但别闹出人命——城里死一个人，麻烦比钱大。
>
> 他这人精明得让人不舒服，放贷、压价、记账一笔不落，可他也确实三年没跟码头帮红过脸。我问他为什么不去自己收，他说他这把骨头去了就是躺着回来。
>
> debtor 每天午后在城西巷口收数，身边常跟着两个人。老周提醒我：硬来之前先掂量掂量。
>
> 钱收回来，老周答应替我想办法。我要找的人，最后是被码头帮带走的——他欠我的，不止三十第纳尔。

### 6.3 妹妹线索（记进"线索"页，不占任务栏）

**一只没赎回的镯子**

> 老周记得很清楚：四月初九，一个穿青布的姑娘当了一只素银镯，押三十，赎期三天。人没来赎。
>
> 他记得这么清楚，是因为这是他三个月里唯一一只没人来赎的当品。镯子内侧刻着一个「宁」字。
>
> 姑娘来的时候，门外跟着一个穿水靠的人。押完镯子，她是跟那个人走的——码头帮的打扮。
>
> 老周把镯子还留着。三十第纳尔可以赎回来。他说：这城里丢过的人，比丢过的钱多。要找你妹妹，往码头那边找，别一个人去。

## 九、落地检查

1. **节点可达性**：每个 `NextNode*` 指向的 Id 必须在同一文件存在（写离线检查脚本）。
2. **选项数**：每个节点 3~4 条，超过 4 条要拆节点。
3. **无死路**：任何节点都要有一条回 hub 或关窗的路。
4. **失败不锁死**：所有 SkillCheck 失败节点都要能关窗回到可重试状态。
5. **多人事件有插话**：每个多人事件至少一个插话节点。
6. **台词密度**：每节点 2~6 行；低于 2 行要补动作或反应。
7. **`custom.inject_dialogue` 逐文件验**：每个 `story_probe_<npc>.json` 单独注入、单独点完一遍。
