### 2.2 织丰实测（源码级实锤）

`Shokuho.dll` 内 Harmony Transpiler `Module_SetInitialModuleScreenAsRootScreen_Patch`：把引擎方法的 3 根 Ldstr 字符串**原地替换**：

**Transpiler 样本**（与织丰等价，Harmony 已依赖）：

```csharp
[HarmonyPatch(typeof(Module))]
[HarmonyPatch("SetInitialModuleScreenAsRootScreen")]
public static class SplashVideoReplacePatch
{
    private static IEnumerable<CodeInstruction> Transpiler(IEnumerable<CodeInstruction> instructions)
    {
        foreach (var inst in instructions)
        {
            if (inst.opcode == OpCodes.Ldstr && inst.operand is string s)
            {
                if (s == "Native") inst.operand = "<模块Id>";                              // 补丁后 GetModuleFullPath("?")
                else if (s == "Videos/TWLogo_and_Partners.ivf") inst.operand = "Videos/<名>.ivf";
                else if (s == "Videos/TWLogo_and_Partners.ogg") inst.operand = "Videos/<名>.ogg";
            }
            yield return inst;   // 原指令 yield（labels 随指令保留）
        }
    }
}
```

⚠️ 补丁目标 `SetInitialModuleScreenAsRootScreen` 已反编译证实存在于 `TaleWorlds.MountAndBlade.dll` 的 `Module` 类（1.2.12 与 1.5.x 字符串相同、签名一致，**两版通用无需分支**）。用 Harmony 字符串式 patch 后仍需按 CLAUDE.md 惯例二进制 grep 复核目标存活。

## 四、UI 素材

引擎 `UIResourceManager`（1.2.12 同构：`UIResourceDepot`）：把**每个模块**的 `<模块>/GUI/` 按启动顺序压入资源栈，**同名文件后加载者覆盖**。四层资产均可覆盖：

| 层 | 文件位置 | 覆盖规则 | 织丰范本 |
|---|---|---|---|
| Prefab（面板布局） | `GUI/Prefabs/<目录>/<名>.xml` | 引用名 = **文件名**（原版 `LoadMovie("MapBar")` 短名与文件目录无关）；同名文件覆盖 | `Prefabs/Native/MapBar.xml`（覆盖 SandBox 原版）共 13 个原版面 |
| Brush（样式/九宫格） | `GUI/Brushes/*.xml` | 按文件名注册 | `Brushes/ShoMapBar.xml` 等 24 个（本轮新增 `Sho*`/`Shokuho*` 前缀） |
| Sprite（图片图标） | `GUI/<模块名>SpriteData.xml` + `AssetPackages/*.tpac` | 模块惯例命名，Sprite 名全局 | `ShokuhoSpriteData.xml` + `pack0-6.tpac`（全部 `ui_sho_*` 分类） |
| Font（字体） | `GUI/Fonts/*.fnt(+.bfnt)` + `<名>Languages.xml` | `*Languages.xml` 后缀文件名自动识别 | `ShokuhoLanguages.xml` + tilda-sans/UTKamoiSans 日文字体 |

**我们照做**：改原版面 → 同名 XML 放 `<mod>/GUI/Prefabs/<源模块>/<同名>.xml`（目录名无约定，织丰用 `Native/` 只是习惯）；新增面板 → 自选目录 + `ui_*` 前缀 + 自己的 SpriteData/tpac（**已有轮子**：内容包 Sprite 契约见 wheels.d/ui.md「Sprite 按需加载 + 内容包契约」）。

## 六、验收标准

1. 启动游戏直接播放自己的 4K 视频（ivf+ogg 齐全），播完正常进主菜单，无黑屏/闪退
2. 断特征检查：Debugger 附加时不播（引擎原生行为，源码条件 `!Debugger.IsAttached`）
3. BGM/UI 若做了：游戏中曲目/面板肉眼可辨差异

## 七、边界与坑

- **不要动 `Native/` 原版文件**（TWLogo/音乐/场景都不碰）——织丰全程零改动原版文件，我们也不该碰
- **mp4 转换**：源 mp4 若为 H.264，ffmpeg `-c:v libvpx` 转 VP8（ivf muxer 在 ffmpeg 原生支持 `-f ivf`）；音频 `libvorbis`；**目标分辨率≤源分辨率**（脚本已 force_original_aspect_ratio=decrease + pad 4K 底）
- 织丰 `Shokuho_4K.ivf` 22.5MB/21.4s ≈ 8.4 Mbps；脚本默认 8M，4K 码率太大会踢爆加载期内存
