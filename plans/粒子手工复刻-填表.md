## 📦 资源清单总则（**每个案例开头都要给**）

### 清单怎么读

每个复刻案例开头给一张 `📦 资源清单`，三段：

| 段 | 内容 | 用户要做什么 |
|---|---|---|
| **① 骑砍材质** | 该案例要用哪几个 `prt_shd_*` + 可用性 | 看"状态"列 |
| **② 贴图 / 图集** | 材质自带哪张贴图、怎么切 | 通常"随材质"，无需动 |
| **③ 其他资产** | 网格 / 贴花 / 音效之类（粒子做不了的东西） | 看"谁做"列 |

**三种状态（看到哪个就知道要不要动手）**：

| 标记 | 含义 | 你要准备的 |
|---|---|---|
| ✅ | **原版在用**（原版粒子 XML 真的引用过它） | **无需准备**，游戏里就有 |
| ⚠️ | **待验**（名字在包里、但原版粒子没用过，可能引擎不认） | 在编辑器里开一次看弹不弹 `Unable to find material` |
| 🔧 | **要额外资源**（自制材质/贴图/网格） | 看"谁做"列：标「我」= 我做，你只需导入或不用管 |

### 🔧 走"自制材质/贴图"这条路的规格（只有需要时才看）

**为什么要自制**：原版材质（`prt_shd_*`）是**骑砍自己的 41 张粒子贴图**，跟 FCS 的贴图不是一套 ——
用原版材质 = 形似（火焰/烟/火星的**类别**对，但不是 FCS 那张图）。要更像原版就得把 UE 贴图搬进骑砍。

**UE 贴图在哪**：`D:\BrainMaker\骑砍2粒子特效复刻\output\tex\FlexibleCombatSystem\VFX\Textures\*.png`（262 张）

**搬进骑砍的规矩**（都有踩坑记录）：
| 步 | 做法 | 坑 |
|---|---|---|
| 1 | 贴图转成**8bit RGB PNG、无附加块**（用 `png_for_editor.py`） | Blender 直出的 PNG 会被编辑器**连源图带产物一起删** |
| 2 | 放进 `<模块>/AssetSources/<类>/<名>/`（**镜像布局**：与 `Assets/<类>/<名>/` 同目录同名，编辑器才会同步） | 放进别处 = 编辑器不认 |
| 3 | 在 ModKit 里 Import → 编辑材质（选 shader / 混合模式 / 挂贴图） | 材质名**必须**与网格引用一致；粒子的 `material` 字段写这个名字 |
| 4 | 混合模式照 FCS 原材质（`BLEND_Translucent` / additive 之类）挑骑砍对应项 | 骑砍只有那几个 `prt_shd_*` 的混合语义，见 §二 |

> 这条路**目前还没走通过一次**（阴魔斩那条线试过，卡在"没有要自制的材质"）。若某案例真需要，
> 我会先做一张**最小验证**（1 个自制材质 + 1 个发射器）确认链路，再往下推。

## 🔴 先记四条硬规矩（每次填表都适用）

| # | 规矩 | 为什么 |
|---|---|---|
| 1 | **`Diffuse multiplier` 必须给**（发光类材质） | 引擎默认 1；原版火焰是 **1000**、火星 **30**。给 1 = 比原版暗 1000 倍 = **看不见**（我们栽在这上面三次） |
| 2 | **材质只许用原版粒子用过的** | 像 `prt_shd_lightning` 那种"名字在包里有、引擎不认"的材质会让编辑器直接弹 `Unable to find material` |
| 3 | **`Max alive particle count` 不许留 0** | 引擎里 0 = **一颗都不给**（不是"无限"） |
| 4 | **Alpha 曲线不许全 0 / 只留一根键** | UE 侧很多发射器的 AlphaCurve 是"一根键值 0"，照搬 = 全透明 |

## 案例 1：`NS_Fireball` 的"火焰"发射器（第 1 轮）

### 📦 资源清单

| 段 | 内容 | 状态 | 你要准备的 |
|---|---|---|---|
| **① 骑砍材质** | **`prt_shd_flame_1`**（1 个） | ✅ 原版在用（`static_flame` 就是它） | **无需准备**，游戏自带 |
| **② 贴图 / 图集** | 材质自带 `torchflameloop` | 随材质 | 无需准备。图集切法照填：`animated` ✓ · Sprite 16 / 8 · Frame 128 · Rate 48 |
| **③ 其他资产** | 无（纯粒子，不需要网格/贴花/音效） | — | 无需准备 |
| **可选：更像 FCS 原版** | FCS 那张火焰贴图是 `T_Fire_01`（8×8 序列帧）/ `T_Flame_01` / `T_Embers_01`，本地已导出（`output\tex\...\Textures\`） | 🔧 要自制材质 | 先不用做 —— 等案例 1 用原版材质跑通、你看过观感，再决定要不要为"更像"付这个代价 |

**结论：本案例 = 零准备，直接开填。**

### 1) 新建

Particle Editor → **Add new**（新建空粒子），命名 **`lwn_manual_fireball`**。
打开后应该只有 1 个发射器（名字随意，建议改成 **`flame`**）。

### 2) 逐格填（按面板分区，顺序就是面板顺序）

| 分区 | 面板字段 | 填 | 依据 |
|---|---|---|---|
| **Emission** | Emission rate（base / bias） | **50** / **0** | UE `Fire_8` 的 SpawnRate = 50 |
| | Emitter life | **1.0** | UE Loop Duration 1.0 |
| | Max alive particle count | **200** | 规矩 3（0 = 一颗都不给） |
| **Spawner Shape** | Emit volume type | **sphere** | 骑砍没有 UE 那套力场，用球体让火团有体积（近似） |
| | Sphere radius | **0.25** | 同上 |
| **Initial velocity** | Particle life（base / bias） | **0.40** / **0.10** | UE `Fire_8` 寿命 0.3~0.5 s |
| | Emission Velocity Base X / Y / Z | **0.4** / **0.4** / **0.4** | UE 靠 CurlNoise 吹散，骑砍没有 ⇒ **用向外的初速近似** |
| | Emission Velocity Bias X / Y / Z | **0.4** / **0.4** / **0.4** | 让每颗方向/速度不同 |
| | Initial rotation（base / bias） | **0** / **180** | 火苗朝向随机，避免看出是同一张图 |
| | Emit Velocity Model | 保持默认 `random_velocity_components` | — |
| **Movement** | Gravity | **0, 0, 0** | UE `Fire_8` 无重力 |
| | Damping | base **0.5**, bias **0** | 让喷出的火苗很快慢下来（近似 UE 阻尼） |
| **Visual** | Billboard type | **3d** | 火苗是立体朝向相机 |
| **Size** | Particle size（base / bias） | **0.65** / **0.15** | UE 尺寸 50~80 cm → 0.65±0.15 m |
| | Particle size curve operation | **multiply** | 原版火焰用 multiply（`static_flame`） |
| **Render** | **Material** | **`prt_shd_flame_1`** | 见资源清单 |
| | **Diffuse multiplier** | **1000** | 规矩 1（原版火焰就是这个值） |
| | Particle color（渐变色条） | 起点 **(1.00, 0.85, 0.55)** → 终点 **(0.75, 0.20, 0.08)** | UE 这边颜色曲线是**暗的**（靠材质发光），骑砍得自己给火色 |
| | Particle color 的 Alpha 条 | **(0.0, 0)** → **(0.25, 0.55)** → **(0.7, 0.55)** → **(1.0, 0)** | 规矩 4；两端淡入淡出 |
| **Texture sprite** | Type | **animated ✓** | 火苗贴图是 128 帧动画 |
| | Sprite count x / y | **16** / **8** | 同上 |
| | Frame count / Frame rate | **128** / **48** | 同上 |

### 3) Save 之后请看三件事（= TODO M1 判据）

1. 视口里出现**一簇橙色火苗**（约 50 颗、每颗 0.65 m 左右，往外散开、慢慢熄灭）？

3. 火焰的**朝向**对不对（永远正面朝你 = `3d`）。
