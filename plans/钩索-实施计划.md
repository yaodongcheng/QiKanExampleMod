> **修法（已落盘 + 已编译 0 error）**：`TryGetRightHandAnchor` 重写为**双解释 + 三级兜底**：
> ✅ **实机验证通过（2026-10-07 晚）**：`custom.spell hand` 打出
> `mainHandBone=26 resolved=True src=[bone/local d=1.41 (world d=575.7)]`
> ⇒ 原生返回的**确是角色局部坐标**（当世界用会飞出去 575 m），双解释正确识别成 **local**，
> 钩随即出现在**手边**并绕转（用户实机："这次看到旋转的钩子了"）。
> 解释层抽成**唯一实现** `SpellCastInput.TryReadBoneWorld`（手挂点与手臂轴共用，别抄第二份）。
> ① 原始值既按**世界**量一次离身体的距离，也按 **`Agent.Frame` 转世界**量一次 ⇒ 谁 ≤ **1.5 m** 采信谁（两种空间自动识别）；

>    —— 就是实机里能看见的那把钩所在的位置，天然在手，不依赖任何骨空间假设）；
> ③ 还不行才 false。
> **自报来源**：`SpellCastInput.LastHandSource` ⇒ 日志打 `手源=[bone/local d=0.87]`、
> `custom.spell hand` 打 `raw=(…) worldD=… localD=… src=[…]`。
> **现场开关（不用重编）**：`custom.spell handsrc <auto|world|local|item>` —— 手工锁定某一路做对照
> （锁 world/local 时**不退兜底**，正好用来二分"到底哪一路对"）。

## 一、结论（先说做什么）

1. **决定：绳子自己摆，不等引擎。** 理由：1.2.12 的实体组件只有 8 种（MetaMesh / Light / Composite / ClothSimulator / 粒子 / TownIcon / CustomType1 / Decal），**没有绳索**；战帆 DLC（1.5.x）文档里的 `rope_physics_body` 本工程用不上（用户无该 DLC）。
2. **决定：不抄缰绳。** 理由：缰绳是引擎给坐骑开的专用管线（两端锚点骨写死在 `monsters.xml` + 专用骨架 + 物品字段），只能"焊死在马身上"，做不了自由绳。
3. **决定：一根绳 = N 个小实体。** 每个实体挂同一节绳段网格（共享件，开局解析一次），每帧沿"手 → 钩头"的曲线摆位。观感靠段长与重叠，不靠物理。
4. **决定：第一版不做绳索物理（verlet）。** 理由：钩索的绳 95% 时间是绷直的（飞行中拽着、勾住后拉着），直线插值就够；松弛态（收线、脱钩）留第二版。
5. **决定：起手走「弓形武器」—— 不占新键位**（用户裁定 2026-10-01）。右键瞄准出准星、松手发射，准星指哪钩头飞哪；瞄准手感 / 准星 / 射击动画全部白拿。**详见 §3.0。**
6. **决定：弹药做成"隐形且打出去就退还"。** 理由：引擎硬性要求弓必须配一个 `ammo_class` 匹配的弹药物品（`MissionEquipment.HasAmmo`），做不到"零弹药槽"；但可以配 1 个绳弹、每次发射后由我们**立刻退还** ⇒ 玩家永远只有 1 个、永远不用管、永远打不完 —— **体验上就是"不需要箭"**。
7. **决定：两种用法都做**（拉自己 / 拉人）。
8. **决定：分五步做**，每步一个验收命令，能单独停下来看效果（§二）。

## 三、机制设计

### 3.0 起手 = 弓形武器 + 隐形弹药（2026-10-01 用户裁定）

**用什么**：
- **钩索本体** = `Type="Bow"` 的物品（`item_usage` 指向弓的用法组；为将来换投掷动作留口子）—— 装备即得全套原生射击操作。
- 🔴 **准星是引擎自带的，我们零 UI 代码**：骑砍的准星是远程武器通用件（装备远程武器就显示，玩家还能在游戏设置里换准星样式）。
  **左键按住 = 拉弓（原生瞄准姿态，准星变成精确度指示）· 松手 = 发射** —— 这三件事全是引擎干的，
  （⚠️ 2026-10-04 实机更正：弓系瞄准是**左键**、不是右键——本节原文写的"右键=拉弓"是错的；物品文件头注释同此，待一并改。）
  我们**只接管"发射之后"**：把引擎要生成的那颗箭换成钩头（前缀补丁 `return false`）。
- **绳弹** = `Type="Arrows"` 的弹药物品，只随钩索一起发（不给商人、不进掉落）。
- 🔴 **弹种只能借引擎现成枚举**（`WeaponClass` 是引擎枚举，加不了新值）⇒ 绳弹借用 `Arrow`（或 `Bolt`）。
  **副作用**：别人拿普通弓也能装这发绳弹 ⇒ **拦截补丁的判据要写成"弹药是我们的绳弹"**（与法术同款判据，见下）。

**发射链路**（照抄法术系统的现成做法 `Combat/SpellSealFirePatch.cs`）：

1. 弓正常开火 → 引擎建导弹 → 回调 `Mission.OnAgentShootMissile`
2. 我们的前缀补丁判据 = **这一发用的弹药物品是绳弹** → `return false`（**真的没有导弹被建出来**）
3. 改发我们自己的钩头实体 + 绳子

**"不需要箭"怎么做到**：拦掉导弹后**立刻把弹药退回去**（`Agent.SetWeaponAmountInSlot(slot, 数量, true)`）⇒ 玩家背包里永远只有 1 个绳弹，也从来不用管它。
- ⚠️ **待实测**：拦掉导弹后引擎到底扣不扣弹药 —— 现有法术系统已埋了日志点（打两发看余量），做第 2 步时顺手验；**无论扣不扣，退弹都要写**（写成幂等：退到"应该有的数量"而不是 `+1`）。

**方向 = 准星**：飞行方向取 `CameraLook.TryGet`（CLAUDE.md 铁律 35 唯一入口）。弓的准星是按弹道标定的，钩头飞得快且直时准星基本对得上；对不上就调 `missile_speed` / 飞行速度。
**可选旋钮**：弓的**拉弓时间**可以映射到投掷力度（拉满 = 最快最远），第一版不做。

**物品怎么写（照抄法印，别再摸索）**：一对物品（武器 + 弹药），范本 = `Modules/Taikou/ModuleData/taikou_items/spells.xml`。
那份文件头注释已经把坑写全了：类型/usage 怎么选、`Civilian="true"` 必带（铁律 33）、
`campaign.add_item_to_main_party` 是**按显示名**查（不是 StringId）、参数组用竖线 `|` 分隔。

### 3.1 状态机

```
Idle ──开火──▶ Throwing（钩头飞向瞄准点）──命中──▶ Attached（钩头钉住）
                  │ 打空 / 超距                          │
                  ▼                                     ▼
               Retract ◀────── 松键 / 打断 ────── Pulling（拉自己：木板承载 + 曲线位移）
                                                        │ 到位
                                                        ▼
                                                   Landing（减速落台）──▶ Idle
```

- **命中人**：Attached（挂在目标身上）→ Pulling 走"拉目标"分支（§3.6）。
- 同一时刻只有一根绳（玩家的）。NPC 用不用见 §八。
- **任意状态 → Retract 的出口必须有**（受击 / 倒地 / 进对话 / 骑马），解除一切接管（控制权一定还给玩家）。

### 3.2 钩头 = 复用自管实体投射物

照抄现有配方（`wheels.d/spells.md`「自管实体投射物」）：

```csharp
MetaMesh mm = MetaMesh.GetMultiMesh(name) ?? MetaMesh.GetCopy(name, showErrors:false, mayReturnNull:true); // 解析一次整局缓存
GameEntity e = GameEntity.CreateEmpty(scene, true);  e.AddMultiMesh(mm, true);
e.SetGlobalFrame(new MatrixFrame(rotation, position));                     // 每帧只改 origin
// 命中：①打到谁  ②打到墙/地 —— 两条各给距离，取近的那个
Agent v = V.RayCastForClosestAgent(mission, from, to, excludeIndex, hitRadius, out float dAgent);
bool hit = scene.RayCastForClosestEntityOrTerrain(from, to, out float dWorld, out Vec3 point, 0.01f,
                                                  BodyFlags.CommonCollisionExcludeFlagsForMissile);
```

- **飞行**：直线 + 轻微下坠（数据可调）；碰撞检查 **0.05 秒一次**（不是每帧）。
- **勾住墙**：钩头停在命中点，按命中法线摆姿态。
- **勾住人**：钩头每帧吸附到目标躯干；同时给目标打"被勾"标记。

### 3.3 绳子 = 唯一新件（**已落地** —— 代码见 `Combat/GrappleRope.cs`，实机结论见 §十）

- **起点**：手骨 —— `SpellCastInput.TryGetRightHandAnchor`（内部走 `Monster.MainHandBoneIndex` + `GetBoneEntitialFrame`，带"离身体太远就不可信"的兜底）；取不到退回身体坐标 + 抬 1.25 米。
- **终点**：锚点（现阶段）/ 钩头（步骤 2 起）。
- **两种画法**（可运行期切换，**铁链是实机选定的**）：
  | 画法 | 做法 | 现状 |
  |---|---|---|
  | **铁链**（`chain 1`，推荐） | 一串**竖长铁环**（长:宽 ≈ 2.5:1），相邻环绕链轴转 90° 咬合；沿 **Catmull-Rom 光滑曲线**按固定节距铺 | ✅ 实机验证 |
  | **分段管**（默认） | N 个实体挂同一根直管，**中点法**摆放（段 i 从中点画到中点） | ✅ 实机验证 |
  | ~~整条弯曲管~~ | 一个网格每帧重建顶点 | ❌ **实机画不出来，已删除**（§10.4） |
- **几何是代码算的**：管/环都用运行时 `Mesh.CreateMesh` + `AddTriangle` 造（**只造一次、所有件共用**），
  **材质借现成的**（`custom.grapple mat <网格名>` 可借任意原版件）。
- 🔴 **实体池按最大长度一次备好**（24 米 ≈ 326 环 —— 上限随钩索射程从 16 抬到 24，覆盖 20 米瞄准射程），每帧只决定"显示前 N 个" —— 绳长每帧在变，**不能跟着重建实体**。

### 3.4 模拟：verlet 点链 + 绷直态解析解（**已落地**）

第一版原计划"不做 verlet、只用两点直线"—— **实施时改成了完整的 verlet 点链**，因为：
- 松弛态才是钩索的常态（被拽出去、脱钩、收线），直线插值在这些状态下一眼假；
- 距离约束点链本身很便宜（48 点 × 8 次迭代 ≈ 400 次浮点运算/帧，实测 tick 0.05ms 量级）。

**两条口径**（都是实机撞出来的，见 §10.3 坑 3 / 坑 7）：
- 每段的静止长度 = **绳长 ÷ 实际段数**（不是"目标段数"）—— 两者错配会把绳子拉成直线；
- 绳长 ≤ 跨度（绷直）时**走解析解**：点均匀铺在两端直线上 —— verlet 在"约束刚好拉满"时永远留残余弧度。

### 3.5 拉自己（勾到墙 / 勾到地形）—— 时间线照 UE 参考工程

**时间线**（前两段是"人还没动、钩头在飞"；第三段才是位移）：

| 段 | 空中起钩 | 地面起钩 | 发生什么 |
|---|---|---|---|
| 投掷 | 0 → ~0.35s | 0 → ~0.45s | 钩头从手飞向钩点，绳跟着伸出去 |
| 蓄势 | → 0.70s | → 1.10s | 钩头已钉住，人还没动（摆姿势、绳子绷紧） |
| **拉升** | 0.70 → 1.65s（**0.95s**） | 1.10 → 2.30s（**1.20s**） | **人被带着飞**（曲线驱动，见下） |
| 收势 | 最后 10~15% | 最后 10~15% | 减速落到终点 |

（数字来源 = UE 参考工程的蒙太奇通知点，见 §3.8。空中起钩更快、地面起钩蓄势更长 —— 这是原作的手感，照抄。）

**位置公式**（每帧算一次，逐字照 UE 的写法）：
```
alpha = speedCurve(t)                   // 0→1：起点慢、中段快、末尾收（UE 曲线实测斜率 2.2/s → 0.29/s）
pos   = lerp(起点, 终点, alpha)
pos.z += arcCurve(t)                    // 起跳弧线（中途抬升 ~1.5 米），**结束必须归零**
```

- 🔴 **与 UE 的唯一刻意差异**：UE 的高度曲线结束时还有 +2 米，靠"恢复重力把最后 2 米掉下来"收尾。
  我们**让弧线在结束归零**（终点 = 平台面本身）。理由：骑砍的落地 = "拆板、交还控制"一步到位，
  多 2 米悬空下落要额外处理引擎的"由悬空变被托住时按地形重算位置"（实测 63 米瞬移那个坑，§七 风险 1），
  不值当。想要"俯冲落台"的手感，第 2 版再加。
- **位移必须走脚下木板**（骑砍写不进 agent 的 Z，§七 风险 2）：
  复用飞行工程已验证的 **冻结**（`Controller=AI` + `SetIsAIPaused(true)`）+ **`CarrierBoard` 逐帧瞬移**。
  - 木板按"拉力方向"贴到玩家脚下（起飞那套 `_takeoffSettled`：板放好、等人站住、再动）。
  - **空中起钩**（人正在坠落）：板直接出现在脚下把人接住 —— 复用飞行工程的"板载坠落"路径。
- **落点**：`Landing` 段复用飞行工程的落地流程（板降到贴地 → 拆板 → 交还控制）。
- **骑马时**：第一版**不可用**（提示"马上用不了"），理由见 §八。
- 🔴 **到位前必须减速**——引擎在"悬空变被托住"的瞬间会按地形重算位置（§七 风险 1），减速段是硬需求不是润色。
- **可调旋钮**（都用 `custom.grapple` 命令改，实时生效）：拉升时长 / 弧线高度 / 最大瞄准距离（默认 **20 米**，UE 是 12 米，骑砍地图更大）/ 钩头飞行速度（默认 ~35 m/s）。

### 3.6 拉目标（勾到人）

- 拖拽姿势：第一版用最简单的（倒地/匍匐姿态），可复用现有击晕/倒地的动作件（`KnockoutFlow` 一带）。
- 释放条件：到玩家身边 / 目标死亡 / 松键 / 超时。
- **骑马的目标**：见 §八待拍板。
- 🔴 **平权纪律**（铁律 18）：判定与结算（勾住判定、拖拽应用）写成**共享函数**，玩家侧与将来的 NPC 侧共用，别写两份。

### 3.7 落点平台计算（2026-10-01 用户要求；UE 参考工程没有这件 —— 是他们手工摆"落点区"，我们自动算）

**要解决的问题**：钩中一面墙直接飞向钩点 = 撞在墙面上。真人要**落到钩点附近的平台上**（墙顶、屋顶、岩台）。

**三步**：

1. **打点**：准星射线命中 P（钩点）。
2. **找平台**：在 P 的水平位置四周做环形采样 —— **8 个方向 × 4 档半径（0.4 / 0.8 / 1.3 / 2.0 米）**，
   每个采样点从 `P.z + 2 米` 高度**向下问地面**（`Scene.GetGroundHeightAtPositionMT(pos, out normal)`）。
   一个候选被接受要**同时**满足：
   - **站得住**：地面法线竖直度 `normal.z ≥ 0.7`（太陡的斜面不算平台）；
   - **是"钩点附近的台"**：高度落在 `P.z − 1 米 ~ P.z + 4 米` 之间（排除掉墙脚那块地）；
   - **站得下**：从候选点往上射一条 2 米的射线不被挡（头顶净空）。
   打分 = `|候选z − P.z| + 半径`（越贴近钩点高度、越近越好），取最优 ⇒ **飞行终点 E = 这个平台点**。
3. **没找到平台**（钩的是树干/旗杆/光秃岩壁）：终点 E = 从 P **沿"玩家→P"方向退回 1.5 米**的位置
   （这一段射线已验证无遮挡）⇒ 玩家飞到那里后**自由落体**（木板带着人往下掉，落地即正常着地）。

**引擎 API 事实（反编译 1.2.12 实证，写实现前照抄）**：
- 🔴 **只有带 `MT` 的重载真填法线**：`GetGroundHeightAtPositionMT(pos, out Vec3 normal, flags)`。
  不带 MT 的同名重载是引擎绑定 bug —— 它把 normal 填成 `Invalid` 就返回了，**法线永远是空的**。
- 返回值可能是 `NaN` / `±1e5` 哨兵 ⇒ 一律当"此处没有地面"（绳子贴地那套已在用同款判据，`GrappleRope.SampleFloors`）。
- flags 传 `BodyFlags.CommonCollisionExcludeFlags`（别打到自己人/自己身上）。

**验收命令**：`custom.grapple probe` —— 打印 **命中点 / 每个采样点的（z、竖直度、是否入选）/ 最终终点**。
调参、排查"为什么这次落在那里"全靠它，**不用真的飞一次**。

### 3.8 UE 参考工程拆解结论（2026-10-01，证据 = `Debug/offline/sekiro_dump/`）

来源：`D:\UEProjects\mySekiro`（UE5.3）的 `BP_GrappleComponent` + 两个蒙太奇 + 8 条曲线 + 钩点 BP + 准星 UMG。
拆解工具 = `tools/ue-dissect/`（本次新增 `export_targeted.py` 定向导出；`t3d_tools.py` 补了 UTF-16 嗅探）。

**它是一个"蒙太奇驱动"的设计** —— 一张动画表从头到尾管着一切：

| 时间点（秒） | 空中蒙太奇 | 地面蒙太奇 | 通知干什么 |
|---|---|---|---|
| 0.16 / 0.41 | RopeAppear | RopeAppear | 绳与苦无出现在手 |
| 0.34 / 0.44 | ThrowRope | ThrowRope | 甩出去（绳伸向钩点） |
| **0.70 / 1.10** | **StartGrapMoving** | **StartGrapMoving** | **位移开始**：重力归零、记起点、开拉 |
| 1.37 / 2.05 | RopeDisappear | RopeDisappear | 绳收掉 |
| **1.65 / 2.30** | **GrappleEnd** | **GrappleEnd** | **位移结束**：重力恢复、清目标、状态复位 |
| 1.98 / 3.08 | —（表尾） | —（表尾） | 动画演完 |

**每帧位移**（`GrappingMovement`，逐帧调用）：`位置 = lerp(起点, 终点, 速度曲线(表进度)) + (0,0,高度曲线(表进度))`。
- 速度曲线（表进度 0.7→1.65 采样）：值 0→1，斜率 2.2/s → 0.29/s（先加速后收，无明显中段）。
- 高度曲线：0 → 峰值 2.75 米（约 40% 处）→ 2.0 米（结束）——**结束时不归零**，靠恢复重力掉最后 2 米。
- 终点 = 钩点的 **LandingZone 组件位置 + 1.1 米**（每帧刷新，允许落点动）。

**其它件**（照抄结论，不照抄实现）：
- 检测（我们不需要）：球搜 20 米 + 距离 >5 米 + 相机前向点积最大 + 点积 >0.9 + 视线检查 → 唯一目标；射程 12 米。
- 准星提示 = 每个钩点上挂一个小 UMG（圆形标记，被瞄准时播一个放大动画、按距离改大小/颜色）。
- 绳 = UE 自带的 CableComponent（长度与端点由曲线驱动）——**我们用自己的点链 verlet 绳，不用抄**。
- 钩头 = 苦无（SM_Kunai 静态网格）—— 我们第一版拿现成细长件占位（§八 #4）。
- 动作 = 两段式：空中/地面各一套动画（我们是后续资产工程，见 §八 #7）。

**我们取什么、不取什么**：取**时间线结构与两条曲线的形状**（§3.5 照抄）；不取 LandingZone（改成自动算，§3.7）、
不取 CableComponent（已有更好的绳）、不取检测系统（改成"准星指哪打哪"）。

## 六、验收命令（`custom.grapple`）

> 纪律：纯英文返回、首参可弃（CLAUDE.md 控制台纪律）。

| 命令 | 干什么 |
|---|---|
| `custom.grapple anchor <距离> <绳长> <段数>` | 钉绳。① 准星外推距离（默认 12 米）② 绳长（**给了就关掉橡皮筋**）③ 模拟分辨率；例 `anchor 8`、`anchor 8 10 40` |

| `custom.grapple radius` · `mat` · `smooth` | 粗细倍率（0.6）· 材质借谁（空 = 借绳子那件）· 铺链加密步长（0.03 米） |
| `custom.grapple seg <n\|auto>` · `damp` · `grav` · `ground <0\|1>` | 模拟分辨率（48）· 阻尼（0.94）· 重力（9.8）· 贴地开关 |
| `custom.grapple freeze <0\|1>` · `release` · `clear` | 定格看形状 · 远端松手（掉地上）· 收绳 |
| `custom.grapple dump` | **一行状态**：`length/span/slack/sag` + `segments/radius/shape/tick` + 手与锚点坐标 |
| **（步骤 2 起）** `custom.grapple throw` · `retract` | 朝准星发一根钩头（完整链路：飞行 → 命中 → 落点平台解算）；**不装备武器也能测** · 收钩 |

### 10.2 实机结论（用户裁定）

1. **铁链画法胜出**（`chain 1`）—— 观感明显优于分段管。**"整条弯曲管"实机完全画不出来，已删除。**
2. **橡皮筋绳长**（默认开）就是用户要的手感：走远被拽长、走近自动收短，**但永远留一份余量** ⇒ 一直有自然的弧。
   默认余量 **1.05**（微微有弧）；**1 = 绷直**（走解析解，见坑 7）。
3. 性能实测（用户日志）：**分段 8 段 0.01ms · 40 段 0.05ms · 铁链 ~0.6ms** —— 都远小于 60fps 的 16.7ms 预算。
   `tick=` 就是为此加的字段（只算我们花的钱，不含 draw call）。
4. **外观设置会记住**（`chain`/`radius`/`mat`/`smooth` 打一次，之后每个场景自动生效）。

### 10.3 本次踩的坑（全部是实机撞出来的，按症状查）

| # | 症状 | 根因 | 修法 |
|---|---|---|---|
| 1 | 绳子是一串"钩子" | `rope_stealth_mission_a` 是 **4 个子网格**（绳身 + 钩子 × 两个 LOD），`AddMultiMesh` 全挂上了；且**绳身本身是弯的**（18 米装饰绳） | 原版绳不能当段 ⇒ **运行时自造直管** |
| 2 | 管子全**立起来** | `Mat3.CreateMat3WithForward(d)` 把方向写进 **`f`（局部 Y）**，而我们的网格沿**局部 Z** 长 | 自定义基底 `BasisWithLocalZ`（**u = dir**） |
| 3 | 绳子笔直、`sag=0` | `anchor` 改了绳长**却没重建段数** ⇒ 每段静止长度按新长度算、实际段数还是旧的 ⇒ **绳子总长比跨度还短 = 被拉直** | ① 先定长度再 `Build` ② 静止长度按**实际段数**算 |
| 4 | 绳**陷进石板路** | 用了 `Scene.GetTerrainHeight` —— 那是**高度图**，城镇里脚下是网格铺装、高度图在铺装之下 | 改 `Scene.GetGroundHeightAtPositionMT`（地表系统 `SurfaceDecalFx.GroundZ` 同款，带探针高从上方找） |
| 5 | 拐弯处两根管子**交叉** | 每段是直管且比该占的位置长（overlap 1.35）⇒ 一拐弯就斜插过去 | **中点法**摆放（段 i 从中点画到中点）+ overlap 退回 1.0 |
| 6 | 铁链"**4 个环一组、第 5 个突然折**" | 链节直接铺在模拟折线上（折线 25cm 一点、链节 7cm）⇒ 一个区间内 3~4 环严格共线 | 铺链前 **Catmull-Rom 加密成光滑曲线**再按弧长铺 |
| 7 | `slack 1` 还**有弧** | **不是余量**，是 verlet 的极限：绳长 = 跨度时物理上只能直线，但数值迭代永远解不干净 | 绷直态（跨度 ≥ 绳长 × 0.995）**走解析解**：点均匀铺在两端直线上 + 清速度 |
| 8 | 自动长度**偷偷多留余量** | 我把公式写成 `max(跨度 × slack, 跨度 + 0.25)` | 改成纯 `跨度 × slack` |
| 9 | 链节数随绳长变 ⇒ 会**每帧重建实体** | 段数 / 实体池按"当前长度"算 | 池子按**最大长度**一次备好（当时 16 米 ≈ 217 环；2026-10-01 随钩索射程抬到 24 米 ≈ 326 环），每帧只决定"显示前 N 个" |
