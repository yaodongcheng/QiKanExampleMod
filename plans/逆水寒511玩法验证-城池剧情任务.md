## 0. 结论

- **这次验证的是真实城镇场景里的序章，不是菜单。** 菜单只用于进入场景（原版「在城里逛逛」）。
- **玩家一开始是 nobody**：进场景时收走场景 agent 的武器 / 金钱，换粗布衣；序章结束恢复。
- **入口是一个额外的入城选项（如「入城（玩法测试）」）**：只有从它进场景才加载玩法；原版「在城里逛逛」不加载。
- **城门口是四家势力的地盘**：水脚行的城门打手（blocker）+ 中人行（当铺）+ 夜行会（儿子）+ 红袖班（寡妇）；屠户是水脚行的叛逃者（武老师）。**底层百姓互帮互助 + 四家各有算盘**：你帮谁，谁教你一手；钱是中人行的路（跑腿换铜板，收买打手）。
- **动机：找妹妹**：三个月前她进城做工，再没消息；你一路找来，钱被偷、身上只剩她的信；水脚行栽了你一桩小事，你背着小额通缉——正门进不去，只能惑 / 巧 / 武 / 钱。
- **势力不白给**：你求他东西 → 他让你去教训他的**仇家**（委托）→ 完成才算数；势力关系 +，仇家关系 -，水脚行内圈 A/B 还要选边。
- **玩家 0 钱**：钱靠零活赚（跑腿 / 搬货 / 送信）；**钱不是万能**（blocker 能打点，势力的工具不卖）。
- **每个 NPC 抗性不同**：力量 / 技巧 / 魅力三档抗性不一样；选对人用对招，或者先打听弱点。
- **三个能力家族，每个家族下面是多个我们已有的真玩法**：
  - **惑**：乔装（身份：冒充通行 / 通缉脱险 / 冒充犯法）/ 收买（钱）。对话类先不做。
  - **巧**：钩索 / 扒窃 / 撬锁 / 潜行 / 偷属性道具（偷东西也能涨值）。
  - **武**：决斗 / 击晕 / 威吓（开战前）/ 绑起来 · 扛走（力量检定）。
- **🔴 311 是逆水寒的叫法，不是要新造骰子。** 我们直接复用 mod 已有的**属性检定**：社交用 `SingleRollResolver` + `IntentBase`（Charm / Roguery），武力用 `AgentStatsHelper` + `KnockoutFlow` 的 Vigor+Control ratio。**不新建骰子系统、不新建属性系统。**
- **结果只有成功 / 失败两个分支**（不做大成功 / 大失败）；现有检定本身就是 bool。
- **选择有反馈**：用哪个家族，那个势力关系 +、天赋点 +1；选武会和拦路者结仇；惑 / 巧留下不同隐患。
- **不新建角色 / 资产 / 物品定义**；4 个 NPC 全用原版 Hero（notable / wanderer）；不依赖 LLM。

> 脑图里的「偷传送手套 / 发现地下密道」是神界原罪 2 的举例，不照搬；「311 骰子」是逆水寒术语，落到我们已有的属性检定。

## 3. 场景与触发

### 3.0 剧情前言：为什么非要进这座城

- **一句话**：三个月前，你妹妹进城做工，再没消息；你一路找来，钱被偷了，身上只剩她最后一封信。城门在眼前。
- **动机 = 找妹妹**：势力各自知道她的一截下落——寡妇卖过她路引、儿子见过她、屠户认识带走她的人、当铺有她当的东西；**水脚行是带走她的那条线**。
- **为什么不能走正门**：你没路引、没钱；更糟的是，水脚行在路上栽了你一桩小事——你背了个**小额通缉**（`ChangeCrimeRatingAction`）。走正门 = 被抓；所以你只能**惑 / 巧 / 武 / 钱**。
- **为什么你什么都没有**：路上被抢 / 被偷，武器和钱都没了（nobody）。
- **妹妹是谁**：一个**名字 + 一封信**（原版书 / 信物当载体）；**第一阶段不登场**，后续再用现成 hero / 内容包角色。
- **开场怎么给**：进场景时给一封**信**（物品描述 / 通知）+ 一句旁白；玩家可以拿信问势力；不新建角色。
- **主线钩子**：水脚行 / 第一张凭证；妹妹是情感线，水脚行是主线。
- **和四条的对应**：乔装 = 遮住通缉身份；偷 = 摸进城门；打 = 硬闯；钱 = 打点。**没有一条是「白走进去」**。

- **目标城**：默认 `town_EN1`（Epicrotea，帝国城镇；1.2.12 与 1.5.x 都有），可在 `config.json` 改。
- **入口 = 一个额外的入城选项**（名字随意，暂叫「入城（玩法测试）」）：**默认不出现**，只在**目标城 + 玩家打过 `custom.story_probe enable` 之后**出现；`disable` 后消失。**只有从这个选项进来的场景才加载玩法**；原版「在城里逛逛」不加载序章。
- **选项做什么**：设置 `EnterViaOption` 标记 → 走原版城镇中心场景的加载路径（`GameMenuManager.NextLocation = center` / 原版 `town_center` 菜单）；场景加载后 `StoryProbeMissionBehavior` 检查标记，**只有标记为真才布置玩法**，并消费标记。
- **序章发生在城门外的关厢**：玩家在门外，blocker 在门口，势力在关厢；目标点 = 门内。
- **恢复**：中途存档 / 读档后，玩家再点同一个选项进来，标记为真 → 恢复序章；原版进城不恢复。
- **触发判定**：`StoryProbeMissionBehavior` 在 `OnMissionBehaviorInitialize` 检查：
  1. `StoryProbeState.Enabled == true`（`custom.story_probe enable` 打开；默认 false）；
  2. `EnterViaOption == true`（由入城选项设置；**未设置 = 原版入口，直接 return**）；
  3. `Settlement.CurrentSettlement.StringId == StoryProbeSettlementId`；
  4. 当前地点是 **center**（不是 tavern / lordshall / keep）；
  5. 序章状态 = 未开始 / 进行中（读档恢复）。
  然后**消费** `EnterViaOption`。
- **只在 center 触发**：判定用 `Campaign.Current.GameMenuManager.NextLocation` / `LocationComplex`，照 `custom.enter_lordshall` 的取值方式。
- **提示**：入城选项本身就是提示（「入城（玩法测试）」）；可在目标城菜单里高亮，不自动发通知。
- **验收命令**：`custom.story_probe enter` = 设 `EnterViaOption` + 走原版 center 加载路径（调试用）；不在目标城则打印提示。

## 4. 城门口的四个势力

| 势力 | 性质 | 城门边的代表 | 对应家族 | 和谁敌对 |
|---|---|---|---|---|
| **中人行**（友好；头目是捉刀人） | 中间人 / 掮客，替人跑腿、找门路、写状子 | 当铺老板（他的前台） | **钱 / 人脉**（零活、收买、消息） | 水脚行 |
| **夜行会**（中立） | 小偷 / 撬锁 / 扒窃 | 寡妇的儿子（小贼） | **巧**（钩索 / 扒窃 / 撬锁 / 潜行 / 偷属性道具） | 水脚行 / 外帮贼 |
| **红袖班**（中立） | 戏班 / 舞姬，靠表演和魅力 | 寡妇（班主 / 舞姬） | **惑**（乔装 / 魅惑 / 身份） | 水脚行 / 对台戏班 |
| **水脚行**（邪恶） | 水脚行 / 黑帮，收数 / 放贷 / 打手 | blocker（城门打手）；thug（打手）；屠户是叛逃者 | **武**（决斗 / 击晕 / 绑 / 扛 / 威吓） | 中人行 / 夜行会 / 红袖班 |

- **英文 fallback / 本地化**：中人行 = The Brokers · 夜行会 = The Nightwalkers · 红袖班 = The Red Sleeves · 水脚行 = The Water Gang；名字一律走 `LWN_faction_*` 键。
- **站位**：blocker 在玩家正前方 8 m；四个势力的代表（当铺老板 / 儿子 / 寡妇 / blocker）在他左右后 3~5 m；屠户在街边。站桩、面向玩家；用 MissionBehavior 每帧钉住位置 / 朝向。
- **生成**：复用 `HeroSpawnerMissionBehavior.SpawnHeroInFrontOfPlayer` 的做法（`SimpleAgentOrigin` + `Mission.SpawnAgent`），加一个 `SpawnHeroAt(hero, position, direction)` 变体。
- **防重复**：先查场上有没有这个 hero 的 agent（按 `Character` 匹配）；有就移动，没有才 spawn。
- **必须是 Hero**：社交检定 `InteractionController.ResolveAdversarialIntent` 要求 `ctx.Speaker` / `Profile` 存在（模板 NPC 会被拒「不能深谈」）；所以代表都用原版 Hero，不用模板。
- **身份**：全部原版 Hero；不新建 Hero / 模板 / 外观。四个势力各存代表 HeroId + 关系，序章结束显示「他日再会」。
- **屠户**：水脚行的**叛逃者**（former enforcer），不是水脚行代表；他教你武，是为了报复砸他摊的旧同伙。

### 4.1 故事网：城门口的四家

**设定**：玩家是个 nobody，被**水脚行**的城门打手拦在**城外**。门外关厢是四家的地盘：**中人行**摆一张桌子替人写状子 / 找门路，**夜行会**蹲墙头，**红袖班**搭戏台，**水脚行**摆收数摊。四家都在门口，各有各的难处；**你帮谁，谁教你一手；不帮，没人白给**。

| 势力 | 难处 | 你帮它做什么（委托） | 它给你什么 | 和谁敌对 |
|---|---|---|---|---|
| 中人行（当铺前台） | 水脚行收保护费 / 抢他生意 | 替他跑腿 / 收债 / 打点 | 铜板 + 消息 + 零活 | 水脚行 |
| 夜行会（儿子） | 外帮贼抢地盘 / 水脚行打压 | 教训外帮贼 / 偷回工具 | 钩索 + 后路 | 外帮贼 / 水脚行 |
| 红袖班（寡妇） | 水脚行砸场 / 对台戏班抢客 | 教训对台 / 赶走 thug | 官服 + 路引（身份） | 对台戏班 / 水脚行 |
| 水脚行（blocker / thug） | —（反派） | 打 / 绑 / 扛 / 威吓他们 | 武器 / 绳子（从叛逃者屠户处学） | 所有人 |

- **四家都在城门口**：中人行摆桌、夜行会蹲墙头、红袖班搭台、水脚行收数；玩家一眼能看出四家的行头。
- **每个人知道妹妹的一截**：中人行给她找过活；儿子见过她被带走；寡妇卖过她路引；水脚行知道她在哪。
- **不是四个高人一人一句**：每家先演一件小事（中人行写状子、儿子从墙头滑下、寡妇甩袖 / 递假路引、blocker 收数 / 砸摊），玩家看见 → 搭话 → 帮 → 才教。
- **选择有后果**：帮谁，谁就是你的第一个势力；没帮的人说一句「你选了别人」；水脚行的反应不同。
- **钱是中人行的路**：替他跑腿 → 几个铜板 → 收买 blocker；不要求你打 / 偷 / 骗。
- **水脚行**：不管走哪条，最后都指向水脚行 / 第一张凭证——这是沙漏第一段 → 第二段的接缝。
- **气质**：底层百姓互帮互助 + 四家各有算盘；不是「神秘高人传功」。
- **每个势力给的是整个家族**：官服 / 钩索 / 武器只解锁**主路**；其他玩法用玩家已有的能力。
- **blocker 的后续**：惑 → 被耍；巧 → 没看见；武 → 被打服 / 结仇。

### 4.1.1 势力 / 仇家 / 委托：把「帮忙」做成交易

**四个势力与内部矛盾**：

- **中人行（友好；头目是捉刀人）**：当铺老板是前台；替人跑腿 / 找门路；被水脚行收保护费。
- **夜行会（中立）**：寡妇的儿子是小贼；和**外帮贼**（水脚行的线人）争地盘。
- **红袖班（中立）**：寡妇是班主 / 舞姬；和**对台戏班**（水脚行捧的）抢客。
- **水脚行（邪恶）**：水脚行；blocker 守门、thug 打手、debtor 收数；内圈 A / B 争地盘；屠户是叛逃者。

**仇家贸易（委托结构）**：

1. 你求一个势力（官服 / 钩索 / 武器 / 铜板）。
2. 势力不白给：「先帮我教训 X」——X 是它的仇家。
3. 你用惑 / 巧 / 武 / 钱完成（揍 / 吓 / 偷 / 绑 / 扛 / 收债）。
4. 完成 → 势力关系 +；仇家关系 -；仇家势力 -；水脚行警觉 +。
5. 你拿到的能力 / 工具，再用来过 blocker。

| 势力 | 你求它什么 | 它让你做什么（委托） | 仇家 | 完成 → 你得到 | 后果 |
|---|---|---|---|---|---|
| 中人行（当铺） | 铜板 + 消息 + 零活 | 收 debtor 的债 / 打点 | debtor（水脚行 A 的收数） | 铜板 + 消息 | 中人行 +；debtor -；水脚行 A - |
| 夜行会（儿子） | 钩索 + 后路 | 教训外帮贼 / 偷回工具 | 外帮贼（水脚行的线人） | 钩索 | 工会 +；外帮贼 -；水脚行警觉 + |
| 红袖班（寡妇） | 官服 + 路引（身份） | 教训对台戏班 / 赶走 thug | 对台戏班（水脚行捧的） | 官服 + 路引 | 红袖班 +；对台 -；水脚行 - |
| 水脚行（反派） | — | —（打 / 绑 / 扛 / 威吓他们） | blocker / thug | 武器 / 绳子（从叛逃者屠户处学） | 水脚行 -；屠户 + |

- **选边**：帮中人行 / 夜行会 / 红袖班 = 动水脚行；帮水脚行 = 动三家。水脚行内圈 A / B 也有矛盾。
- **不白给**：不做委托，势力不教 / 不给；你可以花钱 / 硬闯，但那不是它的人情。
- **序章先做一条**：红袖班（寡妇）的委托（教训对台戏班）作为示范；其他势力留接口，后续内容加。
- **现成系统**：委托数据 / 目标 / 奖励复用 `CommissionQuest` / `CommissionData` 的形状（不跑程序化生成器）；关系走 `ChangeRelationAction` / `SettlementHonorStore` / `InfamySystem`；揍 / 绑 / 扛走 `KnockoutFlow` / `CombatManager` / `GrappleBind` / `GrappleCarry`；偷走 `StealManager`。

### 4.1.2 背包里的属性道具：偷东西也能涨值

- 每个势力 / 仇家的**背包**里放一件**属性道具**（原版书 / 药剂 / 护符当载体；不给新资产）。
- **偷到**（现有扒窃条 / `StealManager`）或**委托奖励**得到；使用 / 装备后 **+1 对应技能**（例如 +1 Roguery / Charm / Vigor），走现有 `Hero.AddSkillXp` / `SetSkillValue`；不新造属性系统。
- **偷有风险**：被目击 = 犯罪 / 警觉；所以「偷属性道具」是**有代价的成长**，不是白拿。
- **每件唯一**：一个 NPC 只有一件；偷了 / 拿了就没了；不能反复刷。
- **和委托互补**：不想冒险偷 → 做他的委托换；想走巧 → 直接偷。

| NPC | 背包道具（载体） | 拿到 → +1 |
|---|---|---|
| 寡妇（红袖班） | 香囊 / 假印 | Charm |
| 儿子（夜行会） | 细钩 / 撬锁包 | Roguery |
| 屠户（水脚行叛逃者） | 磨刀石 / 护腕 | Vigor / OneHanded |
| 当铺（中人行） | 算盘 / 账本 | Trade / Charm |
| 仇家 | 抢来的护符 | 对应家族 |

- **现有系统**：`StealBarVM(Pickpocket)` / `StealManager.StealSpecificItem` / `Hero.ItemRoster` / `AgentControlHelper.TransferItems` / `Hero.AddSkillXp`。

### 4.1.3 赚钱：零活 + 钱不是万能

- **玩家一开始 0 钱**（nobody）。
- **赚钱点（零活）**：当铺跑腿 / 寡妇送信 / 屠户搬肉 / 儿子把风 —— 每次几个铜板；不是委托，是**零活**。
- **提示**：势力会顺口说「缺钱？帮我跑一趟」；`status` / 通知列出当前零活。
- **钱不是万能**：
  - **能买**：blocker 的打点（100 文）；当铺的消息（几十文）；酒 / 情报。
  - **不能买**：势力的**工具 / 手艺**（只换人情，不卖）；仇家的**恩怨**（揍 / 吓 / 偷才解决）；有些 NPC 不吃钱（例如死脑筋的屠户）。
- **钱是第四条路，但只解决「钱能解决的那一段」**：blocker 可以打点，势力的委托不行。

### 4.1.4 NPC 抗性：力量 / 技巧 / 魅力各不相同

每个 NPC 对三个家族有不同抗性（高 = 难，低 = 容易）；检定用 `playerSkill / (playerSkill + 抗性)`（同一套 ratio，不走 NPC 实际技能）。

| NPC | 力量抗性 | 技巧抗性 | 魅力抗性 | 提示 |
|---|---|---|---|---|
| blocker（水脚行） | 高 | 低（贪 / 不警觉） | 中 | 硬闯难，偷 / 混过去容易 |
| 寡妇（红袖班） | 低（弱） | 中 | 高（老江湖） | 吓她容易，骗她难 |
| 儿子（夜行会） | 低 | 高（贼） | 低（年轻） | 偷他难，骗他容易 |
| 屠户（水脚行叛逃者） | 高（壮） | 中 | 低（直） | 打他难，骗他容易 |
| 当铺（中人行） | 低（老） | 中 | 高（精） | 吓他容易，骗他难 |
| rival vendor（对台戏班） | 低 | 中 | 高（同行） | 吓 / 偷比嘴炮容易 |
| rival thief（外帮贼） | 低 | 高 | 中 | 骗他比偷他容易 |
| thug（水脚行） | 高 | 低 | 低 | 绑 / 骗比硬打容易 |
| debtor（水脚行 A 的收数） | 中 | 中 | 中 | 三条路差不多 |

- **抗性可以打听**：跟势力 / 围观者聊（`Info` / `Chat`）能知道某人「吃软不吃硬」；知道后**检查里显示**（或给情境加成）。
- **不是所有路都通**：高抗性 = 成功率低；玩家要**选对人用对招**，或者先打听。
- **和「311」的关系**：311 的「情境加成」可以来自**抗性情报**（知道弱点 +2）；数值在 Defs。

### 4.3 角色来源与 AI 行为

**结论：不新建 CharacterObject / Hero / 模板；全用原版。**

**选人顺序（两轮，铁律 5）**：

1. 目标城的 `Settlement.Notables`（按 occupation：GangLeader / Merchant / Artisan / Headman / Preacher）；
2. `Hero.AllAliveHeroes` 的流浪者（`IsWanderer`）；
3. 原版 `CharacterObject` 模板（`guard` / `gangster` / `villager` / `merchant` / `artisan` / `preacher`；按文化查，见 `spnpccharacters.xml` / `spnpccharactertemplates.xml`）。

**角色表**：

| 角色 | 来源 | 背包（属性道具） | AI 行为 |
|---|---|---|---|
| blocker（水脚行） | 优先 notable（GangLeader）；没有就用 guard 模板 | 有（hero 时） | 站门口、面向玩家；惑→对话；偷→扒窃条；武→决斗/击晕/绑/扛；被打→还手 |
| 寡妇（红袖班） | 优先女性 notable（Merchant / Preacher）；没有就流浪者 / 模板 | 有 | 站摊、递假路引小动作；对话 / 委托；被打→逃 |
| 儿子（夜行会） | 流浪者 hero 或 notable（Artisan / GangLeader） | 有 | 站墙头 / 摊边、滑下小动作；对话 / 委托；被打→逃 / 还手 |
| 屠户（水脚行叛逃者） | notable（Artisan / Headman）或 artisan 模板 | 有 | 站摊、拎人小动作；对话 / 委托；被打→还手 |
| 当铺（中人行） | notable（Merchant） | 有 | 站柜、数钱小动作；对话 / 交易；不打架 |
| rival vendor（对台戏班） | notable（Merchant）或 merchant 模板 | 有 | 站摊；被吓 / 偷 / 打→还手 / 逃 |
| rival thief（外帮贼） | 流浪者或 gangster 模板 | 有 | 站墙边；被吓 / 偷 / 打→还手 / 逃 |
| thug（水脚行） | gangster 模板或 notable（GangLeader） | 有 | 站街口；被吓 / 偷 / 打→还手 |
| debtor（水脚行 A 的收数） | notable（Merchant）或模板 | 有 | 站巷口；被吓 / 收债→还手 / 逃 |

**AI 行为（不跑原版日程）**：

- **站桩**：`StoryProbeMissionBehavior` 每帧钉位置 / 朝向，或 `AgentControlHelper` 脚本位置；**不要 `SetIsAIPaused`**（城镇里会冻住行走输入，村民直走不停）。
- **小动作**：`AgentControlHelper.ForcePlayAction` / `SetPose` 播 3~5 秒（递货、滑下、拎人、数钱），然后回站桩。
- **面向**：交互时 `FaceToActor`。
- **对话 / 选项**：`InteractionMissionView` + `IntentRegistry`（现有）；NPC 只冒一句 `AgentSay`，不跑日程。
- **战斗**：`CombatManager.StartFight(Peace:true)`（决斗）/ `KnockoutFlow`（击晕）/ `GrappleBind` / `GrappleCarry`（绑 / 扛）；被打的 NPC 由 `AgentBrain` / `CombatManager` 还手。
- **偷**：`StealBarVM` / `StealManager`；目击 → 犯罪 / 警觉（现有）。
- **不做**：巡逻、跟随、日程、群聊 AI（这些是原版 / 现有系统，不在这段演出里跑）。

**风险**：目标城 notable 不够 9 个 → 先用 6 个（blocker + 3 势力 + 当铺 + thug），其他仇家留接口；或用流浪者 / 模板补——**模板没有背包，属性道具只放 hero 身上**。

## 5. 三个能力家族的真实玩法（每个家族多个现有玩法）

### 5.1 帮忙 / 学一手（4 家势力 + 1 个钱路）

- 每个势力身上一个「委托」入口：你求他东西 → 他让你去教训他的**仇家** → 完成算委托完成 → 他给你东西 / 教你一手。
- 帮的内容是**小活**（揍 / 吓 / 偷 / 绑 / 扛 / 收债），不是「拜师学艺」；她 / 他顺带教你一手。
- **红袖班（寡妇）**：帮完给你官服 + 路引（某个真人的身份）。
- **夜行会（儿子）**：帮完给你钩索。
- **水脚行叛逃者（屠户）**：帮完给你武器 + 绳子。
- **中人行（当铺）**：帮完给你几个铜板（用于收买），不教家族。
- **数值**：帮完给该家族所有具体玩法 +2 情境；不直接改骑砍技能 / 属性。
- 可以都帮，也可以只帮一个；帮忙本身不检定、不花钱。

### 5.2 惑（乔装 / 收买）——乔装是「身份」，要和通缉 / 冒充接上

**先说清楚**：对话类（策反 / 劝降 / 谈判 / 说服 / 魅惑 / 套话 / 寒暄 / 身份表演 / 虚张声势 / 对话威胁）有代码但**不成熟**，本验证**不用**。惑只做两条成熟的：**乔装（身份）** 和 **收买（钱）**。

**A. 乔装（主路）——你不是「穿官服」，你是「变成某个人」**

- 红袖班（寡妇）是假路引贩子：她卖的不是衣服，是**身份**。给你一套**某个真人**的官服 + 路引，告诉你「穿上他，你就是他」。
- **身份目标** = 目标城里一个真实的 Hero（官员 / 守卫队长 / notable），存 `DisguiseHeroId`；官服就是这个人的行头。
- 你穿上（换场景 agent 的 Body 槽；换装不稳就退回 `disguised` 旗标 + 文字提示，加成照旧）。
- **用途 1：冒充通行（主路）**：blocker 看见这身行头，**把你误认成那个人**，让路（一句「大人」）。一次识别检定（Charm / Roguery；官服给大情境加成）决定他信不信。
- **用途 2：通缉脱险**：如果你走巧 / 武失败、被通缉（`Kingdom.MainHeroCrimeRating` / `ChangeCrimeRatingAction`），守卫本来要抓你；**乔装后他们认的是「那个人」，不是你** → 一次识别检定，过了就躲过去。
- **用途 3：冒充犯法（可选验证）**：乔装状态下犯事（偷 / 打 / 砸），**罪名记在「那个人」头上**，不是你 —— 复用 `FrameSuspect` / `WorldEvent` 的 suspect 字段；你的通缉不涨，那个人的关系 / 势力掉。**这是把「乔装」和「通缉 / 嫁祸」接上的关键一条。**
- **你背着水脚行栽的小额通缉**：乔装不只是为了过门，也是为了**不被认出来**；没通缉时它也能冒充通行。
- **不是对话树**：穿上 → 一次识别检定 → 认成谁 / 被识破；用途 3 是犯事后的记账，不是谈判。
- **失败**：被识破（警觉 / 被抓）；可以换收买，或换巧 / 武。
- **后续**：被冒充的那个人以后会来找你（伏笔）；本阶段只存 `DisguiseHeroId` + 冒充次数。

**B. 收买（钱）**

- 直接塞钱（现有 `TransferGold` + 贿赂语义）；钱够就过。
- 他收钱放行；留下「被拿捏」隐患 flag；不增加通缉。
- 钱不够：选项灰掉；这是脑图「钱可以辅助加速，但不独立成一条路线」。
- **先赚钱**：势力的零活（§4.1.3）给几个铜板；没钱就去跑腿。
- **钱不是万能**：blocker 能买；势力的工具 / 手艺不卖（只换人情）；仇家的恩怨不卖。

**两条共用**：失败不锁死，可以换另一条；**不新造对话系统**。

### 5.3 巧（钩索 / 扒窃 / 撬锁 / 潜行 / 偷属性道具）——一个家族五个现有玩法

巧是伞；夜行会（儿子）给钩索（解锁主路），另外四个是玩家已有的身手。巧 1 级给五条都 +2 情境。

**A. 钩索（主路）**

- 夜行会（儿子）给你一副**现有钩索**（`lwn_grapple_*` / `GrappleLogic`；两轮查找）。
- blocker 身上出现「勾住墙头翻过去」选项；先走 **Roguery 检定**决定钩点 / 时机（现有 `SingleRollResolver`；`Tactic = Threaten` 映射到 Roguery，或加一个按技能直算的小重载）。
- 检定过了 → 用**现有钩索**勾住城门上方的墙 / 梁，被拉上去 / 翻过去；blocker 没反应过来（或看见但拦不住）。
- 失败 / 钩空 → 他察觉（警觉）；可以换扒窃 / 撬锁 / 潜行，或换惑 / 武。
- 钩索本身是现有系统（`GrappleLogic` / `custom.grapple`）；这一路不需要新代码，只需要任务状态和触发。

**B. 扒窃**

- 趁他不注意，用**现有扒窃条**（`StealBarVM(Pickpocket)` + `StealManager.StealSpecificItem`）扒走他的武器 / 钥匙。
- 得手：他手里没家伙 / 你拿到钥匙，只能让路；失败：他察觉（警觉），可换路。
- 这条需要一个 quest 目标模式（只对序章 blocker 生效），是**备选**，不是主路。

**C. 撬锁**

- 绕到他身后的侧门 / 锁，用**现有撬锁条**（`StealBarVM(Lockpick)` + `StealManager.GetLockpickPinCount`）开锁。
- 成功：侧门打开，你从他背后过去；失败：发出声响 / 他察觉，可换路。
- 如果场景没有真门，这条**不做**（不新造门）；备选。

**D. 潜行**

- 蹲下（现有 `crouch` + `NpcSightSystem`），趁他转身 / 被别的事引开，从他背后溜过去。
- 成功：他没看见你；失败：被看见（警觉），可换路。
- 这条依赖场景和 AI 视线，**作为情境选项**，不是必做。

**E. 偷属性道具（成长）**

- 势力 / 仇家的背包里有一件**属性道具**；用现有扒窃条（`StealBarVM(Pickpocket)`）偷。
- 得手 → 道具进背包，**+1 对应技能**（`Hero.AddSkillXp` / `SetSkillValue`）；被目击 → 犯罪 / 警觉。
- 每件唯一，不能刷；不想偷就做他的委托换。
- 这是「偷东西还能提升值」：偷不是只拿钱，是**成长**。

**五个玩法共用**：只要一个成功就能过；失败不锁死；**钩索是主路**，另外四个是同一把伞下的备选。

### 5.4 武（决斗 / 击晕 / 威吓 / 绑扛）——一个家族四个现有玩法

武是伞；水脚行叛逃者（屠户）给武器（解锁主路），击晕 / 威吓 / 绑扛是玩家已有的武力。武 1 级给四条都 +2 情境。威吓是「开战前亮兵器逼他」，不是对话树；绑 / 扛是力量检定。

**A. 决斗（主路）**

- blocker 身上出现「动手」选项。
- 先用**现有属性检定**看开局：`AgentStatsHelper.GetAgentStats` 取双方 Vigor+Control，按 `KnockoutFlow.ComputeSuccessRate` 的 ratio 式算成功率；**成功 → 开局优势（他起手慢），失败 → 正常开局**。
- 然后 `CombatManager.StartFight(玩家, blocker, Peace: true)` 开**非致命决斗**；现有侧容器模型会把随从扫到一边（1v1）。
- 打赢：他让路；打输：他嘲笑你，可以换击晕，或换惑 / 巧；**无论胜负，关系 -20**（结仇）。

**B. 击晕**

- 从背后 / 趁他不备，用**现有击晕**（`KnockoutFlow.Roll` + `PlayStrikeAnim` + `Resolve`）把他放倒。
- 成功：他倒地，你过去；失败：他反击（进战斗），可换决斗。
- 这是巧 / 武交叉：潜行接近是巧，动手放倒是武。

**C. 威吓（开战前）**

- 在动手前，亮兵器 / 逼上前，用**现有威胁**（`Threat` / `threaten_verbal` 的语义）压他。
- **一次 Vigor + Control 检定**（或现有 `Threat` 的 Roguery 检定；两条选一条，Defs 定）：
  - **成功**：他退开，不战而屈；关系 -10（被吓住，记恨）。
  - **失败**：他动手，直接转**决斗**（可以继续打）。
- **不是对话树**：亮兵器 → 一次检定 → 退开或开打；没有谈判条。
- 这是「武」的开战前动作，不是惑的「虚张声势」（后者是对话类，不做）。

**D. 绑起来 / 扛走（力量检定）**

- 在**击晕 / 决斗打赢**之后（或直接冲上去按倒），用现有 `GrappleBind` / `PairAction`（被绑）把他绑起来。
- **力量检定**（复用 `AgentStatsHelper` 的 Vigor+Control ratio，和击晕同一套）：
  - **成功**：绑住；他动不了，门就通了。
  - **失败**：他挣脱 / 喊人；可以再打（决斗）或换别的路。
- **扛走**用现有 `GrappleCarry` / `PairAction`（扛人）：把他扛到街角 / 门边；**扛的时候不能同时给「松绳 / 放下」**（现有纪律）。
- **这一路是「制服 + 绑 + 扛」**：不一定要打死他；把人挪开，门就通了。
- **不是对话树**：按倒 → 力量检定 → 绑 / 扛 / 失败。

**四个玩法共用**：只要一个成功就能过；失败不锁死；**决斗是主路**，击晕 / 威吓 / 绑扛是同一把伞下的备选。

### 5.5 目标与完成

- blocker 被解决后：他说一句台词，走到一边（`ScriptedMoveToPoint` 或直接平移 3 m）。
- 目标点 = **门内**（他原来位置身后 3 m）；玩家走进 2 m 内 → 序章完成。
- 完成时：恢复金钱，发总结（用了哪条路、势力关系、天赋点、结仇 / 隐患），主线钩子出现。
- 如果玩家没解决 blocker 就绕过去：不完成，blocker 会喊一句「站住」（第一阶段不做物理推回，靠叙事阻挡）。

## 6. nobody 状态

- **进场景瞬间**：
  - 记录玩家金钱；`AgentControlHelper.SetGold(Hero.MainHero, 0)`。
  - 收走**场景里玩家 agent** 的武器（`StealManager.StripAgentEquipment` / `Agent` 武器槽清空）。
  - 换原版粗布衣：用原版低阶 body armor（两轮查找）；找不到就只收武器 + 金钱，不换衣。
- **只动场景 agent，不动战役英雄装备**：离开场景 / 重进，agent 会按英雄装备重新生成；「被剥夺」只发生在序章场景里。
- **金钱是英雄的**：记录原始值，序章完成时恢复；中途存档 / 读档保留「已剥夺」状态。
- **已知限制（第一阶段接受）**：
  - 不锁背包：玩家可以从背包重新装备（战役装备没被改，只是场景 agent 被收）；序章短、有引导，第二阶段再做完整锁。
  - 随从：武 走 Peace 决斗，现有逻辑会把随从扫到一边；惑 / 巧不受影响。
- **通知**：进场景时一条「你身上只剩一身粗布衣，钱袋空了」的提示。

## 7. 311 = 现有属性检定（核心）

### 7.1 一句话

**311 是逆水寒的叫法；我们不新造骰子、不新造属性，直接用 mod 已有的属性检定。** 三个家族各接一套现有检定：

| 能力 | 现有检定 | 技能 / 属性 | 现有入口 |
|---|---|---|---|
| 惑（家族） | 乔装 = 一次识别检定（Charm / Roguery）+ 身份 / 通缉 / 嫁祸；收买 = 钱 | 乔装（冒充 / 脱险 / 嫁祸）/ 收买 | `SingleRollResolver` / `FrameSuspect` / `WorldEvent` / `TransferGold` |
| 巧（家族） | Roguery 检定 + 现有身手 | 钩索 / 扒窃 / 撬锁 / 潜行 / 偷属性道具 | `SingleRollResolver` + `GrappleLogic` / `StealBarVM` / `crouch` / `Hero.AddSkillXp` |
| 武（家族） | Vigor + Control 属性检定 + 现有武力 | 决斗 / 击晕 / 威吓（开战前）/ 绑起来 · 扛走 | `AgentStatsHelper` / `KnockoutFlow` / `CombatManager` / `GrappleBind` / `GrappleCarry` / `Threat` |

### 7.2 脑图公式怎么落

脑图：`对应属性数值 + 总等级加成 + 当前情境加成`。

| 脑图项 | 现有系统里的落点 |
|---|---|
| 属性数值 | 惑 = Charm 技能；巧 = Roguery 技能；武 = Vigor + Control 属性 |
| 总等级加成 | 玩家等级 / 角色等级，折进 `offerValue` 或目标难度 |
| 目标抗性 | 每个 NPC 的力量 / 技巧 / 魅力抗性（§4.1.4 表）；成功率 = `playerSkill / (playerSkill + 抗性)`，不走 NPC 实际技能 |
| 情境加成 | 官服 / Charm / 帮忙加成 / 势力关系 / 抗性情报，折进 `GetOfferValue`（0~1）或难度修正 |

**不新写公式**：社交走 `SingleRollResolver.Compute`（技能胜率 + 献礼/情境 + 性格倍率），武力走 `KnockoutFlow.ComputeSuccessRate`（Vigor+Control ratio）。

### 7.3 结果只有成功 / 失败

- 现有检定本身就是 bool：`SingleRollResolver.Roll(chance)` 返回成功 / 失败；`KnockoutFlow.Roll` 返回 `Success`。
- **不做大成功 / 大失败**；成功后按家族给奖励，失败后按家族给后果（警觉 / 通缉 / 换路）。
- 不新增 `RollDetailed`、不新增分档阈值。

### 7.4 显示

- 点击前：沿用现有**成功率预览**（`LWN_ui_option_chance_suffix`，太阁 5 式）。
- 掷完：显示「掷点 X% vs 门槛 Y% → 成功 / 失败」；不写「成功率」以外的目标难度措辞（铁律 17）。
- **311 的骰子外观**以后用 Gauntlet 面板套皮；第一阶段只做数值和文字，不做新 UI。

### 7.5 明确不做

- 不做 3d10 / 自定义骰面 / 重掷 / 暴击面。
- 不做新的惑 / 巧 / 武属性值。
- 不做新的熟练度 / 江湖阅历系统；第一阶段用现有技能 XP / 玩家等级。
- 不做新的势力声望系统；第一阶段用现有个人关系 + 通缉。

## 12. 验收命令

全部是游戏内控制台命令，写全称：

```
custom.story_probe enable
custom.story_probe disable
custom.story_probe city town_EN1
custom.story_probe status
custom.story_probe enter
custom.story_probe spawn
custom.story_probe check 惑
custom.story_probe check 巧
custom.story_probe check 武
custom.story_probe roll 惑 95
custom.story_probe roll 巧 5
custom.story_probe roll 武 50
custom.story_probe learn 惑
custom.story_probe learn 巧
custom.story_probe learn 武
custom.story_probe resolve 惑
custom.story_probe strip
custom.story_probe restore
custom.story_probe reset
```

要求：

- 命令返回文本**纯英文**；首参可弃（给了解析不出来就回落到默认并注明）。
- `enable` / `disable`：开关运行时入口；**默认关**，`enable` 之后目标城菜单才出现「入城（玩法测试）」；`disable` 后消失。
- `check <能力>`：空跑，打印这套检定用的技能 / 属性、当前成功率、门槛、情境加成；不改状态。
- `roll <能力> <0~100>`：强制下一次掷点，用于成功 / 失败验收（0~100 → 0~1）。
- `learn` / `resolve`：强制学 / 强制结算，用于跳过流程。
- `strip` / `restore`：单独测 nobody 剥夺 / 恢复。
- `status`：阶段 / 城池 / 三门是否已学 / 势力关系 / 天赋点 / 隐患 / 是否已剥夺 / 是否完成。

## 13. 手工验收清单

1. 先 `enable`；原版战役（不带 Taikou）进 `town_EN1`，**菜单里才出现**「入城（玩法测试）」选项；点它。
1b. 开场：给一封信 + 一句旁白；`status` 显示妹妹名字、初始小额通缉。
2. 进中心场景：4 个 NPC 出现；玩家武器 / 金钱被收走，收到提示。
2b. 原版「在城里逛逛」进场景：没有 4 个 NPC、不收武器、不触发；只有额外选项触发。
3. 分别帮四家势力做小事：各学一手；`status` 可见；可以都帮；红袖班（寡妇）给官服。
4. 惑（乔装）：穿上官服 → 走到 blocker 面前 → **一次属性检定**（他有没有看出破绽）；`check 惑` 能看到技能 / 情境拆解；掷完显示掷点 / 门槛 / 成功或失败；**没有对话树**。
4b. 乔装身份：blocker 把你误认成官服的主人（一句「大人」）→ 让路；被识破 → 警觉。
4c. 通缉脱险：先用巧 / 武失败被通缉 → 乔装 → 守卫识别检定 → 过了不被抓。
4d. 冒充犯法（可选）：乔装状态犯事 → `status` 显示 suspect=目标，玩家通缉不涨；目标的势力 / 关系掉。
4e. 乔装遮通缉：初始通缉 >0 → 乔装 → 守卫识别失败 → 不被抓。
5. 惑（收买）：钱够就能过；钱不够选项灰掉；留下「被拿捏」flag。
5b. 对话类（魅惑 / 套话 / 谈判 / 说服 / 策反 / 劝降 / 虚张声势）本验证不做，不验收。
6. 巧：出现「勾住墙头翻过去」；先过 Roguery 钩点检定，再用现有钩索翻过去；失败能换路；没有钩点时用扒窃备选。
6b. 巧的备选：扒窃 / 撬锁 / 潜行各至少验一条；不行就明确标「本场景不可用」。
7. 武：出现「动手」；先看 Vigor/Control 开局检定，再开现有非致命决斗；打赢能过；打输能换路；关系 -20。
7b. 武的备选：击晕 / 威吓（开战前）/ 绑扛各验一条。
7c. 绑 / 扛：击晕或打赢后 → 力量检定 → 绑住 / 扛走；失败他挣脱。
7d. 委托：求势力 → 接「教训仇家」→ 完成 → 势力给东西 / 教一手；`status` 显示委托状态、仇家关系。
8c. 零活：替势力跑腿 → 几个铜板；用铜板打点 blocker。
8d. 抗性：每个 NPC 的 check 成功率因抗性不同；打听弱点 → 加成 / 显示。
8. 选路反馈：对应势力关系 +、天赋点 +1；武 结仇；惑 / 巧 隐患 flag。
9. 走到 blocker 身后目标点：序章完成；金钱恢复；再进不重开。
10. 中途存档 / 读档：阶段、帮忙、势力关系、旗标、已剥夺状态保留；完成时恢复。
11. 进酒馆 / 领主大厅不触发；别的城不触发；`disable` 后不触发。
12. 两个客户端各编译一次（1.2.12 与 1.5.x）；`run_all_checks.py` 通过；新增文本无 emoji、无裸中文。

## 14. 风险与待确认

**风险**：

- **生成重复**：目标 hero 可能已经在场上；先查再 spawn，避免一个 hero 两个 agent。
- **交互 UI 认不认 spawn 的 agent**：先用 `spawn` 命令实测；不认就改成「复用场上已有 agent + 移动」。
- **社交检定要求 Hero**：`ResolveAdversarialIntent` 对模板 NPC 会拒绝；4 个 NPC 全部用原版 Hero。
- **钩索需要钩点**：城门上方的墙 / 梁要能勾；场景没有合适钩点就退回扒窃备选，或第二阶段加一个 prefab 钩点。
- **扒窃条（备选）是独立 UI**：`OpenQuestPickpocket` 要照 `OpenStealInterface(Pickpocket)` 的 Layer / 输入 / 子弹时间 / 冻结写法，漏一个就可能卡输入；扒窃结果要回调或轮询武器槽判断。
- **决斗胜负判定**：`CombatManager` 有非致命仲裁，但「谁赢」要用 blocker 的击倒 / 血量 / 战斗状态组合判断；实机先验一遍。
- **装备剥夺 / 恢复**：只动场景 agent、不动战役英雄装备；换衣比收武器风险高，先做「收武器 + 金钱」，粗布衣 / 官服作为第二步。
- **物理阻挡是叙事**：blocker 不一定真挡住路；完成条件是「解决他 + 走到目标点」，第一阶段不做推回。
- **nobody 不锁背包**：玩家可以重新装备；序章短，第二阶段再锁。

**待确认（需要策划拍板）**：

1. **三个家族用哪套现有检定**：本方案是 **惑 = 乔装检定（Charm）+ 收买（钱）、巧 = Roguery（钩索 / 扒窃 / 撬锁 / 潜行）、武 = Vigor + Control（决斗 / 击晕 / 威吓 / 绑扛）**；巧的主路是**钩索**。如果你要 武 用 OneHanded、或巧也用 Charm，告诉我。
2. **拦路者身份**：用目标城的 notable（帮派头目 / 商人，结仇是个人关系）还是守卫模板（结仇是势力关系）？本方案默认 notable。
3. **nobody 的剥夺程度**：只收武器 + 金钱，还是连护甲也换粗布衣？第一阶段不锁背包，这点已在方案里标限制。
4. **官服怎么给**：本方案是惑 势力 直接递给你、当场换上（不依赖背包）；如果你要「去偷 / 买官服」作为前置小玩法，告诉我。
5. **序章暴露多少选项**：本方案把 9 个具体玩法都列进家族，但序章可以只暴露「每个家族主路 + 1 个备选」（6 条）；全暴露会让第一关变复杂。你要全暴露还是收着？
6. **乔装目标用谁**：本方案用目标城一个真实 Hero（官员 / 守卫队长）；你指定谁，或者按城里的 notable 挑？
7. **冒充犯法进不进序章**：本方案是可选验证（`status` / 通知看结果）；要进正式流程，还是先只验「通缉脱险」？
8. **先做哪条委托**：本方案先做屠户（揍 thug）；寡妇 / 儿子 / 当铺的委托留接口。你要先做哪条？
9. **水脚行 A/B 选边**：当铺是 B 的后台，blocker 是 A 的人；序章要不要让玩家明确选边，还是只埋关系？
10. **零活给多少钱**：每个零活几文；blocker 打点 100 文；够不够跑两趟？
11. **抗性数值**：表里的高 / 中 / 低换算成具体数值（例如 30 / 50 / 70）；你定还是我按难度梯度填？
12. **入口选项的加载路径**：原版 `town_center` 菜单 / 场景加载 API 要验；如果新选项不能直接触发场景，就复用原版选项的 consequence（先设标记再调原版路径）。
13. **妹妹是谁**：名字 + 信（原版书 / 信物当载体）；第一阶段不登场。你给个名字 / 性别？
14. **初始通缉**：水脚行栽的赃，给多少（小额，例如 +10）？

## 15. 设计哲学四原则

- **反馈明确**：帮忙、成功率预览、掷点 / 门槛、成功 / 失败、势力关系 / 天赋点 / 结仇，全部当场可见。
- **自由感**：四家势力可全学；每个家族任选一个具体玩法；失败能换路，不锁死。
- **NPC 接得住**：4 个 NPC 全是原版 Hero；对话 / 钩索 / 战斗都是现有系统。
- **信息塑造目标**：玩家先被拦住，再去问势力；不是一上来就知道「三个家族」。

## 16. 审批人四问

- **结论是什么？** 在真实城镇中心场景做序章：**动机 = 找妹妹（开场给信 + 旁白，背水脚行栽的小额通缉）**；点额外的「入城（玩法测试）」选项（只有这条路径加载玩法）→ nobody 在城门外被拦 → 0 钱起步，靠零活赚铜板 / 求势力接「教训仇家」委托 → 完成才学一手 → 用惑（乔装身份 / 收买）/ 巧（钩索 / 扒窃 / 撬锁 / 潜行 / 偷属性道具）/ 武（决斗 / 击晕 / 威吓 / 绑扛）过 blocker → 门内完成；每个 NPC 对三家族抗性不同；钱只解决「钱能解决的那一段」；检定全部复用 mod 已有的属性检定，**311 只是逆水寒叫法**；对话类不成熟，本验证不做。
- **凭什么？** 战役菜单选项 / `EnterViaOption` 标记、场景触发、生成、交互、委托（`CommissionQuest` 形状）、关系 / 仇家、零活 / 钱、NPC 抗性表、乔装（身份/通缉/冒充）、收买、钩索、扒窃、撬锁、潜行、偷属性道具、击晕、威吓、决斗、绑人、扛人、存档、本地化都有现成轮子；新增的只有状态、3 个帮忙 + 6~8 个解决 Intent、一个 MissionBehavior。
- **代价是什么？** 第一阶段是现有文字 / 成功率显示（不是 Gauntlet 311 面板）；物理阻挡靠叙事；nobody 不锁背包；成功 / 失败阈值要调。
- **要做哪几件事？** 六个新文件 + 十个改动文件；八步实施，前六步是核心，后两步可选。
