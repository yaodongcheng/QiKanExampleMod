## 0. 结论

- **这次验证的是真实城镇场景里的序章，不是菜单。** 菜单只用于进入场景（原版「在城里逛逛」）。
- **玩家一开始是 nobody**：进场景时收走场景 agent 的武器 / 金钱，序章结束恢复。**不换衣服**——玩家穿自己的默认装备进场（2026-11-12 用户裁定）。
- **入口是一个额外的入城选项（如「入城（玩法测试）」）**：只有从它进场景才加载玩法；原版「在城里逛逛」不加载。**点它先弹一段背景弹窗（§3.2），确认后才进场景；进场后随从说 3 句交代目标。**
- **城门口是四家势力的地盘**：码头帮的城门打手（blocker）+ 捉刀人（当铺）+ 夜行会（儿子）+ 流浪剧团（寡妇）；屠户是码头帮的叛逃者（教你打斗的人）。**底层百姓互帮互助 + 四家各有账本**：你帮谁，谁教你一手；钱是捉刀人的路（跑腿换第纳尔，收买打手）。
- **动机：找妹妹**：三个月前她进城做工，再没消息；你一路找来，钱被偷、身上只剩她的信；码头帮栽了你一桩小事，你背着小额通缉——正门进不去，只能魅力 / 技巧 / 武力 / 钱。
- **势力不白给**：你求他东西 → 他让你去教训他的**仇家**（委托）→ 完成才算数；势力关系 +，仇家关系 -，码头帮内圈 A/B 还要选边。
- **玩家 0 钱**：钱靠零活赚（跑腿 / 搬货 / 送信）；**钱是第四手段但不万能**（blocker 能打点，势力的工具不卖）。
- **每个 NPC 三属性不同**：武力 / 技巧 / 魅力各有一个数值；检定就是**同类对拼**（武力比武力、技巧比技巧、魅力比魅力），没有「抗性」这回事。选对人用对招，或者先打听他的底。
- **三种能力 + 钱（第四手段），每种能力下面是多个我们已有的真玩法**：
  - **魅力**：乔装（身份：冒充通行 / 通缉脱险 / 冒充犯法）。对话类先不做。
  - **技巧**：钩索 / 扒窃 / 撬锁 / 潜行 / 偷属性道具（偷东西也能涨值）。
  - **武力**：决斗 / 击晕 / 威吓（开战前）/ 绑起来 · 扛走（武力检定）。
  - **钱（第四手段，不属于任何能力）**：收买 blocker（打点）/ 买消息 / 买酒——只解决「钱能解决的那一段」。
- **🔴 检定不新造，直接复用 mod 已有的属性检定。** 社交用 `SingleRollResolver` + `IntentBase`（Charm / Roguery），武力用 `AgentStatsHelper` + `KnockoutFlow` 的 Vigor+Control ratio。**不新建骰子系统、不新建属性系统。**
- **结果只有成功 / 失败两个分支**（不做大成功 / 大失败）；现有检定本身就是 bool。
- **选择有反馈**：用哪种能力，那个势力关系 +、天赋点 +1；选武力会和拦路者结仇；魅力 / 技巧留下不同隐患。
- **🔴 玩家怎么和 NPC 打交道（新增章节 §5.6）**：**先出事再搭话**（§4.1.5：开场 6 起事件——4 起双人冲突 + 2 起单人发愁，参与者头顶「!」，玩家凑近就自动接入）→ 走近按 F → **走原版对话流注入**（`DialogueInjector`，不新建面板）→ 节点树里 NPC 一句 + 几个选项 → 五步关系（搭话 / 打听 / 求 / 交差 / 熟人），选项随步数变 → 检定走 `SkillCheck` 分成功 / 失败两条节点。**手上的事（偷 / 打 / 绑 / 买 / 换装）在对话外，各走各的。**
- **🔴 NPC 自己会动（新增章节 §5.7）**：城外集市这 9 个人有常驻小动作、有双人桥段（收保护费 / 骂对台 / 砸摊 / 抓小偷）、对玩家有反应（招呼 / 警告 / 让路）。玩家站着不动也看得出这地方在过日子。**不跑日程、不做全城模拟、不接管原版村民。**
- **不新建角色 / 资产 / 物品定义**；4 个 NPC 全用原版 Hero（notable / wanderer）；不依赖 LLM。

> 脑图里的「偷传送手套 / 发现地下密道」是神界原罪 2 的举例，不照搬；脑图上的骰子落到我们已有的属性检定。

## 1. 一图流程

```
找妹妹（信）→ 进城 → 点「入城（玩法测试）」
  → 【弹窗】交代背景（妹妹 / 钱被偷 / 通缉 / 正门进不去）→ 点【进城】
  → 城镇中心场景（只有这条路径加载序章）
  → 进场景：随从站到身边说 3 句（没随从就改旁白）；收走武器 / 金钱（不换衣服）
  → 城门口四家：捉刀人 / 夜行会 / 流浪剧团 / 码头帮（blocker 守门）
  → 求势力 → 接「教训仇家」委托 → 完成 → 她 / 他给你工具 / 教你一手
  → 选一个具体玩法搞定 blocker（每种能力任选一个）：
        魅力：乔装（冒充 / 脱险 / 嫁祸）｜钱：收买
        技巧：钩索 / 扒窃 / 撬锁 / 潜行 / 偷属性道具
        武力：决斗 / 击晕 / 威吓（开战前）/ 绑起来 · 扛走
  → 选路反馈：势力关系 + / 天赋点 +1 / 结仇 / 隐患
  → 走到 blocker 身后目标点 → 恢复金钱 → 序章完成
```

## 2. 为什么这样能验证脑图

| 脑图要求 | 本方案怎么落 | 判据 |
|---|---|---|
| 第一个关卡要足够简单 | 1 个 blocker + 4 家势力 + 1 个目标点 | 玩家 5 分钟内能走完 |
| 4 家势力各有一条活路 | 帮势力做委托 → 学会对应能力；钱是捉刀人的路 | `status` 能看到三门已学 |
| 仇家委托（交易） | 求势力 → 完成「教训仇家」→ 才给东西 / 教一手 | 不做委托不给；仇家关系 - |
| 入口只走额外选项 | 只有该选项设置 `EnterViaOption`；原版「在城里逛逛」不加载 | 原版进城没有 cast / 没人收武器 |
| 三种能力、每种能力多个玩法 | 魅力 = 乔装（身份）/ 收买；技巧 = 钩索 / 扒窃 / 撬锁 / 潜行 / 偷属性道具；武力 = 决斗 / 击晕 / 威吓（开战前）/ 绑起来 · 扛走 | 每种能力至少一条能过 |
| 检定 = 属性数值 + 总等级 + 情境 | 复用现有 `SingleRollResolver` / `AgentStatsHelper`；总等级和情境折进 `offerValue` / 难度 | `check` 命令能打印技能 / 等级 / 情境拆解 |
| 脑图上的骰子 | 落到我们已有的属性检定（d20：掷点 ≥ 门槛） | 不出现新骰子系统 |
| 成功 / 失败 | 现有检定本身就是 bool | 成功 / 失败各跑一次，后果不同 |
| 成功加熟练度 | 用现有技能 XP / 玩家等级，不新造熟练度 | 成功后技能 / 等级有变化 |
| 失败通缉 / 坐牢 / 声望降 | 现有 `ChangeCrimeRatingAction` / 关系 / 警觉 | 失败后数值可见 |
| 失败也是路线 | 失败可以换另一条路，不锁死 | 每种能力失败后仍能继续 |
| 选择有反馈 | 势力关系 / 天赋点 / 结仇 / 隐患 | 选完立刻弹反馈 |
| 声望按领域不按城池 | 本阶段先用现有**个人关系 + 通缉**表示；领域声望以后再做 | 不新造势力声望系统 |

## 3. 场景与触发

### 3.0 剧情前言：为什么非要进这座城

> 这一节是**背景素材**（写台词时的依据）；实际怎么呈现给玩家见 **§3.2**（弹窗 + 随从 3 句）。

- **一句话**：三个月前，你妹妹进城做工，再没消息；你一路找来，钱被偷了，身上只剩她最后一封信。城门在眼前。
- **动机 = 找妹妹**：势力各自知道她的一截下落——寡妇卖过她通行文书、儿子见过她、屠户认识带走她的人、当铺有她当的东西；**码头帮是带走她的那条线**。
- **为什么不能走正门**：你没通行文书、没钱；更糟的是，码头帮在路上栽了你一桩小事——你背了个**小额通缉**（`ChangeCrimeRatingAction`）。走正门 = 被抓；所以你只能**魅力 / 技巧 / 武力 / 钱**。
- **为什么你什么都没有**：路上被抢 / 被偷，武器和钱都没了（nobody）。
- **妹妹是谁**：一个**名字 + 一封信**（原版书 / 信物当载体）；**第一阶段不登场**，后续再用现成 hero / 内容包角色。
- **开场怎么给（2026-11-12 改）**：点选项**先弹窗**讲背景（§3.2 的 4 句就是本节的删减版）→ 点【进城】才加载场景 → 进场后**随从说 3 句交代目标**（没随从就走旁白）；同时给一封**信**做载体，玩家可以拿信问势力；不新建角色。
- **主线钩子**：码头帮 / 第一张凭证；妹妹是情感线，码头帮是主线。
- **和四条的对应**：乔装 = 遮住通缉身份；偷 = 摸进城门；打 = 硬闯；钱 = 打点。**没有一条是「白走进去」**。

- **目标城**：默认 `town_EN1`（Epicrotea，帝国城镇；1.2.12 与 1.5.x 都有），可在 `config.json` 改。
- **入口 = 一个额外的入城选项**（名字随意，暂叫「入城（玩法测试）」）：**默认不出现**，只在**目标城 + 玩家打过 `custom.story_probe enable` 之后**出现；`disable` 后消失。**只有从这个选项进来的场景才加载玩法**；原版「在城里逛逛」不加载序章。
- **点完先弹窗再进场景**（§3.2）：选项的 consequence 里先弹背景介绍弹窗，点【进城】才设 `EnterViaOption` 并加载城镇中心；点【再想想】什么都不发生。
- **选项做什么**：设置 `EnterViaOption` 标记 → 走原版城镇中心场景的加载路径（`GameMenuManager.NextLocation = center` / 原版 `town_center` 菜单）；场景加载后 `StoryProbeMissionBehavior` 检查标记，**只有标记为真才布置玩法**，并消费标记。
- **序章发生在城门外**：玩家站在主门外的站位点，blocker 守在门口，四家在门外的摊位区；目标点 = 门内。**具体坐标见 §3.1（已从场景 XML 实测，不用开 ModKit）。**
- **恢复**：中途存档 / 读档后，玩家再点同一个选项进来，标记为真 → 恢复序章；原版进城不恢复。
- **触发判定**：`StoryProbeMissionBehavior` 在 `OnMissionBehaviorInitialize` 检查：
  1. `StoryProbeState.Enabled == true`（`custom.story_probe enable` 打开；默认 false）；
  2. `EnterViaOption == true`（由入城选项设置；**未设置 = 原版入口，直接 return**）；
  3. `Settlement.CurrentSettlement.StringId == StoryProbeSettlementId`；
  4. 当前地点是 **center**（不是 tavern / lordshall / keep）；
  5. 序章状态 = 未开始 / 进行中（读档恢复）。
  然后**消费** `EnterViaOption`。
- **只在 center 触发**：判定用 `Campaign.Current.GameMenuManager.NextLocation` / `LocationComplex`，照 `custom.enter_lordshall` 的取值方式。
- **提示**：入城选项本身就是提示（「入城（玩法测试）」）；可在目标城菜单里高亮，不自动发通知。
- **验收命令**：`custom.story_probe enter` = 设 `EnterViaOption` + 走原版 center 加载路径（调试用）；不在目标城则打印提示。

### 3.1 场景锚点（已从场景 XML 实测，不用开 ModKit）

**场景是哪一张**：`town_EN1` 的 center = **`empire_town_g`**。
来源链：`Modules\SandBox\ModuleData\settlements.xml` → `town_comp_EN1` → `<Location id="center" scene_name="empire_town_g">`；
场景文件 = `Modules\SandBoxCore\SceneObj\empire_town_g\scene.xscene`（6299 个实体，纯 XML，可离线解析）。

**实测锚点**（直接可用，不用手量）：

| 用途 | 场景实体 | 坐标 (x, y, z) | 朝向（z 轴） | 说明 |
|---|---|---|---|---|
| 玩家开场点（门外） | `sp_outside_near_town_main_gate` | (435.367, 386.905, 4.393) | −2.039 | 场景里唯一一个「主门外」站位点 |
| 城门 | `european_castle_gate_outer_l2` | (459.840, 375.480, 5.670) | 1.131 | 同名 `_l1` 是 LOD（456.150, 377.160），不要用 |
| blocker 站位（门外侧） | `sp_guard` | (451.579, 375.941, 4.752) | 0.766 | 门外的守卫点，正好卡在玩家与门之间 |

**实测距离**：门外点 → 城门 ≈ **27.0 m**（x +24.5 / y −11.4）；城门 → 门内点 ≈ **10.5 m**。

// 2. 城门：遍历场景实体，按 prefab 名匹配（第一个名字含 gate_outer 且不含 _l1 的）

// 3. 兜底（一个都找不到）：玩家原位不动；blocker = 玩家前方 8 m；目标点 = blocker 后方 3 m

- **摆位**：玩家传送到门外点（离得 > 5 m 才传）→ 面向城门；blocker 站门外那个 `sp_guard` 点；目标点 = 门内那个 `sp_guard` 点；四家代表用玩家身后两侧的摊位区（这一片就是市场，`sp_merchant` / `sp_npc_wait` 密集）。
- **换城怎么办**：`config.json` 改 `StoryProbeSettlementId` 后场景会变。`sp_outside_near_town_main_gate` 与 `sp_guard` 在多数城镇中心场景里都有同名点；查不到就走兜底，**不会崩**。
- **验收命令**：`custom.story_probe where` —— 打印这三个点的实际坐标、彼此距离、用的是「场景点」还是「兜底」，实机一眼核对。

### 3.2 开场：进门前的弹窗 + 进门后的随从交代（2026-11-12 用户裁定）

**为什么**：「四家各有算盘 / 帮谁谁教你一手」这套设定，靠场景里几个人站着说不清楚。玩家需要先被明确告知「我们在哪、你要干什么」。

**流程（三段）**：

| 段 | 发生什么 | 怎么实现 |
|---|---|---|
| ① 点选项 | 玩家点「入城（玩法测试）」→ **不立刻进场景** | 在 game menu 的 consequence 里先弹窗 |
| ② 弹窗 | 标题「城门」+ 4 句背景 + 两个按钮【进城】/【再想想】 | `InformationManager.ShowInquiry(new InquiryData(...))`（现成，范本 `RecruitSoldierIntent.cs:116`） |
| ③ 点【进城】 | 才设 `EnterViaOption` + 加载城镇中心 | 确认回调里走原逻辑；点【再想想】= 什么都不发生 |

**弹窗正文**（4 句）：

```
三个月前，你妹妹进城做工，再没消息。
你一路找来，钱在路上被偷光了，身上只剩她最后一封信。
更糟的是，码头帮栽了你一桩小事——城门上挂着你的小额通缉。
正门是进不去了。城门外的几家，各有各的门路。
```

**进场之后：随从交代目标**

| 情况 | 表现 |
|---|---|
| 队伍里有随从 | 随从 spawn 在玩家左后 1.5 m，**说 3 句**（间隔 2.5 秒，`SpeechChannel.Say`，头顶气泡）；说完就站桩 |
| 队伍里没有随从 | 同样 3 句改**旁白**（`InformationManager.DisplayMessage`，间隔 3 秒），**不阻断玩法** |

- **随从怎么选**：`MobileParty.MainParty.MemberRoster` 里第一个带 HeroObject 的成员（玩家同伴优先，其次任意 hero 成员）；**不新建角色**。
- **随从台词**（3 句）：

```
1. 就是这儿了。你妹妹三个月前进的这座城。
2. 正门挂着你的通缉——硬闯等于自投罗网。
3. 先跟门口这几家搭上线。帮谁，谁教你一手。
```

- **随从站位**：进场后钉在玩家侧后、面向玩家；玩家对话 / 战斗时不动（`AgentBrain` 站桩）；**第一阶段不做跟随**（免得过门时和 blocker 挤在一起）。
- **只播一次**：`IntroPlayed` 标记存进 `StoryProbeState`，读档 / 重进不再播；命令 `custom.story_probe intro` 可重播。

**文本键**（全走 `LWNTextHelper`）：

| 用途 | 键 |
|---|---|
| 弹窗标题 / 正文 / 两个按钮 | `LWN_story_intro_inquiry_title` / `_body` / `_btn_go` / `_btn_back` |
| 随从 3 句 | `LWN_story_intro_line_1..3` |
| 旁白兜底 3 句 | `LWN_story_intro_narr_1..3` |

**技术注意**：

- 弹窗是在**大地图/菜单态**弹的（还没进 mission），那时候没有随从 agent，所以**弹窗只放文字**，随从说话必须在 mission 里。
- 随从 spawn 走 §4 计划的 `SpawnHeroAt`；spawn 前先查场上有无同 Hero 的 agent（原版城镇中心可能已经把他作为 LocationCharacter 刷出来了）。
- 随从说完话就交回站桩，**不接管玩家输入**。

## 4. 城门口的四个势力

> **四家是城里的组织势力，不是家族。** 数据上每家可以挂一个 `Clan` 对象当身份载体（关系 / 声望 / 归属判定都有现成件），叙事里一律叫「公会 / 会 / 剧团 / 帮」，不出现「家族」。
> **四家名字全文档唯一**：捉刀人 · 夜行会 · 流浪剧团 · 码头帮（没有第二个叫法）。

| 势力 | 性质 | 城门边的代表 | 对应能力 | 和谁敌对 |
|---|---|---|---|---|
| **捉刀人**（友好；头目是掮客头子） | 中间人 / 掮客，替人跑腿、找门路、写状子 | 当铺老板（他的前台） | **钱（第四手段）/ 人脉**（零活、收买、消息） | 码头帮 |
| **夜行会**（中立） | 小偷 / 撬锁 / 扒窃 | 寡妇的儿子（小贼） | **技巧**（钩索 / 扒窃 / 撬锁 / 潜行 / 偷属性道具） | 码头帮 / 野贼 |
| **流浪剧团**（中立） | 剧团 / 舞姬，靠表演和魅力 | 寡妇（领班 / 舞姬） | **魅力**（乔装 / 魅惑 / 身份） | 码头帮 / 对台剧团 |
| **码头帮**（邪恶） | 水上脚夫结成的帮派，收数 / 放贷 / 打手 | blocker（城门打手）；thug（打手）；屠户是叛逃者 | **武力**（决斗 / 击晕 / 绑 / 扛 / 威吓） | 捉刀人 / 夜行会 / 流浪剧团 |

- **英文 fallback / 本地化**：捉刀人 = The Fixers · 夜行会 = The Nightwalkers · 流浪剧团 = The Players · 码头帮 = The Dockhands；名字一律走 `LWN_faction_*` 键。
- **站位**：玩家站 `sp_outside_near_town_main_gate`（门外）→ blocker 站门外 `sp_guard` 点 → 目标点 = 门内 `sp_guard` 点；四家的代表摆在玩家身后两侧的摊位区（这一片就是市场）。**坐标与兜底规则见 §3.1**；站桩、面向玩家，用 MissionBehavior 每帧钉住位置 / 朝向。
- **生成**：复用 `HeroSpawnerMissionBehavior.SpawnHeroInFrontOfPlayer` 的做法（`SimpleAgentOrigin` + `Mission.SpawnAgent`），加一个 `SpawnHeroAt(hero, position, direction)` 变体。
- **防重复**：先查场上有没有这个 hero 的 agent（按 `Character` 匹配）；有就移动，没有才 spawn。
- **必须是 Hero**：社交检定 `InteractionController.ResolveAdversarialIntent` 要求 `ctx.Speaker` / `Profile` 存在（模板 NPC 会被拒「不能深谈」）；所以代表都用原版 Hero，不用模板。
- **身份**：全部原版 Hero；不新建 Hero / 模板 / 外观。四个势力各存代表 HeroId + 关系，序章结束显示「他日再会」。
- **屠户**：码头帮的**叛逃者**（former enforcer），不是码头帮代表；他教你武力，是为了报复砸他摊的旧同伙。

### 4.1 故事网：城门口的四家

**设定**：玩家是个 nobody，被**码头帮**的城门打手拦在**城外**。门外城外集市是四家的地盘：**捉刀人**摆一张桌子替人写状子 / 找门路，**夜行会**蹲墙头，**流浪剧团**搭戏台，**码头帮**摆收数摊。四家都在门口，各有各的难处；**你帮谁，谁教你一手；不帮，没人白给**。

| 势力 | 难处 | 你帮它做什么（委托） | 它给你什么 | 和谁敌对 |
|---|---|---|---|---|
| 捉刀人（当铺前台） | 码头帮收保护费 / 抢他生意 | 替他跑腿 / 收债 / 打点 | 第纳尔 + 消息 + 零活 | 码头帮 |
| 夜行会（儿子） | 野贼抢地盘 / 码头帮打压 | 教训野贼 / 偷回工具 | 钩索 + 后路 | 野贼 / 码头帮 |
| 流浪剧团（寡妇） | 码头帮砸场 / 对台剧团抢客 | 教训对台 / 赶走 thug | 贵族制服 + 通行文书（身份） | 对台剧团 / 码头帮 |
| 码头帮（blocker / thug） | —（反派） | 打 / 绑 / 扛 / 威吓他们 | 武器 / 绳子（从叛逃者屠户处学） | 所有人 |

- **四家都在城门口**：捉刀人摆桌、夜行会蹲墙头、流浪剧团搭台、码头帮收数；玩家一眼能看出四家的行头。
- **每个人知道妹妹的一截**：捉刀人给她找过活；儿子见过她被带走；寡妇卖过她通行文书；码头帮知道她在哪。
- **不是四个高人一人一句**：每家先演一件小事（捉刀人写状子、儿子从墙头滑下、寡妇挥手 / 递假通行文书、blocker 收数 / 砸摊），玩家看见 → 搭话 → 帮 → 才教。
- **选择有后果**：帮谁，谁就是你的第一个势力；没帮的人说一句「你选了别人」；码头帮的反应不同。
- **钱是捉刀人的路**：替他跑腿 → 几个第纳尔 → 收买 blocker；不要求你打 / 偷 / 骗。
- **码头帮**：不管走哪条，最后都指向码头帮 / 第一张凭证——这是沙漏第一段 → 第二段的接缝。
- **气质**：底层百姓互帮互助 + 四家各有账本；不是「神秘高人传功」。
- **每个势力给的是整套能力**：贵族制服 / 钩索 / 武器只解锁**主路**；其他玩法用玩家已有的能力。
- **blocker 的后续**：魅力 → 被耍；技巧 → 没看见；武力 → 被打服 / 结仇。

### 4.1.1 势力 / 仇家 / 委托：把「帮忙」做成交易

**四个势力与内部矛盾**：

- **捉刀人（友好；头目是掮客头子）**：当铺老板是前台；替人跑腿 / 找门路；被码头帮收保护费。
- **夜行会（中立）**：寡妇的儿子是小贼；和**野贼**（码头帮的线人）争地盘。
- **流浪剧团（中立）**：寡妇是领班 / 舞姬；和**对台剧团**（码头帮捧的）抢客。
- **码头帮（邪恶）**：码头帮；blocker 守门、thug 打手、debtor 收数；内圈 A / B 争地盘；屠户是叛逃者。

**仇家贸易（委托结构）**：

1. 你求一个势力（贵族制服 / 钩索 / 武器 / 第纳尔）。
2. 势力不白给：「先帮我教训 X」——X 是它的仇家。
3. 你用魅力 / 技巧 / 武力 / 钱完成（揍 / 吓 / 偷 / 绑 / 扛 / 收债）。
4. 完成 → 势力关系 +；仇家关系 -；仇家势力 -；码头帮警觉 +。
5. 你拿到的能力 / 工具，再用来过 blocker。

| 势力 | 你求它什么 | 它让你做什么（委托） | 仇家 | 完成 → 你得到 | 后果 |
|---|---|---|---|---|---|
| 捉刀人（当铺） | 第纳尔 + 消息 + 零活 | 收 debtor 的债 / 打点 | debtor（码头帮 A 的收数） | 第纳尔 + 消息 | 捉刀人 +；debtor -；码头帮 A - |
| 夜行会（儿子） | 钩索 + 后路 | 教训野贼 / 偷回工具 | 野贼（码头帮的线人） | 钩索 | 工会 +；野贼 -；码头帮警觉 + |
| 流浪剧团（寡妇） | 贵族制服 + 通行文书（身份） | 教训对台剧团 / 赶走 thug | 对台剧团（码头帮捧的） | 贵族制服 + 通行文书 | 流浪剧团 +；对台 -；码头帮 - |
| 码头帮（反派） | — | —（打 / 绑 / 扛 / 威吓他们） | blocker / thug | 武器 / 绳子（从叛逃者屠户处学） | 码头帮 -；屠户 + |

- **选边**：帮捉刀人 / 夜行会 / 流浪剧团 = 动码头帮；帮码头帮 = 动三家。码头帮内圈 A / B 也有矛盾。
- **不白给**：不做委托，势力不教 / 不给；你可以花钱 / 硬闯，但那不是它的人情。
- **序章先做一条**：流浪剧团（寡妇）的委托（教训对台剧团）作为示范；其他势力留接口，后续内容加。
- **现成系统**：委托数据 / 目标 / 奖励复用 `CommissionQuest` / `CommissionData` 的形状（不跑程序化生成器）；关系走 `ChangeRelationAction` / `SettlementHonorStore` / `InfamySystem`；揍 / 绑 / 扛走 `KnockoutFlow` / `CombatManager` / `GrappleBind` / `GrappleCarry`；偷走 `StealManager`。

### 4.1.2 背包里的属性道具：偷东西也能涨值

- 每个势力 / 仇家的**背包**里放一件**属性道具**（原版书 / 药剂 / 护符当载体；不给新资产）。
- **偷到**（现有扒窃条 / `StealManager`）或**委托奖励**得到；使用 / 装备后 **+1 对应技能**（例如 +1 Roguery / Charm / Vigor），走现有 `Hero.AddSkillXp` / `SetSkillValue`；不新造属性系统。
- **偷有风险**：被目击 = 犯罪 / 警觉；所以「偷属性道具」是**有代价的成长**，不是白拿。
- **每件唯一**：一个 NPC 只有一件；偷了 / 拿了就没了；不能反复刷。
- **和委托互补**：不想冒险偷 → 做他的委托换；想走技巧 → 直接偷。

| NPC | 背包道具（载体） | 拿到 → +1 |
|---|---|---|
| 寡妇（流浪剧团） | 护符 / 假印 | Charm |
| 儿子（夜行会） | 细钩 / 撬锁包 | Roguery |
| 屠户（码头帮叛逃者） | 磨刀石 / 护腕 | Vigor / OneHanded |
| 当铺（捉刀人） | 账本 / 账本 | Trade / Charm |
| 仇家 | 抢来的护符 | 对应能力 |

- **现有系统**：`StealBarVM(Pickpocket)` / `StealManager.StealSpecificItem` / `Hero.ItemRoster` / `AgentControlHelper.TransferItems` / `Hero.AddSkillXp`。

### 4.1.3 赚钱：零活 + 钱不是万能

- **玩家一开始 0 钱**（nobody）。
- **赚钱点（零活）**：当铺跑腿 / 寡妇送信 / 屠户搬肉 / 儿子把风 —— 每次几个第纳尔；不是委托，是**零活**。
- **提示**：势力会顺口说「缺钱？帮我跑一趟」；`status` / 通知列出当前零活。
- **钱不是万能**：
  - **能买**：blocker 的打点（100 第纳尔）；当铺的消息（几十第纳尔）；酒 / 情报。
  - **不能买**：势力的**工具 / 手艺**（只换人情，不卖）；仇家的**恩怨**（揍 / 吓 / 偷才解决）；有些 NPC 不吃钱（例如死脑筋的屠户）。
- **钱是第四条路，但只解决「钱能解决的那一段」**：blocker 可以打点，势力的委托不行。

### 4.1.4 NPC 三属性：同一类属性对拼（**没有「抗性」这回事**）

**规则**：检定 = **玩家的某类属性 vs NPC 的同一类属性**，各比各的：

| 玩家用什么 | NPC 拿什么对 | 底层数值 |
|---|---|---|
| 武力 | 武力 | Vigor + Control |
| 技巧 | 技巧 | Roguery |
| 魅力 | 魅力 | Charm |

**成功率**（沿用现有 ratio 式，d20：掷点 ≥ 门槛）：

```
chance    = playerAttr / (playerAttr + npcAttr)     玩家侧钳制 [5%, 95%]
threshold = 1 − chance                             掷点 ≥ threshold 即成功
```

**NPC 的三维从哪来**：序章这几个 NPC 在 `StoryProbeDefs` 里**直接填数值**（不读随机生成的 Hero 技能，保证每次难度一致）；模板 NPC 按 Level 估算（现有 `AgentStatsHelper.GetAgentStats` 的做法）。

**序章三维表**（数值是初值，实机再调）：

| NPC | 武力 | 技巧 | 魅力 | 玩家该用什么 |
|---|---|---|---|---|
| blocker（码头帮） | 70 | 30 | 50 | 硬拼难；**技巧**（偷 / 翻）最顺 |
| 屠户（码头帮叛逃者） | 70 | 50 | 30 | 打他难；骗他容易 |
| 寡妇（流浪剧团领班） | 30 | 50 | 70 | 吓她容易；**嘴炮难** |
| 儿子（夜行会小贼） | 30 | 70 | 30 | 偷他难；骗他容易 |
| 当铺老板（捉刀人） | 30 | 50 | 70 | 吓他容易；讲理讲不过 |
| 对台领班（对台剧团） | 30 | 50 | 70 | 偷 / 吓比嘴炮容易 |
| 野贼 | 30 | 70 | 50 | 骗他比偷他容易 |
| thug（码头帮） | 70 | 30 | 30 | 绑 / 骗比硬打容易 |
| debtor（码头帮 A 的收数） | 50 | 50 | 50 | 三条路差不多 |

- **打听 = 把这张表告诉他**：跟势力 / 围观者聊过之后，`check` 里会把这个 NPC 的**三维数字显示出来**（不是给加成），玩家自己判断该用哪条路。
- **不是所有路都通**：数值高 = 成功率低；玩家要**选对人用对招**，或者先打听。
- **钱不参与对拼**：收买**不检定** —— 钱够就过、钱不够置灰。钱是第四手段，不在三属性体系里。

### 4.1.5 开场事件：让玩家自己凑过来（2026-11-12 用户裁定）

**问题**：§4.1 那套「四家各有难处、你帮谁谁教你一手」是**设定**。玩家站在城门口不会主动去找人搭话——他不知道自己该干嘛，也没有理由开口。

**解法**：不要求玩家主动开口。**先出事，再搭话。**

#### 开场 6 起事件（4 起双人冲突 + 2 起单人发愁）

| # | 事件 | 谁 | 玩家**远远**看到什么（10~20 m） | 接入后 |
|---|---|---|---|---|
| 1 | 收保护费 | thug → 当铺老板 | 两个气泡对着弹，thug 推搡，老板后退 | 第一次和**捉刀人**说话 |
| 2 | 砸摊 | thug → 屠户 | 肉案被掀，屠户举刀，吼声 | **武力**路入口 |
| 3 | 骂街 | 剧团领班 ↔ 对台领班 | 隔街对骂，越走越近，开始有人围 | **魅力**路入口 |
| 4 | 抓小偷 | 当铺老板 → 儿子 | 老板揪着领子，小孩挣扎，喊「还我钱袋」 | **技巧**路入口 |
| 5 | **一个人发愁**（单人） | 当铺老板 | 一个人站着反复翻账本、叹气，头顶「!」 | 钱路 / 委托引子 |
| 6 | **一个人在收拾**（单人） | 屠户 | 一个人扶肉案、蹲下捡散落的东西，头顶「!」 | 武力路 / 委托引子 |

- **顺序固定**：进场景 12 秒后第 1 起，之后每 20 秒下一场；玩家不介入也照演，演完散场。
- **同时只演 1 起**（避免满屏人吵架）。

#### 远距离可见（关键：不用走近才知道出事）

- **一开演就出声**：参与者立刻 `SpeechChannel.Say`（`SpeechPriority.Warning`），台词就是冲突内容——玩家在 **10~20 m 外**就能看到**两个气泡对着弹**、听到对骂。
- **动作同步**：推搡 / 掀摊 / 揪领子（`ForcePlayAction` + `act_conversation_aggressive_*`）。
- **视野外兜底**：现有 `AgentHudMissionView` 的 `FarHearDistance`（30 m）会在屏幕给一行提示——背对着也能知道身后在吵。
- **单人事件没有对手可吵**：只能靠**头顶「!」+ 反常举动**（反复翻账本 / 蹲下收拾 / 来回踱步）吸引人，走近他才开口。

#### 为什么要有单人事件

- 四个人不可能时刻都在跟人吵；**单人事件让「有事」也能被看见**。
- 单人事件 = **委托引子最自然的样子**：他一个人在发愁，你走过去问一句，他就把难处说了。
- 双人事件偏「冲突」，单人事件偏「难处」——两种入口都给玩家。

#### 头顶「!」标记

- 参与事件的人头顶挂一个「!」——**复用现有头顶 HUD**（`AgentHudVM` 加一个 `HasEventMark` + `AgentHudNearby` XML 加一个图标位），不新建 UI。
- 标记**只在事件进行中出现**；事件结束 / 玩家接入后消失。
- 没轮到的人不带标记（不然一进场四个感叹号，等于把菜单摊开）。

#### 玩家接入（关键）

| 玩家行为 | 系统反应 |
|---|---|
| 走进事件 4 m 内 | 事件**暂停**（动作停在原地），双方看向玩家 |
| 停住约 2 秒 | **自动开对话**（原版对话流，走 `ConversationEntryPatch` 的 trigger） |
| 第一句 | 事件里的人冲你说一句（「看什么看」/「客人稍等」） |
| 选项 | 【帮这边】【帮那边】【问怎么回事】【走开】 |
| 选【走开】 | 事件恢复，继续演 |
| 接入 | 事件收尾 → **这就是和该 NPC 的「搭话」**（五步关系第 ① 步）→ 之后按 F 才能继续打听 |

- **接入 = 搭话**：玩家不是"无目的地找人聊天"，是**卷进了别人的麻烦**。
- **不接入也不会卡**：事件演完，NPC 回到可对话状态，按 F 仍能进五步关系——只是少了那点代入感。

#### 和 §5.7 的关系

§5.7 的「双人桥段」就是这些事件的**演出层**。区别只有三点：

1. 开场 6 起是**排好顺序**的（不随机）；
2. 演出中**挂「!」标记**；
3. 玩家靠近能**暂停 + 接入对话**。

之后随机刷的桥段仍然只是氛围：不带标记、不可接入。

#### 技术

- `StreetLifeDirector` 加 `EventDef`（Id / 参与者 / 步骤 / 接入节点 / 暂停半径）与一个「开场队列」。
- 标记：`AgentHudVM.HasEventMark` + `AgentHudNearby` XML 一个图标位。
- 接入对话：设 `ConversationEntryPatch` 的 trigger → `StartConversation` → 注入 `event_<n>_join` 节点（沿用 §5.6 的 JSON 机制）。
- 暂停：事件里的 agent 用 `AgentBrain` 站桩 + 停动作；玩家走开再恢复。

### 4.3 角色来源与 AI 行为

**结论：不新建 CharacterObject / Hero / 模板；全用原版。**

**选人顺序（两轮，铁律 5）**：

1. 目标城的 `Settlement.Notables`（按 occupation：GangLeader / Merchant / Artisan / Headman / Preacher）；
2. `Hero.AllAliveHeroes` 的流浪者（`IsWanderer`）；
3. 原版 `CharacterObject` 模板（`guard` / `gangster` / `villager` / `merchant` / `artisan` / `preacher`；按文化查，见 `spnpccharacters.xml` / `spnpccharactertemplates.xml`）。

**角色表**：

| 角色 | 来源 | 背包（属性道具） | AI 行为 |
|---|---|---|---|
| blocker（码头帮） | 优先 notable（GangLeader）；没有就用 guard 模板 | 有（hero 时） | 站门口、面向玩家；魅力→对话；偷→扒窃条；武力→决斗/击晕/绑/扛；被打→还手 |
| 寡妇（流浪剧团） | 优先女性 notable（Merchant / Preacher）；没有就流浪者 / 模板 | 有 | 站摊、递假通行文书小动作；对话 / 委托；被打→逃 |
| 儿子（夜行会） | 流浪者 hero 或 notable（Artisan / GangLeader） | 有 | 站墙头 / 摊边、滑下小动作；对话 / 委托；被打→逃 / 还手 |
| 屠户（码头帮叛逃者） | notable（Artisan / Headman）或 artisan 模板 | 有 | 站摊、拎人小动作；对话 / 委托；被打→还手 |
| 当铺（捉刀人） | notable（Merchant） | 有 | 站柜、数钱小动作；对话 / 交易；不打架 |
| rival vendor（对台剧团） | notable（Merchant）或 merchant 模板 | 有 | 站摊；被吓 / 偷 / 打→还手 / 逃 |
| rival thief（野贼） | 流浪者或 gangster 模板 | 有 | 站墙边；被吓 / 偷 / 打→还手 / 逃 |
| thug（码头帮） | gangster 模板或 notable（GangLeader） | 有 | 站街口；被吓 / 偷 / 打→还手 |
| debtor（码头帮 A 的收数） | notable（Merchant）或模板 | 有 | 站巷口；被吓 / 收债→还手 / 逃 |

**AI 行为（不跑原版日程）**：

- **站桩**：`StoryProbeMissionBehavior` 每帧钉位置 / 朝向，或 `AgentControlHelper` 脚本位置；**不要 `SetIsAIPaused`**（城镇里会冻住行走输入，村民直走不停）。
- **小动作**：`AgentControlHelper.ForcePlayAction` / `SetPose` 播 3~5 秒（递货、滑下、拎人、数钱），然后回站桩。
- **面向**：交互时 `FaceToActor`。
- **对话 / 选项**：`InteractionMissionView` + `IntentRegistry`（现有）；NPC 只冒一句 `AgentSay`，不跑日程。
- **战斗**：`CombatManager.StartFight(Peace:true)`（决斗）/ `KnockoutFlow`（击晕）/ `GrappleBind` / `GrappleCarry`（绑 / 扛）；被打的 NPC 由 `AgentBrain` / `CombatManager` 还手。
- **偷**：`StealBarVM` / `StealManager`；目击 → 犯罪 / 警觉（现有）。
- **不做**：巡逻、跟随、日程、群聊 AI（这些是原版 / 现有系统，不在这段演出里跑）。

> 完整设计（行为表 / 双人桥段 / 对玩家反应 / 频率 / 技术口径）见 **§5.7**；互动选项与台词见 **§5.6**。

**风险**：目标城 notable 不够 9 个 → 先用 6 个（blocker + 3 势力 + 当铺 + thug），其他仇家留接口；或用流浪者 / 模板补——**模板没有背包，属性道具只放 hero 身上**。

## 5. 三种能力的真实玩法（每种能力多个现有玩法）

### 5.1 帮忙 / 学一手（4 家势力 + 1 个钱路）

- 每个势力身上一个「委托」入口：你求他东西 → 他让你去教训他的**仇家** → 完成算委托完成 → 他给你东西 / 教你一手。
- 帮的内容是**小活**（揍 / 吓 / 偷 / 绑 / 扛 / 收债），不是「拜师学艺」；她 / 他顺带教你一手。
- **流浪剧团（寡妇）**：帮完给你贵族制服 + 通行文书（某个真人的身份）。
- **夜行会（儿子）**：帮完给你钩索。
- **码头帮叛逃者（屠户）**：帮完给你武器 + 绳子。
- **捉刀人（当铺）**：帮完给你几个第纳尔（用于收买），不教能力。
- **数值**：帮完给该能力所有具体玩法 +2 情境；不直接改骑砍技能 / 属性。
- 可以都帮，也可以只帮一个；帮忙本身不检定、不花钱。

### 5.2 魅力（乔装）+ 钱（收买）——乔装是「身份」，要和通缉 / 冒充接上

**先说清楚**：对话类（策反 / 劝降 / 谈判 / 说服 / 魅惑 / 套话 / 寒暄 / 身份表演 / 虚张声势 / 对话威胁）有代码但**不成熟**，本验证**不用**。魅力只做成熟的**乔装（身份）**；**收买（钱）单列，属第四手段**。

**A. 乔装（主路）——你不是「穿贵族制服」，你是「变成某个人」**

- 流浪剧团（寡妇）是假通行文书贩子：她卖的不是衣服，是**身份**。给你一套**某个真人**的贵族制服 + 通行文书，告诉你「穿上他，你就是他」。
- **身份目标** = 目标城里一个真实的 Hero（贵族 / 守卫队长 / notable），存 `DisguiseHeroId`；贵族制服就是这个人的行头。
- 你穿上（换场景 agent 的 Body 槽；换装不稳就退回 `disguised` 旗标 + 文字提示，加成照旧）。
- **用途 1：冒充通行（主路）**：blocker 看见这身行头，**把你误认成那个人**，让路（一句「阁下」）。一次识别检定（Charm / Roguery；贵族制服给大情境加成）决定他信不信。
- **用途 2：通缉脱险**：如果你走技巧 / 武力失败、被通缉（`Kingdom.MainHeroCrimeRating` / `ChangeCrimeRatingAction`），守卫本来要抓你；**乔装后他们认的是「那个人」，不是你** → 一次识别检定，过了就躲过去。
- **用途 3：冒充犯法（可选验证）**：乔装状态下犯事（偷 / 打 / 砸），**罪名记在「那个人」头上**，不是你 —— 复用 `FrameSuspect` / `WorldEvent` 的 suspect 字段；你的通缉不涨，那个人的关系 / 势力掉。**这是把「乔装」和「通缉 / 嫁祸」接上的关键一条。**
- **你背着码头帮栽的小额通缉**：乔装不只是为了过门，也是为了**不被认出来**；没通缉时它也能冒充通行。
- **不是对话树**：穿上 → 一次识别检定 → 认成谁 / 被识破；用途 3 是犯事后的记账，不是谈判。
- **失败**：被识破（警觉 / 被抓）；可以换收买，或换技巧 / 武力。
- **后续**：被冒充的那个人以后会来找你（伏笔）；本阶段只存 `DisguiseHeroId` + 冒充次数。

**B. 收买（钱 · 第四手段，不属于魅力）**

- 直接塞钱（现有 `TransferGold` + 贿赂语义）；钱够就过。
- 他收钱放行；留下「被拿捏」隐患 flag；不增加通缉。
- 钱不够：选项灰掉；这是脑图「钱可以辅助加速，但不独立成一条路线」。
- **先赚钱**：势力的零活（§4.1.3）给几个第纳尔；没钱就去跑腿。
- **钱不是万能**：blocker 能买；势力的工具 / 手艺不卖（只换人情）；仇家的恩怨不卖。

**两条共用**：失败不锁死，可以换另一条；**不新造对话系统**。

### 5.3 技巧（钩索 / 扒窃 / 撬锁 / 潜行 / 偷属性道具）——一种能力五个现有玩法

技巧是伞；夜行会（儿子）给钩索（解锁主路），另外四个是玩家已有的本事。技巧 1 级给五条都 +2 情境。

**A. 钩索（主路）**

- 夜行会（儿子）给你一副**现有钩索**（`lwn_grapple_*` / `GrappleLogic`；两轮查找）。
- blocker 身上出现「勾住墙头翻过去」选项；先走 **Roguery 检定**决定钩点 / 时机（现有 `SingleRollResolver`；`Tactic = Threaten` 映射到 Roguery，或加一个按技能直算的小重载）。
- 检定过了 → 用**现有钩索**勾住城门上方的墙 / 梁，被拉上去 / 翻过去；blocker 没反应过来（或看见但拦不住）。
- 失败 / 钩空 → 他察觉（警觉）；可以换扒窃 / 撬锁 / 潜行，或换魅力 / 武力。
- 钩索本身是现有系统（`GrappleLogic` / `custom.grapple`）；这一路不需要新代码，只需要任务状态和触发。

**B. 扒窃**

- 趁他不注意，用**现有扒窃条**（`StealBarVM(Pickpocket)` + `StealManager.StealSpecificItem`）扒走他的武器 / 钥匙。
- 得手：他手里没家伙 / 你拿到钥匙，只能让路；失败：他察觉（警觉），可换路。
- 这条需要一个 quest 目标模式（只对序章 blocker 生效），是**备选**，不是主路。

**C. 撬锁**

- 绕到他身后的侧门 / 锁，用**现有撬锁条**（`StealBarVM(Lockpick)` + `StealManager.GetLockpickPinCount`）开锁。
- 成功：侧门打开，你从他背后过去；失败：发出声响 / 他察觉，可换路。
- 如果场景没有真门，这条**不做**（不新造门）；备选。

**D. 潜行**

- 蹲下（现有 `crouch` + `NpcSightSystem`），趁他转身 / 被别的事引开，从他背后溜过去。
- 成功：他没看见你；失败：被看见（警觉），可换路。
- 这条依赖场景和 AI 视线，**作为情境选项**，不是必做。

**E. 偷属性道具（成长）**

- 势力 / 仇家的背包里有一件**属性道具**；用现有扒窃条（`StealBarVM(Pickpocket)`）偷。
- 得手 → 道具进背包，**+1 对应技能**（`Hero.AddSkillXp` / `SetSkillValue`）；被目击 → 犯罪 / 警觉。
- 每件唯一，不能刷；不想偷就做他的委托换。
- 这是「偷东西还能提升值」：偷不是只拿钱，是**成长**。

**五个玩法共用**：只要一个成功就能过；失败不锁死；**钩索是主路**，另外四个是同一把伞下的备选。

### 5.4 武力（决斗 / 击晕 / 威吓 / 绑扛）——一种能力四个现有玩法

武力是伞；码头帮叛逃者（屠户）给武器（解锁主路），击晕 / 威吓 / 绑扛是玩家已有的武力。武力 1 级给四条都 +2 情境。威吓是「开战前亮兵器逼他」，不是对话树；绑 / 扛是武力检定。

**A. 决斗（主路）**

- blocker 身上出现「动手」选项。
- 先用**现有属性检定**看开局：`AgentStatsHelper.GetAgentStats` 取双方 Vigor+Control，按 `KnockoutFlow.ComputeSuccessRate` 的 ratio 式算成功率；**成功 → 开局优势（他起手慢），失败 → 正常开局**。
- 然后 `CombatManager.StartFight(玩家, blocker, Peace: true)` 开**非致命决斗**；现有侧容器模型会把随从扫到一边（1v1）。
- 打赢：他让路；打输：他嘲笑你，可以换击晕，或换魅力 / 技巧；**无论胜负，关系 -20**（结仇）。

**B. 击晕**

- 从背后 / 趁他不备，用**现有击晕**（`KnockoutFlow.Roll` + `PlayStrikeAnim` + `Resolve`）把他放倒。
- 成功：他倒地，你过去；失败：他反击（进战斗），可换决斗。
- 这是技巧 / 武力交叉：潜行接近是技巧，动手放倒是武力。

**C. 威吓（开战前）**

- 在动手前，亮兵器 / 逼上前，用**现有威胁**（`Threat` / `threaten_verbal` 的语义）压他。
- **一次 Vigor + Control 检定**（或现有 `Threat` 的 Roguery 检定；两条选一条，Defs 定）：
  - **成功**：他退开，不战而屈；关系 -10（被吓住，记恨）。
  - **失败**：他动手，直接转**决斗**（可以继续打）。
- **不是对话树**：亮兵器 → 一次检定 → 退开或开打；没有谈判条。
- 这是「武力」的开战前动作，不是魅力的「虚张声势」（后者是对话类，不做）。

**D. 绑起来 / 扛走（武力检定）**

- 在**击晕 / 决斗打赢**之后（或直接冲上去按倒），用现有 `GrappleBind` / `PairAction`（被绑）把他绑起来。
- **武力检定**（复用 `AgentStatsHelper` 的 Vigor+Control ratio，和击晕同一套）：
  - **成功**：绑住；他动不了，门就通了。
  - **失败**：他挣脱 / 喊人；可以再打（决斗）或换别的路。
- **扛走**用现有 `GrappleCarry` / `PairAction`（扛人）：把他扛到街角 / 门边；**扛的时候不能同时给「松绳 / 放下」**（现有纪律）。
- **这一路是「制服 + 绑 + 扛」**：不一定要打死他；把人挪开，门就通了。
- **不是对话树**：按倒 → 武力检定 → 绑 / 扛 / 失败。

**四个玩法共用**：只要一个成功就能过；失败不锁死；**决斗是主路**，击晕 / 威吓 / 绑扛是同一把伞下的备选。

### 5.5 目标与完成

- blocker 被解决后：他说一句台词，走到一边（`ScriptedMoveToPoint` 或直接平移 3 m）。
- 目标点 = **门内**（他原来位置身后 3 m）；玩家走进 2 m 内 → 序章完成。
- 完成时：恢复金钱，发总结（用了哪条路、势力关系、天赋点、结仇 / 隐患），主线钩子出现。
- 如果玩家没解决 blocker 就绕过去：不完成，blocker 会喊一句「站住」（第一阶段不做物理推回，靠叙事阻挡）。

### 5.6 玩家怎么跟 NPC 打交道（互动脉络 · 选项 · 台词）

#### 5.6.0 一句话

每个 NPC 都是一个能对话的活人：走近 → 他先开口 → 面板上列出**你现在能对他做的事** → 点下去有检定、有台词、有后果 → 做过的事会改变下次见面。

#### 5.6.1 交互怎么开始（走原版对话流注入，**不自建面板**）

**两条路**：**从事件接入是主路**（§4.1.5：NPC 正在出事，玩家凑过去），主动按 F 是兜底（NPC 没在出事时）。

| 步 | 玩家做了什么 | 走哪个现有件 |
|---|---|---|
| 0 | **从事件接入**：走进正在出事的 NPC 4 m 内 → 事件暂停 → 自动开对话 | `StreetLifeDirector` + `ConversationEntryPatch` 的 trigger |
| 1 | 或者走近 NPC 主动按 **F** 交谈（原版键） | 原版 `StartConversation` |
| 2 | 原版对话界面打开；`ConversationEntryPatch` 的 Postfix 在 `hero_main_options` 挂一个入口选项 | `DialogueInjector.InjectScript`（Gateway 模式） |
| 3 | 玩家点进去 → 我们的节点树（NPC 一句 + 几个选项） | v2 模型：`DialogueNode` + `DialogueTransition` |
| 4 | 点选项 → 执行（不检定 / 检定）→ 路由到下一个节点或关窗 | `CheckType.None` / `SkillCheck` |

- **不自建面板、不写 StoryDialogVM**：对话全在原版对话界面里完成。
- **注入统一收口 `StartConversation`**（对话注入铁律 B）：调用方只设 trigger，不自己 `InjectScript` + `StartConversation`，否则会双重注入。
- **嘴上的事在对话里，手上的事在对话外**：
  - 对话里 = 打听 / 求 / 交差 / 闲聊 / 亮身份
  - 对话外 = 扒窃（扒窃条）、动手（拔刀）、绑 / 扛（动作键）、收买（钱够直接给）、乔装（换装）
  - 两套各走各的，不硬塞进对话。
- **没什么可聊就不注入**：原版选项照旧出现，玩家自己看得出这人没话说。

#### 5.6.2 选项长什么样（原版对话里的 `PlayerLine`）

- 每条就是一句玩家台词，前面带方括号标类别：`【打听】三个月前，有没有见过一个穿青布的姑娘？`
- **不显示百分比**（原版对话流不支持成功率后缀）：靠措辞给线索 —— `【试着唬他】没你的事，让开。` / `【低声下气】……行个方便？`
- 条件不满足的选项**干脆不注入**（不是置灰）；想告诉玩家"为什么没有"，就让 NPC 那句 `LazyNpcLine` 点一句（「你连话都没跟我搭过，问这些做什么？」）
- 问过的事：那条 `PlayerLine` 换成 `【再问一次】…`，或者直接不注入
- 【离开】用原版自带的退出，不自造

#### 5.6.3 每个 NPC 的对话分五步（关系递进，落成节点）

| 步 | 节点 Id | 玩家选项 | 什么时候注入这条 `PlayerLine` | 结果 |
|---|---|---|---|---|
| ① 搭话 | `<npc>_intro` | 【搭话】先问一句 | 第一次见 | 他给一句自我介绍 + 态度；解锁 ② |
| ② 打听 | `<npc>_ask1..3` | 【打听】……（每人 2~3 条） | 搭过话 | 给情报：妹妹线索 / 他的三维 / 怎么过门；**不检定**；问过的不再注入 |
| ③ 求 | `<npc>_deal` | 【求】把东西借我 / 教我一手 | 打听够了 | 他不白给 → 派一个委托（去教训他的仇家） |
| ④ 交差 | `<npc>_turnin` | 【交差】事情办完了 | 委托目标已完成 | 给东西 / 教一手；关系 +；入口换成 ⑤ |
| ⑤ 熟人 | `<npc>_chat` | 【闲聊】【还有活吗】 | 交差之后 | 口吻变热络；给下一阶段的钩子 |

- **没打听就直接求**：走 `deal` 的"拒绝"分支，只回一句「你先去问问别人」——不锁死，回头打听再来。
- **顺序不是硬门槛**：玩家可以跳过打听直接偷 / 打 / 收买（那些在对话外），代价是拿不到线索和他的底。
- **节点 Id 只是约定**：实际名字在 JSON 里定，一个 NPC 一个文件。

#### 5.6.5 台词怎么写（文本层规格）

- **三段式**：**选项标签 = 玩家想做的事**（第一人称、短）· **NPC 回应 = 角色口吻**（一句，能听出职业和处境）· **旁白 = 世界反馈**（只在大事发生时才出现，如「他收了钱，眼睛还盯着你的钱袋」）。
- **口吻定位（决定"像不像活人"）**：

| NPC | 口吻 | 忌 |
|---|---|---|
| 当铺老板 | 客气里带账本，句句不离钱 | 忌文绉绉 |
| 寡妇 | 演戏的腔，刀子嘴，护短 | 忌骚气（她是领班，不是花魁） |
| 儿子 | 快嘴、爱吹、心虚 | 忌老成 |
| 屠户 | 闷、硬、话少，一次不超过两句 | 忌长篇大论 |
| blocker | 冷硬短句，不说整话 | 忌解释自己 |

- **同一个人两套说法**：第一次见（防着你）→ 交差后（认你）。例：老板第一次「当东西还是找门路？」；交差后「来了？账我记着呢。」
- **失败台词必须写**：失败不是"没事发生"，是「他记住了你」「他警觉了」。
- **键名**：`LWN_story_<npc>_<步>_<序>`，中英各一套，全部过 `LWNTextHelper`。
- **第一阶段台词量估算**：6 个 NPC × 8~12 句 ≈ 60 句，加旁白约 70 个键。

#### 5.6.6 NPC 主动开口（不是玩家点了才说话）

| 触发 | 谁说什么 |
|---|---|
| 玩家走近 3 米 | 寡妇「看戏吗？站远点也行，别挡人。」/ 儿子「嘘——」（缩回墙头）/ blocker「站住。」 |
| 玩家掏出武器 | blocker「收起来。」/ 屠户「在我摊子前头别动刀。」 |
| 玩家交差后路过 | 换成热络版：老板「来了？账我记着呢。」 |
| 冷却 | 每人 30 秒，走 `SpeechChannel.Say`（模板；不默认调 LLM） |

#### 5.6.7 玩家现在的目标（一脉络的可见形式）

屏幕角上**一句话目标**，随进度换一行（不做任务栏、不做列表）：

| 阶段 | 屏幕上的那句话 |
|---|---|
| 刚进场景 | 进城。城门有人拦着——问问门口这几家。 |
| 搭过话 | 问出妹妹的下落。四个人，四截线索。 |
| 接了委托 | 弄到进城的门路。帮谁，谁教你一手。 |
| 拿到工具 / 学了一手 | 走过那道门。 |

### 5.7 NPC 自己会动（市井行为模块）

#### 5.7.0 一句话

城外集市这几个人不是木头：他们摆摊、吆喝、张望、抖腿、吵架、收保护费、抓小偷；玩家站着不动也看得出这地方在过日子。

#### 5.7.1 三层行为

| 层 | 谁做 | 频率 | 玩家看到什么 |
|---|---|---|---|
| 常驻动作 | 每个 NPC 自己 | 8~20 秒一次 | 拨账本、挥手、探头、抖腿；偶尔一句吆喝 |
| 双人桥段 | 两个人（偶尔三人） | 90 秒一次，全场同时只演 1 段 | 收保护费、砸摊、骂对台、抓小偷；说完散开 |
| 对玩家的反应 | 与玩家有关的人 | 事件触发 | 靠近招呼 / 拔刀警告 / 犯罪时喊人 / 交差后热络 |

#### 5.7.2 常驻动作表

| NPC | 动作（原版动作名，实机确认） | 台词（模板） |
|---|---|---|
| 当铺老板 | 低头拨账本 / 抬头招呼 / 搓手 | 「当东西还是找门路？」「利息公道，不欺生客。」 |
| 寡妇 | 挥手 / 理鬓 / 拍手叫人 | 「流浪剧团今日开演——」「看戏的往里站！」 |

- 动作名从 `Scripts/vanilla_action_names.txt`（4792 条）里挑，挑不到就用 `SetPose` 摆姿势代替。
- 每人 2~3 条轮换，同一个动作不连播两次。

#### 5.7.3 双人桥段（4 段，轮流演）

| # | 谁和谁 | 演什么 | 说什么 | 结果 / 对玩家的暗示 |
|---|---|---|---|---|
| 1 | thug → 当铺老板 | 收保护费：thug 走到摊前，老板退半步 | thug「这月的。」老板「上月才给过……」thug「涨价了。」 | thug 拿钱走开；暗示「钱能通神」 |
| 2 | thug → 屠户 | 砸摊：thug 掀肉案，屠户举刀 | thug「老东西，交钱。」屠户「滚。」 | thug 退开；暗示屠户能打 |
| 3 | 寡妇 ↔ 对台领班 | 骂街：隔街对骂，越骂越近 | 寡妇「抢客抢到我门口来了？」对台「台子搭在街上，谁都能演。」 | 路人聚过来看（可选）；暗示两家有仇 |
| 4 | 当铺老板 → 儿子 | 抓小偷：老板喊，儿子翻墙跑 | 老板「小贼！还我钱袋！」儿子「没拿！」 | 儿子往墙头跑；暗示这小孩是贼 |

- 用原版对话动作：吵架 `act_conversation_aggressive_start/loop`，闲聊 `act_conversation_closed_*`（已在原版动作名表里，4792 条实测存在）。
- **开场那 4 起双人事件是这 4 段的事件版**（§4.1.5）：同样的演出，加了「!」标记、排好顺序、可暂停可接入；另有 2 起**单人发愁**只有「!」、没有对手。这里列的随机桥段只是氛围，不可接入。
- **玩家插进去会怎样**：桥段演到一半玩家靠近 → 双方停一下看你（约 1 秒）→ 该说话的人说一句（「看什么看」/「客人，稍等」）→ 桥段继续或散场。**不能让玩家觉得自己在看录像。**

#### 5.7.4 对玩家的反应

| 触发 | 反应 | 冷却 |
|---|---|---|
| 玩家进 3 米 | 转头看 + 一句招呼 / 警告 | 30 秒 |
| 玩家掏出武器 | 后退半步 + 一句警告 | 10 秒 |
| 玩家犯罪（偷 / 打） | 中断当前行为 → 喊人 / 逃跑（现有 `NpcSightSystem` + 警戒） | — |
| 玩家交差之后 | 招呼换成热络版本 | — |

#### 5.7.5 怎么驱动（技术口径）

- 一个 `StreetLifeDirector`，挂在 `StoryProbeMissionBehavior` 的 `OnMissionTick` 里，**不新建 MissionBehavior**（少一个挂载点）。
- 每个 NPC 一个运行状态：`Idle`（站桩等下一拍）/ `Performing`（播动作）/ `Talking`（桥段中）/ `Reacting`（对玩家反应中）。
- 播动作：`AgentControlHelper.ForcePlayAction(agent, 动作名)`；**只在 brain 处于站桩（`IsInStayMode`）时播** —— 正在走路 / 打架 / 对话时一律让位。
- 说话：`SpeechChannel.Say(agent, 台词, SpeechPriority.Chat, forwardToNearby: false)`（只冒泡，不进附近频道，免得刷屏）。
- 走位：投事件给 `AgentAIController.SendEventToAgent`，**不直接碰 Brain 队列**（`EnqueueAction` 是 private）。
- **不冻结 AI**：城镇里 `SetIsAIPaused(true)` 会把行走输入冻在最后一帧（2026-10-22 实机定案，人反而直走不停），全程不用。
- 频率上限：单人动作 8~20 秒一次；桥段 90 秒一次、全场同时 1 段；玩家 4 米内不新起桥段（防挡路、防出戏）。
- **只接管我们 spawn 的这几个人**；原版村民 / 守卫一点都不动。

#### 5.7.6 数据表

- 行为写进 `StoryProbeDefs` 的静态表，加一条行为 = 加一行，不写死在逻辑里。
- `StreetLifeDef { NpcId, ActionName, LineKey, DurationSec, CooldownSec, Weight, RequiredStage }`
- `StreetSceneDef { Id, Actors[], Steps[]（谁、动作、台词、时长）, CooldownSec }`

#### 5.7.7 这段要验证什么

- 玩家不动 60 秒：至少看到 2 次单人动作 + 1 次双人桥段 → 「这地方在过日子」。
- 玩家插进桥段：有反应、不出戏。
- 帧率不掉（9 个人播动作，量级可忽略）。

## 6. nobody 状态

- **进场景瞬间**：
  - 记录玩家金钱；`AgentControlHelper.SetGold(Hero.MainHero, 0)`。
  - 收走**场景里玩家 agent** 的武器（`StealManager.StripAgentEquipment` / `Agent` 武器槽清空）。
  - **不换衣服**：玩家穿自己的默认装备进场（2026-11-12 用户裁定）；只收武器 + 金钱。
- **只动场景 agent，不动战役英雄装备**：离开场景 / 重进，agent 会按英雄装备重新生成；「被剥夺」只发生在序章场景里。
- **金钱是英雄的**：记录原始值，序章完成时恢复；中途存档 / 读档保留「已剥夺」状态。
- **已知限制（第一阶段接受）**：
  - 不锁背包：玩家可以从背包重新装备（战役装备没被改，只是场景 agent 被收）；序章短、有引导，第二阶段再做完整锁。
  - 随从：武力 走 Peace 决斗，现有逻辑会把随从扫到一边；魅力 / 技巧不受影响。
- **通知**：进场景时一条「你身上没武器，钱袋也空了」的提示。

## 7. 检定 = 现有属性检定（核心）

### 7.1 一句话

**不新造骰子、不新造属性，直接用 mod 已有的属性检定。** 三种能力各接一套现有检定：

| 能力 | 现有检定 | 技能 / 属性 | 现有入口 |
|---|---|---|---|
| 魅力 | 乔装 = 一次识别检定（Charm / Roguery）+ 身份 / 通缉 / 嫁祸；收买 = 钱 | 乔装（冒充 / 脱险 / 嫁祸）/ 收买 | `SingleRollResolver` / `FrameSuspect` / `WorldEvent` / `TransferGold` |
| 技巧 | Roguery 检定 + 现有本事 | 钩索 / 扒窃 / 撬锁 / 潜行 / 偷属性道具 | `SingleRollResolver` + `GrappleLogic` / `StealBarVM` / `crouch` / `Hero.AddSkillXp` |
| 武力 | Vigor + Control 属性检定 + 现有武力 | 决斗 / 击晕 / 威吓（开战前）/ 绑起来 · 扛走 | `AgentStatsHelper` / `KnockoutFlow` / `CombatManager` / `GrappleBind` / `GrappleCarry` / `Threat` |

### 7.2 脑图公式怎么落

脑图：`对应属性数值 + 总等级加成 + 当前情境加成`。

| 脑图项 | 现有系统里的落点 |
|---|---|
| 属性数值 | 魅力 = Charm 技能；技巧 = Roguery 技能；武力 = Vigor + Control 属性 |
| 总等级加成 | 玩家等级 / 角色等级，折进 `offerValue` 或目标难度 |
| 目标属性 | 每个 NPC 的武力 / 技巧 / 魅力数值（§4.1.4 表）；成功率 = `playerAttr / (playerAttr + npcAttr)`，**同类属性对拼** |
| 情境加成 | 贵族制服 / Charm / 帮忙加成 / 势力关系 / 弱点情报，折进 `GetOfferValue`（0~1）或难度修正 |

**不新写公式**：社交走 `SingleRollResolver.Compute`（技能胜率 + 献礼/情境 + 性格倍率），武力走 `KnockoutFlow.ComputeSuccessRate`（Vigor+Control ratio）。

### 7.3 结果只有成功 / 失败

- 现有检定本身就是 bool：`SingleRollResolver.Roll(chance)` 返回成功 / 失败；`KnockoutFlow.Roll` 返回 `Success`。
- **不做大成功 / 大失败**；成功后按能力给奖励，失败后按能力给后果（警觉 / 通缉 / 换路）。
- 不新增 `RollDetailed`、不新增分档阈值。

### 7.4 显示

- 点击前：沿用现有**成功率预览**（`LWN_ui_option_chance_suffix`，太阁 5 式）。
- 掷完：显示「掷点 X% vs 门槛 Y% → 成功 / 失败」；不写「成功率」以外的目标难度措辞（铁律 17）。
- **骰子的外观**（以后要好看的掷骰动画）走 Gauntlet 面板套皮；第一阶段只做数值和文字，不做新 UI。

### 7.5 明确不做

- 不做 3d10 / 自定义骰面 / 重掷 / 暴击面。
- 不做新的魅力 / 技巧 / 武力属性值。
- 不做新的熟练度 / 阅历系统；第一阶段用现有技能 XP / 玩家等级。
- 不做新的势力声望系统；第一阶段用现有个人关系 + 通缉。

## 11. 实施顺序（每步单独验收）

| 步 | 内容 | 验收 |
|---|---|---|
| 1 | 入城选项 + **背景弹窗** + `EnterViaOption` 标记 + 场景触发 + 生成 NPC + **随从登场说 3 句（无随从走旁白）** + nobody + 命令 | 点选项先弹窗、点【进城】才加载；进场随从说 3 句；原版进城不加载 |
| 2 | **五步对话（原版对话流注入）+ 每个 NPC 的节点 / 台词 + 目标提示（§5.6）** | 走近按 F 出现入口选项；五步能推进；问过的不再出现；失败有台词；屏幕目标随阶段换 |
| 3 | **市井行为 + 事件钩子**：常驻动作 + 双人桥段 + **开场 6 起事件（4 双人 + 2 单人，带「!」标记、暂停、接入）** + 对玩家反应（§4.1.5 / §5.7） | 进场 12 秒看到第一起事件且参与者头顶有「!」；走近事件自动开对话；不接入也能自己演完；`life stop` 后人变木头 |
| 4 | 魅力：乔装；钱：收买 | 成功率预览、掷点 / 门槛、成功 / 失败结果不同；失败能换路 |
| 5 | 技巧：先做钩索，再补扒窃 / 撬锁 / 潜行 | 钩索翻过去能过；失败能换路 |
| 6 | 武力：先做决斗，再补击晕 / 威吓 / 绑扛 | 打赢能过；打输能换路；关系 -20 |
| 7 | 选择反馈 + 目标点 + 恢复金钱 + 存档 | 势力关系 / 天赋点 / 结仇可见；完成后恢复 |
| 8 | 本地化 + 双端编译 + `run_all_checks.py` | 无裸中文；1.2.12 与 1.5.x 各编一遍 |
| 9（可选） | Gauntlet 掷骰皮肤 / 真实门锁 / 锁背包 / NPC 视线 | 单独评审后再做 |

> 顺序理由：先把「人怎么说话、怎么自己动」立起来（步 2、3），再做三条玩法路——不然三条路都做好了，玩家站进去还是觉得像测试关卡。

## 12. 验收命令

全部是游戏内控制台命令，写全称：

```
custom.story_probe enable
custom.story_probe disable
custom.story_probe city town_EN1
custom.story_probe status
custom.story_probe enter
custom.story_probe intro
custom.story_probe where
custom.story_probe spawn
custom.story_probe check 魅力
custom.story_probe check 技巧
custom.story_probe check 武力
custom.story_probe roll 魅力 95
custom.story_probe roll 技巧 5
custom.story_probe roll 武力 50
custom.story_probe learn 魅力
custom.story_probe learn 技巧
custom.story_probe learn 武力
custom.story_probe resolve 魅力
custom.story_probe strip
custom.story_probe restore
custom.story_probe reset
custom.story_probe talk 老板
custom.story_probe goal 2
custom.story_probe life status
custom.story_probe life list
custom.story_probe life force 老板 0
custom.story_probe life scene 1
custom.story_probe life stop
custom.story_probe life resume
custom.story_probe event list
custom.story_probe event force 2
```

要求：

- 命令返回文本**纯英文**；首参可弃（给了解析不出来就回落到默认并注明）。
- `enable` / `disable`：开关运行时入口；**默认关**，`enable` 之后目标城菜单才出现「入城（玩法测试）」；`disable` 后消失。
- `check <能力>`：空跑，打印这套检定用的技能 / 属性、当前成功率、门槛、情境加成；不改状态。
- `roll <能力> <0~100>`：强制下一次掷点，用于成功 / 失败验收（0~100 → 0~1）。
- `learn` / `resolve`：强制学 / 强制结算，用于跳过流程。
- `strip` / `restore`：单独测 nobody 剥夺 / 恢复。
- `status`：阶段 / 城池 / 三门是否已学 / 势力关系 / 天赋点 / 隐患 / 是否已剥夺 / 是否完成 / **每个 NPC 的互动步数**。
- `where`：打印场景锚点 —— 门外点 / 城门 / 目标点的实际坐标与彼此距离，以及用的是「场景实体」还是「兜底」（§3.1）。
- `talk <npc>`：不走近也能直接开这个 NPC 的对话（走原版 `StartConversation`，验节点树）；`<npc>` 认中文名或序号。
- `goal <0~4>`：强制设置屏幕角上那句目标提示（验五阶段文案）。
- `life status`：打印每个人当前状态（Idle / Performing / Talking / Reacting）、当前动作、下次触发倒计时。
- `life list`：列出行为表与桥段表（编号 + NPC + 动作 + 台词键）。
- `life force <npc> <序号>`：立刻播一条常驻行为（验动作 / 台词）。
- `life scene <id>`：立刻演一段双人桥段。
- `life stop` / `life resume`：停 / 恢复自发行为；`stop` 用来对照「没有行为是什么样」。
- `event list`：列出 6 起开场事件（4 双人 / 2 单人）与状态（未演 / 演出中 / 已演 / 已接入）。
- `event force <1~6>`：立刻演某一 起（跳过排队，验「!」标记与接入）。

## 13. 手工验收清单

1. 先 `enable`；原版战役（不带 Taikou）进 `town_EN1`，**菜单里才出现**「入城（玩法测试）」选项；点它。
1b. 开场：给一封信 + 一句旁白；`status` 显示妹妹名字、初始小额通缉。
1c. **场景锚点**：`where` 打印的门外点 / 城门 / 目标点坐标与 §3.1 表一致；玩家确实站在门外、面向城门；换城后如果打不出场景点，显示 `fallback` 且仍能跑完整序章。
1d. **背景弹窗**：点「入城（玩法测试）」先弹 4 句背景 + 【进城】/【再想想】；点【再想想】不进场景、不设标记。
1e. **随从开场**：有随从的玩家进场后看到随从站到侧后并说 3 句（头顶气泡）；没随从的玩家看到 3 句旁白；`intro` 可重播；读档重进不重复播。
2. 进中心场景：NPC 出现；玩家武器 / 金钱被收走，收到提示。
2b. 原版「在城里逛逛」进场景：没有这些 NPC、不收武器、不触发；只有额外选项触发。
2c. **自发行为**：站着不动看 60 秒 —— 至少 2 次单人动作、1 次双人桥段；`life status` 能看到各自的计时；`life stop` 后全场变木头，`life resume` 恢复。
2d. **桥段插话**：桥段演到一半走近 → 双方停一下看你并说一句话 → 桥段继续或散场；不出戏。
2e. **常驻台词**：靠近某个 NPC → 他主动说一句；30 秒内不重复。
2f. **事件钩子**：进场 12 秒后第一起事件（收保护费）开演，两个参与者头顶有「!」；走近 4 m 事件暂停并自动开对话；选【走开】事件继续；完全不介入时事件自己演完、标记消失，之后按 F 仍能进五步关系。
3. **对话入口**：走近 NPC 按 F → 原版对话界面 → `hero_main_options` 里出现入口选项 → 点进去是节点树（NPC 一句 + 几个 `PlayerLine`）。
3a. **五步推进**：搭话 → 打听（问过的那条不再出现）→ 求（转委托）→ 交差（给东西）→ 闲聊（口吻变热络）。
3b. **选项显示**：检定选项靠措辞给线索（不显示百分比）；条件不足的不注入；离开用原版自带。
3c. **检定分支**：`CheckType.SkillCheck` 的成功 / 失败各走一个节点，两段台词都能读到。
3d. **目标提示**：屏幕角上那句话随阶段变化；`goal 0~4` 能强制切换。
3e. 分别帮四家势力做小事：各学一手；`status` 可见；可以都帮；流浪剧团（寡妇）给贵族制服。
4. 魅力（乔装）：穿上贵族制服 → 走到 blocker 面前 → **一次属性检定**（他有没有看出破绽）；`check 魅力` 能看到技能 / 情境拆解；掷完显示掷点 / 门槛 / 成功或失败；**没有对话树**。
4b. 乔装身份：blocker 把你误认成贵族制服的主人（一句「阁下」）→ 让路；被识破 → 警觉。
4c. 通缉脱险：先用技巧 / 武力失败被通缉 → 乔装 → 守卫识别检定 → 过了不被抓。
4d. 冒充犯法（可选）：乔装状态犯事 → `status` 显示 suspect=目标，玩家通缉不涨；目标的势力 / 关系掉。
4e. 乔装遮通缉：初始通缉 >0 → 乔装 → 守卫识别失败 → 不被抓。
5. 钱（收买）：钱够就能过；钱不够选项灰掉；留下「被拿捏」flag。
5b. 对话类（魅惑 / 套话 / 谈判 / 说服 / 策反 / 劝降 / 虚张声势）本验证不做，不验收。
6. 技巧：出现「勾住墙头翻过去」；先过 Roguery 钩点检定，再用现有钩索翻过去；失败能换路；没有钩点时用扒窃备选。
6b. 技巧的备选：扒窃 / 撬锁 / 潜行各至少验一条；不行就明确标「本场景不可用」。
7. 武力：出现「动手」；先看 Vigor/Control 开局检定，再开现有非致命决斗；打赢能过；打输能换路；关系 -20。
7b. 武力的备选：击晕 / 威吓（开战前）/ 绑扛各验一条。
7c. 绑 / 扛：击晕或打赢后 → 武力检定 → 绑住 / 扛走；失败他挣脱。
7d. 委托：求势力 → 接「教训仇家」→ 完成 → 势力给东西 / 教一手；`status` 显示委托状态、仇家关系。
8c. 零活：替势力跑腿 → 几个第纳尔；用第纳尔打点 blocker。
8d. 属性对拼：每个 NPC 的 check 成功率因他的三维不同（同类对拼）；打听过 → 三个数字直接显示出来。
8. 选路反馈：对应势力关系 +、天赋点 +1；武力 结仇；魅力 / 技巧 隐患 flag。
9. 走到 blocker 身后目标点：序章完成；金钱恢复；再进不重开。
10. 中途存档 / 读档：阶段、帮忙、势力关系、旗标、已剥夺状态保留；完成时恢复。
11. 进酒馆 / 领主大厅不触发；别的城不触发；`disable` 后不触发。
12. 两个客户端各编译一次（1.2.12 与 1.5.x）；`run_all_checks.py` 通过；新增文本无 emoji、无裸中文。

## 14. 风险与待确认

**风险**：

- **生成重复**：目标 hero 可能已经在场上；先查再 spawn，避免一个 hero 两个 agent。
- **交互 UI 认不认 spawn 的 agent**：先用 `spawn` 命令实测；不认就改成「复用场上已有 agent + 移动」。
- **社交检定要求 Hero**：`ResolveAdversarialIntent` 对模板 NPC 会拒绝；4 个 NPC 全部用原版 Hero。
- **钩索需要钩点**：城门上方的墙 / 梁要能勾；场景没有合适钩点就退回扒窃备选，或第二阶段加一个 prefab 钩点。
- **扒窃条（备选）是独立 UI**：`OpenQuestPickpocket` 要照 `OpenStealInterface(Pickpocket)` 的 Layer / 输入 / 子弹时间 / 冻结写法，漏一个就可能卡输入；扒窃结果要回调或轮询武器槽判断。
- **决斗胜负判定**：`CombatManager` 有非致命仲裁，但「谁赢」要用 blocker 的击倒 / 血量 / 战斗状态组合判断；实机先验一遍。
- **装备剥夺 / 恢复**：只动场景 agent、不动战役英雄装备；不换衣服（2026-11-12 用户裁定：默认装备进场），只收武器 + 金钱；贵族制服仍由魅力线发。
- **物理阻挡是叙事**：blocker 不一定真挡住路；完成条件是「解决他 + 走到目标点」，第一阶段不做推回。
- **nobody 不锁背包**：玩家可以重新装备；序章短，第二阶段再锁。
- **小动作可能播不出来**：动作名在平民 action set 里不存在时，`ForcePlayAction` 是静默失败（只写了通道，画面没动）。先用 `life force` 一条一条验，播不出来就换同义动作或用 `SetPose` 摆姿势。
- **场景锚点可能不存在**：`sp_outside_near_town_main_gate` / `gate_outer` 在个别城镇场景里可能没有 → 走兜底（玩家原位、blocker 前方 8 m），玩法和验收不受影响；`where` 会打印用的是 `scene` 还是 `fallback`。
- **自发行为打断交互**：NPC 正在演桥段 / 播动作时玩家点他 → 必须先中断行为再进对话，否则动作会叠在对话上。做法：进 `StartInteraction` 前对该 agent 清动作并置 `Reacting`。
- **桥段挡路 / 出戏**：桥段点位不能放在玩家必经路线上；玩家 4 米内不起新桥段；同一时刻全场只演 1 段。
- **台词量**：约 70 句 × 中英两套 = 140 条本地化，注意铁律 14（`Languages/` 不得含 emoji / BMP 外字符）。
- **行为被原版 AI 抢**：NPC 若被原版城镇逻辑接管（走动 / 站位），我们的动作会被覆盖——所以只在 `IsInStayMode` 时播，且这几个 NPC 的站位由 `StoryProbeMissionBehavior` 钉住。

**待确认（需要策划拍板）**：

1. **三种能力用哪套现有检定**：本方案是 **魅力 = 乔装检定（Charm）+ 收买（钱）、技巧 = Roguery（钩索 / 扒窃 / 撬锁 / 潜行）、武力 = Vigor + Control（决斗 / 击晕 / 威吓 / 绑扛）**；技巧的主路是**钩索**。如果你要 武力 用 OneHanded、或技巧也用 Charm，告诉我。
2. **拦路者身份**：用目标城的 notable（帮派头目 / 商人，结仇是个人关系）还是守卫模板（结仇是势力关系）？本方案默认 notable。
3. ~~nobody 的剥夺程度~~（已定：只收武器 + 金钱，**不换衣服**，玩家默认装备进场）。
4. **贵族制服怎么给**：本方案是魅力 势力 直接递给你、当场换上（不依赖背包）；如果你要「去偷 / 买贵族制服」作为前置小玩法，告诉我。

## 15. 设计哲学四原则

- **反馈明确**：帮忙、成功率预览、掷点 / 门槛、成功 / 失败、势力关系 / 天赋点 / 结仇，全部当场可见；**每个选项点了都有台词回应**，失败也有话说（不是「失败了」三个字）。
- **自由感**：四家势力可全学；每种能力任选一个具体玩法；失败能换路，不锁死；**打听可以跳过**——你愿意直接偷 / 打 / 买也行，代价是拿不到线索。
- **NPC 接得住**：NPC 全是原版 Hero；对话 / 钩索 / 战斗都是现有系统；**玩家不找他说话时他也在过日子**（§5.7），插话有反应。
- **信息塑造目标**：玩家先被拦住，再去问势力；不是一上来就知道「三种能力」；屏幕角上只有一句话目标，不摆任务列表。

## 16. 审批人四问

- **结论是什么？** 在真实城镇中心场景做序章：**动机 = 找妹妹**；点「入城（玩法测试）」→ **先弹一段背景弹窗，点【进城】才加载场景** → 进场后**随从站到身边说 3 句交代目标**（队伍里没随从就用旁白，不阻断）→ nobody 在城门外被拦（背码头帮栽的小额通缉、0 钱、武器被收）→ 0 钱起步，靠零活赚第纳尔 / 求势力接「教训仇家」委托 → 完成才学一手 → 用魅力（乔装身份）/ 技巧（钩索 / 扒窃 / 撬锁 / 潜行 / 偷属性道具）/ 武力（决斗 / 击晕 / 威吓 / 绑扛）/ 钱（收买）过 blocker → 门内完成；每个 NPC 的武力 / 技巧 / 魅力三个数值不同，检定是同类对拼；钱只解决「钱能解决的那一段」；检定全部复用 mod 已有的属性检定；对话类不成熟，本验证不做。
  **玩家怎么和 NPC 打交道见 §5.6**（**先出事再搭话**：§4.1.5 的 6 起开场事件带「!」标记，玩家凑近自动接入 → 再按 F 走原版对话流注入的五步关系：搭话 / 打听 / 求 / 交差 / 熟人 → 检定分成功 / 失败两条节点 → 屏幕角一句目标）。
