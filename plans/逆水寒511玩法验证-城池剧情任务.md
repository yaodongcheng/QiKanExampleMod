# 市井 · 城门序章 —— 需求文档

> **状态**：待审批，未实施。审批通过前不动代码。
> **一句话**：在真实城镇场景里做一段 5 分钟的序章——玩家是个进不了城的穷光蛋，靠嘴、手、拳头或钱，从城门口四家手里换来一条进城的路。
> **三个名词**：
> - **三种能力**：魅力（人际 / 身份）、技巧（偷 / 翻 / 撬 / 潜）、武力（打 / 吓 / 绑 / 扛）
> - **钱是第四手段**，不属于任何能力，只解决「钱能买的那一段」
> - **一次检定**：玩家某类属性 vs NPC 同一类属性，掷点 ≥ 门槛即成功

---

## 一、这段要验证什么

| 要验证的 | 怎么落 | 判据 |
|---|---|---|
| 关卡足够简单 | 1 个守门人 + 4 家势力 + 1 个目标点 | 玩家 5 分钟走完 |
| **硬闯必败** | 第一次进城守卫数值碾压，必输 → 进牢 | 玩家第一次不可能打进去 |
| 四家各有一条活路 | 帮一家做事 → 换来一样工具 / 一手本事 | 每家的路都能通 |
| 帮忙是交易不是白给 | 求 → 派一件事 → 办完才给 | 不办事不给 |
| 三种能力各有多条玩法 | 每种能力 4~5 个现有玩法 | 每种至少一条能过 |
| 检定用现有系统 | 复用 `SingleRollResolver` / `AgentStatsHelper` | 不新建骰子 / 属性 |
| 失败也是路线 | 失败了换一条路，不锁死 | 每种失败后仍能继续 |
| 玩家看得懂 | 先出事 → 凑过去 → 才搭话 | 玩家不需要主动找人聊天 |

## 二、玩家流程

```
【第一次进城】
点「入城（玩法测试）」
  → 弹窗：你被这座城通缉，正门进不去 →【硬闯】
  → 场景里只有守门人：拦住你 → 动手 → 你必败（数值碾压）
  → 黑屏：「你被打晕，扔进了牢里。」
  → 弹窗：同监的老囚递给你一套旧衣服和一块面罩 →【换上】
  → 出狱：装备被没收，只剩这身旧衣 + 面罩（遮脸 = 不被通缉画像认出来）

【第二次进城 —— 序章正式开始】
  → 酒馆自动招一个随从（免费）→ 随从说 3 句交代目标
  → 城门口：有人正在被收保护费（头顶「!」，气泡在弹）
  → 玩家凑过去 → 事件暂停 → 自动开对话 → 插话
  → 认识四家之一 → 打听妹妹线索 → 求一样东西 → 他派一件事
  → 办完回来交差 → 拿到工具 / 学了一手
  → 用魅力 / 技巧 / 武力 / 钱过守门人
  → 走到门内 → 恢复金钱 → 序章完
```

**第一次为什么必败**：这是教学。玩家必须先亲身撞一次墙，才会去想「明着进不去，那就别明着进」——后面魅力的遮面、技巧的翻墙、武力的硬打、钱的打点才有意义。

## 三、场景与进入

### 3.1 目标城与场景

- **目标城**：默认 `town_EN1`（Epicrotea，帝国城镇，1.2.12 与 1.5.x 都有），`config.json` 可改。
- **场景**：该城 center = **`empire_town_g`**。来源：`Modules\SandBox\ModuleData\settlements.xml` → `town_comp_EN1` → `<Location id="center" scene_name="empire_town_g">`。
- **只在 center 触发**：tavern / lordshall / keep 不触发；别的城不触发。

### 3.2 进入流程（两进：第一次必败，第二次才是序章）

菜单选项「入城（玩法测试）」**默认不出现**，只在目标城且打过 `custom.story_probe.enable` 后出现；`disable` 后消失。原版「在城里逛逛」永远不加载序章。

#### 3.2.1 第一次进城：必败教学

| 步 | 发生什么 | 实现 |
|---|---|---|
| ① 弹窗 | 标题「城门」+ 4 句背景 +【硬闯】/【再想想】 | `InformationManager.ShowInquiry` |
| ② 进场 | 场景里**只有守门人**——四家、事件、目标点都不布置 | `Phase = FirstAttempt` |
| ③ 对话 | 守门人：「通行文书。」→ 你「我要进城」→ 他动手 | 原版对话流注入 |
| ④ 必败 | **强制失败**：不掷骰，直接播被击倒（`KnockoutFlow.PlayStrikeAnim`）→ 你倒地 | 不给玩家翻盘的机会 |
| ⑤ 黑屏 | 淡出 + 旁白「你被打晕，扔进了牢里。」 | MissionScreen 淡出 |

**为什么强制失败**：「打不过」如果只是数值设定，操作好的玩家仍可能赢；所以这一场的武力检定**直接判负**（`forceFail`），保证教学一定成立。

**弹窗正文**（4 句）：

```
三个月前，你妹妹进城做工，再没消息。
你一路找来，钱在路上被偷光了，身上只剩她最后一封信。
更糟的是，码头帮栽了你一桩小事——城门上挂着你的小额通缉。
正门是进不去了。城门外的几家，各有各的门路。
```

#### 3.2.2 牢里：换装束 + 面罩

黑屏之后弹第二个窗：

```
同监的老囚把一套旧衣服和一块面罩塞给你：
「想进城？先让人认不出你。」
【换上】【我再想想】
```

- 点【换上】→ **装备与钱被没收**（武器 / 甲 / 钱袋全没）→ 得到旧衣 + 面罩 → 出狱，回到城门外。
- **面罩的作用 = 遮脸**：通缉画像认不出你（`Disguised = true`），这是后面「正门走进去」的基础。
- 点【再想想】→ 留在牢里，弹窗再出现（不锁死，也不能跳过）。

#### 3.2.3 第二次进城：序章开始

| 步 | 发生什么 | 实现 |
|---|---|---|
| ① 随从 | **酒馆自动招一个随从**（免费），他从酒馆跟你出来 | 目标城酒馆里挑一个 wanderer → `AddCompanionAction`；没有可招的 → 跳过，用旁白 |
| ② 随从说话 | 站在玩家左后 1.5 m，说 3 句（间隔 2.5 秒，头顶气泡） | `SpeechChannel.Say` |
| ③ 布置场景 | 四家代表 + 6 起事件循环 + 目标点全部就位 | 完整序章 |

- **随从台词**：`就是这儿了。你妹妹三个月前进的这座城。` / `正门挂着你的通缉——硬闯等于自投罗网。` / `先跟门口这几家搭上线。帮谁，谁教你一手。`
- **强制随从**：这一次不判断「玩家有没有随从」——**没有就从酒馆招一个**，保证目标一定有人讲。
- 随从只播一次（`IntroPlayed` 存状态）；`custom.story_probe intro` 可重播；`custom.story_probe phase first|second` 可强制切阶段。

**文本键**（走 `LWNTextHelper`）：`LWN_story_intro_inquiry_title/_body/_btn_go/_btn_back` · `LWN_story_intro_line_1..3` · `LWN_story_intro_narr_1..3` · `LWN_story_jail_inquiry_body/_btn_wear`。

**触发判定**（`StoryProbeMissionBehavior.OnMissionBehaviorInitialize`）：`Enabled` 为真 → `EnterViaOption` 为真（否则直接 return）→ 当前定居点 = 目标城 → 当前地点 = center → 按 `Phase` 布置第一次（只有守门人）或第二次（完整序章）→ 消费标记。

### 3.3 场景锚点（已从场景 XML 实测，不用开 ModKit）

场景文件：`Modules\SandBoxCore\SceneObj\empire_town_g\scene.xscene`（6299 个实体，纯 XML）。

| 用途 | 场景实体 | 坐标 (x, y, z) | 朝向 |
|---|---|---|---|
| 玩家开场点（门外） | `sp_outside_near_town_main_gate` | (435.367, 386.905, 4.393) | −2.039 |
| 城门 | `european_castle_gate_outer_l2` | (459.840, 375.480, 5.670) | 1.131 |
| 守门人站位 | `sp_guard` | (451.579, 375.941, 4.752) | 0.766 |
| 目标点（门内） | `sp_guard` | (470.311, 374.142, 5.686) | −2.421 |

实测距离：门外 → 城门 **27.0 m**；城门 → 门内 **10.5 m**。

**运行时按名字查，不写死坐标**：先 `Scene.FindEntityWithTag("sp_outside_near_town_main_gate")`；城门遍历实体取名字含 `gate_outer` 且不含 `_l1`（`_l1` 是 LOD）。一个都找不到就走兜底：玩家原位不动、守门人在前方 8 m、目标点在守门人身后 3 m。`custom.story_probe where` 打印用的是场景点还是兜底。

**两次进城都用这张表**：第一次只有守门人站在 `sp_guard`（门外侧）；第二次四家代表摆在玩家身后两侧的摊位区（这一片就是市场，`sp_merchant` / `sp_npc_wait` 密集）。

## 四、世界：城门口的四家

**四家是城里的组织势力，不是家族。** 数据上每家可挂一个 `Clan` 当身份载体（关系 / 声望判定现成），叙事里只叫「公会 / 会 / 剧团 / 帮」。

| 势力 | 性质 | 城门口的代表 | 对应能力 | 和谁敌对 |
|---|---|---|---|---|
| **捉刀人**（友好） | 中间人 / 掮客，跑腿、找门路、写状子 | 当铺老板 | **钱 + 人脉** | 码头帮 |
| **夜行会**（中立） | 小偷 / 撬锁 / 扒窃 | 寡妇的儿子（小贼） | **技巧** | 码头帮 / 野贼 |
| **流浪剧团**（中立） | 剧团 / 舞姬，靠表演和魅力 | 寡妇（领班） | **魅力** | 码头帮 / 对台剧团 |
| **码头帮**（敌对） | 水上脚夫结成的帮派，收数 / 放贷 / 打手 | 守门人（blocker）、thug；屠户是叛逃者 | **武力** | 其余三家 |

英文 fallback：The Fixers · The Nightwalkers · The Players · The Dockhands（键 `LWN_faction_*`）。

### 4.1 帮忙换手艺

玩家求一家要东西 → 对方派一件小事（教训他的仇家）→ 办完才给。

| 你求谁 | 求什么 | 他让你做什么 | 仇家 | 完成得到 | 后果 |
|---|---|---|---|---|---|
| 当铺老板（捉刀人） | 钱 + 消息 | 收一笔欠账 | debtor（码头帮的收数） | 第纳尔 + 消息 | 捉刀人 +；debtor − |
| 儿子（夜行会） | 钩索 | 教训抢他生意的野贼 | 野贼 | 钩索 | 夜行会 +；野贼 − |
| 寡妇（流浪剧团） | 一个能进城的身份 | 砸对台的招牌 | 对台领班 | 贵族制服 + 通行文书 | 剧团 +；对台 − |
| 屠户（叛逃者） | 武器 / 教两手 | 教训砸他摊的 thug | thug | 武器 + 绳子 | 屠户 +；码头帮 − |

- **不白给**：不办事不给；可以花钱或硬闯，但那不是人情。
- **可以都帮**，也可以只帮一家；帮忙本身不检定、不花钱。
- **序章先做屠户那条**（教训 thug）：目标就在门口，武力的决斗 / 击晕 / 绑扛都现成；其余三家留接口。
- 委托形状复用 `CommissionQuest` / `CommissionData`（giver / target / reward），不跑程序化生成器。

### 4.2 每个人知道妹妹的一截

| 谁 | 他知道的 |
|---|---|
| 当铺老板 | 她当过一个镯子，还没赎（当票） |
| 寡妇 | 卖过她一张通行文书，后来有个水手把她领走 |
| 儿子 | 上个月夜里，码头帮押着个女的从后巷过去 |
| 屠户 | 那天夜里他们往码头去了 |

**码头帮是带走她的那条线**——序章结束时把线索引到「第一张凭证」。

## 五、玩家能做什么：三种能力 + 钱

### 5.1 总表

| 手段 | 玩法 | 用什么判定 |
|---|---|---|
| **魅力** | 乔装（冒充通行 / 通缉脱险 / 冒充犯法） | Charm 对 Charm |
| **技巧** | 钩索 / 扒窃 / 撬锁 / 潜行 / 偷属性道具 | Roguery 对 Roguery |
| **武力** | 决斗 / 击晕 / 威吓 / 绑起来·扛走 | Vigor+Control 对 Vigor+Control |
| **钱** | 收买（打点 / 消息 / 酒） | **不检定**，钱够就过 |

**嘴上的事在对话里，手上的事在对话外**：
- 对话里 = 打听 / 求 / 交差 / 闲聊 / 亮身份
- 对话外 = 扒窃（扒窃条）、动手（拔刀）、绑 / 扛（动作键）、收买（钱够直接给）、乔装（换装）

### 5.2 魅力：遮面与冒充

**两件事，同一套机制（`Disguised` 旗标），用途不同**：

| 做法 | 来源 | 对付什么 | 检定 |
|---|---|---|---|
| **遮面**（旧衣 + 面罩） | 出狱时老囚给的 | 通缉画像认不出你——正门能站，守卫不会直接抓 | 魅力对拼（被盘问时） |
| **冒充**（贵族制服 + 通行文书） | 寡妇给的 | 守门人把你当成某位大人，直接让路 | 魅力对拼（他信不信） |

- **遮面是底子**：没有它，通缉状态下走正门直接被认出来；有了它才站得住门口。
- **冒充是升级**：穿贵族制服 + 通行文书（存 `DisguiseHeroId`），守门人一句「阁下」让路。
- **通缉脱险**：走别的路失败被通缉后，遮面 / 冒充都能让守卫认错人。
- **冒充犯法**（可选）：乔装状态下犯事，罪名记在「那个人」头上（`FrameSuspect` / `WorldEvent` 的 suspect 字段），你的通缉不涨。
- **失败**：被识破 → 警觉 / 被抓；可换收买或其他路。
- **后续伏笔**：被冒充的人以后会来找你（本阶段只存 `DisguiseHeroId` + 次数）。

### 5.3 技巧：五个玩法

| 玩法 | 怎么做 | 成功 | 失败 |
|---|---|---|---|
| **钩索**（主路） | 儿子给你钩索后，勾住城门上方的墙 / 梁翻过去 | 守门人没反应过来 | 钩空 → 他察觉 |
| 扒窃 | 扒窃条扒走他的武器 / 钥匙 | 他手里没家伙 | 察觉 |
| 撬锁 | 绕到侧门开锁 | 从背后过去 | 发出声响；**场景没真门就不做这条** |
| 潜行 | 蹲下趁他转头溜过去 | 没被看见 | 被看见 |
| 偷属性道具 | 扒窃条偷 NPC 背包里那件（见 §5.6） | 拿到并 +1 对应技能 | 被目击 → 犯罪 |

### 5.4 武力：四个玩法

| 玩法 | 怎么做 | 结果 |
|---|---|---|
| **决斗**（主路） | 先一次武力检定看开局（成功 = 他起手慢）→ 非致命决斗 | 赢：让路；输：可换路；**无论胜负关系 −20** |
| 击晕 | 从背后 / 趁不备放倒 | 成功倒地；失败他反击 |
| 威吓（开战前） | 亮兵器逼上前，一次武力检定 | 成功他退开（关系 −10）；失败直接开打 |
| 绑 / 扛 | 制服后用现有绑人 / 扛人把他挪开 | 武力检定；失败挣脱 / 喊人 |

### 5.5 钱：收买与零活

- 玩家**一开始 0 钱**。
- **零活**（不是委托）：跑腿 / 搬货 / 送信 / 把风，每次几个第纳尔。
- **能买**：守门人打点（100 第纳尔）、消息（几十第纳尔）、酒。
- **不能买**：势力的工具 / 手艺（只换人情）、仇家的恩怨、不吃钱的人（如屠户）。
- 钱不够时那条选项**不注入**。

### 5.6 属性道具：偷东西也能涨值

- 每个 NPC 背包里一件（原版书 / 药剂 / 护符当载体，不给新资产）。
- **偷到或委托奖励**得到 → 用掉 / 装备后 **+1 对应技能**（`Hero.AddSkillXp`），不新造属性系统。
- **每件唯一**，不能刷；偷有风险（被目击 = 犯罪 / 警觉）。

| 谁 | 道具 | +1 |
|---|---|---|
| 寡妇 | 护符 / 假印 | Charm |
| 儿子 | 细钩 / 撬锁包 | Roguery |
| 屠户 | 磨刀石 / 护腕 | Vigor / OneHanded |
| 当铺老板 | 账本 | Trade / Charm |

## 六、怎么把玩家拉进来：事件 → 对话

**问题**：玩家站在城门口不会主动找人搭话——他不知道该干嘛。**解法：先出事，再搭话。**

> 本章全部发生在**第二次进城**；第一次场景里只有守门人。

### 6.1 开场 6 起事件

| # | 事件 | 谁 | 玩家 10~20 m 外看到什么 | 接入后 |
|---|---|---|---|---|
| 1 | 收保护费 | thug → 当铺老板 | 两个气泡对着弹，推搡，老板后退 | 第一次和**捉刀人**说话 |
| 2 | 砸摊 | thug → 屠户 | 肉案被掀，屠户举刀，吼声 | **武力**路入口 |
| 3 | 骂街 | 剧团领班 ↔ 对台领班 | 隔街对骂，越走越近 | **魅力**路入口 |
| 4 | 抓小偷 | 当铺老板 → 儿子 | 揪着领子，小孩挣扎 | **技巧**路入口 |
| 5 | 一个人发愁（单人） | 当铺老板 | 反复翻账本、叹气 + 头顶「!」 | 钱路 / 委托引子 |
| 6 | 一个人在收拾（单人） | 屠户 | 扶肉案、蹲下捡东西 + 头顶「!」 | 武力路 / 委托引子 |

**三条硬规则**：

1. **不推进**：事件开演后停在开头状态**自循环**——两个人一直对着吵（`act_conversation_aggressive_loop`）、气泡每 3~5 秒冒一句；单人就一直重复发愁的动作。**不会自己散场，也不会自己结束**。
2. **只有玩家介入才推进**：走近 4 m → 暂停 → 对话 → 选择 → 才收尾。
3. **同时只循环 1 起**：进场 12 秒起第一起；玩家走远（>20 m）才换下一场。

**远距离可见**：
- 循环里持续出声（`SpeechChannel.Say`，`Warning` 优先级）——10~20 m 外就能看到两个气泡反复弹。
- 动作循环播放（`ForcePlayAction`）。
- 背对着也知道：现有 `AgentHudMissionView` 的 `FarHearDistance`（30 m）会在屏幕给一行提示。
- 单人事件没对手可吵，只能靠「!」+ 反常举动吸引人。

**头顶「!」**：参与者挂标记，复用现有头顶 HUD（`AgentHudVM.HasEventMark` + `AgentHudNearby` 加一个图标位），不新建 UI；事件结束或玩家接入后消失；没轮到的人不带。

### 6.2 玩家接入

| 玩家行为 | 系统反应 |
|---|---|
| 走进 4 m | 事件**暂停**，双方看向玩家 |
| 停约 2 秒 | **自动开对话**（原版对话流） |
| 第一句 | 事件里的人冲你说一句（「看什么看」/「客人，稍等」） |
| 选项 | 【帮这边】【帮那边】【问怎么回事】【走开】 |
| 选【走开】 | 回到循环 |

**接入 = 搭话**：这就是五步关系里的第 ① 步；之后按 F 才能继续打听。不介入也不会卡——它一直循环，没有「错过」。

### 6.3 对话：走原版对话流注入，不自建面板

| 步 | 玩家做了什么 | 走哪个现有件 |
|---|---|---|
| 1 | 从事件接入，或走近按 **F** 交谈 | 原版 `StartConversation` |
| 2 | `ConversationEntryPatch` 在 `hero_main_options` 挂一个入口选项 | `DialogueInjector.InjectScript`（Gateway 模式） |
| 3 | 点进去 → 节点树（NPC 一句 + 几个玩家选项） | v2 模型：`DialogueNode` + `DialogueTransition` |
| 4 | 点选项 → 执行 → 路由到下一个节点或关窗 | `CheckType.None` / `SkillCheck` |

- **注入统一收口 `StartConversation`**：调用方只设 trigger，不自己 `InjectScript` 再 `StartConversation`（会双重注入）。
- **数据**：`ModuleData/DesignData/Dialogues/story_probe_<npc>.json`，一个 NPC 一个文件。

**选项的写法**：
- 每条就是一句玩家台词，前面带方括号标类别：`【打听】三个月前，有没有见过一个穿青布的姑娘？`
- **不显示百分比**（原版对话流不支持）：靠措辞给线索——`【试着唬他】没你的事，让开。`
- 条件不满足的选项**不注入**（不是置灰）；想说明原因，让 NPC 那句台词点一句。
- 问过的事不再注入；【离开】用原版自带。

### 6.4 五步关系

| 步 | 节点 | 玩家选项 | 什么时候注入 | 结果 |
|---|---|---|---|---|
| ① 搭话 | `<npc>_intro` | 【搭话】先问一句 | 第一次见 / 事件接入 | 自我介绍 + 态度；解锁 ② |
| ② 打听 | `<npc>_ask1..3` | 【打听】……（每人 2~3 条） | 搭过话 | 妹妹线索 / 他的三维 / 怎么过门；不检定 |
| ③ 求 | `<npc>_deal` | 【求】把东西借我 / 教我一手 | 打听够了 | 派一个委托 |
| ④ 交差 | `<npc>_turnin` | 【交差】事情办完了 | 委托已完成 | 给东西 / 教一手；关系 + |
| ⑤ 熟人 | `<npc>_chat` | 【闲聊】【还有活吗】 | 交差之后 | 口吻变热络，给钩子 |

没打听就求 → 走「拒绝」分支（「你先去问问别人」），不锁死。

### 6.6 台词规范

- **三段式**：选项标签 = 玩家想做的事（第一人称、短）· NPC 回应 = 角色口吻（一句，能听出职业和处境）· 旁白 = 世界反馈（只在大事发生时才出现）。
- **口吻定位**：

| NPC | 口吻 | 忌 |
|---|---|---|
| 当铺老板 | 客气里带账本，句句不离钱 | 文绉绉 |
| 寡妇 | 演戏的腔，刀子嘴，护短 | 骚气（她是领班，不是花魁） |
| 儿子 | 快嘴、爱吹、心虚 | 老成 |
| 屠户 | 闷、硬、话少，一次不超过两句 | 长篇大论 |
| 守门人 | 冷硬短句，不说整话 | 解释自己 |

- **同一个人两套说法**：第一次见（防着你）→ 交差后（认你）。
- **失败台词必须写**：失败不是「没事发生」，是「他记住了你」「他警觉了」。
- **键名**：`LWN_story_<npc>_<步>_<序>`，中英各一套，全走 `LWNTextHelper`。量级：6 个 NPC × 8~12 句 ≈ 70 个键。

### 6.7 NPC 主动开口

| 触发 | 说什么 |
|---|---|
| 玩家走近 3 米 | 寡妇「看戏吗？站远点也行，别挡人。」/ 儿子「嘘——」/ 守门人「站住。」 |
| 玩家掏出武器 | 守门人「收起来。」/ 屠户「在我摊子前头别动刀。」 |
| 玩家交差后 | 老板「来了？账我记着呢。」 |
| 冷却 | 每人 30 秒；走 `SpeechChannel.Say`（模板，不默认调 LLM） |

### 6.8 屏幕目标

左上角一句话，随进度换一行（不做任务栏）：

| 阶段 | 那句话 |

### 7.1 三层行为

| 层 | 谁做 | 频率 | 玩家看到什么 |
|---|---|---|---|
| 常驻动作 | 每人自己 | 8~20 秒一次 | 拨账本、挥手、探头、抖腿；偶尔一句吆喝 |

### 7.4 对玩家的反应

| 触发 | 反应 | 冷却 |
|---|---|---|
| 进 3 米 | 转头看 + 一句招呼 / 警告 | 30 秒 |
| 掏出武器 | 后退半步 + 一句警告 | 10 秒 |
| 犯罪（偷 / 打） | 中断行为 → 喊人 / 逃跑（`NpcSightSystem` + 警戒） | — |
| 交差之后 | 招呼换热络版 | — |

### 7.5 技术口径

- 一个 `StreetLifeDirector`，挂在 `StoryProbeMissionBehavior.OnMissionTick` 里，不新建 MissionBehavior。
- 每人一个状态：`Idle` / `Performing` / `Talking` / `Reacting`。
- 播动作：`ForcePlayAction`，**只在站桩（`IsInStayMode`）时播**——走路 / 打架 / 对话时让位。
- 说话：`SpeechChannel.Say(..., forwardToNearby: false)`（只冒泡，不进附近频道）。
- 走位：投事件给 `AgentAIController.SendEventToAgent`，不直接碰 Brain 队列。
- **不冻结 AI**：城镇里 `SetIsAIPaused` 会把行走输入冻在最后一帧（人反而直走不停）。
- 只接管我们 spawn 的这几个人，**原版村民 / 守卫一点都不动**。
- 行为写进 `StoryProbeDefs` 的静态表（`StreetLifeDef` / `StreetSceneDef`），加一条 = 加一行。

## 八、检定

### 8.1 同类对拼

**检定 = 玩家的某类属性 vs NPC 的同一类属性**，各比各的：

| 玩家 | NPC 拿什么 | 底层数值 |
|---|---|---|
| 武力 | 武力 | Vigor + Control |
| 技巧 | 技巧 | Roguery |
| 魅力 | 魅力 | Charm |

```
chance    = playerAttr / (playerAttr + npcAttr)     玩家侧钳制 [5%, 95%]
threshold = 1 − chance                             掷点 ≥ threshold 即成功
```

**NPC 三维直接填数值**（不读随机生成的 Hero 技能，保证难度一致）；模板 NPC 按 Level 估算。

### 8.2 NPC 三维表（初值，实机再调）

| NPC | 武力 | 技巧 | 魅力 | 玩家该用什么 |
|---|---|---|---|---|
| 守门人 | 70 | 30 | 50 | 硬拼难；技巧最顺 |
| 屠户 | 70 | 50 | 30 | 打他难；骗他容易 |
| 寡妇 | 30 | 50 | 70 | 吓她容易；嘴炮难 |
| 儿子 | 30 | 70 | 30 | 偷他难；骗他容易 |
| 当铺老板 | 30 | 50 | 70 | 吓他容易 |
| 对台领班 | 30 | 50 | 70 | 偷 / 吓比嘴炮容易 |
| 野贼 | 30 | 70 | 50 | 骗他比偷他容易 |
| thug | 70 | 30 | 30 | 绑 / 骗比硬打容易 |
| debtor | 50 | 50 | 50 | 三条路差不多 |

**打听 = 把这张表的数字告诉他**：聊过之后 `check` 里显示这个 NPC 的三维，玩家自己判断走哪条路。
**钱不参与对拼**：收买不检定。

### 8.3 结果与显示

- **只有成功 / 失败**（现有检定本身就是 bool），不做大成功 / 大失败。
- 对话节点里：`CheckType.SkillCheck` → 成功 / 失败各走一个节点，两段台词都要写。
- **不显示百分比**（原版对话流限制）；要看精确数值用 `custom.story_probe check`。
- 掷完提示：「掷点 X% vs 门槛 Y% → 成功 / 失败」（铁律 17：不写成功率以外的难度措辞）。

## 十、nobody 状态

**剥夺发生在坐牢那一刻，不是进场景时**：

| 时机 | 发生什么 |
|---|---|
| 第一次进城被打倒 | 进牢：**武器 / 甲 / 钱袋全部没收**（记原始值，序章完成恢复） |
| 出狱时 | 只留**旧衣 + 面罩**（魅力线「遮面」的底子） |
| 第二次进场 | 已经是 nobody，不必再收一次 |

- **只动场景 agent 与英雄身上那套**：战役装备不销毁，记下来最后还。
- **中途存档 / 读档**：保留「已剥夺」状态。
- **通知**：出狱时一条「你身上没武器，钱袋也空了」。
- **已知限制**：不锁背包（玩家能从背包重新装备）；武力走 Peace 决斗时现有逻辑会把随从扫到一边。

### 11.3 实施顺序

| 步 | 内容 | 验收 |
|---|---|---|
| 1 | 入城选项 + **第一次必败**（弹窗 → 场景里只有守门人 → 强制失败 → 黑屏）+ **牢房换装弹窗**（旧衣 + 面罩 → 没收装备与钱）+ **第二次自动招随从 + 3 句** + 命令 | 第一次必输；出狱只剩旧衣 + 面罩；第二次随从说 3 句；原版进城不加载 |
| 2 | 事件钩子 + 市井行为：6 起事件循环、头顶「!」、暂停接入、常驻动作、随机桥段、对玩家反应 | 进场 12 秒看到第一起；不介入一直循环；走近自动开对话 |
| 3 | 对话：原版注入 + 五步关系 + 每个 NPC 的节点与台词 + 屏幕目标 | 按 F 有入口；五步能推进；检定分成功 / 失败；目标随阶段换 |
| 4 | 魅力（乔装）+ 钱（收买） | 乔装检定有成功 / 失败；钱够就能过、不够不出现 |
| 5 | 技巧：钩索 → 扒窃 / 撬锁 / 潜行 / 偷属性道具 | 钩索能翻过去；失败能换路 |

| 7 | 反馈 + 目标点 + 恢复金钱 + 存档 | 关系 / 天赋点 / 隐患可见；完成后恢复 |

### 12.1 命令（游戏内控制台）

```

custom.story_probe disable
custom.story_probe city town_EN1
custom.story_probe status
custom.story_probe enter
custom.story_probe intro
custom.story_probe phase first
custom.story_probe phase second
custom.story_probe where
custom.story_probe spawn
custom.story_probe check 魅力
custom.story_probe check 技巧
custom.story_probe check 武力
custom.story_probe roll 魅力 95
custom.story_probe roll 技巧 5
custom.story_probe roll 武力 50
custom.story_probe learn 魅力
custom.story_probe learn 技巧
custom.story_probe learn 武力
custom.story_probe resolve 魅力
custom.story_probe strip
custom.story_probe restore
custom.story_probe reset
custom.story_probe talk 老板
custom.story_probe goal 2
custom.story_probe life status
custom.story_probe life list
custom.story_probe life force 老板 0
custom.story_probe life scene 1
custom.story_probe life stop
custom.story_probe life resume
custom.story_probe event list
custom.story_probe event force 2
```

- 返回文本**纯英文**；首参可弃。
- `check <能力>`：打印技能 / 属性、成功率、门槛、情境；不改状态。
- `roll <能力> <0~100>`：强制下一次掷点（验成功 / 失败）。
- `learn` / `resolve`：跳过流程强制学 / 强制结算。
- `strip` / `restore`：单独测 nobody。
- `status`：阶段 / 城池 / 三门 / 关系 / 天赋点 / 隐患 / 是否剥夺 / 是否完成 / 每个 NPC 的步数。
- `where`：打印门外点 / 城门 / 目标点坐标与距离，以及用的是场景点还是兜底。
- `talk <npc>`：不走近直接开对话（验节点树）。
- `phase first|second`：强制切到第一次（必败教学）或第二次（完整序章），不用重开档。
- `goal <0~4>`：强制切屏幕目标。
- `life status|list|force|scene|stop|resume`：行为调试。
- `event list|force <1~6>`：事件调试。

### 12.2 手工验收清单

1. `enable` 后进 `town_EN1`，菜单出现「入城（玩法测试）」；点它**先弹窗**，点【再想想】不进场景。
1a. **第一次必败**：进场只看到守门人（**没有四家和事件**）；谈话后动手 → **必败倒地** → 黑屏；`phase first` 可直接复现。
1b. **牢房弹窗**：黑屏后弹「旧衣服和面罩」；点【换上】→ 出狱、装备与钱被没收、只剩旧衣 + 面罩（`status` 可见 `Disguised`）。
1c. **第二次**：再进 → **酒馆自动招到一个随从** → 随从说 3 句 → 四家与 6 起事件就位；`phase second` 可直接跳到这一阶段。
2. `where` 打印的坐标与 §3.3 一致；玩家站在门外、面向城门；换城打不出场景点时显示 `fallback` 且仍能跑。
3. 第二次进场：玩家穿旧衣 + 面罩、空手、0 钱；收到提示。
4. 原版「在城里逛逛」进场景：不加载玩法。
5. **事件**：进场 12 秒第一起开演，参与者头顶「!」，气泡每 3~5 秒一句；**不介入就一直循环、不推进、不散场**；走近 4 m 暂停并自动开对话；选【走开】回到循环。
6. **事件类型**：4 起双人（收保护费 / 砸摊 / 骂街 / 抓小偷）与 2 起单人（发愁 / 收拾）都能看到；单人只靠「!」和反常举动。
7. **对话**：按 F → 原版界面 → 入口选项 → 节点树；五步能推进；问过的不再出现；检定成功 / 失败走不同节点；屏幕目标随阶段换。
8. **自发行为**：站着不动 60 秒，能看到常驻动作与随机桥段；`life stop` 后变木头。
9. **魅力**：穿贵族制服 → 守门人误认（「阁下」）→ 让路；被识破 → 警觉；通缉状态乔装能脱险。
10. **钱**：钱够打点就过；不够那条选项不出现；留下「被拿捏」。
11. **技巧**：钩索翻过去；扒窃 / 撬锁 / 潜行各验一条；失败能换路。
12. **武力**：决斗打赢能过；打输能换路；关系 −20；击晕 / 威吓 / 绑扛各验一条。
13. **委托**：求屠户 → 教训 thug → 交差拿到武器 + 绳子；`status` 显示委托状态与关系。
14. **属性对拼**：不同 NPC 的 `check` 成功率不同；打听过之后三个数字直接显示。
15. **选路反馈**：势力关系 / 天赋点 / 结仇 / 隐患都能看到。
16. 走到门内目标点：序章完成、金钱恢复；再进不重开。
17. 存档 / 读档：阶段、步数、关系、旗标、剥夺状态保留。
18. 酒馆 / 领主大厅 / 别的城不触发；`disable` 后不触发。
19. 两个客户端各编译一次；`run_all_checks.py` 通过；新增文本无 emoji、无裸中文。

## 十三、风险与待确认

**风险**

| 风险 | 应对 |
|---|---|
| 目标 hero 已在场上 | spawn 前先查，有就移动不重复生成 |
| 社交检定要求 Hero | 代表全用原版 Hero，不用模板 |
| 场景锚点不存在 | 走兜底（玩家原位、守门人前方 8 m），`where` 打印 `fallback` |
| 城镇没有可勾的墙 / 梁 | 退回扒窃 / 潜行；或第二阶段加一个 prefab 钩点 |
| 决斗胜负判不准 | `CombatManager` 有非致命仲裁，实机先验一遍 |
| 小动作播不出来 | 动作名不在平民 action set 里时静默失败；用 `life force` 逐条验，不行换动作或 `SetPose` |
| 行为打断交互 | 进对话前对该 agent 清动作并置 `Reacting` |
| 桥段挡路 | 点位不放在必经路线；玩家 4 米内不起新桥段 |
| 台词量 | 约 70 句 × 中英 = 140 条；注意不得含 emoji / BMP 外字符 |
| 玩家不锁背包 | 序章短，第二阶段再做 |
| **酒馆招不到随从** | 城里的 wanderer 可能已被招走 / 没有 → 跳过招募，用旁白兜底，不阻断 |
| **面罩找不到合适物品** | 原版头部件两轮查找；找不到就用兜帽 / 围巾替代，效果只看 `Disguised` 旗标 |

## 十四、设计原则对照

- **反馈明确**：帮忙、检定成功 / 失败、势力关系、天赋点、结仇、隐患，全部当场可见；每个选项点了都有台词回应，失败也有话说。
- **自由感**：四家可全帮；每种能力任选一条；失败能换路；打听可以跳过——直接偷 / 打 / 买也行，代价是拿不到线索和他的底。
- **NPC 接得住**：全是原版 Hero；对话 / 钩索 / 战斗都是现有系统；玩家不找他说话时他也在过日子，插话有反应。
- **信息塑造目标**：先看到出事，才去搭话；不是一上来就知道「三种能力」；屏幕角上只有一句话目标，不摆任务列表。
