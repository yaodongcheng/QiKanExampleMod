# 剧情对话写作 — 入口

> 🔴 **规则正文只有一份**：`plans/rules/dialogue-design.md`（10 条硬规则 + 标准形状 + 反例库）。本文件只讲"怎么用"。

> **一句话**：一个节点 = **NPC 的一次开口**，最多 2 行；每句话必须**推进**（给信息 / 给态度 / 给任务）；
> 同一件事**只许说一次**；玩家的每个选项都**得有代价或检定**。写不出新东西的话，删掉，不要拿填充句凑。

## 五条硬规格

| # | 规则 | 怎么查 |
|---|---|---|
| 1 | **单节点 ≤2 行**（一个节点是他一次开口，不是一段独白） | `check_story_probe.py` 自动查 |
| 2 | **同一信息只说一次**（名字 / 价码 / 线索在一条链里出现两遍 = 错） | 自动查重复 |
| 3 | **每句必须推进**：换来的必须是"新信息 / 态度变化 / 任务动作"，否则删 | 人工（问：删了这句玩家少知道什么？） |
| 4 | **玩家选项必须有代价或检定**（铁律 12）：给钱 / 掷点 / 关系变化 / 世界后果 | 人工 |
| 5 | **禁止假选项**：`……（听他说下去）`、`继续`、`嗯` 这类不给玩家任何选择的"选项"一律不许用 —— 内容太长就**删内容**，不要加续接 | 自动查 |

## 🔴 最常见的三个错（都是我踩过的）

### ① 重复自报家门

```
intro  ：我姓周，街坊都叫老周。这铺子开了二十三年。
   ↓ 你选"先说说你自己吧"
ask_self：我？姓周，人家都叫老周。        ← 同一句说两遍
```
✅ 正确：**名字只在"说说你自己"里给**；开场只说"这是当铺"。

```
intro   ：买东西？当东西？还是找门路？
intro   ：看你这身土，不像来当东西的。
   ↓ 先说说你自己吧
ask_self：我姓周，街坊都叫老周。
ask_self：这铺子开了二十三年——后十三年，是给别人开的。
```

### ② 机械切行 + 加填充选项

把 4 行的节点切成 2+2，中间塞一句 `……（听他说下去）`。
**错**：玩家没有做任何选择，而且多一次点击。
✅ **对**：重写这段，让它本来就只值 2 行；剩下的信息挪到别的节点或直接删。

### ③ AVG 式旁白

`（他驼着背，正拨着算盘，听见脚步声，抬眼把你从头到脚看了一遍。）`
3D 游戏演不出来的动作**不写**；心理描写**不写**。
✅ 要让人看到"他在拨算盘"，就在 `StoryStage.json` 里摆柜台 + 播动作，而不是写一行字。

## 格式（两条都强制）

```
（说话人，听话人）：文本          ← NPC 与玩家之间
（打手，老周）：钱呢？这月的。     ← NPC 之间
（旁白，玩家）：路让开了。         ← 只用于"结果播报"，不是动作描写
```

英文同构：`(Thug, Old Zhou): The money. This month's.`

## 写一场对话的顺序

1. **先列信息清单**：这场戏玩家必须拿到几件事？（例：妹妹押过镯子 / 码头帮押人 / 铁头贪钱）
2. **一件事 = 一个节点**，每个节点 ≤2 行。信息多的拆成**并列选项**（玩家问哪个就听哪个），不是排队说。
3. **给每个选项配代价或检定**（给钱 / 掷点 / 关系）。
4. **配动作**：每行台词配一个动作（走 `story-line-action` 技能，动作必须在 `as_human_warrior`）。
5. **自查三问**：
   - 这条链里有没有信息说了两遍？
   - 有没有哪个节点删掉之后，玩家什么都没少？（有 → 删）
   - 有没有哪个选项玩家白拿好处？（有 → 加代价）

## 离线检查会抓什么

- 单节点台词 **>2 行**
- **假选项**（`……（听他说下去）` / `继续` / `嗯` 这类）
- 同一条对话链里**同一 NPC 的同一句关键信息出现两次**（名字/价码重复）
- 台词格式不是 `（说话人，听话人）：…`
- 台词引用了不存在的动作 / 台词键 / 物品

## 一条判断标准

**把这条链读一遍，像不像两个人在办事？**
如果读起来像"NPC 在念人物卡、玩家在背提问清单" —— 重写。
KCD2 的标准是：**每句话都是这个人此刻非说不可的**。
